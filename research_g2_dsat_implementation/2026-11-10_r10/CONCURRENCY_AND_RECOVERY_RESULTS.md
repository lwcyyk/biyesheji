# 并发与恢复的实际证据

十项并发和十四位置均通过。每个worker由Popen创建并持有句柄，记录PID、创建时点、唯一目录token、命令、准备快照、握手、退出码和输出。两个worker同时存活，各持有独立SQLite连接；二者读完同一基准后才由父进程释放操作顺序。

| 并发 | 测试 | 观测 |
|---|---|---|
| C1同基准 | T006 | P1提交到新世界；P2拒绝，保留新O |
| C2撤回次序 | T007 | 两种顺序均实际执行，原历史/责任保留 |
| C3迟到 | T008 | 原来源新增close:c2，旧提案CAS拒绝 |
| C4第三批准 | T009 | 合成frontier进入O，旧提案拒绝 |
| C5外部异步 | T010 | 外部模型变动不修改本地a/o；历史可归档，原生资格保持缺口 |
| C6独立O | T011 | O/依赖与a/o同变，旧提交拒绝；刻意漏o的坏状态恢复拒绝 |
| C7权限/过期 | T012 | 当前管理写权撤回后拒绝新写；历史读权单独检查；过期current-required拒绝 |
| C8失败ID异体 | T013 | 原拒绝回放稳定，异体冲突 |
| C9最后检查后过期 | T014 | COMMIT前握手与另一worker外部时钟模型交错；仅输入时点历史，无持续当前性承诺 |
| C10异owner | T015 | 不披露他人回执；满256簿后本人已知ID重放继续成功 |

外部AS和时钟只使用合成模型，未发起真实API。真实Casdoor的变化可观测性、阻断语义与原子frame仍归S3-B。

## 十四位置

| 位置 | 测试 | 实际结果与证据等级 |
|---|---|---|
| K01–K06 | T024–T029 | 实际终止新worker，四表保持；阶段为冻结读/取证子集/S1输出/未交付S2输出/proof/checker记录的交接模型。S1/S2和真实取证未重跑 |
| K07 | T030 | BEGIN前终止，原四表保持 |
| K08 | T031 | 三个真实SQL边界kill；重开后对象/世界/事件/提案均回滚 |
| K09 | T032 | COMMIT成功且in_transaction=false握手后kill；全部接受字段、回执与work恢复 |
| K10 | T033 | 恢复后同ID/体回放原receipt，无新效果 |
| K11 | T034 | 恢复后异体冲突，原绑定保持 |
| K12 | T035 | 历史可读；新当前资格在逻辑时钟101时重新核对并拒绝 |
| K13 | T036 | 重开后合成迟到，原origin/责任保留，旧提案拒绝 |
| K14 | T037 | 重开后撤回事务与旧提案实际进程交错；旧授权未复活 |

最终运行共16次owned worker强制终止，含K8三个边界及重复恢复场景。所有终止通过本轮Popen对象持有的句柄完成；原生Controller/Provider及其他用户进程均在范围之外。

最终运行创建71个专用库。7个刻意破坏的header/实例/codec/O/初始化或摘要实例按预期拒绝恢复，其余状态/引用按测试断言核对。另有未知现存文件在连接前拒绝，文件字节保持。

这组证据覆盖可信SQLite/文件系统上的进程突然退出。断电、外部整体回滚、恶意主机、多主分叉和最终业务效果关闭仍需单独证据。
