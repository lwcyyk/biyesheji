# 有界异常与来源证据

已实现接受值的源级边界，并保留原完整异常证据的未结责任。`R35_EVIDENCE_FIELD_BOUNDS.json`逐字段记录来源、生产者、目的文件、原/新语义和源码定位。

| 内容 | 强制边界 |
|---|---:|
| 通用JSON字符串，含引号/转义 | 8192 B |
| 模块路径/元数据字符串 | 2048 B |
| 模块名/类型/函数/帧模块 | 256 B |
| loader标签 | 512 B |
| 模块清单 / 来源快照 | 512 / 8 |
| 原生异常参数JSON | 2048 B |
| 有条件渲染的builtin消息 | 4096 B |
| traceback帧路径 / 帧数 | 1024 B / 8 |
| 异常链链接数 / 源摘录 | 3 / 0 B |
| 完整诊断描述对象 | 16384 B |
| 单份case详情 / 数量 | 65536 B / 68 |
| 框架失败记录 | 192 |
| 进入codec的单份原JSON | 1048576 B |
| codec结果 / base64数据 | 1114112 / 1485484 B |

这里的“完整诊断描述对象”表示描述对象自身序列化完整；原异常全文的 FULL_EXCEPTION_TEXT_PRESERVED 保持false。描述对象溢出时保存固定不完整标记。未知原全文长度与摘要均为UNKNOWN，未宣称处理过未遍历内容。

## 序列化证明

`json_size`仅接受精确内建容器/基本类型，深度16、每容器4096项、节点131072、整数128位，浮点有限。每个字符串在 canonical 之前逐字符计其 ensure_ascii 转义字节：普通可打印ASCII为1，短转义为2，其他BMP为6，非BMP为12，另加两引号；数组/字典显式加结构、分隔与冒号。随后实际canonical长度须等于计算值。无缩进，sort_keys=True，分隔符comma/colon，UTF8，allow_nan=False。LF仅在外层文件/记录加1。

对260个惰性字符样本完成独立JSON算术核对，包含控制字符、DEL、中文、非BMP和代理字符；未运行Runner函数。源级一般公式与这些样本分开管理。无损zlib/base64仍使用原codec，对输入形状和输出字节均有限制，未来压缩率未作假设。

## 异常记录

通用 repr/str 和完整 traceback 格式器已移除。通过 BaseException/OSError 内建描述符取得参数、errno/winerror、文件名和链；类型字段直接读type描述符。仅精确白名单内建异常类型且参数与OS属性已通过有界基本值检查时调用其原生格式器。自定义异常格式器保持UNRENDERED。已有帧只读code/全局模块名与行号，源摘录0，无额外源读取。链与帧超限均显式标记，原始总量无法确认时为UNKNOWN。

所有描述对象触发 EVIDENCE_CONTRACT_UNSATISFIED / evidence_complete=false，完整合同接受保持false。受限材料属于失败取证，仍待用户审定其是否可替代失败路径的完整原文义务；本轮没有据此宣布原完整容量合同通过。对可渲染的短消息，记录提供实际取得的内容；它不能恢复被省略的异常链/帧/原始格式。

## 来源清单

清单数量在复制前检查，遍历时再次设限，键名在排序前检查长度；超额触发 MODULE_ORIGIN_AUDIT_INCOMPLETE。可审计域外模块只显示名称，延续原作用域。必需对象超额/元数据未知会拒绝，省略对象从未自动获得可信分类。元数据字段以完整原字符串匹配原pin；没有前缀路径参与可信判断。

来源文件、spec、loader、SHA、模块对象身份、Rust父对象/子属性、utils包装类型的验证核心沿用原函数；静态AST比较为相同。CFFI/Rust当前二进制已发生入场漂移，其旧pin继续拒绝当前冲突，来源冲突保持失败。
