# 全局2MiB证明与第48项裁决

预算S(t)使用瞬时逻辑文件总字节，覆盖失败前缀和部分文件；累计请求I/O、重试刷盘量、实际磁盘簇和RAM分别管理。代码只对新目标独占创建，既有文件不会被覆盖以释放额度。历史只读R14—R33资料位于固定运行目录之外。

在受信独占写入、无未记账缓冲、所有前次flush正确计入的条件下，每个文件≤cap，合计2,000,167字节，裕量96,985。调用槽681字节的源级界进一步将正常完成存储上界降至1,992,656，裕量104,496。这里把全部13项相加，使用所有共存的保守上界，未假定高消耗路径互斥。

| 可由代码确定的阶段子集 | 条件性已存上界 |
|---|---:|
| admission_refused | 8192 |
| slot_or_initial_sink_setup_failure | 8873 |
| preflight_raises_before_RUN_START | 1909417 |
| test_failure_before_D24 | 1991337 |
| timeout_while_tests_active_before_core_emission | 1271760 |
| commit_or_post_commit_observer_loss | 1992656 |

这些数值证明的是对应条件下的已存文件空间。完整必需内容能够进入这些份额的结论仍然缺失；用拒绝超额的guard作为负载尺寸证明会循环依赖。

全I/O异常峰值还需要处理日志缓冲。若P_k表示某日志流可在失败/重入后再落盘的未记账字节，则条件上界为1,992,656+ΣP_k。源码没有给出预算相关的P_k界；默认缓冲的真实平台行为与冻结调用路径不能被默认为0。磁盘证据临时副本0已经证明，全故障总峰值的证明仍为UNKNOWN。

R33的47项版本、AST、字段留存和分区算术事实继续复用。其第48项完整负载/异常路径容量条件继续未通过。新证书给出了13个对象、1项明确源级681字节证明、4项条件证书和8项接口无界证书；每条都保留了实际冻结执行最大值尚未建立的范围。

`R34_GLOBAL_BUDGET_PROVED=false`、`R34_CAPACITY_CERTIFICATE_PROVED=false`、`R34_STATIC_PREFLIGHT_BLOCKED=true`。正常成功flush的存储上界及零临时副本保持各自有效范围，完整字段/全异常容量与终态可用性各有待补条件。R33源码、预算定义、SOURCE_LOCK和禁用命令均保持原字节。
