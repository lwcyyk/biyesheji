# 损失、有限采样及资源复核

本文件保留算法、理想游戏及 DDH* 假设，区分精确等式、保守上界与需额外指定的失败包装器。当前为同会话审计，独立阶段未执行。

## 1. 理想优势与非零条件化

SELECT 令 F=L(L−1)/2。受限子概率测度相等及望远镜和给出

    Adv_SELECT^ideal=F·Adv_DDH*(D_ideal).

ALL 的事件为最终挑战代次 c=i，M=L−1。原有历史腐化使某个猜测不能回答时，该前缀没有“有效且c=i”的续接。相同评分分解给

    Adv_ALL^ideal=M·Adv_DDH*(D_ideal).

固定切点前轮因子1、ALL的M、SELECT的F是三个不同范围。普通完整带查询次数没有另一个优势乘数；它影响模拟时间、返回长度和采样失败上界。

标准 DDH 的 X=g^x、x←F_q；归约在 X=1 时输出独立公平币，其余调用 DDH* 判定器。两输入分布均满足 Pr[X≠1]=τ=1−1/q，条件分布正好是 DDH*。所以输出概率差**精确**缩放 τ。原 `F/τ` 系数通过，无需附加一个猜测非零指数的损失。

## 2. 截断耦合及原公式

取每个标量/有限索引采样至多 B 次独立固定宽词试验。F_q、F_q* 的接受概率至少1/2；三角索引也可从 F 个位置均匀拒绝采样，接受概率至少1/2。F=1 时可直接确定。

若整个执行有至多 N_A、N_D 次试验型采样调用，真实游戏与判定器的“至少一次超过B”概率分别≤ε_A=N_A2^(−B)、ε_D=N_D2^(−B)。这包括隐藏的私有官方更新；不能因为其密文未公开就漏计真实算法消耗。

一般有界失败处理只保证：游戏成功率变化≤ε_A；DDH两世界的输出概率各变化≤ε_D，因此两世界差变化≤2ε_D。由三角不等式

    Adv_G^cap ≤ F·Adv_DDH*(D_cap)+2F ε_D+ε_A
               = F/τ·Adv_DDH(D_cap')+2F ε_D+ε_A.

取共同 N 上界，得到原式

    Adv_G^cap ≤ F/(1−1/q)·Adv_DDH(D_cap')+(2F+1)N2^(−B).

**裁决：原优势主公式是有效的保守界，系数无需强制修改。** ALL 将 F 换为 M 即可。采样误差在 DDH* 模拟的条件空间中先界定，再作精确 τ 换算，误差项不需要再额外乘 1/τ。

## 3. 可改进常数的条件

若另行明确采用 cap 包装器：**任何采样失败时游戏最终猜测与判定器输出均立即改为独立公平币**，则一次世界的输出概率相对理想续接变化至多 ε/2。游戏 bias 变化≤ε_A/2，判定器两世界差变化≤ε_D。

于是可以写

    Adv_G^{cap,fair} ≤ F/τ·Adv_DDH(D_cap')+F ε_D+ε_A/2
                     ≤ F/τ·Adv_DDH(D_cap')+(F+1/2)N2^(−B).

它是更具体失败包装器下的改进；不将未注明失败行为的旧 cap 版本悄然替换为此版本。原理想算法/游戏保持不变。原 conservative 公式对这个特例当然也成立。

## 4. N 的逐项计数

Q 包含全部 oracle 查询，epoch≤L，L≥2。公开计数/句柄使用确定性计数器；群元素以 g 的均匀标量幂采样。

| 类型 | 次数上界 |
|---|---|
| 正常 Enc/Upd | Enc每次2e，Upd到e代每次3e−1；合计≤(3L−1)Q |
| 完整 Gen/Next 轨迹 | Σ_{e=1}^L e=L(L+1)/2；模拟锚少一次，不增加 |
| 真实游戏官方链（含未公开私有更新） | ≤Σ_{e=2}^L(3e−1)=(3L²+L−4)/2 |
| SELECT判定器独立混合流 | ≤Σ_{e=2}^L(2e+1)=L²+2L−3；替换锚不增加 |
| ALL判定器 | 同真实链上界；起始新鲜化不增加 |
| 猜测、隐藏位、最终公平币 | 共同放宽为3次；重复同代Get只读缓存 |

边界采完整 Y 替代该步倍率采样，两者同维度；不能把它们误计为先采倍率再额外采整个 Y。由表取共同精细上界

    N_ref=(3L−1)Q+2L²+L+1.

它覆盖实际游戏、ALL和SELECT模拟（SELECT的独立流更少）。因此旧 `N=10(QL+L²+1)` 在 L≥2、Q≥0 时充分宽松。修补的是计数论证，N本身不需要加大。

## 5. 时间、空间与位带

令 ell_q=ceil(log2 q)，ell_F=ceil(log2 max(F,1))，w=max(1,ell_q,ell_F)。每条截断带≤B个相应宽度词，全部采样输出长度≤N B w。隐藏Key/Next带不输出；这是含这些带的安全上界。

群/域运算数量 O(QL+L²)。闭包用数组同时扫描三类规则，最多 O(L) 次增加和 O(L) 长度扫描，可实现每查询 O(L²)（旧 O(L³) 也是保守上界）。可写

    t_A+O((QL+L²)(T_exp+T_field)+(Q+1)L²+NBw).

返回数据另含密文/公钥 O((QL+L²)ell_G) 和 id/元数据 O(Q log(QL+2))。当 L,Q为κ的固定多项式且 logq≥κ 时，索引词和元数据被旧渐近上界吸收；有限精确口径仍应列出 logF/logQ。

模拟器只需保存正常对象的接受值表示、消息、密文和来源，连同历史钥匙/public-key缓存，共 O(QL+L²) 个域/群对象。攻击者自己的已收位带计入其空间；若审计器另保存逐字节完整转录，再加 NBw及元数据长度。原“对象数”空间界不应被写成无B的完整转录字节界。

## 6. 总体裁决

三角因子、非零因子和主误差系数通过内部复核。需要在论文中补上失败策略、采样调用计数、索引字长和对象数/转录字节的区别。没有发现要求增加 F、Q 优势乘数或改变算法/假设的反例。
