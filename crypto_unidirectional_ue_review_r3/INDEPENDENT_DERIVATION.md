**以下是当前模型、同一会话、知情重建。** 它支持内部数学复核，不构成独立外审、同模型隔离复核或跨模型验证。新 Python 进程只运行确定性数学检查，也没有充当独立密码学研究者。

## 1. 普通父表示与逐点桥接

对每个正常登记 id 保存 `(epoch,C,M,{ρ_i,w_i},parent_id)`。Enc 由自采完整带得到 ρ_i 和 w_i；旧父记录保持不可变。对新 η=(a_i,s_i,z_i)，令 v_i=g^{z_i}，得到

    u_i'=(P_{e,i}^{ρ_i})^{δ_i}P_{e+1,i}^{a_i+s_i}
         =P_{e+1,i}^{ρ_i+a_i+s_i},
    v_i'=g^{ρ_i+a_i+s_i}w_i v_i.

新坐标按实际算法加密，Z'=Z∏v_i。将 `ρ_i'=ρ_i+a_i+s_i mod q, w_i'=w_i v_i` 和新坐标表示存入新 id，证明由正常查询次数归纳。接口只允许诚实正常 id，所以表示总可取得；明文 M 是 oracle 已登记的消息，无需解密未知钥匙。

同父两次更新读取同一旧表示，独立采带；两条子记录保持独立来源。若字节碰撞发生，在同一非零公钥下 u 唯一决定 ρ 模 q，v 再决定 w，因此诚实表示不会冲突；不同采样位前缀仍按各自实际调用保留。

关系对隐含倍率的每个合法数值和每条真实 η 都成立。后续暴露完整 K_t 只是进一步读取同一钥匙轨迹，不能改变已经成立的重放等式。没有把 token 输入混入普通带，也没有补造未知 Gen/Next 带。

## 2. 挑战流的联合新鲜化

在理想采样中固定完整钥匙/token 轨迹 θ。对任意诚实父，旧坐标的新指数 `ρ_i+a_i+s_i` 在 F_q 上均匀；新 pad `w_i v_i` 在 G 上均匀，二者独立。新最后坐标独立采样。故更新核等于目标键的 Enc(M) 核，且不依赖父的具体表示。

逐次替换真实隐藏挑战更新核，得到各代独立新鲜流。必须在真实链上完成这一步，之后才定义 real/random 流混合。不能把一个已经随机化的父继续称为加密同一 M_b。

同代第一次公开缓存该值，重复 Get 返回同一个值。未公开内部值没有其它公共使用路径；惰性生成仅推迟群值，保留计数与句柄规则。公开 token 上的本地更新是已有公开历史的任意计算，普通 oracle/完整带是同一 θ 上的相同转移核；后来选取何种钥匙响应也由相同 θ 和查询决定。这是交互过程的联合等价，不能再对最终自适应事件条件化后声称样本仍独立。

## 3. 完整未来钥匙

在隐藏边界 t=r+1，固定旧非零向量 X_r，先采完整独立非零向量 Y_t，再隐含定义 δ_{t,i}=Y_{t,i}/X_{r,i}。对每个固定旧向量，δ↔Y 是双射，因此与真实 Next 的联合分布相同。

模拟器在首次公开 P_t 以前就选定 Y_t；P_t=(g^{Y_{t,i}}) 随后不变。锚坐标的 δ 数值未知，但正常更新按第1节逐点计算；其它倍率可数值计算。以后完整 K_h 从 Y_t 正常演进，返回全部标量，所有公开 P 和 token/历史带关系同时成立。

需要的前提均属于冻结游戏：未来 P 不提前公开承诺；Gen/Next 带隐藏；正常 id 不可任意导入；普通随机带相互独立。公开编码已经唯一确定未知倍率，但没有将其作为已知标量交付。完整归约要覆盖攻击者对这些编码的所有实际运算。
