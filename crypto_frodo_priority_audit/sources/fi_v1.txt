                                               Abstract. In this paper we construct a new efficient updatable encryption (UE) scheme based on
                                               FrodoPKE learning with errors key encapsulation [1]. We analyse the security of the proposed
                                               scheme in the backward-leak uni-directional setting within the rand-ind-eu-cpa model. Since the
                                               underlying computationally hard problem here is LWE, the scheme is secure against both classical
                                               and quantum attacks.


                                               Keywords: Updatable Encryption; Unidirectional Key Update; Lattices; LWE problem.



                                        1. Introduction
                                        Updatable encryption (UE) allows a third party to periodically rotate encryption keys from one epoch
                                        to another without the need to download, decrypt, re-encrypt and upload already encrypted data by
                                        a client. Updating those outsourced ciphertexts is carried out via the use of so-called update tokens
                                        which in turn are generated during key rotation and can be sent (publicly) to the third party.
                                            In this paper we construct a new efficient UE scheme and consider its security in rand-ind-eu-cpa
                                        model. Since the underlying computationally hard problem here is LWE, the scheme is secure against
                                        both classical and quantum attacks. In addition, we analyse the existing security requirement and
                                        provide the new one that turns out to be strictly stronger than its more general counterpart.

2.1. Lattices
In this subsection we define lattices and present some of their basic properties. An excellent and
comprehensive introduction to this theory can be found in [8].

    Any discrete additive subgroup L of Rm is called an m-dimensional lattice, i.e. L is a lattice iff
the following conditions hold:

    1. 0 ∈ L, and if v, w ∈ L then −v, v + w ∈ L;

    2. there is ε > 0 such that for every v ∈ L we have L ∩ {w | kv − wk < ε} = {v}.

    Because a lattice L is is an additive subgroup of Rm , it induces the quotient group Rm / L of
cosets

                                  x + L = {x + v | v ∈ L}, x ∈ Rm ,

with respect to the addition operation (x + L) + (y + L) = (x + y) + L.
    It turns out that lattices have clearer representation, namely for a lattice L there is a set B consist-
ing of linearly independent vectors B = {b1 , . . . , bk } such that any lattice point is a integer linear
combinations of vectors form B.

Definition 2.2. Given a basis B of an m-dimensional lattice L = L(B) of the rank k, the goal of the

5. Implementations
This section provides a detailed analysis of the execution times for different parts of the updatable
encryption scheme based on FrodoPKE variants, including AES and SHAKE versions for various
security levels (i.e. NIST level 1, level 3, and level 5). The results include average times and standard
deviations for key generation, encryption, decryption, token generation, and update operations.
We made the implementation of an updatable encryption scheme based on FrodoPKE in Python pro-
gramming language utilizing NumPy library. As the core of our implementation, we used the ref-
erence one of FrodoPKE. It should be noticed that although Python is not be considered as a high-
performance language, the primary goal of this implementation is to compare the execution time of
the individual components of an updatable encryption scheme based on FrodoPKE. Despite Python’s
slower execution time, it still remains a popular choice for this tasks since its simplicity and the ac-
cess to a number of libraries. A library that can be indicated here is NumPy, which provides a lot of
powerful tools for numerical computations.
We conducted 100 series of tests in terms of the execution times, so as to analyze the relationships
between algorithm parts depending on algorithm variants and random messages. Out of the examined
factors, decryption times are consistently low and have minimal standard deviations. Due to multi-
plications of many large matrices, the most computationally complex part of the algorithm is token
generation and its computation time increases significantly with the type of FrodoPKE. These results
highlight the trade-offs between security levels and performance, with higher security levels leading
to increased computation times, especially in token generation and overall execution time.
