# 服务语义、获取状态与有界正确性

## 1. 源模型与固定 B

源 schema 为 `auth-lifecycle-a/1`。每个 `worlds[w]` 是一个符合固定 B schema 的可能服务契约。假设类、价格表、允许接口和故障结果在输入中公开；哪一个世界当前为真不提供给运行者。

本轮支持最多 4 个任务、8 个语义世界、6 条 B 路径、4 类 probe、4 类 cleanup，整体 H≤8。B 的原任务上限没有改动；A/AB 首版采取更小联合域。这是输入上限，不是已穷尽范围。

每个世界必须共享同一任务、路径目录、停止/保留场景、授权接口、批准包、预算和价格表。允许变化的包括原生范围、撤销效果域/覆盖语义、环境控制语义。所有方法收到同一源 JSON 与同一编译动作表。没有给候选增加原生授权或管理员信息。

共享预算 `requests, approvals` 从核验开始贯穿 configure、stop 和 cleanup。configure 计入 B 的所有 issue/create/delegate 操作费用；失败或响应丢失的已发动作同样计费，不退还预算。批准的成员资格与新增批准计费独立核对。无 reset、补批准或免费重试动作。

服务模型是一类**已登记有限假设**，不是对任意未知网站自动学习完整状态机。字段 `verified/evidence` 继承 B 的可信契约前提，不能据此声称真实服务已经核实。

B 反馈中的每次单世界调用都是“若该候选契约为真”的条件诊断；给它满足 B schema 的假设，并不等于已向运行者证明该世界为真。实际动作仍须对整个 K 通过 W 检查，契约证据也只取所有存活假设的共同结论。

## 2. 具体状态和真实效果

L0 具体状态包含：语义世界 w、已安装配置 C 或未配置、已生效的停止动作集合、会话句柄槽、当前批准集合、剩余共享预算、各动作尝试次数、B 停止步数和语义 epoch。

这里的“真实状态”指独立合成执行器持有的具体 L0 分支，不是网站服务器。控制器只取得可能状态集合和可见 observation；评分器单独持有实际分支，用于核对生效、费用和终态。

| 动作 | 明确建模的效果 |
|---|---|
| probe | 请求/批准消耗、指定观察、可能新建会话、撤回批准、配置前切换已登记语义世界并递增 epoch |
| configure | 原子执行固定 B setup；按真实原生语义建立支持关系，计入全部 setup 操作费用 |
| stop | 关闭任务门控/环境或原生撤销；结果可成功、未生效、丢响应；观察和是否生效分别登记 |
| cleanup | 按已知句柄或已获准账户根清理指定会话类型；可生效但丢响应，允许登记的幂等重试 |

每次核验创建的会话使用独立的“类型#探针#尝试次数”槽，防止重复核验把多个义务合成一个。`opaque:*` 表示不知道可直接寻址的句柄，模型拒绝用 known_handle 清理它；只有声明覆盖该类型且已获准的 account_root 清理可以结清。代码没有发明真实平台的 root 清理能力。

probe 有 before/after/both 阶段、调用方、scope 描述和逐世界/逐尝试的结果集合。调用方与批准是硬前置条件；scope 是注册接口契约的资源描述，不是由字符串自动证明的服务授权。`active:false`、`UNKNOWN`、`LOST` 的含义由完整后继关系决定，不会直接变成“撤销成功”。

probe 日程最多三次，耗尽后接口在该输入中不可用。stop/cleanup 故障日程的最后一组结果可重复；若它包含永久失败分支，就可能没有任何有限保证。一次故障后保证成功的日程仅表示该合成故障类，不能外推为网络重试一定成功。

本版不允许配置后静默迁移到另一 B 契约：那需要已安装授权状态的迁移证明。配置前可观察漂移被纳入 Post，epoch 更新使旧证据失效。无法观察到且不属于已声明类的漂移不受保证。

## 3. 非空 K 与保守更新

知识状态为 `(K,r,boundary)`，K 是非空的可能 `(world,node)` 对集合，节点中同时包含外部状态、批准、预算和义务。不是只保留语义标签。

对合法动作 a 和已登记观察 o：

`Post(K,a,o) = ⋃ { targets(s,a,o) : s∈K }`。

将同一个可见观察对应的**全部**具体后继合并。不能在观察后读取真实世界选择分支。已知 `LOST` 可能对应“生效/未生效”或“新会话/无新会话”，必须一起保留。

若观察没有任何已登记解释，`evidence.update` 保留全部已建模后继作为诊断上下文，并设置 `out_of_model_observation` 围栏；此时证据为空、状态为 UNKNOWN、禁止继续依据该集合派发。保留的 K 不声称穷尽模型外真实状态；外围 boundary 表示该覆盖保证已失效。初始 K 为空直接返回 UNKNOWN，不以空集合全称命题放行。

在混合信念中，一个具体分支已经完成不代表整个 K 完成。因此编译器不能提前删掉单个已完成节点的幂等动作；停止/清理响应丢失的混合分支测试覆盖了这一问题。

## 4. W_r、安全和终态

继承 v2.16 的有限语义：W_0 只含非空 K 中所有状态均满足任务停止/保留目标、安全条件且严格义务为空的状态。

`W_(r+1) = W_0 ∪ { K : ∃a. Pre(K,a) ∧ ∀o, Post(K,a,o)∈W_r }`。

Pre 包括服务接口存在、调用方、账户/原生范围、每项批准、共享预算和非空后继。原生停止若损坏保留任务，具体转换仍作为不安全后继记录，W 不接纳该动作；不会将不利效果从模型中删掉。

每个允许动作消耗一个整体决策步。B 内部的停止步上限也独立遵守。H 不是墙钟时间；configure 宏的一步可能包含多个计费请求。本轮没有网络超时或墙钟终止定理。

A1、B-A、AB1/B-AB 使用相同 W 缓存。键包含完整 K 和 r，节点哈希包含批准、预算、会话、尝试次数和 epoch；不是仅按语义标签缓存。因此不能以过期批准或较宽旧预算重复使用安全结论。

## 5. 契约证据

`evidence.contract` 只声明全部存活假设共同蕴含的性质。范围包含 account、caller、source digest、完整 belief、epoch 集合与剩余步数，并附观察历史摘要。

`/credentials/*/scope_for_task_permissions` 是**派生谓词**，表示原生 scope 与登记任务所需权限的交集，不能读作完整原生 scope。未用权限不会成为学习目标；这同时用于 A1、B-A 和关闭反馈版本。

以下变化使旧记录不能原样复用：模型/接口或调用方改变、epoch 改变、批准撤回、预算/状态改变，以及模型外观察。当前实现采用保守的完整上下文失效，尚未实现逐性质依赖最小化或持久化跨会话证据复用。

## 6. 条件性论证与边界

条件命题：若源有限类覆盖真实执行、登记观察和原生效果正确、批准/预算可信、配置宏可靠，且源编译审计和独立策略检查均通过，则每个被执行动作的全部登记后继进入 W_(r−1)，最终在 H 内满足停止/保留并结清严格义务。

论证顺序：独立源解释器逐状态、动作和结果核对编译映射；对 r 归纳，通用前置条件建立每步合法性，Post 联合保持覆盖，W 递减保证有界到达；终态用独立 B 内核和会话账本反映真实 L0 目标。评分器再按实际分支独立重放，不能用候选的成功标签替代效果证据。

这是条件性论证草图和逐实例有限检查，没有机器证明 Python 实现一般正确，也没有证明真实 OAuth/浏览器满足抽象。遗漏一个 probe 副作用、漏列 bearer 路径、错误声明撤销覆盖或错误声明原子 setup，都可能使两套有限求解器在错误模型上一致。模型外围栏只能处理已观察到的不相容结果，不能自动发现不可观察的模型遗漏。
