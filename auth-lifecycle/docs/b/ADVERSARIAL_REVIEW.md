# 反方审查

## Material Passport

范围：本地 B 开发增量、v2.15 指定章节、v2.16 基线及当前原始测试。性质：同一研究工程代理进行的反方检查，不是独立同行评审、跨模型审查或外部查新。方法：检查算法边界、构造负例、运行分离参考与证书检查、固定种子结构生成。正式 H-B：NOT_RUN。

## 负控制与等效性

当输入的所有路径都在同一受控 broker 下时，B-B 的 shared_broker 规则包含完整配置空间。它与 B 使用同一停止 planner、checker 和固定目标，因此在两者都穷尽完成时，**在该 profile 内两者的最优 G/字典序配置等效**；计算实现可能不同。这不是观察到“未显著”后作出的统计等效推断，而是候选集合相同的直接结论。

本地停止负控制 G=1；四任务静态签名最优负控制 G=2；384 参数组合中 84 个可行输入 B、B-B 与参考相同，300 个不可行输入 B/参考一致。不能将这组例子宣称为 B 相对简单组合的资源收益。

96 个固定种子结构输入中，60 个不可行，34 个两方法可行且 G 相同，另有 2 个 B/参考可行但 B-B 没有规则内合法方案。这不是完成率的统计估计，更不是 H-B 判定。原始输入全部保留，不能只报告这两个例子。

## 两个组合遗漏反例的解释

`structural-20261102-034`：可行配置为 a0,b1,c1，G=2。b0 只依赖 x，x 的已知撤销仅禁刷新，无法实现 b 的远端停止；b1 依赖 x AND z，撤 z 可切断 b 并保留 c 的 x 支持。权限贪心偏好新增权限更少的 b0；路径分属 broker/isolated，不满足单 broker；不同任务共享 x，不满足全独立；b 的双域支持不满足单域静态签名规则。

`structural-20261102-084`：可行配置为 a1,b0,c0，G=2。a1 的 x AND z 支持允许撤 z 停 a 保留依赖 x 的 b；权限贪心偏好同用 x 的 a0,b0,c1，导致选择性远端停止冲突。环境混合、原生域共享及双域支持也使其他三条结构规则不适用。

反方结论：这显示了该固定简单规则组合对 AND 支持、混合环境的覆盖缺口。B 的方法是完整枚举，并未据此产生新的优化原理。一个带回退的简单配置枚举也可能补齐这两个实例；下一阶段应加入这类更强组合并冻结规则后重新评价。**不得为了保留收益改变 G，也不应把基线未覆盖实例直接包装为独立机制创新。**
