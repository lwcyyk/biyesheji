# 有界正确性语义与 H-S 条件性论证

## 1 对象与可信输入

输入是有限、显式声明的认证转移表 `M`。`world` 表示候选服务语义及原生授权根；每个世界的节点 `s` 包含账户、事实、可用批准原子、各资源预算、访问能力及严格处置义务。边可以跨世界，表示**已被模型覆盖**的外部语义变化。

信息状态为 `z=(K,r,boundary)`，`K ⊆ {(m,s)}`，`r` 是剩余决策步数。K 同时表示服务语义和外部状态的不确定性；可从历史观察推出的知识由这个可能集合表示。预算和义务属于每个可能节点，不假设响应丢失后两种可能状态的预算/能力相同。

K 不是概率分布，也不是隐藏真实世界的单值标签。一次动作只有在所有仍可能节点中均获准时才可使用。求解器可以看到整个声明假设库，但不能看到适配器当前真实节点；其策略只按可见观察分支。

批准原子与动作的对应、原生根语义及转移覆盖由输入规约提供，不由本系统从网站发现，也没有用密码学签名验证其来源。模型摘要只绑定内容，不认证来源。批准原子的发行和登记、真实设备身份及模型可信获得仍是外部前提。

## 2 模型完整性规则

`schema.validate` 检查类型、状态引用、任务数 ≤4、H≤8、非负整数预算及效果账本一致性。布尔值不能作为预算或 H。动作包含任务、账户、批准原子、前置事实、成本、需独立的原生 grant 对和具体操作标识。

每条边显式给出观察、目标状态、效果引用，以及 facts/capabilities/obligations 的 add/remove、批准撤回和外部额外预算消耗。目标状态必须与 delta 完全一致。L0 不支持无批准的新批准发行或预算补回；若以后支持，需要扩展规约而不是绕过校验。

`probe` 新建能力 `c` 时必须在目标节点登记 `close:c` 严格义务。非探测动作所产生的持久能力是否需要最终关闭由具体目标规约声明；不能把所有长期保留能力都误判为临时资源。原生根关系来自模型，不从 token 字符串推断。

这些静态检查只防止表内自相矛盾，不能证明表完整覆盖真实网站行为。

原生授权的首版 profile 是 grant 到单一登记 root 的映射；相异 root 的独立性是该 profile 的已审定输入事实，不适用于未经映射的任意 AND/OR 支持图。动作的批准引用也只是有限规约中的授权原子，不是已经完成真实用户签名或执行者身份协议。

## 3 终态与 Pre

`Terminal(K)` 当且仅当：K 非空；每个可能节点均满足安全约束、目标账户及全部目标事实；每个节点的严格义务均为空。带 boundary 的状态不能终止成功。`W_0` 只包含这些状态。

对 `a`，每个 `(m,s)∈K` 都必须满足：

1. 当前状态安全，账户与动作账户一致。
2. 动作需要的批准原子仍存在，前置事实满足。
3. 对每种成本资源，余额足够；原生独立性要求有已登记且不同的根。
4. 在该节点至少有一个对应原生后继。不能用其他世界有后继掩盖某世界没有后继。

令 `T(m,s,a)` 为所有允许结果边。对于可见观察 `o`：

`Post(K,a,o) = ⋃ {(m',s') | (m,s)∈K 且 T 中存在 observation=o 的该边}`。

同一个观察的后继必须取并集。响应丢失、操作已生效与未生效、同观察下的批准撤回、未知句柄均因此保留；不能把目标节点或世界 ID 当成额外观察。

## 4 有界递推

```
W_0 = Terminal
W_(r+1) = Terminal ∪ {
  K | Safe(K) ∧ 存在动作 a 满足所有前置条件，
      Obs(K,a) 非空，且对每个可达观察 o，Post(K,a,o) ∈ W_r
}
```

未到终态时，每个允许动作消耗一个决策步，即使它没有消耗调用预算。r=0 时不能再派发动作。已达终态可以立即停止，不要求终态在服务的无限未来中保持不变。

实现中，候选 `candidate.solve` 用记忆化 AND/OR 递归；`candidate.allowed_actions` 仅列出所有观察分支均在剩余 r−1 步可完成的动作。若任一必要子搜索未完成，完整菜单返回 INCONCLUSIVE。

**stay 反例：** s 有 stay→s 和 finish→done。无秩的 W 规则可无限 stay。新规则允许在 r>1 时先 stay（仍预留完成步），但 r=1 时只允许 finish；只有 stay、没有 finish 时，在所有测试 H 内均 IMPOSSIBLE。不是简单把 stay 从动作字典删除。

H 只限制模型决策步，绝不自动给出墙钟时间上界。网络阻塞和一次原生操作内部的步骤必须由后续适配器契约单列。

`controller.BoundedController.step` 在真实调用本地表适配器之前，使用独立 R-I 检查所有后继的剩余步可完成性，拒绝 r=1 时的 stay。只有实际派发才消费该决策步；搜索未完成或动作被拒不调用适配器。异常或模型外响应消耗已派发步，保留 `pending_action`、派发前信息及所有预测后继，不宣告成功。后续再次调用仍返回 UNKNOWN。这个控制器不是进程隔离边界；绕过它直接调用原始适配器不在保证内。

## 5 模型边界与结果类型

| 状态 | 充要的使用约束 |
|---|---|
| FEASIBLE | 找到完整观察策略；未搜索其他选择不妨碍正证据成立 |
| IMPOSSIBLE | 给定模型与 r 内已覆盖全部动作选择并有完整反证；不是无界无解 |
| INCONCLUSIVE | 搜索或检查资源限额耗尽，所需证明尚不完整 |
| UNKNOWN | 空 K、无效输入、非法状态或已观察到模型外结果；不能转成成功或无解 |

原生观察字符串 `"UNKNOWN"` 或 `"response-lost"` 与求解结果 `Status.UNKNOWN` 不同。前者如果已在模型中声明，会更新到包含全部可能效果的 K，并继续按目标/义务判断；后者是模型边界状态，停止发放完成保证。

`semantics.observe` 遇到未注册观察会生成带 boundary 的不可用空 K；求解器明确拒绝真空真。它不声称能发现所有未出现可见冲突的模型外变化。已声明的外部变化则通过普通边进入后继；不能因其是外部事件而忽略。

## 6 独立 R-I 的定义

R-I 从同一原始 JSON 和同一初始 K 出发，前向展开所有合法动作/可见观察的可达 `(r,K)`，然后按 r 升序自底向上计算可完成性。它不调用候选的搜索、`semantics.branches`、目标判定或 memo。

R-I 使用 `_reference_kernel` 独立解释账户、批准、成本、原生根、每世界非空后继及观察并集。证书检查器也使用这个解释器，而不重新运行候选。共享 schema 是显式可信基础；R-I 与检查器的共享解释器也意味着它们可能有共同缺陷。

R-I 是模型内真值参考，不是能够窥视真实世界再为各世界选择不同动作的全知规划器。其初始判定要求一条统一可观察策略。CLI 的 `--horizon` 是显式、记录在证书 query 中的覆盖参数，仍限制在 0—8；默认使用输入的 horizon。

## 7 条件性命题及论证状态

**命题 T1（规格层有界进度）。** 若 K 属于 W_r，且尚未终止时仅选择所有后继属于 W_(r−1) 的动作，则在有限表覆盖的所有结果分支上，至多 r 次动作后到达 Terminal。

论证：r=0 由 W_0 定义。r>0 时，前置条件保证这一步获准且具有结果；任一观察后继位于 W_(r−1)，应用归纳假设即可。初态与各前缀安全。终态反映严格义务为空。这是已有有界可达性思想的直接实例化，不声称新规划原理。

该命题以驱动器按策略继续执行为条件。驱动器无限不发请求或实际网络永不返回，不能由 r 强迫其在现实时间内完成；模型内等待若作为动作，照常消耗一步。

**命题 T2（两实现的规格等价）。** 对通过 schema 验证的固定有限表，且搜索完整结束时，候选和 R-I 的布尔可完成性应与 W_r 一致。候选按递归定义判断，R-I 在同一可达层次图反向判断，可按 r 归纳。

状态：纸面递推论证已给出；Python 实现与规格的完整精化尚未机器证明。有限穷尽/回归只检验列明输入域，不把一致运行等同一般实现证明。独立参考也可能有错误，不能因名字是 R-I 就视为不出错。

**命题 T3（证书健全性）。** 一个完整反证节点为每个候选动作给出真实前置阻断，或给出至少一个可达的不可完成观察子节点；以 r=0 非终态或初态不安全为叶，可按 r 归纳推出该 K 在该界内无策略。正策略反向量词为“存在动作、全部观察可完成”。

状态：局部检查规约与归纳思路已给出；检查器源代码未作机器证明。哈希防止用不同输入重放，但不证明输入或批准的真实性，也不是签名。

H-S 对真实部署还要求抽象覆盖、操作回译、执行边界完整、批准存储可信及原生提供方契约成立。详见 [ABSTRACTION.md](ABSTRACTION.md)。这些真实平台条件本轮没有证明。

## 8 明确不覆盖的时间和攻击面

每个表动作表示一次原子准入/效果边界；批准在该动作源状态核验。边中的撤回表示对应模型顺序中的后继变化。若真实服务存在“检查后、提交前”竞争，必须拆成带该竞争结果的多个状态/边；本轮不把本地原子表步骤当成网络原子事务。

未实现真实密钥存储、OAuth/浏览器协议、操作系统隔离、真实AI提案、认证语义自动发现或生产状态持久化。未执行 H-A、H-B、H-AB 正式实验。CS03 的完整转录隐私和密码学安全仍独立待证明。
