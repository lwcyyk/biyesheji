# 可检查证书

## 1 两种作用域

`bounded_policy_impossible`：相对证书绑定的输入模型、初始 K 和 horizon，所有获准的可观察策略均无法在该决策界内完成。包括核验动作和所有允许观察结果；不等于任意时限均无解。

`no_common_immediate_completion`：当前不存在一步即可保证完成的共同动作。其证明界为 1，但绑定的查询可有更长 H；检查器报告 `no_common_one_step_completion`，不得被上层误译为 H 步无解。

`examples/adaptive_probe.json` 同时具有合法的一步不可行证书和两步可行策略。核验后的可见结果能区分世界；这个正例防止把“没有当前共同动作”错当“不能补证”。

## 2 三世界与任意有限核心

`examples/three_worlds.json` 精确使用：

```
P1 = {a,b}
P2 = {b,c}
P3 = {a,c}
```

三组都使用同一批准和预算，观察均为 `ok`。任意两世界有共同一步计划，三个世界没有共同计划。检查器不局限于两世界：生成器可以递减初始世界子集，也可保留完整集合。五世界测试中，每个世界禁止不同一个动作，五者共同无解而任意四者有解。

生成器的缩减是可选启发式。证书始终标记 `core_minimality=not_claimed`，不声称基数最小或已证明不可再约简。即使缩减尝试达到限额，已有完整不可行证书仍然可用；没有完整根反证时，不能借此返回 IMPOSSIBLE。

## 3 证书携带的信息

`model_digest` 绑定完整规范化 JSON 输入；`query` 绑定原初始信息与查询 H；`context` 明列初始世界子集、核心 K、证明界、完整声明世界与状态、动作、批准/预算账本、原生根、目标、安全约束及约束类型引用。

上下文包括整个声明宇宙，因为允许边可能跨到另一已登记语义世界；核心子集限制的是初始不确定性，不能删除其后可达的世界。

```
proof node:
  belief: 全部可能 (world,state)
  remaining: 当前剩余步数
  kind:
    unsafe                 存在初态安全约束反例
    horizon                remaining=0 且非终态
    all_actions_fail       对每个注册动作提供以下一种说明
       blocked             真正失败的账户/批准/预算/独立性/非空后继引用
       losing_observation  一条可达观察 + 对完整观察后继集合的子反证
```

阻断引用格式可定位到动作、批准原子、资源和具体世界状态，例如 `approval:cleanup:w/created`、`independence:gA:gB:w/s`、`successors:a:P2/s`。检查器重新解释原始表，不相信证书自己声明的原因。

正策略的量词相反：选择一个获准动作，并为**每一个可达观察**提供下一策略。删掉响应丢失分支、用隐藏世界 ID 替代观察、伪造剩余步数和在有义务时返回 done 都会拒绝。

## 4 独立性与检查结果

`certificates.py` 是不可信生成端，可调用候选求解器。

`checker.py` 不导入或调用 `candidate.py`、`semantics.py` 或 `certificates.py`。它直接检查每个证明节点，使用候选之外的 `_reference_kernel`。测试不仅检查导入关系，也在运行时把候选生成函数替换为抛错函数，证明检查仍可完成。

检查器并非与 R-I 完全独立：两者共享原始表解释器和 schema。独立性不意味着实现没有共同错误；这项限制必须进入 H-S 的证据边界。

检查结果是 ACCEPTED、REJECTED 或 INCONCLUSIVE。资源限额不足导致 INCONCLUSIVE；不能把检查未完成当作接受或证书逻辑错误。ACCEPTED 同时返回明确 `claim`，调用者必须使用该字段的有界作用域。

## 5 篡改测试与绑定限制

已覆盖删除动作、删除观察、编造观察、剩余步数替换、账户/批准/预算快照变更、模型摘要替换、核心世界删空以及伪称最小核心。JSON `false` 与整数 `0` 必须区别：不能使用 Python 的宽松对象相等作为字节/类型绑定。

摘要不是签名。攻击者若能替换受信模型、批准源或整个执行接口，本检查器不能恢复真实授权关系；原始契约及其版本的可信取得仍是外部条件。
