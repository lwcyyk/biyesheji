# A、B、AB 实验协议草案

## Material Passport

依据：v2.15 第 5—8 节，固定 A/B/AB 开发版本和两种新部署的原生认证实现。阶段：能力调查、原生校准预实验、确认性协议准备。所有 H-A/H-B/H-AB 正式状态均为 NOT_TESTED。没有外部预注册，也没有研究者阈值确认。

## 1. 假设登记

| 假设 | 类型 | 成本条件（建议） | 完成条件（建议） |
|---|---|---|---|
| H-A | 主要经验假设 | A1 相对 B-A 的 C_Q 均值比 <0.80 | 合法完成率差 >−0.05 |
| H-B | 主要经验假设 | B 相对 B-B 的 C_G 均值比 <0.80 | 合法完成率差 >−0.05 |
| H-AB | 主要经验假设 | AB1 相对 B-AB 的 C_Q 均值比 <0.85 | 合法完成率差 >−0.05 |
| H-S | 条件正确性 | 不与成本收益合并 | 单列一般证明、有限检查、原生抽象保持和反例 |
| H-M | 次要机制实验 | 义务跟踪×反馈的机制解释 | 不冒充主假设支持 |
| H-D | 可选扩展 | 可观察语义漂移后的处理 | 不把不可观察漂移算作可检测；未进入主检验族 |

上述数值是 v2.15 的**待确认建议**。登记在 `experiments/registry.json`；当前开关 `confirmatory_execution_enabled=false`。正式 CLI 入口亦硬阻断，因为研究者批准、足量独立家族和需要补证的原生映射尚未完成。

## 2. 层级与方法

L0 保留有限模型正确性、R-I/R-J 和证书结果；L1 使用未修改的完整 Keycloak/Casdoor；L2 真实 AI 尚未运行。原生组件、HTTP/资源夹具和自写认证模型分类见 AUDIT.md。

H-A 固定 B，B-A 使用已有性质导向测试选择与共同 W/预算约束。H-B 使用已有四规则 B-B 全合法候选组合及同检查器。H-AB 仅切换具体 B 分歧反馈，关闭版保留任务性质、安全筛选和缓存。算法源代码未因调查结果修改成本目标。

当前原生绑定为 `known-contract-single-path/v1`：可信已知合同、每任务一条选中支持路径、受控 broker、fresh password grant、grant 局部撤销。H-B 校准采用 4 任务，local 或 mixed（t0 远端停、t1 本地停、t2/t3 保留）；A/AB 校准采用 2 任务。它是**无须补证/无反馈收益的必要负控制**，不是完整的 H-A/H-AB 查询需求分布，也不是所有 B 多支持/隔离环境的原生实现。

需要补证、探测产生新材料后继续规划、非原子 setup、中途重绑和真实故障全分支的 L1 抽象保持仍待完成。故障发生时，当前绑定作批准重查、预算阻断或 UNKNOWN 围栏；仅在尚未交付保留任务时尝试获准的账户级恢复，不假称完成剩余联合策略。

## 3. 账户与环境

只使用两个项目内新建数据库、专用 realm/组织和随机生成的 `l1-*` 测试用户。适配器保存本实例创建的用户名/原生 ID 绑定，并拒绝操作未登记 actor。所有认证端点限于固定回环端口；不调用生产账户或公开演示站。

每个配对臂用不同但结构相同的新用户，初始无会话/凭据；方法内部不 reset。配对之间的用户创建、验证状态清理与用户删除属于实验隔离步骤，单独记录。授权包、接口、原生凭据类型、请求上限和批准槽相同。

批准槽是预授权的 grant 发行额度，不是实际人工弹窗次数；本轮人工批准交互为 0。真正 UI/用户批准次数需在后续流程单独测量。

## 4. 配置、目标和故障

原生调查逐项区分 grant 局部/共享根、AT/RT 作用、查询方 active 范围、缓存层、核验新会话/新凭据、不可实现强停止、批准撤回、响应丢失、迟到请求、并发、可观察策略改变及核验后预算耗尽。来源层与实际发现见 CAPABILITIES.md。

配对校准计划固定四类资源策略：发行客户端在线内省、另一客户端内省、资源层内省缓存、离线签名验证。两个目标档、无故障/批准撤回/丢响应、每格两次重复、两个实现、三组方法对：计划 288 对、576 次方法运行，即每方法 96 次。

这不是 v2.15 建议的“144 次/方法”完整网格；没有为凑数制造第三个目标族或独立家族。迟到请求、并发、原生策略漂移和预算耗尽已由独立原生能力调查触发，**尚未声称全部接入 A/AB 的端到端配对控制器**。

故障以语义事件为触发点：批准在最终发送检查前撤回；丢响应在原生返回新凭据后、方法收到前；旧刷新意图在撤销响应后释放；并发用屏障同时放行两个真实请求；策略漂移先确认原生配置 API 更新，再观察结果。未到达触发点必须记为未触发，不能算抵抗成功。

## 5. 统一日志和独立评分

`experiments/log-schema.json` 定义逐事件格式。每个运行保存实现/版本、配置家族/谱系、目标/故障、种子、配对顺序、源码哈希、未提交的 commit=null、授权/预算、环境摘要、计划、实际发送、原生响应、效果、义务和评分。确定性方法的 LLM/model/prompt 不适用，不能伪填。

`Journal` 追加写入、哈希链接并对口令、token、cookie、client_secret 作指纹化。哈希链用于完整性校验，不声称抵抗同权限恶意改写者。真实服务日志和数据库留在私有 `.runtime`，不作为可公开原始数据导出。

独立 witness 使用 JWKS 验证签名、发行者、受众、过期和账户；另用正确作用域的内省/原生会话或 token 记录核对效果。资源 fixture 发出真实 HTTP 决策，远端测试绕过本地 gate，不能把关 gate 当成远端撤销。503/内省失败等 UNKNOWN 不当成拒绝访问的成功证据。

评分器重放授权撤回事件并重算实际请求数、批准额度、原生单位和目标；不采信方法自报的“已批准/已清理”。G 在本 profile 中由经核验的 Keycloak 会话+客户端单位或 Casdoor 原生 OAuth token 记录确定，不能按 token 字符串数量计数；一般刷新链/SSO 共享会话的映射仍需另证。

U=1 仅当任务先被合法建立、目标停止实际成立、保留任务仍可用、严格材料/停止义务结清、无越权/预算违规且方法未超时。记录 E、FA、O_end，并分别列材料义务和未满足的停止目标。未知 HTTP 创建结果保留未决义务，不能因为未收到 token 就认为没有新材料。

## 6. 成本与分母

Q_total 包含方法实际发出的配置、核验、失败、重试、撤销、收尾与恢复请求；原生成功后被隐藏的响应仍计费。合法完成时 C_Q=Q_total，否则 C_Q=Q_cap+1。合法交付时 C_G=G，否则 C_G=G_cap+1。

本轮 Q_cap=64、G_cap=8、批准槽=8，方法超时档为 30 秒。CPU/求解、缓存命中、原生运行时间、观察者查询和实验建户/复位成本分列，不合成风险分数。

独立评分查询和配对隔离不是算法获得的免费信息：结果不回传给选择器，费用另列。用户建户/删除是实验基础设施；方法配置中的 grant 发行计入 Q。方法义务所需恢复计入 Q；保留任务在评分之后被研究设施删除，不回写为方法完成或漏算其此前未决义务。

计划清单在运行前保存。合法完成、拒绝、UNKNOWN、INCONCLUSIVE、超时和基础设施中断均保留。缺失配对臂使用明确标记的分析惩罚占位，不伪造执行日志；不得只保留完成者或反馈活跃者。解析器核验家族/条件标签与原计划、事件评分及请求账本一致。

## 7. 统计计划（待冻结）

以配置家族为主要聚类单位，认证实现分层；每家族先平均其全部预定配对运行，再等权汇总；两个实现拟各权重 1/2。报告的是均值之比，不能替换成个体比值平均或仅成功运行比值。

拟用总体单侧 α=0.05，对 H-A/H-B/H-AB 做 Bonferroni，各 α=0.05/3。每个假设用交并判定，成本上界和完成率下界同时满足；不再将两个分量误分成六个独立主假设。主单侧界为 98.333%，另列双侧 95% 描述。

bootstrap 在实现内对整个配置家族重抽，候选和基线始终成对；当前脚本种子 20261102、10,000 次。四个操作性家族共享一个构造谱系，独立性未获确认，bootstrap 只演示描述性分位数，不具有已验证的名义覆盖。正式若存在跨实现同谱系依赖，还需冻结联合重抽方式或层级模型。

不得把多账户、多种子、参数微调或两个同源部署当成独立家族/独立实现。正式进入前必须提供独立家族清单、谱系审查和功效依据，而不是用一个任意最小簇数阈值自动放行。

## 8. 预实验、功效和分割

能力调查与本轮原生校准均属于独立开发/预实验域，永久排除在正式留出中。调查重复不是新实现或新家族。真实确认性样本须按配置家族和故障模板划分，不能将同源快照/细微变体跨集合泄漏。

先估计分层运行成本、配对差异和家族相关；若配对成本恒等，零方差不表示只需极少样本。当前样本不能可靠估计目标 D_A/D_AB 的效应方差；家族 ICC 亦可能退化。脚本据此输出无可辩护的经验样本量，并给不同真实效应、方差、配对相关和 ICC 假设下的条件敏感性计算。

功效敏感性采用拟议单侧 α 和 0.80 功效，完成率真差暂设 0、非劣界 −0.05；这些是分析假设，不是研究者确认的预期结果。真实成本比在阈值上或更差时，不能靠增大 N 获得所要求的优势功效。正式样本量需在足够独立家族下，用已冻结分析程序进行经校验的功效模拟；本轮正态/设计效应近似不能替代它。

其中 0.80 指联合 IUT 功效目标，敏感性计算保守地给两个分量各 0.90 功效，以分配漏检概率；这不改变 α=0.05/3。成本 SD 指对 log(均值比) 的配对影响量，而不是个体 log 比值。原始成本的 ICC 与配对差分/影响量的 ICC 也不得互换。
