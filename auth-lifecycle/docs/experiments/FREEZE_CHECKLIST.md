## 重要限制

576 次校准运行不等于 576 个独立家族。A/AB 的补证选择在本轮已知契约场景未激活；它们的成本与完成率只能描述该负控制。B-B 在这一共享 broker 子域本就包含强可行组合，不应制造配置收益。

账户级处置并不能让离线验证的已发 JWT 立即失去密码学有效性；丢响应后的这类材料在数据中保留为未决。Casdoor 的本轮根处置还会禁用账户，不能假定之后可直接重新认证。更广的承诺必须重新建模，而不是删除这些失败/未知运行。

正式入口保持关闭。研究者确认只是必要条件；尚未完成的技术映射和家族/功效条件也必须满足，不能仅把一个布尔值改成 true 就称可开展确认性验证。
