# 隐藏线性token作用的提取与合法挑战攻击

ROUND-007，2026-11-07。固定输入锁SHA-256：**b4d9d34ef02cd2217734dcdc2dfc7cca4a191ca91fa212c522f7253117548562**，见 `sources/input_record.json`。知情纸面证明；待独立数学复核。

**裁决：PROVED_IN_STATED_MATRIX_SELECT_MODEL。** 在公开可计算父特征、已知普通更新系数、重复token和有效模表示条件下，普通更新带可暴露隐藏token足够多的作用，从而击中SELECT允许的未来钥匙路径。一般线性求解与模块容量界属于成熟工具。

## 1. 可核验的适用类

固定同一epoch边界的隐藏token包含K∈Z_q^(g×d)、N∈Z_q^(t×d)，q=2^D。普通诚实父C=(u,c)具有公开可算H=f(u)∈Z_q^g。每次普通更新得到可观察

\[
Z=(u',c')-(0,c)=HK+rN.
\tag{Obs}
\]

要求：

1. 同一token用于多个诚实普通父及同父重复更新，父记录保留。
2. 普通完整带可有效解码r∼χ^t，更新调用及坐标独立，χ mod2平衡。Gen/TG带和token仍隐藏。
3. (Obs)没有残余未知逐次加性项，输出保留环运算所需信息。可由公开带解码并扣除的额外项也可处理；其余项需新证明。
4. 训练父来自同一epoch独立诚实Enc，其H条件于固定参数／钥匙与fresh挑战H同律。训练输入和数量预先固定，未按父值筛选。
5. h在训练行模内时，能有效求出系数λ。普通环坐标满足此条件；隐式群表示需另证。
6. 游戏允许隐藏下一token、保留旧挑战、跳过新版本读取，并合法腐化目标更新后钥匙。正确性覆盖对应的一次或两次更新。

不要求N方阵／可逆，不要求H的分布均匀，不要求学习完整K，也不要求LWE伪随机性。

## 2. 两阶段提取

预先取Q≥1个独立诚实普通父，特征H₁,…,H_Q。对父1作s+1次更新，其中s=t+κ，保留基准(Z₀,r₀)。由同父差分

\[
Z_j-Z_0=(r_j-r_0)N
\]

在秩事件G上恢复完整N。G的精确概率a及失败ρ见RANK文件，ρ<2^−κ；该事件与挑战位、父、钥匙及挑战内容独立。若失败，以新独立公平位结束攻击。

G上，用基准观测得到V₁=Z₀−r₀N=H₁K。对其余Q−1个普通父各调用一次UpdLeak，得到V_i=Z_i−r_iN=H_iK。保存

\[
L_Q=\operatorname{span}_{\mathbb Z_q}(H_1,\ldots,H_Q).
\]

任意公开目标h∈L_Q，求λ使λ(H₁;…;H_Q)=h，然后计算hK=λ(V₁;…;V_Q)。这是精确模q作用恢复。g个方向全部可见与否无关；未覆盖方向上的K可能仍无法确定。

## 3. 完整分类规则

选择不同消息M₀、M₁并取得旧挑战C*：b=0为Enc₂(M₀)，b=1为Upd₂(Enc₁(M₁))。训练父在epoch2新Enc。Next到3、隐藏Δ3、跳过Get3，完成上述普通观测，再合法取得完整Key3。

对保存挑战计算h=f(u*)：

* h∉L_Q时，输出1（update）。
* h∈L_Q时，恢复hK，独立按真实χ^t采样r_loc，离线计算

  \[
  C_{loc}=(0,c^*)+hK+r_{loc}N.
  \]

  该值逐字等于真实Upd(Δ3,C*;r_loc)。用Key3本地解密；得到M₀时输出0，其余情况输出1。额外Dec oracle调用数为0。

FI批量实例只需计算和解码第一行：令M₀、M₁在第一行的一个已编码位不同，检查该位即可。其余行没有被伪造成普通oracle输入。

选择r_loc来自真实支持并使用同一分布；学习λ无需短，因为λ仅用于重构hK。它没有替代r_loc或改变更新算法。

## 4. 精确概率账目

令G为差分满秩事件，a=Pr(G)=1−ρ。条件于G定义：

\[
m_0=\Pr_{b=0}[h\notin L_Q\mid G],
\]

\[
e_0=\Pr_{b=0}[h\in L_Q\land\operatorname{Dec}(C_{loc})\ne M_0\mid G],
\]

\[
e_1=\Pr_{b=1}[h\in L_Q\land\operatorname{Dec}(C_{loc})=M_0\mid G].
\]

批量第一行判定时用相应的消息标签／位替换M₀、M₁。两个条件事件中的本地更新币可在全部执行中预采；未落模的分支忽略它。

令p_b=Pr[b'=1|b]。按算法逐支有

\[
p_0=\rho/2+a(m_0+e_0),\qquad
p_1=\rho/2+a(1-e_1),
\]

\[
p_1-p_0=a(1-m_0-e_0-e_1),\quad
\Pr[b'=b]=\tfrac12+\tfrac a2(1-m_0-e_0-e_1).
\tag{Exact}
\]

这条精确式未对update分支的h分布施加同律条件。非成员时默认update正是避免该额外前提的步骤。若非成员改公平猜测，两分支都要分别记遗漏量，原保证随之改变。

由Module引理，m₀≤ε_mod=min(1,gD/(Q+1))。把一份虚拟真实本地Upd用于所有执行，假设fresh的再更新错误概率≤δ₀，update挑战再更新的两步链错误概率≤δ₁。G独立于真实钥匙、挑战和该本地随机性；成员事件只取错误事件的子集，故e₀≤δ₀、e₁≤δ₁。于是

\[
\Delta:=|p_1-p_0|\ge
a\max\{0,1-\epsilon_{mod}-\delta_0-\delta_1\}.
\tag{Attack}
\]

在合法均匀位游戏中bias=Δ/2，成功率=(1+有符号差)/2。CANS/IEICE原定义采用成功率bias；FI原定义采用两个输出实验概率差。本轮原FI轨迹非法，所以(Attack)不被赋给原FI游戏。

Q≥4gD时ε_mod<1/4；κ为增长安全参数且δ₀、δ₁足够小，得到常数优势。固定多项式Q并不能仅从gD/(Q+1)断言遗漏概率可忽略；本轮主要使用常数界。

## 5. 固定父、隐藏token与辅助信息

分析可先条件于A、epoch2/3钥匙和两条相关token，再独立采训练父与fresh挑战；实际公开仍按真实时点进行。不同加密消息若会改变H分布，训练消息应选择M₀。FI第一块独立于消息，因此任何固定训练消息均适用。

普通带是合法接口的返回值，不包含token输入。提取成功来自多次线性观测，非oracle直接泄露。冻结闭包只由实际Corr及既定递归规则生成，攻击中新计算的N或限制作用不会自动改写T。

若实际实现以共同RNG、token过滤、解密成功筛选或分支相关采样失败改变这些联合律，需要对应分布／失败界。对于规定理想独立有限CDF，本文结论无需计算困难性。
