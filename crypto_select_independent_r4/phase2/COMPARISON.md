## 2. 矩形域到三角域

矩形域 B={(j,r):2≤j≤L,1≤r≤L}，大小Lambda=L(L−1)。三角域 T={(j,r):2≤j≤r≤L}，大小F=Lambda/2。

第一阶段对r<j在交互前直接公平输出，因此每种DDH输入下该分支输出概率均为1/2，中心差为0。对任意t∈T，矩形条件分布为

    Pr_B[t | R≥J]=(1/Lambda)/(F/Lambda)=1/F.

该条件只依赖预先抽取的索引，不是对最终合法历史或匹配事件进行条件化。后者仍必须保留概率质量。

统一为下面的同一有效位置子模拟器 S_{j,r}：启动时采一个全局b；按共同后台处理；已接受c>j可安全提前公平结束；未来对象先返回⊥；其它中止与最终事件筛选完全相同。其余oracle随机流与索引采样流独立。

对每个有效(j,r)、每个DDH世界，S_{j,r}的输入/响应分布及最终判定位相同。原两文本的非匹配路径可能有不同早停时点，故不宣称原稿全部内部转录逐字相同；这些额外路径的中心评分均为0，统一早停不改变优势。

于是理想判定器输出概率有

    p_box,W=1/2·1/2+1/2·p_triangle,W,
    delta_box=delta_triangle/2,
    Adv_DDH*(D_triangle)=2 Adv_DDH*(D_box).

因此 `Lambda·Adv(D_box)=F·Adv(D_triangle)`。三角界通过，矩形证明仍然有效且作为较保守来源保留。

## 3. 必须明示的控制流

待审“公开第j版时……并自采b”的句子可能被误读为此前响应使用一个位，到j再采新位。若c<j，早期真实官方版本已经要加密M_b，不能在j处首次决定或重采该位。

定稿明确：**b在开始交互前独立均匀抽一次，所有官方版本、中心评分和第j嵌入共享同一b。** 也可等价推迟到首次接受Challenge之前；本稿采用前一种。该补全保持原混合H_i的语义，不改变算法/游戏/计算假设。若按字面实现为重采，则不能证明对应同一H_i；本轮没有把这种错误实现认定为合法证明。

正常采样器改记为mathsf{S}，猜测索引仍记J，避免第一阶段两处J符号复用。

## 4. 差异分类

| 差异 | 分类 | 裁决 |
|---|---|---|
| 移除r<j的空位置 | 更保守归约界 / 索引采样差异 | 理想优势精确2倍关系，未改变密码模型 |
| 两个矩形索引 vs 一个三角秩 | 采样效率差异 | 有限词长、拒绝率和调用数单独计，不能直接沿用理想2倍关系 |
| c>j时提前结束或继续到最终筛选 | 模拟器行为差异 | 对最终中心评分等价，非匹配内部转录可能不同 |
| b的采样时点措辞 | 需要补充论证/控制流 | 已按唯一全局位补全；不增加安全前提 |
| 第一阶段已公平失败却用保守误差 | 更保守归约界 | 合法；较小常数仅写入公平失败版本 |
| 新增导入、共享RNG、Gen带暴露等 | 游戏或前提差异 | 均未采用，不能据本定理覆盖 |

未发现补全后仍要求改变理想算法或游戏的实质证明缺口。结论是知情比对后的定稿候选，不是独立同行验收。
