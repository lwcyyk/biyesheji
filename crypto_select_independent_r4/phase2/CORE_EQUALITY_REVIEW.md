# 共同后台与核心等式复核

本文件对A–F逐项使用规定状态。最终VERIFIED指本次知情数学核对通过，不表示无历史或外部同行验证。唯一必要控制流澄清是b启动时抽一次并贯穿全部官方版本；不存在的对象先做检查。两点均进入本次定稿模拟器。

## A. 正常记录归纳 — VERIFIED

定位：第一阶段§2；待审引理1。对记录N的每坐标存 `(rho_i,w_i)`，满足

    C_i=(P_{e,i}^{rho_i},g^{rho_i}w_i), Z=M∏w_i.

实际新带eta含a_i,s_i和新pad v_i。因为P_new=P_old^delta，原算法首分量逐点等于 `P_new^{rho_i+a_i+s_i}`；次分量等于 `g^{rho_i+a_i+s_i}w_i v_i`。接受值更新rho/w，新id记录父来源，父不变。

Enc提供已知根表示，此更新给归纳步骤。所有位前缀由相同mathsf{S}诚实采样，没有改写历史拒绝词。重复同父用独立eta，给同一潜在delta同时成立的等式。没有任意导入路径是输入明示条件，不是本轮新增限制。

## B. 官方链新鲜化 — VERIFIED

定位：第一阶段§3；待审引理2及SUBPROBABILITY §§1、3。固定完整theta与b，隐藏更新的s全域均匀，使rho+a+s均匀；独立新pad使w_old v均匀，二者独立，外部掩码同步变化。转移核只依赖目标P和M_b。

在线逐核替换支持正常查询、完整带、token/Key回调与自适应Get的整个联合过程。同代缓存，未公开j不能在后代独立流中传出。固定theta用于核证明；不在最终选事件后重新声称样本独立。实际cap后的失败率可能因调用数不同而变化，因此本等价仅以理想游戏形式使用，有限版本分别耦合到理想过程。

## C. 完整未来钥匙 — VERIFIED

定位：第一阶段§5；待审后台段。隐藏边界t=r+1，固定旧非零X_r，映射 `delta_i ↔ Y_i=delta_i X_{r,i}` 是逐坐标双射。故先采完整Y再定义隐含delta，联合分布与诚实Next相同。

首次P_t交付前就已选Y；以前P不改，P_t=g^Y固定。普通边界更新由A项逐点成立。以后完整K_h从Y正常演进，返回全部标量，连同已公开context构成完整对象。Gen/Next带及未来P无预先承诺属于原输入。

## D. 每个世界的子概率 — VERIFIED

定位：第一阶段§7；SUBPROBABILITY §4。扩展记录omega含b、公共转录、查询元数据和猜测。令 `f=1_correct−1/2`，E_jr为最终有效、直接j可见且规范边界r。

对DDH real参考H_j、random参考H_{j−1}，在筛选前建立同一随机源核：出生根X真实均匀、边界重参数化同密度、正常带真实、j处由DDH精确对应诚实或整份均匀密文。第E项证明每个模拟停止前缀均无E_jr续接。因此对任何记录集合B，

    Pr_D[未停止且omegahat∈B且E_jr]=Pr_H[omega∈B且E_jr].

取全集给概率质量，积分f给未正规化z。两世界可以有不同的E概率；没有省略这些权重。

## E. 停止与实际合法查询 — VERIFIED

| 动作 | 处理/无匹配续接论证 |
|---|---|
| 已有K_h，j≤h≤r | 若最终j公开且到r边齐，则h在C*且K*，不可能有效 |
| 已有边界token r+1曝光 | 中间边齐则r_j>r，否则r_j<r，匹配不可能 |
| 由相邻Key推边界token | r一端在K*，目标段又可达，匹配有效性失败 |
| 尚未生成Key/token | ⊥且不进暴露集；不得因猜测区间而中止 |
| 实际接受c>j | 当前Get无追溯，j不可能官方公开；可提早公平评分 |
| j始终未公开 | 该步两混合不可见部分相消，最终筛选给零贡献 |
| 后续曝光令历史非法 | 闭包单调，之后不能恢复，最终公平评分 |

其中前两种查询可能在真实游戏中合法。模拟器停止来自猜测不匹配，未把它们一概定义为非法。看过密文后的自适应策略、挑战前腐化及多个隐藏缺边都被“任意后续”论证覆盖。

## F. 分割与望远镜 — VERIFIED

定位：第一阶段§§4、8；SUBPROBABILITY §§2、3、6。对每个H_i自己的最终历史定义r_j。固定j的r事件分割有效且直接j可见路径。未公开j时两侧在第一次读取前使用相同公开核，永不读取则全部观测/评分相同。

令 `z_i(j,r)=E_{H_i}[Z_i 1_{j∈C,r_j=r}]`。每个有效位置的判定器有

    p_real(j,r)=1/2+z_j(j,r), p_random(j,r)=1/2+z_{j−1}(j,r).

先对所有j,r线性求和，再取绝对值；不对单步绝对值求和，不要求边界事件与密文/隐藏位独立。mu_1=0，mu_L为真实signed bias。统一三角D给 `delta=mu_L/F`，矩形D给 `delta=mu_L/Lambda`。
