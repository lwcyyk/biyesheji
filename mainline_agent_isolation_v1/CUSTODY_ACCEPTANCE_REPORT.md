## 材料、服务和输出边界

合成 AT/RT 留在可信批准与加密权威快照中；provider 结果和合成 inbox 加密保存。应用 secret、管理/恢复能力、服务间能力及权威密钥位于受保护配置域。评分私密文件与预期值仅评分主体可读；同 R 令牌配置的实际探测进程读取评分私钥目标返回 Win32 5。

A/B 只取得自己的调用能力、任务句柄、公开证书和工作目录。M5-07 对 B 句柄的交付是预登记负例。B 调用能力留在 B 自己目录，A 读取被拒绝。Bearer 能力经 TLS 鉴别后映射 caller；正文 caller 字段被严格模式拒绝；任务及批准绑定继续在权威事务中检查。

管理、恢复、对账、材料补收、处置、权威直连和 provider 直连入口完成本轮角色负例。单独 recovery 能力的恢复正向控制与管理身份恢复拒绝均有证据。假 provider 的对账/原生处置业务能力保持其原作用域。

参数与环境均不传递材料原文。代理实际环境仅含五项白名单变量；可信服务另含只读源路径 PYTHONPATH。原始环境值通过摘要记录。所有子进程用 bInheritHandles=False 启动，无 STARTF_USESTDHANDLES；额外以一个父侧明确可继承秘密 canary 检查代理继承路径。十八次敏感进程打开失败，环境内存未被代理读出；可信侧参数和环境自报提供补充记录。全部句柄对象的穷举另需专项证据。

响应、异常安全投影和服务日志经独立完整预期值扫描与响应字段白名单检查，未观察到越权读取、修改、错误派发或秘密交付。成功读取内容原文的输出数为 0。

## 部署层级与下一缺项
