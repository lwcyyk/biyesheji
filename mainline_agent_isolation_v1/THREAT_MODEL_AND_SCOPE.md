# M5 攻击模型、预登记与证据边界

合同为 ONLINE_TRUSTED_STATE_V1，资源状态 NO_HARD_LIMIT_YET，密码学辅助线 FROZEN。本轮使用成熟 Windows ACL、受限令牌、本地 TLS 与既有事务组合。新增密码学候选实现为 0，原生 AS/RP 请求为 0。

## 可信边界

信任 R、权威服务、可信假适配器、身份能力配置、Windows 内核及管理员、配置和评分主体。现有 OS 用户的完整令牌和密码未交付代理。评分/配置主体可以读取全部本批合成材料；服务进程使用独立 R 限制 SID，无法读取评分私有目录。

A/B 使用不同限制 SID 的低完整性主令牌，可以在该令牌下执行任意测试代码。任意子程序继续受实际令牌、DACL 和完整性规则约束。测试程序的业务逻辑承担当次攻击输入生成；隔离判断依赖 OS 和服务实际返回值。代理可复制自身句柄、重放请求、修改自身文件。M5-07 明确向 A 提供 B 任务句柄。

代理具有自己的服务能力、任务句柄、公开 CA 证书和专用可写目录。管理、恢复、服务间能力和合成 AT/RT 均由可信侧持有。请求只使用已登记 loopback HTTPS 地址；服务绑定 127.0.0.1。系统级出站网络过滤本轮未配置，任意网络出口与主机全面沙箱隔离留在额外部署审查范围。

## 十二个预登记场景

| 场景 | 正向控制与攻击 |
|---|---|
| M5-01 | A 实际低权限进程读写自己的目录，并合法执行 A.g0 |
| M5-02 | B 实际低权限进程读写自己的目录，并合法执行 B.g1 |
| M5-03 | A 读取权威密钥、适配器配置、管理能力、收件箱、评分私钥、B 配置、R 配置、材料库及评分预期，共九个已存在文件 |
| M5-04 | A 请求可信数据库、批准配置、安全日志、恢复缓存的写访问；另试改写这四个对象的 DACL |
| M5-05 | A 对三个已登记可信 PID 请求六类敏感访问及有限查询，测试父进程可继承 canary 和自身完整性提升 |
| M5-06 | 管理/恢复/对账/材料补收等十一项服务调用负例；错误能力；代理 status 过滤；独立恢复角色正向控制 |
| M5-07 | A 使用 B 句柄，注入 caller，篡改 task/account/audience/generation；B 正向调用 |
| M5-08 | 同 rid 同正文返回重复结果；同 rid 异正文冲突；预算及 provider 效果只计一次 |
| M5-09 | 重复 JSON 键、语法、非有限数、类型错误；权限错误；实际停 provider 产生 UNKNOWN，再启动并完成 B 调用 |
| M5-10 | 撤回持久 ACK 后保留 A 句柄及能力发起新请求，B 继续 |
| M5-11 | A 进程保持运行；终止并等待旧 R；恢复旧缓存；新 R 在线恢复；A 拒绝、B 合法 |
| M5-12 | 实际停止权威；A/B 请求 UNKNOWN；重启权威；预算与未决义务保留；B 最终恢复 |

正式批次总分母 12，每场景一次，观察窗口上限 60 秒，批次上限 30 分钟。开发测试单独登记。实际越权读取、修改、错误派发或秘密交付使正式批次停止；未执行项继续计入完整分母。目标缺失、启动失败和请求未到达分别记证据不足，无法作为成功权限拒绝。

## 证据与秘密

本批合成 AT/RT 是既有 legacy synthetic 材料中的两个可识别测试分量；这项输入不承担原生 typed token bundle 的行为验证。应用 secret 是假适配器配置中的合成值。权威 AES 密钥真实生成并保存在受保护目录。评分私钥目标为可识别的合成测试私密文件，用于权限边界验证；本批评分读取自身预期和独立数据库路径。

代理公开输出只包含结果白名单、对象、系统错误码、大小和摘要。读取攻击获得访问时，仅报告对象及摘要。预期值存于 scorer_private；数据库为加密快照；假 provider 的结果日志及合成收件箱加密保存。进程参数包含角色和配置路径，环境按白名单构造，均不携带认证原文。HTTP 禁止环境代理与重定向。

每场景评分另读 SQLite 只读连接、权威密钥及 provider truth，记录独立路径。事务 version 和提交事件建立授权顺序；客户端 monotonic 时间只表示其实际观察。真实 PID、文件 DACL 回读、有效 SID 和令牌特权单独保存。

## 适用范围

内核漏洞、管理员控制、侧信道、生产浏览器状态、真实用户批准 UI、主机断电/磁盘损坏、权威自身回滚、无限恶意耗尽和互联网出口控制均未验收。R/权威/适配器共享可信服务域，彼此恶意隔离不在本模型中。M5 的故障覆盖本批进程和缓存目录。主线 B 目标继续采用条件满足后最终恢复。

M2/M3/M4 的真实 provider 结果继续绑定各自原代码与环境。M5 的假 provider OS 测试与这些历史结果分别登记。原共享组织账户级读取问题继续沿用原适用域。
