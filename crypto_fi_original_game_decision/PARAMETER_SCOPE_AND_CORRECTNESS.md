## 2. 相同参数、预算与精确采样合同

CF-1取整数λ≥2，n=8λ，L=ceil(log2n)，D=8L，q=2^D，m̄=n̄=8，B=2，χ=χ640，k=T=t_max=n。这里T是Next次数/最大epoch标签，epoch为0,…,n；t_max为单条诚实链允许的更新次数。消息长128位。n与λ线性对应，PPT及可忽略性的口径一致。

有n^8≤q<(2n)^8、D=O(logn)。χ640取官方有符号整数表：0及正/负每点的分子依次为

`[9288,8720,7216,5264,3384,1918,958,422,164,56,17,4,1]/65536`。

零项计一次，其余正负各计一次。每项用独立16位精确反CDF采样，随后取模q。该合同没有截断、拒绝或采样失败事件；样本本来就是有限表分布。无限高斯的逼近只属于历史困难性讨论。大q环元素按D位处理，官方uint16负数表示要先解释为带符号整数再嵌入，不能把其机器表示直接沿用到大q。

所有KG、Enc、TG和挑战Upd共同使用同一组参数、公开A和上述独立采样合同。不存在按分支换表、按可逆性重采token或隐藏免费轮换。

## 3. 完整解密残差的逐样本正确性

令旧、新秘密均为n×n̄；新公钥B_new=A S_new+E_new。父残差写为C2−C1 S_old=Encode(M)+η。初始FrodoPKE残差为

η0=U0 E_old+G0−F0 S_old，故||η0||max≤B0=2ns²+s。

按p14代入TG/Upd并用Ord_n(C1)Tensor_D(S_old)=C1 S_old，更新引入

`δ=(H U1+R U2)E_new−(H F1+R F2)S_new+H G1+R G2`。

H为m̄×nD的0/1矩阵，R为m̄×n的小样本，U1/F1为nD×n，U2/F2为n×n，E_new/S_new为n×n̄，G1为nD×n̄，G2为n×n̄。在所有小量坐标绝对值≤s时，逐坐标相乘求和给

||HU1 E_new||max、||HF1 S_new||max≤n²D s²；

||R U2 E_new||max、||R F2 S_new||max≤n²s³；

||H G1||max≤nDs，||R G2||max≤ns²。

所以W=2n²D s²+2n²s³+nDs+ns²。将s=12代入，

B0=288n+12，W=288n²D+3456n²+12nD+144n。

每一步可在整数中保留该残差并在Z_q中相等，故经过t次更新有||η_t||max≤B0+tW。只要B0+nW<q/8，所有残差均落在p12 Lemma5.1的B=2解码区间内；这个界同时排除残差在中心区间的模回绕。它覆盖全部消息、全部诚实钥匙/token/随机样本、任意固定A及最长n次诚实更新。

对n≥16，D≤4n，直接得到

`B0+nW < 1372n^4 < 8192n^4 ≤ n^8/8 ≤ q/8`。

因此CF-1共同正确性是逐样本结论。这里显式计入初始噪声，避免只把每次更新界相加后遗漏η0。FI p15 Theorem6.3打印的充分界及其“epochs”措辞按原文保留；本证明直接从其算法的残差恒等式导出完整链保证。源p15正文把E的维度一处写成n×n，按p12 KeyGen和乘积类型应为n×n̄；以上使用实际KeyGen维度。

## 4. 攻击在同一CF-1族中的优势与成本

令a=1161/8192，μ64为χ640模q的64重卷积峰值，γ=25μ64<1/2。q≥2^32>1536，64重整数卷积与模q卷积峰值相同。n≥64时

ε_n=min{1, binom(n,63)a^(n−63)+γ^n}；n<64取ε_n=1。

ε_n≤2^126 n^63 2^(−2n)+2^(−n)=negl(λ)。χ640奇偶质量各半，逐个固定A和U2时P2 mod2均匀独立，α=p_n=∏_{i=1}^n(1−2^(−i))>1/4。新token调用独立，故p_k=1−(1−p_n)^k。k=n时

`Δ_n ≥ [1−(1−p_n)^n](1−ε_n) ≥ 1−(3/4)^n−ε_n`。

Δ是输出1猜update时的有符号实验差；其绝对值为原文Adv，成功率为(1+Δ)/2，成功bias为Δ/2。n=64时当前ε仍截为1；渐近结论不赋予每个小参数非平凡界。已有精确证书给n=96时ε≤2^-7，n=128时≤2^-59，n=256时≤2^-300；这些值在相同大D合同中成立。

一个完整的有限实例为λ=16、n=128、D=56、q=2^56、χ640、m̄=n̄=8、B=2、T=k=t_max=128：最长128次更新逐样本正确，≤385次调用，gap至少1−(3/4)^128−2^-59。它是CF-1的打印域实例，与官方640配置分别命名。

| 资源 | 同参数账本 |
|---|---|
| 查询 | Enc≤n、Next≤n、Corr(token)≤n、Challenge≤1；其余0；合计≤3n+1 |
| 当前token大小 | n(D+1)(n+n̄)个环元素；按每项D位为n(D+1)(n+n̄)D位 |
| key、ciphertext | 完整key两块共2nn̄个环元素；密文m̄(n+n̄)个环元素 |
| 流式攻击存储 | O(n²(D+1)²)位，含A、当前父/token和矩阵消元；原游戏保存全部历史的成本另计 |
| 通信上界 | O(n³(D+1)²)位，含真实返回的完整token和密文 |
| 位时间上界 | 保守O(n^4(D+1)^3)，包含所有查询的诚实矩阵计算、模2秩检查、一次Z_q逆和成员测试；普通整数学校算法已足够 |

矩阵逆可用奇数主元的局部环消元求出，奇数模2^D逆由扩展Euclid计算。参数长度和所有成本均为poly(λ)。以上是可行上界；成本最优性、运行实验和保护协议资源分离各未形成声明。

## 5. 官方640/976/1344：有限证书准确覆盖的事件

表中参数来自官方2021规范Table3–4/PDF p25；1344 CDF采用官方确认的完整7项。统计解释使用理想独立χ抽样和FI打印算法。

p_n约0.288788；L_1344=∏_{i=1}^{1344}(1−(16385/32768)^i)约0.2887397288961254。单次bias为表中下界的一半。640/976有精确平衡奇偶性；1344偶/奇质量分别32770/65536与32766/65536，使用知情N1秩界。证明方法为：余维i子空间可由i个主元比特限制描述，其概率至多pmax^i；逐行条件化相乘得到下界。环上可逆等价于mod2满秩，因为det是单位恰当且仅当det为奇数。N1的历史身份保持，当前没有将它改记为新独立推导。

ε认证的是`Pr_fresh[存在r∈S^n使Y=HP1+rP2 | A,P2=p]`的上界，因而也约束可逆且支撑通过的联合事件。证书采用第一行指数n。64重系数总和、峰值和完整两项和的整数比较均已核准；较长卷积由模群卷积的ℓ∞收缩处理。它没有给出完整联合视图均匀性，也没有认证解密失败率。

本轮重新核对三个外部系数文件哈希与PARAMETER_CERTIFICATES内引用完全一致，读取全部系数，检查总质量、峰值、无合并条件q>128s和两项和上界，结果见[finite_certificate_recheck.json](sources/finite_certificate_recheck.json)。未重新运行卷积生成或密码实验。phase1已独立重算三组峰值和上界；外部系数字节哈希的本轮检查属于知情有限证据。

粗略初始充分界B0分别184332、195210、96774，解码半宽分别4096、4096、2048。该最坏界无法认证三组有限配置的初始/更新正确性。要给完整构造结论，须取得或推导每t的实际联合残差分布、全部m̄n̄坐标解码失败概率、token与连续更新依赖、允许T及总体失败预算。普通FrodoPKE或KEM的失败率无法直接替代这些UE量。充分界未满足、存在实际解密错误、来源游戏可区分三项分别登记。

## 6. 官方采样与作者程序的对应边界

1344完整CDF为`[9142,23462,30338,32361,32725,32765,32767]`。[官方issue35](https://github.com/microsoft/PQCrypto-LWEKE/issues/35)于2024-11-27确认规范缺32765是排版错误；2024/2025修订规范原图也给完整表。已取得官方代码快照`e1edeb3af1fae0d5727683bd2f5465280ec2437a`中的noise.c及frodo1344.c支持同一采样映射。该commit是冻结读取快照，不能据此称为当年的CDF修复提交。

公开seedA→A的任意确定性生成，在A先固定且噪声独立的合同下可直接对固定A定理平均，所需A生成器困难性假设数量为0。秘密噪声seed的展开仍须证明所读F0、F1、F2等的联合律与理想模型可耦合，或给计算差ν_b。若两个实际实验分别偏离理想输出概率至多ν0、ν1，则实际gap≥max{0,理想gap−ν0−ν1}，bias损失为其一半。

作者代码对应最小缺项为：准确commit及配置；D/B/CDF/T；全局A生成；U0/F0、U1/F1、U2/F2、R的seed来源、域分离和复用；筛选/重试；溢出、取模、打包；失败语义。源包及已检索代码记录未提供这些材料。官方参考实现自身不能认证作者UE程序的联合采样和性能实例。
