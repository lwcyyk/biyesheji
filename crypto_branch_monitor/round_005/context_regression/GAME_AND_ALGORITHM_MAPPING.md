## 2. 参数、维度、模数及可见字段

FI pp11–12：D>0，q=2^D，0≤B≤D，n,m̄,n̄>0，n≡0 mod 8，消息空间 M={0,1}^{B m̄ n̄}。B 为编码位数；B_e 为矩阵，两者需区分。所有以下矩阵运算在 Z_q 上进行；Z_q 是环，D>1 时带有零因子。

**VERIFIED（参数域边界）**：FI 此处允许一般 D>0；官方 2021 Frodo 规范 §2.2／§2.3 的算法参数域另有限制 D≤16。将 D 取得更大属于 FI 纸面域的参数分析，迁移到官方算法或论文计时程序时须单独核准。标准参数数值与特定性能表的完整配置分别登记。

χ 为对称、零中心的有限离散分布，整数支持 Sχ={−s,…,s}，s>0。FI p12 通过 Frodo.SampleMatrix 和反演采样引用具体实现。纸面概率模型中，每次标记 χ 的矩阵由独立 χ 元素组成，各调用使用独立随机性。种子展开的实际实现另见概率审查及辅助信息审计。

token 确实是 Δ_(e+1)=((P1,Q1),(P2,Q2))，P2 确实为方阵。p14 TG 第3、5、6行及 Upd 第2–5行的 PDF 原图已核对。

FrodoPKE 的加密和解密为

\[
C_1=U_0A+F_0,\quad C_2=U_0B_e+G_0+\operatorname{encode}(M),
\quad \operatorname{Dec}=\operatorname{decode}(C_2-C_1S_e).
\]

原 p14 更新完整输出为

\[
C'_1=H P_1+R P_2,\qquad C'_2=C_2+H Q_1+R Q_2.
\]

原文此处具有固定 token 中的噪声 F1,F2,G1,G2；Upd 本次新采样的 R 与它们相乘。p14 中逐次额外加性噪声矩阵的采样次数为零。

## 3. Ord 与 Tensor-D 的规范化依据

**VERIFIED（数学及原文意图）；NEEDS_CLARIFICATION（印刷域）**。

对 X∈Z_q^{m̄×k}，先取每个元素在 {0,…,q−1} 的代表，写

\[
X_{ij}=\sum_{t=0}^{D-1}2^t x_{ijt},\qquad x_{ijt}\in\{0,1\}.
\]

定义 Ord_k(X) 的第 i 行依次为第0位的 k 个坐标、第1位的 k 个坐标，直到第 D−1 位。这个排列逐字遵循 p13 的“位层优先、层内列顺序”。对 S∈Z_q^{k×n̄} 定义 Tensor_D(S)=[S;2S;…;2^{D−1}S]。于是

\[
(\operatorname{Ord}_k(X)\operatorname{Tensor}_D(S))_{i\ell}
=\sum_{t,j}x_{ijt}2^tS_{j\ell}=(XS)_{i\ell}\pmod q.
\]

取 k=n 即得到 p14 所需乘积。依据还有 p13 Remark 6.1、p15 明写 H∈{0,1}^{m̄×nD}，以及 p16 用该恒等式替换 H Tensor_D(S_e)。这一解释只给已有逐位操作补上列数参数；比特顺序、采样次数和矩阵数值均保持原定义。攻击的第一块关系本身也无需使用 Tensor 恒等式。

## 4. 原文基础游戏的最小合法查询串

**VERIFIED**。选择固定消息 M=0^{B m̄ n̄}，令 M0=M1=M。实验位 b 由实验内部提供；p10 伪代码 O.Chall 的 b 形参属于实验参数。

| 顺序 | 调用 | 状态／理由 |
|---|---|---|
| 0 | 实验 Setup | 初始 e=0，K=T=C=∅，phase=twf=0 |
| 1 | C←O.Enc(M) | p9 登记 (qid,C,0;M)∈L；保存完整 C |
| 2 | O.Next() | e=1，生成 k1 和 Δ1；尚未进入挑战阶段 |
| 3 | Δ1←O.Corr(token,1) | 1≤e，p9 允许返回全部 token；T={1}，K=∅ |
| 4 | C*←O.Chall(M,C) | p10 第4行认可上一代普通父；b=0 时新鲜 Enc_1(M)，b=1 时 Upd(Δ1,C) |
| 5 | 用第一块 Y 计算判定并立即输出 | C={1}；没有后续依赖挑战的查询 |

p9 的钥匙闭包由实际腐化钥匙与向过去传播的规则生成。K=∅ 的最小闭包仍为 K*=∅。因而 p11 实验末尾 K*∩C*=∅，twf 保持0。即使进一步扩大 C*，这个结论仍成立。p11 把一般 C* 的具体求法委托给 Jiang [15]；本轮没有重新核准该外引全文，最小串的合法性对这项缺口无依赖。

本串需要一次普通加密、一次 Next、一次 token 腐化、一次挑战。钥匙、挑战随机带、普通随机带、解密接口的请求数均为0。O.Dec 在 p10 的 CPA 说明中被排除；本攻击也没有调用它。

p8 的 Q*、Q̃* 用于追踪已知消息／挑战消息；这里既无解密调用，也无钥匙腐化。将两条消息设为同一消息符合 p10 挑战检查。普通父的明文已知是游戏设计的一部分。

攻击稿中的两次普通 Upd 以及挑战后的 Next/GetChallenge 均可删去。若保留，O.Upd 对注册父的记录执行集合并入，原父仍在 L 中，可以重复调用；后续 Next 也没有删除攻击者私有存储中旧挑战的步骤。最小证明直接使用上表，避免引入额外交互量词。
