## 1. 支持、算法与总定义

令 q=2^D，N=m̄n，S_q={z mod q:−s≤z≤s}。由于这是一段连续整数的模像，

\[
h=|S_q|=\min(q,2s+1).
\]

当 2s+1<q 时，标准代表下

\[
S_q=\{0,\ldots,s\}\cup\{q-s,\ldots,q-1\},\quad h=2s+1.
\]

这里 χ 的概率质量可以非均匀；支撑判定只需要成员资格。若使用真实支持的更大已知包络，更新接受率仍为1，fresh 计数中的 h 应取该包络基数。FI p11 的“小支持”没有逐项写出 h<q，攻击稿已显式限定这个条件。h=q 时该测试优势为0。

**修订后的完整纸面攻击（VERIFIED）**：

1. 按 `GAME_AND_ALGORITHM_MAPPING.md` 的最小串，固定 M0=M1，取得诚实普通父 C、token Δ，以及挑战 C*。各阶段遇到 ⊥、缺失必要第一块、错误维度或公开参数无法解释时，立即输出一枚新独立公平比特并终止。读取完整父对象仅为原样提交给挑战；判定函数使用 C1。
2. 从 Δ 解析 P1∈Z_q^{nD×n}、P2∈Z_q^{n×n}，取挑战第一块 Y∈Z_q^{m̄×n}。将这些元素统一为模 q 标准代表。原数学算法产生的元素天然满足该类型。
3. 在 F2 上判断 P2 mod 2 是否满秩。秩小于 n 时输出新独立公平比特。
4. 满秩时求 P2 在 Z_q 上的逆，令 H=Ord_n(C1)，计算

   \[
   \widehat R=(Y-HP_1)P_2^{-1}\pmod q.
   \]

5. 若所有坐标均在 S_q，输出 b′=1（更新）；其余情况输出 b′=0（新鲜）。随后终止。

这是攻击规范与数学分析，本轮没有编写或运行其密码实现。

求逆的完整性：方阵 P2 在 Z_(2^D) 上可逆，当且仅当 det(P2) 为奇数，当且仅当 P2 mod 2 满秩。必要性来自将逆映到 mod 2；充分性来自 det(P2) 为环单位，再用伴随矩阵公式。实际多项式算法可使用单位主元消元，或先求 mod 2 逆再逐次提升精度。消元 O(n³) 环运算，HP1 为 O(m̄n²D)，右乘逆为 O(m̄n²)；模运算的位长为 D。成员资格可用区间比较完成。参数维度和 D 均为安全参数的多项式时，攻击为 PPT。

**VERIFIED（精确恢复）**：在可逆的更新分支，原 p14 给出 Y=HP1+RP2，因此

\[
\widehat R=RP_2P_2^{-1}=R\pmod q.
\]

这里恢复的是 R 的模 q 矩阵；在 h<q 的支持域上，整数代表也唯一。R 的每一坐标属于 S_q，故全部通过。该结论对每个诚实父和每个 token 成立，独立于消息、P2 的分布、解密噪声和正确性参数界。

## 2. 无假设等式与优势口径

令 J=[P2 可逆]。在最小串中，token 和父均于挑战之前生成；两个实验到挑战时的联合分布完全相同。令

\[
\alpha=\Pr[J],\qquad
\beta_{\rm real}=\Pr[J\land\widehat R\in S_q^N\mid b=0].
\]

在原文理想采样算法与合法最小串中，格式错误及 ⊥ 的概率为0。则

| 分支 | 输出1的概率 | 猜对的概率 |
|---|---|---|
| b=1，更新 | α+(1−α)/2=(1+α)/2 | (1+α)/2 |
| b=0，新鲜 | β_real+(1−α)/2 | (1+α)/2−β_real |

取均匀挑战位，得到 **VERIFIED**：

\[
\Pr[b'=b]=\frac12+\frac{\alpha-\beta_{\rm real}}2.
\]

由于 fresh 事件中的 J 边际同样为 α，有 0≤β_real≤α；本攻击的 bias 为非负。两种口径为

\[
\operatorname{Adv}_{\rm bias}=\left|\Pr[b'=b]-\tfrac12\right|
=\frac{\alpha-\beta_{\rm real}}2,
\]

\[
\operatorname{Adv}_{\rm FI}
=\left|\Pr[\mathrm{Exp}_0=1]-\Pr[\mathrm{Exp}_1=1]\right|
=\alpha-\beta_{\rm real}=2\operatorname{Adv}_{\rm bias}.
\]

FI p11 的优势式有绝对值，已对照原图。令 Δ=α−β_real，则成功率=(1+Δ)/2。不能将成功率、bias 和两个实验的概率差使用同一数值。

允许自适应查询的安全定义包含上述固定查询攻击，因此反例成立所需的是一个合法 PPT 攻击。当前等式针对这一个固定骨架。若改成观察 token 后选择多个父、拒绝某些 token、重试直到可逆或按挑战内容继续腐化，则应重定义相应 α、β 及终止事件。当前稿件无需这些扩展。

## 3. 均匀可逆概率与仿射计数

**VERIFIED（均匀矩阵）**：若 P←U(Z_q^{n×n})，则 P mod 2 为均匀二元方阵。依次选择线性独立的列，第 j+1 列可用的向量数为 2^n−2^j（j=0,…,n−1）。于是

\[
\Pr[P\text{ 可逆}]
=\frac{\prod_{j=0}^{n-1}(2^n-2^j)}{2^{n^2}}
=\prod_{i=1}^n(1-2^{-i})=:p_n.
\]

每个二元方阵恰有 2^{(D−1)n²} 个 mod q 提升，所以 D 不影响这一均匀概率。n=1 时为1/2；n→∞ 时趋于 0.2887880950866024…。例如 p2=3/8，尾积至少 1−Σ_(i≥3)2^(−i)=3/4，故对 n≥2 有 p_n≥9/32>1/4。

**EXTRA_ASSUMPTION_REQUIRED（真实矩阵）**：真实 P2=U2A+F2 的每行是小秘密 LWE 行。上面的均匀计数不能直接赋给真实 P2。若事件概率差受 ε_P 控制，才有 |α−p_n|≤ε_P。辅助信息审计给出具体的 n 行混合。

令 Z←U(Z_q^{m̄×n})，独立于 A、父、P1、P2 及所有先前上下文。固定任意具有可逆 P2 的上下文 w，映射

\[
Z\longmapsto(Z-H(w)P_1(w))P_2(w)^{-1}
\]

是 Z_q^N 上的双射；其逆是 r↦H(w)P1(w)+rP2(w)。故条件通过概率为

\[
\theta=(h/q)^N.
\]

对全部上下文求和：

\[
\Pr[J\land\text{通过，均匀 fresh 块}]
=\sum_{w:J(w)}\Pr[w]\theta=\alpha\theta.
\]

奇异 P2 的上下文贡献0。该计算没有假设父、P1、P2 无条件独立，也没有用 LWE 结论去逐个固定 A 或除以 α。均匀替换必须在该联合视图中成立；仅有 Y 的边缘伪随机性不足以推出此式。

## 4. 条件优势下界

若 fresh 联合投影替换的事件差≤ε_ct，则

\[
|\beta_{\rm real}-\alpha\theta|\le\epsilon_{ct}.
\]

因此先有真实分布界

\[
\operatorname{Adv}_{\rm bias}\ge
\max\{0,[\alpha(1-\theta)-\epsilon_{ct}]/2\}.
\]

再代入 |α−p_n|≤ε_P 得到较紧的式子

\[
\operatorname{Adv}_{\rm bias}\ge
\max\{0,[p_n(1-\theta)-(1-\theta)\epsilon_P-\epsilon_{ct}]/2\}.
\]

因为 0≤θ≤1，攻击稿的较宽下界 **VERIFIED（有条件）**：

\[
\boxed{\operatorname{Adv}_{\rm bias}\ge
\max\{0,p_n(1-\theta)/2-(\epsilon_P+\epsilon_{ct})/2\}.}
\]

FI 优势口径下将整个右侧乘2。每行判定 LWE 的优势采用两个输出概率差，则 ε_P≤Σ_(i=1)^n δ_(P,i)，ε_ct≤Σ_(j=1)^{m̄}δ_(ct,j)。若统一界为 δ，得到 ε_P≤nδ、ε_ct≤m̄δ；此处无需再乘2。

只有在明确的参数族上，这些总误差可忽略且 θ 可忽略，才得到趋近 0.1443940475433012 的 bias 下界（FI 概率差趋近 0.2887880950866024，成功率下界趋近 0.6443940475433012）。各常数均为下界中的主项。实际参数优势仍含尚待评估的 ε 项。

较弱的条件 θ≤1−c、c>0 为常数且 ε_P+ε_ct 可忽略，已经足够得到常数优势。θ 可忽略的精确增长条件为 N log(q/h)=ω(log λ)，其中 λ 为参数族的安全参数。

**EXTRA_ASSUMPTION_REQUIRED（参数族适用性）**：上述结论是一项明确的条件蕴含。对某一指定参数族作渐近反驳时，应同时列出 χ_λ、n、D、m̄、n̄、允许更新次数及所用 LWE 困难性界；需要加密正确性时，再核对其正确性条件。当前 Part I 的条件证明没有为任意参数选择认证 LWE 困难性，也未为论文六个计时实例给出有限 ε 证书。已有后续摘要中的无假设路线保留为知情背景，其复核需要对应证据和独立任务范围。

## 5. 失败、异常与反条件

**VERIFIED（原数学算法）**：χ 被定义为有限支持采样；Frodo 的固定长度反演采样会产生一个支持内的值。原 p12/p14 没有拒绝超限、解密后筛选或“P2 必须可逆”的重试程序。合法最小串中的 oracle 资格检查全部通过。

**NEEDS_CLARIFICATION（实际故障模型）**：若具体代码有失败响应、重试或分支相关错误率，应使用完整算法中的公平终止规则，并计入它们。设 a_b 为分支 b 中“可继续且 P2 可逆”的概率，g_b 为该事件内支撑检查通过的联合概率。则一般恒等式为

\[
\Pr[b'=b]=\tfrac12+\tfrac12(g_1-g_0)+\tfrac14(a_0-a_1).
\]

原等式是 a0=a1=α、g1=α、g0=β_real 的特例。若真实实现与理想实验在各分支分别以概率至多 ν0、ν1 发生不一致，则成功率下界可减去 (ν0+ν1)/2。给错误响应公平猜测可使算法完整，同时保留这项概率账目。

若改用无界高斯，令 τ=Pr[J 且更新 R 落在被测支持外]，则成功率公式变为 1/2+(α−τ−β_real)/2。原 χ 是有限表分布，当前 τ=0。

**COUNTEREXAMPLE（针对去掉条件的扩大主张）**：

- h=q 时全部坐标总能通过，β_real=α，优势为0。小支持条件有实质作用。
- 取支持 {−1,0,1} 的对称分布，χ(0)=1−η、χ(±1)=η/2，η=2^(−n)，n 沿8的倍数增长。事件 U2=F2=0 发生概率至少 1−2n²η，所以 α≤2n²η。由此“一切有限小支持 χ 都有 α≈p_n”的无假设说法失效。该分布也使指定 LWE 假设失效。
- 若额外把 fresh 的随机秘密／误差作为辅助信息公开，可直接重算 Y；本文对隐藏挑战带的归约随之改变。当前游戏保护挑战带。
- 若更新改为 Y=HP1+RP2+E_new，恢复量含 E_new P2^(−1)；原完美通过证明需重新建立。这对应修改后的算法。

这些反条件未出现在已核准的最小攻击对象中。

## 6. 正确性与更新次数

对原 p12/p14 逐式展开，设 η=C2−C1 S_e−encode(M)。初始加密满足

\[
\eta_0=U_0E_e+G_0-F_0S_e,\quad
\|\eta_0\|_{\max}\le B_0:=2ns^2+s.
\]

一次更新的精确模 q 恒等式为

\[
\eta'=\eta+(HU_1+RU_2)E_{e+1}
-(HF_1+RF_2)S_{e+1}+HG_1+RG_2.
\]

H 有 nD 个0/1元素参与每个内积，故新增项的逐元素绝对值满足

\[
W=2n^2Ds^2+2n^2s^3+nDs+ns^2.
\]

对连续 t 次成功 Upd，始终选择一致的整数噪声提升，可得充分条件

\[
B_0+tW<r_{dec}:=q/2^{B+1}.
\]

原文 Lemma 5.1 使用半开区间 [−r_dec,r_dec)；上述对称严格界回避舍入端点。可认证最大更新数为满足该不等式的非负整数最大值。若 B0<r_dec，则等于 ceil((r_dec−B0)/W)−1；若 B0≥r_dec，这一最坏情况界的认证集合为空。

FI p15 Theorem 6.3 使用

\[
W_{pub}=2(n^2Ds^3+n^2s^3)+nDs+ns^2.
\]

s≥1 时 W_pub≥W。原证明在 max 范数推导后写了 ∞ 范数，本轮按所需的逐元素界解释。E 应为 n×n̄，p15 文本中的 n×n 为维度简写问题，乘法和界可按 n×n̄ 修正。

**NEEDS_CLARIFICATION（计数与初始噪声）**：原 theorem 把 T 叫最大 epochs，证明末尾却按 T 次 updates 累加，且未显式写 η0。若 T 表示包含初始代次的总 epochs，则更新至多 T−1 次，B0≤W_pub，T W_pub<r_dec 足够覆盖初始噪声。若 T 表示更新次数，需核对 B0+T W<r_dec；s≥2 时宽界中的余量也可能覆盖 B0（事实上本参数域有 W_pub−W≥B0），s=1 时该余量为0。故原稿“未单独计入 B0”的观察成立；将其直接提升成所有参数上的 theorem 反例还需另外证据。

本攻击只计算公开第一块，代数和精确概率等式不依赖正确解密。判断 UE 作为加密构造是否正确，以及判断其 fresh/update 安全性，应分别完成。
