## 2. 本轮矩阵实例的显式定义

使用 SELECT 的oracle骨架与合法性评分，算法换为冻结 FI-v4 及其已说明的 Ord_n 列数解释，记为 **MATRIX-SELECT-FI-IID**。这是新增的矩阵实例化，不属于原GP23群定理的算法量词。

* q=2^D；消息为 {0,1}^(B m̄ n̄)；当前公钥上下文取B_e∈Z_q^(n×n̄)，完整钥匙为(S_e,B_e)。
* 密文为(C₁,C₂)，形状m̄×n、m̄×n̄；token为((P₁,Q₁),(P₂,Q₂))，P₁:nD×n、Q₁:nD×n̄、P₂:n×n、Q₂:n×n̄。
* 对第一行，设 g=nD、t=n、d=n+n̄，K=[P₁|Q₁]、N=[P₂|Q₂]。公开H=Ord_n(C₁[1,:])。
* 普通更新完整带允许解码第一行r=R[1,:]；Gen/TG带、token值和官方挑战带隐藏。
* 选χ640理想独立CDF采样时，每项使用独立16位输入、逐次调用独立；全模数采样为D位。普通带返回实际消费字，固定解码器公开。矩阵采样替代了SPEC2的群标量S_n，固定长度版无拒绝／耗尽。
* 保留SPEC2的原子响应、普通来源id、同父重复、未来对象⊥、实际返回C及最终闭包评分。C0/FAIR失败规则只有在相应矩阵采样器确有失败时才参与，不能由攻击者覆盖强制终止。

此实例把群公钥向量字段映射为当代B_e矩阵，属于显式暴露选择。本攻击忽略这些Next公开值；省去该额外字段也保留所用观测、查询资格和概率。因此结论的关键新增权限为普通Upd完整带与合法未来Key。

FI只新采R，故第一行观测为

\[
Z=(C'_1[1,:],C'_2[1,:]-C_2[1,:])=HK+rN.
\]

没有未公开的逐次附加噪声；固定token内部的误差已经包含在K、N中。独立新增输出噪声、截断／压缩丢失或非线性消息变换将改变该前提，需重新评估。

ROUND-006的单行矩形profile也满足同型关系，参数为K:g_b×d、N:t×d；其完整安全与可行参数尚未认证。一般类定理给出条件边界，不把该纸面profile标为已建立的安全新协议。

## 4. GP23群实例为何保留

GP23/CTX1的普通父坐标有已知表示(P_i^ρ_i,g^ρ_i w_i)。普通带给出ρ_i、pad及后续a_i,s_i,z_i；模拟器用公开P'_i直接生成P'_i^(ρ_i+a_i+s_i)，全程无需未知倍率δ_i。这正是冻结 NORMAL-BRIDGE。

尝试移植本轮线性学习有两处阻碍：把H取为训练加密指数ρ时，隐藏挑战的ρ并非公开可算；把H取为群元素编码时，现有算法没有一个已核准的Z_q固定小维矩阵线性表示。即便把循环群视为一维模，表示挑战元素为已知基元素的系数仍是离散对数问题。子群成员资格与有效系数表示必须分开。

因此本攻击的“公开H＋可解线性组合”前提无法赋给GP23。RISE的同类公开编码／隐藏指数问题也使其处于类外。普通完整带的既有模拟和本轮矩阵反例可以同时成立。
