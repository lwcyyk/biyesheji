## 4. 联合特征补充的直接推导

本节全部属于第二阶段知情审查。第一阶段封存材料未包含该补充。[联合特征补充快照](D:/毕业设计/crypto_branch_monitor/round_007/independent_review_packet/author_input/JOINT_ACTION_SUPPLEMENT.md)

### 4.1 完整前提与待学对象

取整数 q≥2，设 m=g+t，R=Z/qZ，隐藏固定矩阵

\[
W=\begin{bmatrix}K\\N\end{bmatrix}\in R^{m\times d},
\qquad X=(H,r),\qquad Z=XW.
\]

训练父采用 Q 个独立诚实 Enc(M0) 输出，每个父只执行一次普通 Upd。H 公开可计算，r 从该次完整返回带有效解码。固定参数、相关钥匙和 token 上下文 θ 后，训练联合特征 X_i 为 iid。目标 fresh H* 与训练 H 同分布且独立。

局部真实更新随机输入记为 ω_loc，r_loc 由其公开解码。ω_loc 的采样器使用攻击者可获得的信息，并给出与目标真实更新相同的条件分布。该随机输入独立于训练加密／更新随机带和挑战生成币，在成员测试之前抽取一次。于是 branch 0 的 `X*=(H*,r_loc)` 与训练 X_i 在 θ 条件下同分布独立。

若局部更新只有 r_loc 这一随机系数，ω_loc 可以直接等于 r_loc。若其余公开随机分量参与可扣除项或重构，它们也应包括在 ω_loc 中。

指定公开输出投影 Π，取完整密文或目标行均可。要求一个有效重构函数 Rec 对两类诚实挑战支持中的每个 C 及合法 ω 满足

\[
\operatorname{Rec}(C,\omega,X(C,\omega)W)
=\Pi\bigl(\operatorname{Upd}(\Delta,C;\omega)\bigr).
\]

并要求持有 Key3 时，该投影足以计算目标标签 ℓ(M)，其中 `ℓ(M0)≠ℓ(M1)`。原 TOKEN 的完整 `(u,c)` 公式可取 Π 为恒等映射。FI 的第一行公式可取 Π 为第一行并选一个编码位标签。这个前提封闭了从作用恢复到可用判定的推理。

### 4.2 任意模数的遗漏界

令 `L_j=span_R(X_1,…,X_j)`。有限加法群 R^m 的大小为 q^m。每次严格增加至少使模的大小翻倍，故任意样本路径的严格增长次数至多 `floor(m log2 q)`。结合 iid 产生的遗漏质量单调性，得到

\[
\Pr_0[X^*\notin L_Q]\le
\varepsilon_{joint}=\min\{1,m\log_2q/(Q+1)\}.
\]

该证明使用有限加法群的陪集计数，对 q 的素性、素幂分解或 2-adic 结构没有额外要求。各 r 坐标之间允许相关，单个 r 分布允许偏置、退化或仅含偶数。实际要求为各训练联合样本的条件 iid 和 fresh 目标联合分布匹配。

### 4.3 任意整数 q 的有效表示

令 A_X 为 Q×m 的训练行矩阵，取其整数规范代表并构造

\[
B=[A_X^{\mathsf T}\mid qI_m].
\]

`x∈L_Q` 等价于整数线性方程 `Bz=x^T` 可解。带变换记录的整数 Smith 正规形给出整可逆矩阵 P,V 和

\[
PBV=[\operatorname{diag}(d_1,\ldots,d_m)\mid0].
\]

qI_m 保证行秩为 m。令 y=Px^T，成员条件为各 d_j 整除 y_j。满足条件时取前 m 个坐标 `w_j=y_j/d_j`、其余为 0，令 z=Vw。z 的前 Q 项模 q 即为所需 α，满足 `αA_X=x`。整数 HNF 的带表示版本也可完成相同任务。标准多项式位复杂度正规形算法使用整数运算与 gcd，q 的素因数分解无需作为输入。

因此当 `X*∈L_Q` 时

\[
\sum_i\alpha_iZ_i=\sum_i\alpha_iX_iW=X^*W.
\]

任意两个有效系数向量的差都落入 A_X 的左核，故得到同一个作用值。该结论直接学习联合目标作用，完整 N 的可辨认性可以保持未知。

### 4.4 概率、条件化与默认输出

按前述一次独立采样产生 X*，先判断成员资格。非成员输出 1。成员内用 Rec 得到真实目标输出投影，目标标签等于 ℓ(M0) 时输出 0，其余输出 1。

令 m0 为 branch 0 的遗漏概率，令 e0 为 branch 0 的成员内错误标签联合概率，令 e1 为 branch 1 的成员内得到 ℓ(M0) 的联合概率。定义虚拟真实更新于每条执行，无论成员资格如何。则

\[
p_0=m_0+e_0,\qquad p_1=1-e_1,
\qquad d_{sign}=p_1-p_0=1-m_0-e_0-e_1.
\]

以原消息标签为基准的一次／两次累计错误率分别至多 δ0、δ1 时，`e0≤δ0,e1≤δ1`。两个标签不同是第二个包含关系的依据。定义 `Δ=|d_sign|` 后，得到

\[
\Delta\ge\max\{0,1-\varepsilon_{joint}-\delta_0-\delta_1\},
\quad \operatorname{bias}=\Delta/2,
\quad \Pr[\widehat b=b]=\tfrac12+d_{sign}/2.
\]

成员事件本身会筛选 r_loc 分布。证明通过联合事件与全执行虚拟错误界处理这一点。先独立抽样、再测试成员、非成员直接输出 update 的规则保留了正确的概率账目。update 分支的 H 分布可以任意变化，错误包含关系和精确式仍成立。

训练／目标币分布匹配具有实质性。例如在 q=2、m=2、Q=4 时，训练 X 恒为 (0,0)，目标 X 恒为 (0,1)，遗漏概率为 1。误用 iid 公式会给出 2/5。因此“公开可采”还必须与目标真实更新的条件分布相匹配。
