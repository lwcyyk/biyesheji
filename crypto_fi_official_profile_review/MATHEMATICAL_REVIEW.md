## 5. P：参数化判据及端点

一般数学参数为整数n,D,m̄,k≥1、q=2^D、0≤B≤D，χ为有限支撑对称整数分布。涉及模原子时先合并同余支撑点；称为FI打印域实例时再携带8∣n。令π=|𝓓|/q，𝓖为𝓑可测好事件，每个固定A满足Pr(𝓖ᶜ∣A)≤δ∈[0,1]。对每个好环境要求

\[
E[|p(V)-\pi|\mid\mathcal B]\le Z,\qquad 0\le Z<\infty.\tag{P1}
\]

定义C_k(π)=Σ_{j=0}^{k−1}π^j；π<1时等于(1−π^k)/(1−π)。对x∈[0,1]，x≤π时x^k≤π^k；x>π时

\[
\frac{x^k-\pi^k}{x-\pi}=\sum_{j=0}^{k-1}x^{k-1-j}\pi^j\le C_k(\pi).
\]

故E[p^k∣𝓑]≤F:=π^k+C_kZ。又有p^k≤p≤1，令f=min{1,F,π+Z}。真实坏概率b≤δ时，

\[
\Pr(J\mid A)\le(1-b)f+b\le(1-\delta)f+\delta.\tag{P2}
\]

F≤1时同一单调性给U_raw=(1−δ)F+δ；F>1时U_raw≥1，概率的平凡上界足够。因此候选原始公式在其全部声明范围成立。若需非平凡高错误率结论，仍须实际证明U<1。

好环境中E[p]≥(π−Z)₊；先用Jensen，再解除好事件，得

\[
\begin{aligned}
L_J&=(1-\delta)(\pi-Z)_+^k,&U_J&=(1-\delta)\min\{1,F,\pi+Z\}+\delta,\\
L_S&=(1-\delta)(\pi-Z)_+,&U_S&=(1-\delta)\min\{1,\pi+Z\}+\delta.
\end{aligned}\tag{P3}
\]

| 端点 | 准确处理 |
|---|---|
| π=0 | 𝓓为空，所有非空正确事件概率0；C_k=1 |
| π=1 | 𝓓为全群，正确事件概率1；C_k=Σ1=k，商式按连续延拓 |
| k=1 | C₁=1，行退化为指定坐标，P2/P3一致 |
| δ=1 | 通用区间退化到[0,1]，𝓖上的条件可以为空；π端点仍有其精确值 |
| Z≥π | Jensen通用下界为0；上界继续有效 |
| F≥1 | 截断版本采用min{1,F,π+Z}；U_raw≥1 |
| k=0 | 可单列空行概率1、C₀=0；当前算法命题取k≥1 |
| D=0或n=0 | 须按各自退化算法定义；本命题取n,D≥1 |

若“截断”还指好环境内p≤τ的进一步尾截断：τ∈[π,1]且Pr(p>τ∣𝓑)≤ε_τ时，C_τ=Σ_{j=0}^{k−1}τ^{k−1−j}π^j，点态分拆给E[p^k∣𝓑]≤π^k+C_τZ+ε_τ。当前证书采用全区间τ=1，额外尾引理保持未提供。

有限群反演与|𝓓̂(t)|≤|𝓓|给

\[
|p(V)-\pi|\le\pi\sum_{t=1}^{q-1}|\Phi_V(t)|.
\]

若每个好环境D_t≤R_t，R5给可用Z=πΣ_{t≠0}R_t^n。本轮按负频率共轭配对，采用2πΣ_{t=1}^{q/2}R_t^n；Nyquist额外计一次，方向保守。
