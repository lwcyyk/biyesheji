## 1. 阶段结论

G7 将 G1～G6 的密码学、凭据、生命周期、VDNS、扩展、隐私审计和可选事故响应整合为完整毕业设计交付：

```text
固定 E1～E8 数据与 schema
  → 一键完整密码管理演示
  → 全栈故障与恢复演练
  → 密码学/API/安全审计
  → 性能、正确性与 H1～H6 消融
  → 论文八章与 17 页答辩稿
  → AC-001～021 证据摘要和最终发布门禁
```

系统定位保持为完整密码管理器。隐私审计是持续安全能力，SCOPE-ZK 是事故时可选 provider，不进入解锁、查询、填充或普通同步路径。

## 3. 性能结果

| 指标 | P50 | P95 | P99 | 目标 |
|---|---:|---:|---:|---:|
| RootCapsule 解锁 | 168.86 ms | 392.85 ms | 734.26 ms | ≤ 1.5 s |
| 单 password 字段解密 | 0.084 ms | 0.331 ms | 0.334 ms | ≤ 10 ms |
| RouteMap 10k | 0.127 ms | 0.402 ms | 0.494 ms | ≤ 5 ms |
| RouteMap 100k | 0.115 ms | 0.299 ms | 0.530 ms | ≤ 25 ms |
| 10k 对象分批同步 | 584.15 ms | 614.70 ms | 651.11 ms | ≤ 2 s |
| 100k 叶证明验证 | 12.09 μs | 25.89 μs | 61.37 μs | ≤ 25 ms |
| 1m 叶证明验证 | 14.99 μs | 16.79 μs | 25.39 μs | ≤ 25 ms |

100k 审计真实扫描为 563.62 ms，低于 5 s 目标。百万叶证明含 20 个哈希，低于 32 个上限。

E3 发现真实设计债务：协议类型允许 10k 引用，但冻结的公共签名载荷上限为 64 KiB，单份 10k manifest 无法编码。实验改为 100 批、每批 100 对象，并把风险写入 API 和协议审计。

## 4. 正确性与可用性

故障 runner 实际执行 8 类场景：

- 云回滚、替换、缺对象和不完整对象；
- 日志 proof 变异、分叉、旧 root 和错误一致性；
- 锚定 provider 类型不匹配；
- 断网；
- 磁盘对象损坏和危险路径；
- 进程重启、幂等和 outbox；
- 网站响应丢失或负面结果；
- 撤销设备请求新 secret generation。

8/8 通过。

恢复演练覆盖锁定、断网、重启、高熵恢复、设备丢失、冲突和网站 UNKNOWN，7/7 通过。可复制操作步骤见运行与恢复手册。

H1～H6 对照矩阵保存在 `ablation-h1-h6.json`。完整方案引用可执行回归；弱化方案明确标记 `TEST_ONLY_DECISION_MODEL`。固定样本中的 0 次攻击接受不被表述为形式化安全证明。

## 5. 密码学和协议审计

`./scripts/check-g7-crypto.sh` 覆盖：

- Argon2id、HKDF、AES-GCM、Ed25519、HPKE、CBOR 和 Merkle KAT；
- key purpose 与签名/AEAD 域分离；
- 错误 context、篡改、重放和资源上限；
- Secret/Key JSON、格式化和销毁；
- 公开叶和审计结果最小化；
- L1～L5 负面矩阵。

385 个具名测试通过，失败包为 0。Go 对内存复制的限制使实现只能声称“尽力清零”，不宣称硬件级擦除。

## 6. API 复审

22 个 `/api/v2` operation 通过项目 `$ref` 感知 linter、实现库存、冻结 digest、幂等、分页、统一错误和 secret handle 测试。

评分为 86.35/100（B+），决定为 `PASS_WITH_DOCUMENTATION_DEBT`。第三方工具因不解引用 parameter `$ref` 产生 58 个假阳性；22 个缺少长描述是真实文档债务。

## 7. 安全工程

初始 `govulncheck` 在 Go 1.22.2 和旧依赖组合发现 30 个可达漏洞。项目升级至 Go 1.25.12 和兼容依赖，重新执行全量测试后：

- 可达漏洞 0；
- module-only advisory 1，位于未导入的 `x/crypto/openpgp`；
- `go mod verify` 通过；
- CycloneDX 1.5 SBOM 含 33 个组件；
- 未知/拒绝许可证均为 0；
- 项目秘密和扩展 CSP 扫描通过。

升级前后证据均保留。通用秘密扫描器的测试密码/摘要假阳性有独立裁决，不通过删除测试数据获得绿色结果。

- 完全控制已解锁端点；
- 根控制私钥失陷；
