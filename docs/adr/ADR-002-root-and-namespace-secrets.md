# ADR-002：根签名与名称空间秘密分离

- 状态：Accepted
- 追踪：FR-002～003、FR-007；AC-017

## 背景

白皮书中根控制权与审计/字段加密材料容易被误读为同一秘密。若复用，签名密钥泄露会直接暴露历史内容，设备撤销也无法隔离未来代际。

## 决策

`SKroot` 只做根授权签名；`Rᵤ[g]` 是每代独立 OS CSPRNG 生成的 32 字节对称秘密。撤销和正常轮换都生成全新 `Rᵤ[g+1]`，只用 HPKE 封装给仍获授权设备。

## 替代方案

- 从 `SKroot` 派生所有密钥：用途耦合且扩大泄露半径。
- 由旧代秘密确定派生新代：已撤销设备可计算未来代际。

## 后果

需要设备 envelope、代际确认与恢复流程；已撤销设备保存的旧代秘密仍可解密旧对象，这是明确残余风险。
