# ADR-009：Event Simulator 与 Mock Site 优先

- 状态：Accepted
- 追踪：FR-014～015、FR-039～041；AC-005、AC-008～009、AC-020～021

## 背景

真实浏览器扩展和任意网站改密页面不稳定、难以离线复现，也会把大量时间消耗在页面适配而非核心研究假设。

## 决策

先用 Event Simulator 产生受约束观察事件，用本地 Mock Site 覆盖成功、明确失败、超时和“网站已改但本地提交待恢复”；核心闭环通过后再接薄扩展。

## 替代方案

- 先做真实站点自动化：演示直观，但测试不可重复且存在账号风险。
- 只做后端单元测试：稳定，但无法验证跨系统失败原子性和交互。

## 后果

首版对任意网站自动化能力有限；换来完全离线、可故障注入和可量化的 E5/E6/E7 证据。
