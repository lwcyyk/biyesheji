# ADR-004：最终检查点决定安全顺序

- 状态：Accepted，后由ADR-013明确生产者与实现缺口
- 追踪：FR-006、FR-016～023；AC-002～004、AC-006

## 背景

设备时间可回拨、漂移或伪造，无法裁决“操作是否发生在撤销之前”。仅按接收时间也会受离线重试和网络重排影响。

## 决策

撤销、能力有效性、版本接受和未来Epoch绑定都使用最终序；墙钟只用于展示与分析窗口检索。ADR-013进一步规定最终序由Final Order Authority签发排序回执，透明日志负责追加和证明，锚定层负责周期公告。当前原型尚未实现该Authority，调用方提供的序号不能直接称为生产最终序。

## 替代方案

- 设备时间：离线友好但不可信。
- 服务接收时间：集中且无法证明跨视图顺序。

## 后果

高风险写操作在最终状态不可得时 fail closed；读操作只能在明确缓存窗口内降级，并展示证据新鲜度。
