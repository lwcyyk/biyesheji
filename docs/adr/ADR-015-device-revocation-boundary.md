# ADR-015：设备撤销边界

- 状态：Accepted
- 日期：2026-07-31
- 追踪：FR-005～008、FR-027、FR-030；AC-007～009

## 背景

撤销一个设备不能远程删除该设备已经读取、复制或导出的密码。把控制权限撤销、根秘密轮换和网站密码修改写成一个动作会产生错误安全承诺。

## 决策

设备撤销固定拆为三层：

### 1. 控制面撤销

发布并最终化设备撤销状态。自撤销`finalSequence`起拒绝该设备的新操作、能力续签、同步提交和新设备加入请求。历史签名仍可验证，不能从日志删除。

### 2. 秘密代际隔离

生成独立随机`Rᵤ[g+1]`，只通过HPKE封装给剩余活动设备。新建和更新对象使用新代际。旧代际保留用于合法设备读取历史，不再发送给撤销设备。

### 3. 外部凭据修复

对撤销设备可能接触过的网站密码、TOTP、恢复码、会话、API token和SSO绑定逐项评估并轮换/撤销。该层依赖站点真实结果和恢复安全，不能由控制面撤销自动宣告完成。

产品状态和审计必须分别记录三层进度。只有第一层最终化后才称“设备控制权限已撤销”；只有第二层完成后才称“新名称空间秘密已隔离”；只有第三层获得相应确认后才称“外部凭据已修复”。

## 后果

- UI必须显示“该设备此前知道的密码仍可能可用”。
- 撤销与外部修复失败互不伪装成功。
- 第二阶段增加三层状态、恢复锁定风险和部分失败测试。
