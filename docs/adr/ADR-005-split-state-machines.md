# ADR-005：五状态机分离

- 状态：Accepted
- 追踪：FR-013、FR-015、FR-018、FR-020～021、FR-039～043；AC-001、AC-008～010、AC-014

## 背景

单一“凭据状态”无法表达旧密码仍 ACTIVE、新密码已 PENDING、事件仍待发布、网站状态未知等并发事实，容易造成锁号或过早完成。

## 决策

分别建模设备、事件发布、凭据聚合、凭据版本、Campaign/Item；所有迁移由领域函数验证并通过事务/CAS 写入。

## 替代方案

- 单状态枚举：表少，但组合状态丢失且恢复歧义。
- 只用事件溯源：可表达历史，但首版查询、迁移和审计复杂度过高。

## 后果

表和测试矩阵增加；换来旧/新版本并存、单项失败隔离和每个崩溃点的确定恢复路径。
