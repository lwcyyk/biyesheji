# ADR-001：模块化单体与独立 Monitor

- 状态：Accepted
- 追踪：NFR-MNT-001～002；AC-020～021

## 背景

系统需要身份、凭据、审计、透明日志、解析和轮换的强事务协作，同时答辩环境不得依赖外部编排系统。Monitor 又必须保持独立观察视角，不能与服务进程共享已接受状态。

## 决策

核心采用 Go 模块化单体与六边形端口/适配器；`vdnsd` 是唯一装配根。`vdns-monitor` 独立进程、独立存储观察结果，通过公开接口取证。

## 替代方案

- 微服务：边界明显，但引入分布式事务、部署和故障面，不符合原型目标。
- 完全单进程：实现简单，但无法支持独立 split-view 观察假设。

## 后果

领域包不得导入 HTTP、SQLite、文件系统或链 SDK；模块边界由架构测试执行。单机扩展性是已知限制，论文只按实测规模陈述。
