# ADR-006：AffectedRoot 的证明边界

- 状态：Accepted
- 追踪：FR-028～032；AC-006、AC-010、AC-015

## 背景

对本地加密审计扫描所得集合做 Merkle 承诺，可以防止轮换后替换成员；但在没有公开全部审计明文或零知识完整性证明时，第三方无法证明扫描没有漏项。

## 决策

AffectedRoot 只证明 Campaign 与已提交集合、排序和策略的绑定，不宣称自动证明相对于所有历史证据的全局完整性。分析报告单独给出窗口、证据源和局限。

## 替代方案

- 公开 ReuseTag/Origin：便于第三方扫描，但产生关联与离线猜测风险。
- 首版加入零知识完整性证明：研究价值高，但超出可交付范围。

## 后果

论文和 UI 必须使用“绑定性承诺”措辞；完整性增强保留为后续研究，不能用根值掩盖数据源局限。
