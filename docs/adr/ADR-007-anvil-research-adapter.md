# ADR-007：Anvil 是共识研究适配器

- 状态：Accepted
- 追踪：FR-021、FR-029；AC-005～006、AC-021

> ADR-012进一步将其定性为本地EVM检查点公告研究适配器。名称中的“共识”不表示当前仓库实现了多节点共识或生产最终性。

## 背景

答辩需要演示检查点合约的真实 EVM 执行，但本地单节点 Anvil 没有生产网络的独立验证者、经济安全或重组特性。

## 决策

使用 Solidity + Foundry/Anvil 执行最小检查点注册合约；所有 UI、日志与论文结果标记为“本地共识研究适配器”，不等价生产链最终性。

## 替代方案

- 直接连接公链：成本、稳定性和隐私不适合离线答辩。
- 完全 mock：无法验证 ABI、事件和合约不变量。

## 后果

能复现 EVM 行为和冲突拒绝，但安全结论必须限定在模拟最终性；生产化需新增网络、确认和重组 ADR。
