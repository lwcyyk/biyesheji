for           outsourced          ﬁle           storage           with           forward-security           and           ﬁne-grained           secure          shred-
ding        of        ﬁles.        In        a        recent        work,        Backendal,        Günther        and        Paterson        [      44]        introduced
such          a          so-called          protected          ﬁle          storage          setting          and          show          how          this          can          be          instan-
tiated             via             puncturable             key             wrapping             (introduced             in             the             same             work).             Loosely
speaking,             Backendal             et             al.             achieve             forward-security             via             key-rotation             (but             this
requires        to        download,        decrypt        and        re-encrypt        of        all        ﬁle        encryption        keys)        and        the
shredding         of         ﬁles         is         achieved         via         key-puncturing.
         We        observe        that        the        concept        of        epochs        in        TIPE        (used        as        expiry        epochs        when
instantiating               UE               from               TIPE)               allows               to               implement               the               ﬁne-grained               forward-
security              aspect              via              eﬃcient              key-rotation              (though              in              contrast              to              [    44]              via              help
of             the             server).             Moreover,             the             ciphertext-tag             space             in             TIPE             provides             an             addi-
tional        dimension        for        granularity        which        allows        to        implement        a        secure        ﬁne-grained
shredding         of         ﬁles,         i.e.,         via         puncturing         of         the         ciphertext         (by         excluding         them         from
updates).       We       hope       that       TIPE       will       ﬁnd       additional       applications       in       this       and       beyond
this         context         and         leave          a         more          detailed          study         to         future         work.
