## 2. 共同接口与评分

L≥2 为最大生成代次，Q 为查询总数上界，二者是 κ 的固定多项式。一次自适应挑战，当前代次 c∈{2,…,L}，输入 M0 和上一代的普通登记父对象，其明文 M1 由 oracle 记录。b=0 返回 fresh Enc_c(M0)，b=1 返回 Upd(Δ_c,parent)。只有密文、同格式 opaque id 和代次公开，不泄露分支标签。

普通 `EncLeak`、`UpdLeak` 在挑战前后都自适应可用并返回完整带；同父重复更新独立采样。UpdLeak 只接受诚实普通登记 id，不提供任意密文导入。攻击者可以离线任意计算；新 id 不能把挑战来源变成普通来源。Gen/Next 和挑战链的带隐藏。无 Dec oracle。

`Next` 生成当前钥匙/token，推进服务端私有挑战状态，公开 P_e；`GetChallenge` 只返回当前代次的同一版本，重复读取不重新采样。已经公开的历史版本可保留。内部未返回的版本没有被算作公开。

`CorruptKey(j)`、`CorruptToken(j)` 对已生成对象返回完整对象并记录暴露；j>当前代次返回 ⊥，不添加暴露。不存在预先公开的挑战切点，也不能在真实游戏中为归约方便拒绝尚合法的历史腐化。格式不合格请求返回 ⊥；没有发起合法挑战的执行计零优势。

游戏采用 GP23 的**最终有效性评分**：最终历史非法时用独立均匀位替换猜测；合法时保留猜测。令

    Z_G=1_{有合法挑战且整段历史有效}·(1_{b'=b}−1/2)，
    Adv_G=|E Z_G|.

这等于按均匀 b 抽样的成功率 bias。GP23 的两实验输出概率差为此值的 2 倍。非法历史中止并评分为公平币，只保持最终评分，不声明非法轨迹的完整响应分布相同。

## 3. 三个集合的最小不动点

在每个前缀已生成代次 {1,…,e} 上，K 是直接暴露完整钥匙的代次，T 是直接暴露完整 token 的目标代次，C 是 Chall/Get 实际返回挑战版本的代次。求最小三元组 (K*,T*,C*)，包含 (K,T,C)，并闭合于：

    j∈K* 且 j∈T*       ⇒ j−1∈K*                  (j≥2)
    {j−1,j}⊆K*          ⇒ j∈T*
    j−1∈C* 且 j∈T*     ⇒ j∈C*.

钥匙反推与密文前推分别对应已冻结算法。token 可由相邻完整钥匙的倍率比及公开新坐标公钥生成。所有规则同时迭代到不动点，不要求中间版本被实际调用过。

第二条不会新增加 K*：它产生的反向边两端本已在 K*。但它仍须加入 T*、参与 C*。这给出与 GP23 先用 T 算 K*、再扩展 T* 的对应；单链有限集合上结果一致。

历史非法的条件是某个提交挑战后的前缀有 K*∩C*≠∅。K/T/C 只增不减，故与最终交集非空等价。挑战前的全部钥匙/token 查询在挑战确定后重新参与检查，旧查询不被遗忘。后续诚实更新不能修复一次已经发生的交集。

这些是原游戏的显式代数闭包，不是“攻击者能计算的一切”的可判定 oracle。部分坐标的推导仍可能被攻击者使用；安全证明必须覆盖它们，不能把潜在新攻击通过定义追认为非法。

## 4. G-ALL-ADAPT

每次 Next 将完整 Δ_e 加入 T；公钥编码同样公开。挑战 c 自适应选择，钥匙查询以最终真实 c 的闭包评分。

**闭包引理。** 一旦挑战 c 已公开，每个已经生成的 j≥c 都属于 C*。任何完整 K_j、j≥c 的暴露直接命中，且还可沿全部 token 反推 K_c。只有 j<c 的历史完整钥匙可能合法。挑战前已经取得 j≥c 的钥匙在选 c 时同样非法。

证明是从 c 逐边前推、从 j 逐边后推的有限归纳。它不依赖 GetChallenge 是否公开后来官方版本。因此本 profile **没有合法未来完整钥匙**；证明只需回答真正合法的历史钥匙。若先暴露 K5，再把挑战选在 c6，该历史暴露仍可合法；不得预先禁止它。

## 5. G-SELECT-ADAPT

Next 保留 Δ_e 私有，仅公开 P_e；`CorruptToken(j)` 再选择性公开完整 token。普通 UpdLeak 即使在该 token 未公开时也可由可信 oracle 执行并返回真实带。其它接口和评分相同。

该暴露模式由 GP23 Fig.2 的 O.Corr/O.Upd/O.UpdC 与 p408 C 定义支持。本游戏增加完整普通带和每代公钥向量暴露，并冻结具体群实例、独立 tape 及 1-based profile；它没有被标成“原定理无需修改即可涵盖的同一个游戏”。

钥匙、token 和当前 Get 查询仍实际返回；若后来公开一条边或一个新版本才使交集出现，则从此历史非法。G-ALL 是 token 全部暴露的特例；选择性游戏允许闭包之外的未来完整钥匙。新的闭包实例与证明见另两份交付。

## 6. 与接口处拒绝的准确关系

已出现交集后，继续运行不会使它消失，故可立即终止并以公平币评分，优势完全相同。挑战前尚未确定 c 时，或者闭包仍不交时，提前拒绝钥匙/token 可能移除合法攻击路径，不能称作原游戏等价。

归约的“猜错边界/命中未知钥匙”中止属于模拟器的猜测损失；真实游戏里其中一些查询仍然合法。各证明通过带权事件与最终匹配筛选记账，不把归约中止改写成游戏禁止条件。
