# 选择性 token 下的完整未来钥匙联合模拟

本文件针对已冻结 UNIUE-GP23-EG-CTX1 和 G-SELECT-ADAPT。它补足隐藏 token 边界，不能以“R2-LOCAL 已证明一切”代替本节。理想精确采样下给完整证明，有限 PPT 误差最后计入。

## 1. 普通表示桥接引理 NORMAL-BRIDGE

每个诚实普通坐标保存标量 ρ_i 和群 pad w_i，使

    C_i=(P_{e,i}^{ρ_i},g^{ρ_i}w_i)，Z=M∏w_i.

Enc 的 ρ_i、w_i 来自模拟器自己采的完整带。给定普通父的这个表示，任意新真实 Upd 带 η 中含 a_i、s_i、新 pad v_i，则旧坐标的正确输出为

    C_i'=(P_{e+1,i}^{ρ_i+a_i+s_i},g^{ρ_i+a_i+s_i}w_i v_i).

**引理。** 即使迁移倍率 δ_i 未知，只要 `P_{e+1,i}=P_{e,i}^{δ_i}` 成立，上式逐点等于实际 `KHC(δ_i,P_{e+1,i},C_i;a_i)·Enc(P_{e+1,i},v_i;s_i)`。新坐标照常加密。模拟器可返回 η 的完整位带，并保存 ρ_i'=ρ_i+a_i+s_i、w_i'=w_i v_i。

证明：将父首分量代入 `(P_e^{ρ_i})^{δ_i}=P_{e+1}^{ρ_i}`，其次分量及消息掩码按相同乘法更新。所有等式对每一条实际 η 成立，故不需要事后找一个打开值。重复父输入独立采 η，共享同一个 P_{e+1}，所有回答与后续钥匙检查同时一致。□

完整带只包括 Upd 自己的随机输入；δ 是 token 输入而非该带。Gen/Next 带隐藏。若允许任意未经诚实登记的父密文，模拟器可能不知道 ρ_i，此引理没有覆盖该接口。

## 2. 整条官方挑战链的新鲜化 UNI-FRESH-CHAIN

先固定整条诚实钥匙/token 轨迹 θ（可在概念上预采至 L），固定挑战位 b 和普通父明文 M_b。UNI-FRESH 的代数平移对任意诚实父表示成立，包括之前的挑战父；不要求模拟器知道该表示。

给定 θ 和任意此前公开历史，隐藏新带的官方更新输出分布只依赖 M_b、目标公钥，等于 fresh Enc_e(M_b)，与父的具体 pad/指数无关。因此真实官方链可在**每个代次**改为一次独立 Enc_e(M_b)。同代重复 Get 返回该同一对象。全部正常接口保留原带，钥匙/token 查询仍来自同一 θ。

这是逐次转移核相等的归纳，得到所有公开版本、普通完整带及任意自适应合法钥匙响应的联合分布相等。不能先随机化某个挑战，再用“其明文还是 M_b”调用此引理；后续混合是在已经得到的独立流表示中定义。

官方当前版本可惰性生成：第 e 代第一次 Chall/Get 才物化，重复读取缓存；未公开且随后越过的私有版本可丢弃。原 Next 的内部随机化不会产生其它公共输出，因此该惰性表示精确保持观测分布，不是改变运行算法。

惰性处理仅作用于尚未读取的群值；公开代次、计数器及句柄预留按同一接口执行，不能借推迟物化改变正常响应的元数据。

## 3. 混合及规范边界

H_i（i=1,…,L）具有同一诚实 θ、普通接口和最终闭包评分；一次挑战实际发生在自适应 c≥2。所有官方挑战版本按独立流生成：

- c≤e≤i：fresh Enc_e(M_b)；
- e>i：均匀 G^{2e+1} 元素向量。

H_L 由上节与真实 G-SELECT 精确同分布。H_1 所有官方版本均匀，整个公共视图及合法性决定与 b 独立，中心评分 μ_1=0。记 μ_i=E[Z_{H_i}]，则真实 signed bias 为 μ_L，且 μ_L=Σ_{j=2}^L(μ_j−μ_{j−1})。

对最终历史中**实际公开的官方第 j 代版本**（j∈C），定义 r_j 为从 j 沿最终 T* 连续前推能到达的最后生成代次。即 Δ_{j+1},…,Δ_{r_j}∈T*，且下一 token 若存在则不在 T*。合法性保证所有 K_j,…,K_{r_j} 都不在 K*。r_j 由最终历史决定，可能依赖看到的挑战；不假定它独立于 DDH 世界。

若第 j 代官方版本从未公开，H_j/H_{j−1} 的差异没有公共读出路径。由于所有后代在该独立流中另行采样，含同一 b 的未公开路径中心评分贡献在两侧相等；改变一个看不到的内部样本不会通过后代传出。攻击者自行用公开 token 更新其它已经看见的版本，仍是该相同公共历史的计算。

## 4. 猜测 (J,R) 与完整后台

归约在交互前独立均匀猜

    (J,R)∈{(j,r):2≤j≤r≤L}，F=L(L−1)/2.

输入 DDH* `(g,X,U,V)`，在 J 代的新第 J 坐标嵌入 X。状态表如下。

| 对象/区间 | 已知标量 | 编码/隐含量 | 可响应对象 |
|---|---|---|---|
| e<J | 全部 K_e、token 倍率 | 真实公钥 | 全部历史钥匙、普通带 |
| J≤e≤R | 第 J 坐标以外的全部秘密；累计 d_e；所有内部 token 倍率 | x_{e,J}=x d_e 隐含，P_{e,J}=X^{d_e} | 普通 Enc/Upd 全带；内部 token；第 J 官方挑战 |
| t=R+1≤L | 独立采完整新 K_t=(y_1,…,y_t) | δ_{t,J}=y_J/(x d_R) 隐含；其它 δ_{t,i}可计算；P_t全公开 | 全部 K_t；跨边界普通更新经 NORMAL-BRIDGE |
| e>t | 从已知 K_t 正常演进的全部秘密及倍率 | 实际 P_e | 任意未来完整钥匙及 token（边界 t 除外） |

R=L 时没有右边界，区间内未来钥匙在匹配合法路径均不可能查询。

### 真实分布为何保持

对固定旧非零钥匙向量，独立均匀倍率生成的新旧坐标 `x_new,i=δ_i x_old,i` 均匀且相互独立。改为先独立采 y_i，再定义 δ_i=y_i/x_old,i，是坐标逐一的双射重参数化，联合分布精确相同。边界新坐标也独立采样。全部 P_t=g^{y_i} 在第一次公开时就固定，之后没有更改已公开公钥。

隐含 δ_{t,J} 不是可计算标量；归约没有声称知道它，也未产生它的 Gen/Next 采样带。它的诚实分布由上述双射定义；该带和数值在匹配路径不被输出。普通边界更新使用 NORMAL-BRIDGE，依照每个真实 η 保持逐点等式。

### 每个 oracle

EncLeak 一律用公开 P_e 自采全带；普通 Upd 在通常位置执行真实算法，在边界 t 用桥接等式，所有表示和来源保存。CorruptKey 在区间外返回**全部坐标标量**（连同所需的公开键对象）；没有以公钥代替钥匙。CorruptToken 在非边界返回实际全部倍率及新坐标公钥。Get/Challenge 在 H_J/H_{J−1} 流规则下同代缓存。

先执行共同的存在性/代次检查：尚未生成的对象查询返回 ⊥，不记入暴露集。对于**已生成对象**，若在区间 [J,R] 查询完整钥匙，或查询边界 token t，模拟器输出公平币结束。某些此类查询在真实游戏中确实合法；它们属于猜错/不匹配，而非额外游戏禁止条件。第6节给出没有遗漏合法优势的事件证明。

## 5. 一个 DDH 同时替换第 J 代整份挑战

第 J 代若实际被公开，c≤J，归约已知本轮的 M0、M1，内部采 b。取均匀 Z，非锚坐标 i≠J 各采均匀 pad w_i 和加密指数；令

    w_J=Z/(M_b∏_{i≠J}w_i)，C_J的锚坐标=(V,U w_J).

DDH 真实：这是 fresh Enc_J(M_b)，其它已公开/潜在官方版本按 H_J。

DDH 随机：锚坐标在固定 Z、其它全部数据条件下均匀于 G²。对任何固定非零公钥，`(r,w)→(P^r,g^r w)` 是从 Z_q×G 到 G² 的双射，故其它坐标也独立均匀。于是**整份**第 J 密文精确均匀于 G^{2J+1}，对应 H_{J−1}。这里只需编码 w_J，不返回其未知离散对数或 DDH 加密指数。

两侧普通带、P_e、token/未来钥匙都按同一上述后台产生；其它官方版本按第2节已经证明可用的独立流混合生成。真实链到这个表示的转移核等价已经先行证明，跨隐藏边界的混合生成因此只需公开编码。

## 6. 带权筛选与完整优势界

定义 E_{j,r} 为最终历史满足：有合法挑战、整体有效、j∈C 且 r_j=r。集合计算只读公开查询元数据和闭包，不需求未知标量。

固定猜测 (j,r)，归约在完成时只在 E_{j,r} 成立时输出 `[b'=b]`，其它时输出公平币。它若提前遇到不能回答的查询，也输出公平币：

- 查询 K_h、j≤h≤r：若最后 j∈C 且连续边到 r 全公开，这个钥匙使历史非法，所以没有 E_{j,r} 的合法续接。
- 查询 Δ_{r+1}：若内部边最终连续，规范边界超过 r；若不连续，边界小于 r。两种情况都不满足 E_{j,r}。
- j 没生成或没公开：没有该步混合的可见差异。

因此中止没有删除任何与该猜测匹配的合法子概率质量。在匹配质量上，状态/普通带/完整未来钥匙均与相应 H_j 或 H_{j−1} 精确同分布。定义

    z_i(j,r)=E_{H_i}[Z_{H_i}·1_{j∈C且r_j=r}].

归约真实/随机输出概率差为 `z_j(j,r)−z_{j−1}(j,r)`。对均匀三角猜测求和，利用 r 分割所有可见 j 路径、不可见 j 的差异为0：

    Pr[D(real)=1]−Pr[D(random)=1]
      = (1/F)Σ_{j=2}^L Σ_{r=j}^L[z_j(j,r)−z_{j−1}(j,r)]
      = (1/F)Σ_{j=2}^L(μ_j−μ_{j−1})
      = μ_L/F.

**定理 SELECT-ADAPT。** `Adv_SELECT(A)=F·Adv_DDH*(D)`。规范边界、挑战选择和有效性事件可以依赖挑战内容；证明没有使用它们与未知位/猜测独立的假设。中止本身可能依赖看到的挑战，所以必须保留这一带权筛选，不能简单乘一个“成功猜中概率”。

与 ALL 相同，严格 PPT/标准 DDH 的保守界为

    Adv_SELECT^cap ≤ F/(1−1/q)·Adv_DDH(D_cap') + (2F+1)N2^(−B).

可取 N=10(QL+L²+1)。普通查询次数只进入运行成本及该采样误差，未额外乘 Q。时间、输出和存储界同 ALL 的多项式上界。理想精确采样的数学等式与实际有限采样的误差分开。

## 7. 外部反方可直接核对的等式

对所有已经固定的公开值及普通记录，必须同时有

    P_{e,i}=g^{x_{e,i}}，P_{e+1,i}=P_{e,i}^{δ_{e+1,i}}，
    C_{N,e,i}=(P_{e,i}^{ρ_{N,e,i}},g^{ρ_{N,e,i}}w_{N,e,i})，
    C_{N,e+1}=Upd(Δ_{e+1},C_{N,e};η_N)，
    ρ_{N,e+1,i}=ρ_{N,e,i}+a_i+s_i，w_{N,e+1,i}=w_{N,e,i}v_i.

边界未来钥匙 y 是完整实际标量对象；这些等式在返回 K_t、K_{t+1} 后仍可一起检查。同父重复更新的 η 相互独立，历史带从未被改写。隐藏边界的 δ 日后公开会暴露编程关系；这样的查询并未被真实游戏统一拒绝，而由归约的规范边界筛选计入猜测损失。

没有发现由该模拟障碍直接推出的实方案攻击。这里给出的是一个可检查的增强安全证明候选；其外部充分性和优先权尚待独立核查。
