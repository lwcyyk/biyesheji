# G-ALL-ADAPT：完整自适应归约

设 M=L−1，L≥2。所有优势以 bias `|E Z_G|` 计，DDH* 优势以真实/随机输入输出概率差计。沿用固定 profile 的精确群分布及普通完整 tape 定义。

## 1. 定理 ALL-ADAPT

对任意最多 Q 查询、L 代的 G-ALL-ADAPT 攻击者 A，存在 DDH* 判定器 D 满足

    Adv_ALL(A)=M·Adv_DDH*(D).

这是理想精确采样的等式，归约为期望多项式时间。换用标准 DDH 的全域 x、以及每次至多 B 轮的严格 PPT 采样器时，令 τ=1−1/q、每批标量抽样数上界 N，则可保守写为

    Adv_ALL^cap(A) ≤ M/τ·Adv_DDH(D_cap') + (2M+1)N·2^(−B).

普通重复查询没有额外 Q 次混合损失；Q 进入时间、输出量和 N。固定切点损失1与此 M 损失分别报告。

## 2. 归约何时放置未知秘密

D 收到 `(g,X=g^x,U=g^r,V)`，在交互前独立采 J←{2,…,L}。所有普通钥匙/倍率诚实产生；到第 J 代时把新增公钥 p_{J,J} 设为 X。以后该坐标隐含为

    x_{e,J}=x d_e，p_{e,J}=X^{d_e}，d_e 已知。

J 之前所有钥匙都完整已知。所有普通 Enc/Upd 只读取公开键/token及自采带，因而可诚实执行并返回完整位串，重复输入也独立。在挑战之前 V、U 不参与任何回答；X 的分布与诚实非零新公钥完全相同。

### 事件处理

- 实际合法挑战 c=J：使用固定切点的 DDH 锚坐标生成；更新分支先用 UNI-FRESH 精确新鲜化。其余普通接口保持真实算法。
- c≠J：立即输出独立公平币，不声称完成一条正确的别的切点模拟。
- 在实际挑战前请求现有 K_h、h≥J：无法回答隐含标量，归约停止输出公平币。该查询在真实游戏可能合法；若最后 c=J，它必为非法历史，所以不会移除本次匹配的合法贡献。
- 匹配挑战后请求 K_h、h≥J：真实闭包已经非法，归约可以按该终态输出公平币。
- J 没生成、没有发起挑战、输入无合法父对象或最终无效：公平币评分。真实已有历史腐化 K_h、h<J 均完整回答。

未知键中止发生在 U/V 被用作挑战之前时不依赖 DDH 真假；之后的中止必须按真实有效性或最终匹配事件记账。不能把它的发生概率直接忽略。

## 3. 带权事件证明：自适应选择不能跳过

在真实参考游戏 R 中令

    a_i = E_R[ Z_G · 1_{挑战代次 c=i} ]，i=2,…,L。

于是 `Adv_ALL(A)=|Σ a_i|`。每个 a_i 已包含全部历史有效性、前后腐化及没有挑战的零评分。

固定归约猜测 J=i。DDH 真实输入下，在 `c=i 且历史有效` 的参考路径上，未知新指数 X、所有普通带、token和挑战的**联合分布**与 R 一致。一次早于挑战的 K_h、h≥i 中止不可能有这样的合法续接。c≠i、无挑战或非法的路径由归约赋零中心评分。因此

    Pr[D(real)=1 | J=i] = 1/2 + a_i.

DDH 随机输入下，匹配挑战的完整密文与 b 独立（固定切点定理的随机世界）；匹配前的决定只看到 X 和普通回答，没有 U/V。以后的查询、合法性事件和历史响应都来自同一个不读取 b 的后台。所有猜错或无法匹配的路径仍由公平币赋分，故

    Pr[D(random)=1 | J=i]=1/2.

对独立均匀 J 求和：真实/随机输出差为 `(Σ a_i)/M`，取绝对值即得定理。a_i 可有不同符号；线性求和先于取绝对值，因此没有省略可能的抵消，也没有把“猜中概率1/M”当作独立性证明。

对实际 A，某个公共键可能影响它选择挑战代次；上述等式按每个 i 的未正规化事件概率建立，仍有效，不要求挑战选择与 X 无关。

## 4. 精确损失、有限采样与成本

DDH* 的 x 在 Z_q*；标准 DDH 在 X=1 时输出公平币，其它时运行模拟，真实/随机概率差缩放 τ=1−1/q，得到 M/τ。

每次 F_q/F_q* 或有限索引的拒绝采样接受概率至少1/2。可取保守 `N=10(QL+L²+1)`，包括模拟器猜测及所有正常/秘密标量。截断真实游戏相对理想游戏评分误差≤ε_A=N2^(−B)；判定器两种 DDH 世界的输出概率各误差≤ε_D=N2^(−B)，故优势差≤2ε_D。于是

    Adv_ALL^cap ≤ M(Adv_DDH*(D_cap)+2ε_D)+ε_A，

再作 τ 条件化即得首页界。旧固定切点报告中的 ε_samp 是合并误差；本轮显式展开，不能将单次采样失败率直接代入。

群运算 O(QL+L²)，位带/普通表示和历史钥匙存储 O(QL+L²) 个标量/群元素。用朴素最小不动点校验，每次最多多项式 O(L³) 整数操作；总时间

    t_A + O((QL+L²)T_G + QL³ + NB log q).

普通带和所有响应的序列化长度为 `O((QL+L²)(B log q+ell_G))`。没有额外随每次普通查询累乘的优势因子。

## 5. 结论范围

G-ALL-ADAPT 证明完成。它回答真正合法的任意历史完整钥匙，不提供被其自身闭包排除的未来钥匙。合法未来完整钥匙存在于下一份选择性游戏，而非此 profile 的隐藏需求。
