# 合法查询见证与负控制

状态均按 GAME_AND_CLOSURE 的三元最小不动点，E 为最后生成代次。普通对象和挑战对象使用不同来源标签；所有普通带保存历史。下表不是原生实验，有限集合工具只核对指定集合。

## 1. G-ALL 的自适应历史腐化

在 1 代普通 Enc，Next 到 2、腐化 K2，再 Next 到 3、以普通 2 代父对象发起 c3 挑战，随后 Next4。T={2,3,4}，K={2}，C={3}。

    K*={1,2}，T*={2,3,4}，C*={3,4}，交集为空。

因此挑战前 K2 查询合法。这说明固定切点证明里的“所有 j≥2 都拒绝”不能直接移到自适应游戏。若改在 c2 挑战，同一 K2 历史命中目标；若 c3 后查询 K4，反推 K3 并命中闭包。Get4 是否调用都不改变全 token 下的非法性。

## 2. 用户指定的 G-SELECT 骨架

1. 1 代 EncLeak 得普通 N1，保存其完整 pad/指数带。
2. Next2；可公开 Δ2。对同父 N1 执行两次普通 UpdLeak，分别保存独立 η。随后以 N1 为父公开 C2*。
3. Next3，公开 P3 的群编码，Δ3 保持隐藏，不调用 Get3。允许对普通 N2 调 UpdLeak：token 仍是 oracle 的私有输入，返回带不含该 token。
4. Next4，公开 P4；公开 Δ4，不调用 Get4。查询完整 K4。

取最小集合 K={4}、T={2,4}（Δ2 可省略，不影响以下结论）、C={2}：

    K*={3,4}，T*={2,4}，C*={2}，交集为空。

K4 与 Δ4 给出完整 K3，但 Δ3 未公开，不能由这两者反推完整 K2；C2 没有可用的第 3 代更新边。原文 Next 内部生成 C3、C4 不等于把它们返回给攻击者，因此该骨架在实际 oracle 模式下成立。

## 3. 分别加入一个公开动作

| 在上例基础上单独加入 | K* | T* | C* | 判定 |
|---|---|---|---|---|
| CorruptToken(3) | {1,2,3,4} | {2,3,4} | {2,3,4} | 非法，既可更新 C2，也可反推 K2 |
| Get3（需在第3代执行并保存） | {3,4} | {2,4} | {2,3,4} | 非法，公开 C3 可由 K3 解密 |
| Get4 | {3,4} | {2,4} | {2,4} | 非法，K4 与 C4 同代 |

如果 Get3/Get4 发生在 K4 查询之前，它们当时可能尚未造成交集；后续 K4 使该**历史**转为非法。若 K4 在先，新的 Get 当时就触发交集。原图只提供当前 Get，不能在第4代再首次追溯读取未曾返回的第3代版本；这里的 Get3 是在第3代实际发生的动作。

## 4. 编码与倍率分开

P2、P3、P4 都公开，包含 g^{x_{e,i}}，不等于公开 δ_{3,i}=x_{3,i}/x_{2,i}。在上述 K4/Δ4 暴露后，x_{3,i} 可知；初始/历史 K1 与 Δ2 还可能让 x_{2,1} 可知，所以**部分** δ3 坐标可计算。新增于第2代的 x_{2,2} 仍是未知标量，δ_{3,2} 不能被当作已知数值。

这里没有把“离散对数困难”当作闭包规则；完整安全归约会把全部公开群编码、已知未来标量、部分倍率推导和正常完整带交给攻击者共同处理。若它们导致非忽略攻击，归约必须据此区分 DDH。

对固定非单位旧公钥，群编码关系已唯一确定迁移倍率；这里没有声称条件统计熵仍然存在。区分的是“持有这些编码”和“可高效获得该标量”，模拟器始终按唯一编码关系保持一致。

相邻完整钥匙推 token 的正控制：若 K2 和 K3 均暴露，即使未调用 CorruptToken3，T* 也包含 3，C2 可达3且本来K2已命中，非法。不能以只看显式 T 而漏记此边。

## 5. 完整未来钥匙的可检查见证

固定 c2、隐藏边界 3、末代4，归约在第2坐标保存

    p_{2,2}=X=g^x（x未知），
    x_{3,2}=y2（自采已知），δ_{3,2}=y2/x（隐含且不输出），
    x_{4,2}=δ_{4,2}y2（已知）.

其余坐标诚实采样。K4 返回 `(x_{4,1},x_{4,2},x_{4,3},x_{4,4})` **全部标量**，并使每个 g^{x4i}=p4i；除 Δ4 后得到的完整 K3 也与 P3 相符。

普通父 N2 的表示 `(p2i^{ρ_i},g^{ρ_i}w_i)` 已知。对跨第3代边界的新带 `(a_i,s_i,v_i)`，返回

    u_i'=p3i^{ρ_i+a_i+s_i}，v_i'=g^{ρ_i+a_i+s_i}w_i v_i，

正好等于原算法使用隐含 δ3 的结果。同父第二次更新用另一独立新带，也通过共同的 P3/未来 K3 检查。数学证明见 FUTURE_KEY_SIMULATION，未求 x 或 δ_{3,2} 的离散对数。
