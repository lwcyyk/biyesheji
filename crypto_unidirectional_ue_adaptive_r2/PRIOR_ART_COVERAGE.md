## 1. GP23 原文支持和本轮新增部分

GP23 p407 Fig.2 提供自适应 O.Corr(key/token)、普通更新及当前 O.UpdC；Next 只内部更新，不将该私有版本加入 C。p408 的直接 C 定义也只列 Chall/Get；pp408–409 的式 (1)–(3) 给钥匙反推、相邻钥匙推 token、挑战前推。p420 Fig.5 是本轮固定算法的泛型来源。

pp421–423 Theorem 3/Fig.6 已使用随机右边界、边界后的完整独立钥匙、公开键模拟及挑战 real→random 混合。它不是只回答公钥的方案：Fig.6 在 fwr+1 采完整新 sk 向量，因此“存在合法未来钥匙”这一步已有成熟技术依据。

但原图对普通 O.Upd 返回 `UNIUE.Enc(pk_e,m)`，没有给这份新输出与实际 Upd 的完整带配套的规则。本轮不能逐字引用该算法便宣称带泄露增强已获证明。

## 2. 同条件比较

GP23 的两实验原始输出概率差与本轮 bias 相差 2 倍。源定理以一般 homomorphic PKE 的 IND$-CPA 及 2l² 表述；本轮固定 modified ElGamal、公开整个 P_e、增加完整普通带，并用单 DDH* 同时随机化一份密文。L 采用统一 1-based 最大代次，三角计数、概率差口径和具体实例都已明示。

可以报告本轮的精确界；本轮没有将常数和形式上较小的计数包装成对不同量词原定理的新紧致性优势。独立先例核查仍需围绕“诚实表示桥接＋完整带＋自适应合法腐化”的精确接口进行。

## 3. 内部反方核查

审查方式：同一研究代理分别核对原图、构造方程、模拟量及事件分解，并用有限集合/算术工具检查小实例。无第二模型、外部同行、作者答复或证明助手。

| 反驳尝试 | 处理与证据 |
|---|---|
| A 看公共 X 后挑一个使猜测不利的挑战 | 猜测损失通过每个 i 或 (j,r) 的未正规化中心评分求和；不假定 A 的切点与 X 独立 |
| 普通全带暴露未知关系 | Enc 全部公开输入可运行；边界 Upd 仅用已知普通 ρ/pad，逐点等于隐含 δ 的真实结果 |
| 未来钥匙只有一个 public编码 | 返回全部 y_i；后续 key/token 从其真实演进，并检验每个 g^{y_i}=P_i |
| 旧公开键在将来被改写 | 一次生成即固定。边界对新键先采 y 的双射重参数化无需改变旧 P，也不更改过去普通带 |
| 公共 P 可能就是隐藏 token | 编码向量与倍率标量分开；部分倍率可能推导，完整模拟把这些实际信息全部提供。没有将潜在新攻击定义成非法 |
| 原 oracle 的合法边界 token 查询被拒绝 | 真实游戏照常返回；归约中止归入规范边界不匹配。没有合法匹配事件因此被删除 |
| Next 隐含公开 C3/C4 | 原图反证：C 只在 Chall/Get 增长；私有自动更新不计公开 |
| 用随机父再假装子代仍加密 M_b | 不这样执行；先对全真实官方链证明独立流等价，再在该表示中定义混合 |
| 新鲜化只证一个边缘 | 逐坐标双射与条件转移核归纳支持整个历史联合流；重复 Get 使用缓存 |
| arbitrary ciphertext 可进入正常更新，表示未知 | 新游戏沿原诚实注册限制，没有任意导入。若扩展此接口，本轮桥接前提需要重证 |

这些检查支持明确的手工证明范围，独立外审仍是下一项最有价值的核查。

## 4. Frodo 候选保留状态

只核对上一轮表述和依赖，未重新采样参数或构造修复。

- 真实分布恒等式 `Success=1/2+(α−β_real)/2` 与任何 LWE 假设无关。
- 在 q=2^D 上可逆等价于 mod2 满秩；均匀方阵概率 `p_n=∏(1−2^{-i})`。实际 P2 接近该概率及 fresh 第一块接近均匀，分别由明确的 χ-secret/χ-error LWE 条件给 ε_P、ε_ct。
- 下界为 `max(0,p_n(1−θ)/2−(ε_P+ε_ct)/2)`，不是没有条件的每个实际参数实例优势。
- 它不使用普通随机带暴露，不需要挑战钥匙，攻击 fresh/update 来源；不能提升为消息恢复或一般 FrodoPKE 的破坏。
- 论文实际 D/B/χ/T 性能配置尚未核准；充分正确性界未满足与实际解密失败仍分开。

候选状态保持：**独立密码分析候选，等待独立复核和优先权审查**。本轮没有外部联系、修复或参数实验。
