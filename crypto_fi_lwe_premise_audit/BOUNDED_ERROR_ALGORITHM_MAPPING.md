## 2. 原始素数域证明向2幂环的障碍

CF-1的误差多项式为P_S(t)=∏_{e=−12}^{12}(t−e)，次数25。恒等式P_S(b−〈a,s〉)=0 modq始终成立；单凭它无法在环上宣称线性化系统有单位满秩。

mod2时，对任意整数t都有P_S(t)=0。于是任意二元候选x∈F2^n的真实单项式向量都满足全部mod2线性化方程，第一层的唯一恢复保证失效。GF(2^D)与Z_(2^D)的加法/乘法结构不同，将q写成同样的数值不能把样本变成有限域样本。Schwartz–Zippel、非零系数可除和单位主元均需补充。

合数扩展允许损失gcd(d!,q)精度，并用环上解集替代假定单位满秩。下面完整核准这一点。

## 3. 环上部分恢复命题及自含证明

取q0=2^c，误差支持为{0,…,d−1}，每点概率至少η>0。秘密s可为Z_q0^n中的任意固定向量；a独立均匀，误差独立于a，各样本独立。令N=binom(n+d,d)。对M个样本构造

\[
P_i(x)=\prod_{j=0}^{d-1}(b_i-\langle a_i,x\rangle-j).
\]

将总次数≤d的单项式换成独立变量y_v，并固定y_0=1。求解这M个关于N−1个未知量的线性同余。真实s的单项式向量一定是解。选择任意一个解，并取其一次项y_(1)。

**命题。** 记g=gcd(d!,q0)，则除概率至多

\[
\delta_{AG}=q_0^N(1-\eta/2)^M
\]

以外，每个线性化解均满足y_(1)≡s mod(q0/g)。

证明分三步。

1. 用x=s−z的仿射变量代换，将某候选y映成形式单项式向量z̃。常数固定为1，变换按次数分块三角，主对角项为±1，故在Z_q0上可逆；一次项z̃_(1)=s−y_(1)。无需假设高次坐标等于一次项的真实乘积。
2. 设F_d(t)=t(t−1)…(t−d+1)。整数多项式恒等式为

\[
\sum_{j=0}^{d-1}(-1)^{d-1-j}\binom{d-1}{j}F_d(t+j)=d!t.
\]

它由ΔF_d=dF_(d−1)迭代得到，无除法，在任意模数上成立。固定a，对F_d(〈a,z〉+j)先线性化再取上述组合，结果为d!〈a,z̃_(1)〉。若d!z̃_(1)非零，则均匀a映到非零2幂理想中的均匀值；该内积非零概率至少1/2。因此至少一半a下存在某j使相应线性化约束不成立。每个j的误差概率≥η，坏候选被一份新样本排除的概率≥η/2。
3. 同一坏候选通过全部M份独立样本概率≤(1−η/2)^M。候选不超过q0^N个，取并集即得δ_AG。d!z̃_(1)=0等价于z̃_(1)=0 mod(q0/g)，给出结论。

这个证明重现CJL prime-power结论所需部分；有限差分表达是本轮知情整理，沿用成熟差分/线性化方法。它不引入未经证明的秩假设。有限核对对d=25完整展开检查了该标量恒等式，结果见sources/FINITE_DIFFERENCE_CHECK.json；一般证明由上面的差分递推承担。

### 环上线性求解的完整定义

对系数矩阵以行/列可逆变换作2-adic消元。每次选择剩余非零项中v2最小的主元，将其奇数单位因子消去，化为2^t；其它项的2-adic阶至少t，可用整数比值作行/列消去。递归得到对角2^t_i及零行。方程2^t_i z_i=c_i有解当且仅当c_i被2^t_i整除；求z_i=c_i/2^t_i mod2^(c−t_i)，并允许自由高位。零行必须对应零右侧。选择一组解，再逆变换即可。

其中对2^t的除法同时降低模数，未将非单位当作原环逆元。只有奇数单位使用扩展Euclid。最多N个主元，批量保守位时间O(MN² poly(c)+MnD)，存储O(MNc+MnD)。D是原输入位长。对固定c、d，N=O(n^d)，这些都是PPT上界。

## 4. CF-1的完整代入

训练时将原始响应b_i改为b_i^+=b_i+12，误差变为e+12∈{0,…,24}；下文留出验证及US恢复使用原始响应b。该平移不改秘密、均匀a或独立性。取d=25、η=1/65536。由Legendre公式

v2(25!)=12+6+3+1=22。

CF-1中D≥32。可把所有训练样本精确降模到q0=2^27，它整除原q，a modq0仍均匀独立。于是q0/gcd(25!,q0)=32。取置信参数τ≥1，设

\[
N=\binom{n+25}{25},\qquad
M=2^{20}(27N+\tau+1).
\]

该M也满足索引原Lemma31的M>10N logq0/η门槛；直接用本文件的失败式有

\[
\delta_{AG}\le\exp(27N\ln2-8(27N+\tau+1))<e^{-8\tau}.
\]

对任意秘密，算法获得s mod32。使用常数q0规避“合数定理只讨论常数模数”的额外迁移责任；原q的均匀行经约数降模完全满足该常数模数实验。

**NF搜索。** s坐标在{−12,…,12}，这25个数在mod32下两两不同。将每个恢复余数唯一映回S，即恢复完整s；失败概率≤δ_AG。若某余数无对应元素则输出⊥。

**US搜索。** 获得r=s mod32后，再读取n+κ份新的原q样本。计算(b−〈a,r〉) mod32，唯一映回S得到实际e。于是获得无噪声方程〈a,s〉=b−e modq。新的样本矩阵mod2满列秩失败概率<2^-κ；成功时用n个奇行列式主元求完整s。总样本M+n+κ，成功率≥1−δ_AG−2^-κ。该步骤明确支付新样本，避免对训练成功条件下的秩重复使用独立性。

**决定问题的直接版本。** 为减少资源，可只用训练得到的r=s mod32，再用t份留出样本检查(b−〈a,r〉) mod32∈S mod32。真实分支通过概率≥1−δ_AG；均匀分支在条件于全部训练后，r已固定，新b mod32独立均匀，故通过概率≤(25/32)^t。决定gap至少

`1−δ_AG−(25/32)^t`，样本M+t。

另一路是完整搜索后用原q留出样本验证，均匀误接受≤(25/q)^t；其US样本为M+n+κ+t。一个留出样本也足以给非可忽略gap；要把误接受明确做成negl(λ)，可取τ=t=κ=λ。两种方式均为经典算法，自动包含在QPT允许范围内。

## 5. 样本预算及有限实例

对CF-1取τ=t=κ=λ，M=Θ(N)=Θ(n^25)，q0固定，保守密集线性化时间O(n^75)、存储O(n^50)；读取原输入另有O(MnD)成本。所有次数是上界，未给最优性或必要样本下界。允许任意多项式样本的精确US/NF困难性因此被覆盖。

|---|---|
| CF-1，固定m=n或3n | 缺少达到M的独立同秘密样本；当前定理不提供该样本预算内的求解保证 |
| CF-1，任意多项式新样本 | 上述经典PPT搜索/决定算法适用，不要求新困难性假设 |

| 官方976，d=21、D=16 | v2(21!)=18≥16，同样不给有效保证 |
