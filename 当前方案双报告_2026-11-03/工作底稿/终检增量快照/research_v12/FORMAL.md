# v1.2 条件性形式论证与实现映射

以下为手工论证，未经过证明助手或外部同行复核。有限测试不能代替这些前提，也不能证明真实认证服务符合模型。

## 1. 状态、目标与完整 Post

源状态包含世界/认证语义、configuration、stopped、sessions、approved、budget、attempts、stop_steps 和 epoch。编译状态为非空可能点集合 K 与剩余步数 r；z、O、V 和 Γ 是 K 中对应字段的投影，不假定不同可能点的预算或副作用相同。契约版本由不可变 l0 摘要绑定；批准变化及 epoch 进入点状态。额外原生版本、真实来源证明尚未实现。

Post(K,a,o) 是每个可能点经过 a、产生 o 的所有允许后继的并集，包括 LOST 同观察下 applied/未 applied、未知句柄、批准撤回以及已列举的语义变化。运行者只依赖公开观察，不使用评分器的真实世界。未列举的新语义/新接口属于模型外变化，不沿用旧证书。

W0 为所有点都安全、目标满足且严格义务为空的非空集合。r>0 时，Wr 包含 W0，以及存在已批准、预算足够、硬约束满足、非空 Post 的动作，使每个可能观察分支均在 W(r−1) 的状态。r 是决策步数，不是墙钟时间。stay 自环不能在有限 r 内替代完成；UNKNOWN 是观察标签，必须通过普通 Post 处理，不能作为成功。

模型到真实服务的条件依次为：初态覆盖；具体每一步均被抽象 Post 覆盖；账户、批准、预算、原生效果与副作用不遗漏；终态反映真实停止及义务结清；抽象动作可按同价格/作用域回译执行。源解释器审计只检查声明源到有限表的映射，不验证真实服务满足这些条件。

## 2. AB3：证书传递命题

证书明确 scope=control_only_bounded_completion、objective=total_Q、模型摘要、根 K/r 和约束引用。control 动作包含 configure、stop、cleanup，排除 probe。可行证书是统一观察策略树；不可行证书在每个非终态覆盖全部 control 动作，每个动作给出当前阻塞或一个允许的失败分支。允许任意有限世界，不缩减为世界对。

命题 AB-W（条件性）：若独立解释器完整且正确，旧证书先在旧根通过检查；再确认目标根恰为完整 Post 与 r−1；最后将旧策略模板在新根逐节点重放，每一新观察都有策略、每一 guard 成立、每一叶是终态，则返回的重绑定策略在新根可行。若执行动作恰为旧策略根，先选取对应残余子树，仍需完整重放。证明按剩余策略深度归纳。多余旧观察可以丢弃；缺失新观察返回 INCONCLUSIVE。失效的预算/批准或未结清叶返回 INVALID，仅否定该见证。

命题 AB-U（条件性）：若新根非终态，且旧反驳模板重新覆盖新状态每个 control：当前确有 guard 阻塞，或者存在允许观察使递归反驳成立，则新 control 问题在剩余步内不可行。证明对 r 归纳。旧阻塞消失、旧坏分支不再出现或某子树变成目标，均不允许继续排除；一般返回 INCONCLUSIVE。子树反例不推出整个问题可行。只有新根已经终止等直接反证才把整个旧断言标为 INVALID。当前实现不做最小核心提取，证书可以包含完整有限反驳树。

命题 AB-L（条件性）：对每个具体点分别允许先知选择动作和有利故障结果，求其最小总 Q，再取 K 上最大值，得到不大于统一鲁棒策略最优 Q 的下界 L。每条真实鲁棒策略在各点也属于放宽的策略集合，因此逐点下界成立，取最大值保序。旧下界 b 仅当新 L≥b 才可继续使用；若存在已检查的新策略 Q<b 则 INVALID，否则 INCONCLUSIVE。不得将一个旧数值直接用于剪枝。代码 Checker.lower 按 scope 独立重算，lower_cache 仅缓存不可变精确状态。

可行见证重用不自动证明最优。FullB 只有在新见证 Q 与新 control 下界相等时才跳过完整 B；否则重算。已检查不可行反驳可以直接复用 control 结论。联合搜索仍可选择 probe，不能据 control 不可能宣告联合不可能。当前下界传递检查器有独立测试；主求解器使用新下界，不依赖旧数值作为排除理由。

伪代码：检查旧证书与版本 → 重算 Post → 分证书种类重放 → 返回 VALID/INVALID/INCONCLUSIVE → 仅在适用且最优性闭合时复用 → 否则调用完整 B 和控制策略求解。每次检查、构建与回退均计量。

最坏复杂度不会优于重新搜索：若反驳树大小 T、每个点最多 A 个动作与 E 个后继，重放为 O(T·|K|·A·E) 的直接表实现上界；旧树也可能指数大。动态名称与领域状态绑定不构成新的通用增量验证原理。GENERIC_REPLAY 获得同一机制，必须报告其等效性。

## 3. A4：任务相对价值单元与反例精化

粗摘要包括 r、账户、预算、批准、sessions、configuration、stopped；故意不要求未来全部观察行为相同。摘要只筛选候选，不发放许可。

充分条件 A-V：同一不可变模型下，两个状态具有同一已核验的 W 安全动作集合；并集也具有该集合；存在同一个策略模板可在并集全分支重放，最大总 Q=v；对每个成员均有独立可采纳下界 v。则每个成员最优值等于 v，重绑定策略均最优可行。证明：策略给出上界≤v，下界给出最优值≥v；并集检查与重绑定保证全分支安全。若各成员成本不同，仅并集最优不能证明各自最优，所以代码逐成员检查下界。

此条件只保持任务最优值、一个最优策略和当前安全动作资格，未声称保持所有策略、任意未来任务或概率分布。它弱于完整未来观察签名：可有非必要 audit 返回不同观察，但相同最优配置策略仍通过证明。

A4-2 实现为最小 CEGAR 形式：若资格集合、策略重放或成员下界失败，记录反例类别，将该候选信念精化为单例并回退完整求解。尚未实现从反例自动推导最小谓词或跨输入可复用精化规则。资源/义务不同首先阻止候选配对，不能因同值合并。

伪代码：摘要定位旧单元 → 同资格/并集检查 → 策略重放 → 成员下界等值 → 提升；失败则单例精化。构建与资格检查可能比命中节省的搜索更贵。最坏合并尝试 O(N²)，每次含 W 检查、策略重放与下界计算；没有一般加速保证。通用证书抽象获得同算法，不能凭名称形成独立原创性。

## 4. B4：安全路径类压缩与全局字典序

限定原有单调不可逆 B 模型；原生撤销效果必须分割凭据，真正重叠效果输入为 UNKNOWN。任务支持共享和共享根是允许的，但不能把重叠作用域伪计为多个独立 G。

定义路径等价类：task、grant 集合、environment 和 delegate 操作全部相同，delegate 的 requests/approvals 均为零。非零费用路径保持单例。由此相同类任意非空子集提供相同任务 OR 支持、账号/权限、凭据及环境集合；需批准类型也相同。对同一停止动作序列，实时能力、原生可用性、严格保留和资源费用一致。因此配置只需枚举所选语义类。

命题 B-Q（条件性）：在上述等价关系与模型语义下，枚举类子集完整覆盖原配置可行性与原生 G，且不改变最佳 G。证明将原配置映射到使用的类集合；每类至少保留一条即可保持所有状态谓词及资源；反向选任意代表可实现同一效果。

仅挑每类最小名字不能保证原字典序。反例：类{a,b}和{c}均被选中时，原全局最小配置是[a,b,c]，小于[a,c]；但局部[a]小于[a,b]。局部字典序并不在并集下单调。

命题 B-Lex（条件性）：对选定类集合，按全局路径名递增扫描所有别名，持续加入，直到每类首次出现，立刻停止。所得列表为该类集合的字典序最小代表。证明：若尚未覆盖完所有类，省略当前最小名字会使下一个元素更大，从而严格更差；全部覆盖后任何附加元素只会形成更长前缀，从而更差。类内零费用和相同语义保证插入多余前缀不改变可行性/G。对所有类子集求(G,列表)最小即与原全枚举一致。

复杂度：原始 p 条路径的 2^p 个配置变为 k 个类的 2^k 个配置，附加分组与每次全局展开/检查成本 O(p log p)。规划器仍为原完整停止求解器；当 k=p 时没有指数压缩，额外证书开销可使候选退化。该性质是受限输入的结构界，不是一般认证规划复杂度改进。

B4-1 有界接口路线本轮只实现接口诊断和全局回退。跨组件撤销、isolated 环境停止/创建费用进入共享接口；全局预算必须由可行前沿联结，不能独立最优后相加。若每个接口有 d 个状态且宽度 w，朴素条件枚举至少含 d^w 因子及前沿组合项。尚未实现非零接口的完备局部动态规划，因此不宣称新分解算法。B3 原有零接口分解作为不改动的对照。

## 5. 完整联合接口及强对照边界

oracle.FullB 实际调用完整单世界配置求解，配置后则调用完整残余原生停止 BFS；精确 query 缓存对各组相同。其原生目标为(G,原配置字典序)。随后 control_solve 求全 K 的统一 configure/stop/cleanup 策略，真实预算、故障、义务、批准均进入。原生输出仅作动作排序建议，不能取代全 K 检查。配置后不重复收取 setup。

八组合均调用该接口，A 固定相同联合策略类，B 只切换完整原生实现，AB 只切换经过证明的传递。所有组合仍最小化最坏总 Q；G 单独报告。旧 A2/A3 早承诺及旧 AB2 目录接口保留为历史机制对照，明确不参与公平八组合归因。

R-J12 用独立原始解释器递归穷尽完整观察分支；Z3 用独立图编码将 min/max 递推约束化，push/pop 复用同一不可变图，另记录全部即时后继查询。Z3 UNSAT 不是导出的证明证书。重复求解、通用 BB、精确缓存、GENERIC_REPLAY、GENERIC_ABSTRACTION、GENERIC_PRESOLVE 均不赋予候选额外原生能力。

## 6. 反例、未证明项与状态区分

空 K 返回 UNKNOWN。缺少来源或重叠原生效果在语法边界返回 UNKNOWN。穷尽 control 失败只得 control-only 的 IMPOSSIBLE_IN_MODEL；穷尽 joint 才得界内联合不可能。资源截断返回 INCONCLUSIVE 或 TIMEOUT，PENDING 仅用于未运行项。终态携带未知句柄或其他严格义务不能完成。

未证明：真实服务符合假设、非原子配置、配置后世界迁移、无限时域、真实恢复、并发系统任意交错、一般部分可观测理论创新、三算法独立优势及端到端总体收益。声明故障分支覆盖有限迟到/失败效果，不代表实现真实并发认证部署。

密码学结果完整继承 v1.1 第13—19节，原件不改。本轮不扩大 MPC。C1—C3 仍是受限模型的条件结果；C4/Gate 不提升来源可信性。重新进入需原成功域、同泄漏/接收者、可信结构来源或更便宜合规以及端到端收益同时成立。
