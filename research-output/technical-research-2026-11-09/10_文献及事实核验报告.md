# 文献及事实核验报告

## 方法与结论口径

逐项检查本地文件、论文身份、版本、题录和本次使用的事实。45 篇核心 PDF 均由本次 ARS 结构预检给 PASS，哈希与页码保存在 data/pdf_catalog.json。14 篇核验了定点机制，31 篇采用摘要或首页级证据。字段与来源级状态见 09，机器提取与完整证明核验分别评价。

部分 DOI 或出版方入口返回 403、不可访问或 BotStopper。保留失败回执，采用可读的作者稿、官方会议记录、机构页面或已在本会话读取的同日原始来源。单个入口失败保持其访问含义。CN04 完整来源仍待核，主报告仅在限制部分登记。

## 定向新增来源

新增 3 项独立登记来源：N01 阈值群测前作、N02 最新 OAuth 客户端断言规范、N03Macaroons 基础工作。N01 与 N03 为摘要或题录级对照，完整覆盖归约保留待核；N02 实际核对第 4、5 节及兼容性说明。其他新增公开访问属于已有资料的题录或状态复核，不计作新论文。

N02 的范围限客户端认证 JWT：aud 以授权服务器 issuer identifier 为唯一值。授权授予断言的接收方规则另有分支。显式 typ 属于建议，规范还讨论因旧客户端兼容而形成的迁移次序。该区别已纳入主报告。[N02]

## 国内来源与失败副本

CN01 与 CN03 官方期刊页面匹配题录，CN02 官方电子期刊页面给出作者、刊期与 DOI。章节评价部分复用 L15 的实际范围，保留原始阅读限制。CN03 本地 PDF 截断，网页与本地副本状态分别管理。CN04 只保留原登记，完整正文待核。

PDF 目录还包含一个空的 GroupActions 文件。两份失败副本均保持原状，其本地文本退出本次证据。机器解析出现过字体映射警告；结构 PASS 只验证结构，公式和语义采用已读清晰文本及规范条款，完整页面视觉与证明认证仍按实际范围登记。

## 引用一致性与剩余责任

全套来源 ID 映射到 09 和 data/source_records.json。核心论文编号在各文件保持一致，标题规范化及 DOI 修订见 data/citation_corrections.json。主报告末尾列其实际引用来源；未核线索另列。最终自动检查覆盖未定义 ID、失效本地路径、占位文本、重复 ID 和输出数量。

本次未执行作者实验、原生认证请求、新机制实现、全数据库 PRISMA 检索、外部人工证明评审或第三方模型评审。已完成的是来源与事实分项核验及研究综合。剩余证明、可达性、优先权和成本证据按 07 与 08 保留。
