## 1. 预算和固定参数

用T表示最大epoch下标，允许epoch为0,…,T，即最多T次Next、共T+1个epoch；这是FI混合段使用的计数方式。若外部只给“总epoch数E”，则可用Next次数为E−1。记腐化token集合为𝒯，避免与预算T混名。

预设整数1≤k≤T。若另有总oracle预算Q，要求3k+1≤Q；若各接口有单独限制，还需k≤Q_Enc、Q_Next、Q_Corr。初始化另计一次。n,D,q,m̄,n̄,B、χ及公开A在同一次Setup内固定。没有重启Setup或按token结果改变模数、噪声和维度。

令q=2^D，S_q为χ整数支持模q后的集合，h=|S_q|<q，N=m̄n，θ=(h/q)^N。选择固定M=0^{B m̄ n̄}，所有普通父与挑战消息均使用M。

## 2. 完整纸面攻击 A_k

在初始epoch0开始，对j=1,…,k按顺序执行：

1. 当前epoch为j−1。请求C^(j)←O.Enc(M)，保存其完整返回值及注册身份。
2. 请求O.Next()，当前epoch变为j，生成新钥匙与Δ_j。
3. 请求Δ_j←O.Corr(token,j)，取其中第一块P_(2,j)∈Z_q^{n×n}。
4. 检查P_(2,j) mod2的秩。若奇异且j<k，继续下一轮；phase仍为0。
5. 若可逆，设J=j，请求唯一挑战C*←O.Chall(M,C^(j))。取Y=C*.C1，令H=Ord_n(C^(j).C1)。若

   \[
   (Y-HP_{1,j})P_{2,j}^{-1}\in S_q^{\bar m\times n},
   \]

   输出1（update）；其余情况输出0（fresh），随即终止。

k轮均奇异时，输出一枚独立公平比特并终止。本规范至多调用一次Challenge；S未发生时调用数为0。FI p11的终局规则没有强制phase=1，因此这也是原游戏中的完整策略。

若某种形式化接口要求每次执行恰有一个挑战，可在第k轮失败后，用刚产生的普通父发起一次合法Challenge、忽略返回值并输出公平比特。该变体使用同一k次Next，优势和下面的概率公式保持相同，总查询上界仍为3k+1。

必要第一块缺失、参数／形状错误或oracle返回⊥时，策略以独立公平比特终止。纸面理想算法的诚实合法执行中这些事件概率为0；具体实现的故障损失另列。

## 3. 逐轮合法性

| 状态／动作 | 核准结果 |
|---|---|
| 第j轮父 | 在epoch j−1由O.Enc诚实生成，(qid,C^(j),j−1;M)∈L |
| Next | 当前phase=0；原p10只递增epoch、生成钥匙和token，无已有挑战链需要更新 |
| Corr(token,j) | j等于当前epoch，满足p9的j≤e检查；返回完整Δ_j |
| 奇异时继续 | 尚未发起Challenge，phase仍为0；此前的普通记录留在L中 |
| 首次可逆时挑战 | 父恰属于当前epoch的前一代，满足p10 O.Chall第4行的登记条件 |
| 腐化集合 | Key查询0，所以K=K*=∅；已读取的𝒯={1,…,J}或{1,…,k} |
| 挑战闭包 | S发生时初始C={J}；任何闭包扩大仍与空K*不相交 |

被选择的epoch来自实际生成并腐化的token。每次试探均支付一次Next和一次普通Enc；攻击没有免费取得额外候选token。普通Upd、Key腐化、解密、普通随机带、挑战带和挑战后继请求均为0。

## 4. 一般分布下的停止时间

令E_j为第j轮token可逆的事件，S={至少一次成功}，J为首次成功位置；全失败时J=∞。实际尝试次数τ=min(J,k)。定义

\[
p_k=\Pr[S]=1-\Pr[\bar E_1\cap\cdots\cap\bar E_k]
=\sum_{j=1}^{k}\Pr[J=j].
\]

这些是定义上的精确式，不要求整份token或各轮视图相互独立。令F_(j−1)=前j−1轮均失败，

\[
\bar a_j=\Pr[E_j\mid F_{j-1}],
\quad p_k=1-\prod_{j=1}^{k}(1-\bar a_j).
\]

若某个失败前缀概率为0，p_k已为1，后续乘积因子可任意补定。

更强而便于使用的充分条件是：对每个有正概率、仍会进入下一轮的可见历史h，都有

\[
\Pr[E_j\mid\mathcal H^-_j=h]\ge a_*.
\]

𝓗^-_j包含此前全部可见记录和本轮普通父，位置在本轮token第一块被返回之前。它包含“此前均失败”这个选择事实。由全概率公式与逐轮条件化，

\[
\Pr[F_j]\le(1-a_*)\Pr[F_{j-1}],\quad
\boxed{p_k\ge1-(1-a_*)^k}.
\]

此处需要逐历史条件界。单轮边缘Pr[E_j]≥a_*不足以推出该式：若每轮复用同一个P2，各轮边缘可逆率相同，但首次失败后以后仍失败，p_k一直等于单轮概率。

## 5. 新独立性来自哪里

在理想FI的第j次TG中，

\[
P_{2,j}=U_{2,j}A+F_{2,j}.
\]

F_(2,j)的全部坐标为新独立χ样本，并与A、旧历史、新钥匙、U_(2,j)及其他TG随机量独立。为证明条件概率，可以进一步固定所有这些私有状态和随机量，只留下F_(2,j)未采样；这是分析中的条件化，攻击者没有额外取得钥匙或随机带。

固定后U_(2,j)A只是一个确定平移。此前所有失败、父选择及共享A造成的关联都已包含在固定状态内。于是可以对每个平移直接应用奇偶秩结论，再通过条件期望返回真实可见历史。

**640／976官方理想独立采样：** χ mod2精确均匀，故每个历史上

\[
\Pr[E_j\mid\mathcal H^-_j]=p_n
=\prod_{i=1}^{n}(1-2^{-i}).
\]

因此

\[
\boxed{p_k=1-(1-p_n)^k},\qquad
\Pr[J=j]=(1-p_n)^{j-1}p_n,
\quad\mathbb E[\tau]=p_k/p_n.
\]

这里恒定的条件概率足以推出几何式；无需宣称整份token因共享钥匙而相互独立。

**1344官方修正表的理想独立采样：** 引用前阶段手工N1及主会话知情核查，逐历史仍有L_1344≤Pr[E_j|𝓗^-_j]≤U_1344，其中

\[
L_{1344}=\prod_{i=1}^{1344}(1-(16385/32768)^i),\quad
U_{1344}=\prod_{i=1}^{1344}(1-(16383/32768)^i).
\]

故

\[
1-(1-L_{1344})^k\le p_k\le1-(1-U_{1344})^k.
\]

这些结论在任意固定A下成立。实际秘密种子展开、跨轮复用或相关输入位需要自己的联合分布论证；单份CDF只能认证单样本质量，无法自动认证整个停止过程。

## 6. 查询费用与严格时间界

实际停止在τ时，Enc、Next、Corr(token)各τ次，Challenge为1_S次，故总oracle调用数为3τ+1_S≤3k+1；初始化另计。exactly-one-challenge变体为3τ+1。最多使用k+1个epoch、生成k+1把epoch钥匙和k份token。

攻击者进行至多k次O(n³)个F2操作的秩检查；成功后只求一次模q逆，并进行O(m̄n²D+n³)个环操作。输入元素位长D。只需保留当前父和当前token所需块；此前完整记录可以被丢弃，条件概率证明仍按完整可见历史成立。

每份token有n(D+1)(n+n̄)个环元素，每份密文有m̄(n+n̄)个。接收量至多

\[
k\,n(D+1)(n+\bar n)+(k+1)\bar m(n+\bar n)
\]

个环元素，另加一次Setup的A和参数。提交Challenge时还需发送所选完整父；消息与oracle标识另计。矩阵元素的自然表示各占D位。

640/976理想采样下，期望oracle调用数为3p_k/p_n+p_k，期望尝试次数趋近1/p_n≈3.46275；最坏上界仍为k次。PPT依据预先固定的多项式k及参数长度，未借用无限重试的期望时间来替代最坏时间。
