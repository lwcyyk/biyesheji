挑战者生成用户、权威和材料身份，运行 L 与 Provider。攻击者可提交任意 Agent 消息、调度网络、崩溃/恢复执行域、取得允许失陷域及 Hist 中的能力；保持权威 fault bound、密码学与 Provider 合同。合法用户批准只由挑战者按给定输入签署。

## 2. 账本归纳命题

I1 来源保持：初始空。T02 固定 o；T03 复制；T06 逐字段相等核验；T11 保留；T15 固定原 i/o/quota。其余转换只更新阶段/证据，故每条记录的 o 及业务正文保持。

I2 撤回后新放行截止：Q 日志有全序。T07 先发生时 g inactive，T03 守卫失败。T03 先发生的 a 保持在途责任；该情形可在撤回 ACK 后原生到达。结论严格限 C_local。

I3 预算保持：初始化 reserved=charged=0。T02 在和小于 limit 时加 reserved；T03 原子转移一个单位到 charged；取消仅减 reserved；T11 维持两者；T15 移交同一槽。归纳得额度界。每 i 最多一个机会槽与每前驱最多一个继任由唯一约束保证。重放原生多次发送可仍属于同一 charge，原生效果至多一次另依赖 P1。

I4 未决守恒：T03 同提交产生 Obl；响应丢失无删除转换；Record 仅解析结果部分；迁移及重配置包含旧责任全集；只有 T19 按 matching kind/前沿证据关闭。故旧 a 的责任经崩溃、ID 变化和接管保持。状态可用性和完整快照是必要前提。

I5 分叉/重放：两个 n=3f+1 中大小 2f+1 quorum 相交至少 f+1，含诚实签名者。仅在所选 BFT 的锁定/投票规则成立时，交集支持唯一提交历史；交集算式单独无法证明共识。客户端当前性由读屏障保证。跨配置安全继承所选重配置定理，旧 checkpoint 引导和累计旧钥泄漏仍是明确假设。

## 3. 条件原生命题

N1 精确原 key 重放至多一次：P1 对 k/body 的持久幂等及保留覆盖整个可能交付区间，因此任何重放返回同效果/结果。保留过期或 key 仅在部分端点去重时此命题失去依据。

N2 单继任至多一次机会：P1 的 Terminalize 与旧效果提交原子竞争。COMMITTED 分支禁止继任；FINAL_NO_EFFECT 分支持久阻断旧 k，T15 唯一继任并转同 charge。归纳覆盖继任链；业务意图操作/来源相同。旧域凭已披露材料另选新 k 的路径还需 P2/原生撤销覆盖。

N3 原生/效果关闭：令 R_a(K) 为 oid a 在所有可能状态中的原生接受及未来禁止效果路径并集。每路径若有已证实施且持续有效的原生 cutoff，且所有在途、派生和已接受异步载体均覆盖，才有关闭。T19 检查这些前提即可按反证排除未来路径。R_a 的有限完整表示、证据来源忠实和真实部署模拟尚待验证，故该命题保持条件性。

P1/P2 的效果唯一性、N3 的关闭与来源保持为三个不同命题。C_native 对指定材料接受失败仍可与已接受异步工作继续共存。

## 4. 活性及授权边界

独立 B 完成：若某阶段后故障稳定在允许集合、共识/网络/Provider 最终可达、D2 存在且选择了有限进度策略、B 的必要预算与接口仍存在，则沿胜集 rank 严格下降，B 达到要求目标。单纯 safety invariant 和概率重试均无法替代这些活性前提。

善后能力仅允许指定查询、终态化和获准原生撤销。它与继续执行业务的批准分开，且撤销共享域时需 Preserve 守卫。E1 曾取得管理密码/全账户撤销能力时，可破坏 B 的可用性；恢复 B 的强保证需 Provider 轮换/权限回收或独立原生路径。
