# D1 最小场景与威胁模型

版本 D1-R1，2026-11-09。

## 1. 冻结输入

同一用户批准两个任务 A、B，各有独立 grant、generation、intent 和 quota lineage。A 的 refresh 请求 a 已持久放行，Provider 可能创建子材料 a1，响应丢失。用户撤回 A，E1 随后崩溃、失联或失陷；E2 取得处理权限并继续合法 B。A/B 可以共用账户，原生支持的独立性必须由 D2 检查。

主度量 C_N 和完整计费边界沿用 ../SEPARATION_GATE.md。未知责任和共享撤销导致的 B 损害属于安全/可行性指标。

## 2. 角色与信任

|角色|责任|信任与故障|
|---|---|---|
|用户/批准终端 U|签署可读批准、撤回及必要的修复授权|批准密钥和显示语义可信；密钥失陷须进入独立恢复流程|
|Agent Agt|提出任务、参数与查询|可恶意，持句柄及受限服务身份|
|多域权威 Q|排序并核验授权/预算/迁移/关闭|n=3f+1；固定配置内最多 f 个签名权威全生命周期失陷，QC≥2f+1；状态可用性单列|
|E1/E2|执行与恢复协调，持有任务责任|可崩溃或恶意；其签名自报承担者不能单独证明原生事实|
|托管 V|材料保存、分片或受保护使用|依具体 TEE/HSM/MPC/普通重建 profile；原生明文出现就加入暴露模型|
|执行门 Gt|核验 release 与 native key、隔离 agent|完整中介且可信时提供本地保证；失陷后保留原生接受路径分析|
|Provider P / sink|原生接受、幂等、撤销、状态与效果前沿|按版本合同运行；恶意撒谎的 Provider 需独立可信证据，否则保持 UNKNOWN|
|证据验证者 W|验证真实性、来源范围及新鲜度|可与 Q 的确定性验证模块合并；外部事实采集者仍在信任表|
|对账/关闭 R|查询、隔离、撤销、收集关闭证明|持有限善后权限；批准关闭由 Q 提交|

合并 V/Gt/E2 可减少组件数，同时扩大一个失陷域的能力。将 W 与 Q 合并只合并验证代码，证据来源的真实性与完整性依赖继续存在。BFT 节点看到的复制状态只含材料引用和必要承诺，秘密密文/分片按单独保密策略分发。

## 3. 原生 profile

**P0（legacy bearer）**：发行/刷新/撤销已知 token，可有只读查询；Provider 忽略本地 epoch。历史密码、AT、RT、Cookie、缓存及派生材料均可能形成旁路。可承诺账本内 C_local 和未决责任保持；C_native / C_effect 按具体证据判定。

**P1（请求身份与截止）**：P0 加稳定原生请求 key k，对 operation/account/body 绑定；精确幂等结果及查询保留到协议声明的恢复期限；可原子终态化 k，与提交竞争，返回 COMMITTED 或 FINAL_NO_EFFECT，并在期限内拒绝迟到 k。任务/域级 cutoff 若用于历史能力关闭，必须覆盖所有旧材料与创建入口，包含丢响应派生能力。持有 bearer 仍可另选 key 绕行时，该截止只覆盖 k。

**P2（接受与效果边界）**：在 P1 上，原生接受方验证任务/来源/epoch 或可撤销独立材料，且所有声明路径被覆盖。严格 C_effect 另需已接收异步工作的终止、排空或效果前沿栅栏；栅栏前提交仍能稍后产生被禁止业务效果时保持责任。DPoP 仅在私钥也受保护且 Provider 正确实施时约束发送者；已泄露私钥同样进入暴露闭包。

所有 profile 是能力需求；本项目现有 Casdoor profile 与其逐条对应仍待证。P1/P2 对外接口通过新增可信代理提供时，代理成为额外中介/可信域，成本和旁路须共同计入 G。

## 4. 安全与活性范围

认证网络可延迟、重复、乱序、丢包和分区；崩溃可发生在任何本地提交或网络发送间隙。恢复可持旧快照。Agent 与执行域可串谋。密码学假设为签名不可伪造、哈希抗碰撞、加密按所选原语满足其安全性。

共识安全不依赖墙钟；共识与 B 进展依赖部分同步、足够诚实在线副本、状态可用、Provider 可达及配置存在幸存支持。任意长分区和必达 B 完成之间存在条件限制。原生请求在 Q 中放行与 P 中接受分别排序，跨域用因果收据连接。

权威动态攻陷范围须满足各配置签名生命周期故障上界；移动攻击者累计取得旧配置 quorum 密钥时，本规格的 QC 安全假设失效。若部署要求此模型，需另选已证明的前向安全签名/主动刷新及重配置方案。新验证者从用户认可的最近配置检查点引导，旧 QC 单独承担不了“当前”资格。

历史见过完整秘密的域在恢复、删除、轮换本地封装密钥后仍记录为见过。原生能力失效需要覆盖该秘密及其可达子能力的证据。对不可观察的历史披露采用保守可能暴露集合。
