# 可证伪分离声明与门限裁决

版本 SG-DCL-1，2026-11-09。这里只给纸面规格与反驳；实现资格依赖至少一个严格实例及 G 的必要额外成本证明。

## 1. 共同比较合同

双方拥有相同原生接口、可信组件、故障集合、观察、证据、代码/状态大小限制、缓存、批处理、快照、幂等键、MPC/TEE/HSM 与精确求解工具。G 指本轮构造的具体强组合；“当前最强”按适用能力审查，全球所有算法的最优性另列证明责任。

主度量固定为 **C_N：一次合法停止/接管与要求的 B 完成所产生的原生 API 尝试总数**。超时、失败、重试、查询、撤销、恢复、验证/测量与清理均计；一次批 API 记一次，并另列对象数与字节。预建原生独立撤销域数 R、可信管理域数 D、共识消息/字节、持久读写、求解与验证成本作为次指标逐项报告。比较原生计数的等效性本身涵盖不了 CPU 或墙钟优势。

不满足共同安全/活性合同的方案标为 INFEASIBLE；该结果单独比较，避免将错误完成或永久等待计为零成本成功。

## 2. D1 声明 H1 与反驳

输入族 X_n：n 对独立批准任务 (A_i,B_i)，每对一条 A_i 刷新已放行、结果丢失，E1 失联，A_i 撤回，E2 接管；每请求使用固定 intent/key，每刷新至多一个派生单位，Provider 支持精确结果读取。A/B 各有独立任务原生域，A 域单次截止操作同时阻止旧创建/接受并撤销其全部派生；E1 持有的能力均受此域控制，符合 D1-P1/P2。该族的业务原子效果没有异步后续。原生清理、B 一次完成与读回均要求相同。这是冻结的理想比较 profile，当前 Casdoor 对应待证。

初始可证伪预测 H1：D1 可用 Θ(n) 个原生请求完成，G 需要额外重发或全账户撤销，故 C_N(G)>C_N(D1)，至少多 n 次。

最强 G1：[BASELINE_G](BASELINE_G.md) 的 BFT RSM＋持久工作流＋固定键 outbox＋精确恢复＋原生截止＋来源账本。它保留未知请求并查询原 key，逐项完成与 D1 相同的原生动作。迁移期间只复制受保护状态，原生动作序列可完全一致。

反驳：G1 无需全账户撤销；精确查回也无需重发。对任意本族 D1 轨迹，将每个协议转换映射到 G1 同名持久状态与任务；Provider 观察、动作与失败相同，**C_N(G1)=C_N(D1)**。证明见 BASELINE_G §3。H1 判废。n=1 已是覆盖见证；具体动作可取查询 A 结果、撤销 A 域、读回 A 状态、B 执行、B 读回、相同清理，双方各 5+c 次。这里计数依赖规定的单请求 API profile，c 为双方完全相同的清理调用数。

若原生截止缺失，双方均受 CE1/CE2 边界约束；候选获得额外接口将改变比较合同。

## 3. D2 声明 H2 与反驳

输入族 Y_m：m 个凭据秘密，各有 2-of-3 独立保管域，执行域选择为普通重建或受证明保护使用；任务的 AND/OR 原生路径及撤销 footprint、允许攻陷域集合、历史披露边、证据集合均显式有限。配置目标先满足 D2 博弈合同，再按 (最坏 C_N,R,D) 字典序最小化。

可证伪预测 H2：联合建模可在 m=1 的完整重建实例中排除静态保管的误判，且比 G 使用更少 R 或 D。

G2：有限 Horn 能力闭包＋全部允许故障状态＋观测一致策略＋通用 SMT/QBF 或显式安全博弈。G2 接受相同的历史披露变量和原生接受规则；使用与 D2 完全相同的可行公式和目标。

反驳：m=1 确实区分静态保管检查器，但 G2 同样发现 E1 单点重建→历史披露→原生接受路径。对任意有限 Y_m，D2 的候选解赋值也可交给 G2，其可行配置集和目标最优值逐点相同。**ΔR=ΔD=ΔC_N=0** 在此编码内成立；求解时间差待证，SMT 的一个慢运行无法充当必要下界。H2 的强基线优势部分判废。

## 4. 联合声明 H3 与停止规则

Z 为 X×Y 加入迁移与披露事件。初始预测：D2 证书接入 D1 后得到 G 无法表达的动态接管资格。G3 采用配置摘要绑定、当前快照验证及事务重验，可执行相同迁移守卫；见 JOINT。当前状态为 COVERED_BY_G 限有限模型。

重新打开实现门需要：新输入实例、双方同能力、G 的具体限制及必要代价证明、候选完整上界、计费边界、可推翻条件。新的名称、更多变量、模型中的一个缺项或较慢的通用求解器实现，分别只能支持较窄结论。

## 5. DCL-R2分离尝试与最终门限

STRONG_G_COVERAGE_AUDIT的S1固定一个Casdoor未知refresh、S=1/U=1、可靠归属L=1、独立B和共同C_N。候选通过饱和关闭，完整G的RQ/EB/对账组件可进行同一推导并采用完全相同原生调用，必要额外费用缺失，判COVERED_BY_G。

S2共享RT停止/保留冲突为双方不可行；S3审计补全受信息缺口反驳；S4单配置变更截止被NC7反驳。上述是新的原生实例与反证尝试，R1的X/Y/Z判废继续有效。实现门继续关闭；候选机制与参考新代码、模型检查/原生实验均未进入执行阶段。
