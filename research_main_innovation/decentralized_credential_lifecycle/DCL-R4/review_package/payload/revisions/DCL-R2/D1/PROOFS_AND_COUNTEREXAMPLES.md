# D1 反例、边界与覆盖

2026-11-09。全部为手工可复查轨迹，机器检查运行 0。

## CE1：历史 bearer 的接受旁路

输入：E1 曾得到完整 AT x；P 在到期 t_exp 前仅检查 x 的签名/期限，忽略 Q、mv、任务和新 gate；E1 可直接连接 P。取 t_revoke<t_attack<t_exp。

轨迹：Q 提交 Revoke A → 提交 Move E2 → V 换本地封装密钥 → E1 携 x 调用 P → P 接受 → 产生策略禁止的 A 效果。n=4,f=1 共识完全诚实也有此轨迹。

条件不可能性命题：对任意只修改 Q/V/E2 本地状态的协议，P 在攻击调用前的验证输入与未撤回运行相同，因此接受概率相同。只要 x 仍可达接受，保证“撤回后所有原生 A 操作均失败”在此接口类内不可实现。若效果由该调用继续产生，同样排除严格 C_effect。证明直接依 P 的输入无变化；随机化本地协调仍无法影响其接受判定。

修复选择：使 P 真实撤销所有旧能力及派生、令牌受未泄露持有者证明约束、完整可信中介且旧域无法旁路，或等待可证明的到期并覆盖延迟/刷新。新接口/信任与等待成本同等给予 G。边界属标准能力泄露结论，独立新定理优先权待核。

## CE2：查无记录与延迟发送

Q Release(k) → 网络滞留旧请求 → Revoke A/Move E2 → E2 Query(k)=ABSENT → E2 释放 charge 或新建 k' → P 接受 k' → 旧 k 到达 P 再生效。

即使“查询发生时确无效果”是真命题，未来旧交付仍可发生。两条历史在 Query 前同观察：h0 旧包永久丢失；h1 旧包延迟。候选若此时释放并给继任，在 h1 上可能重复。保持可靠性只能保留责任、获得 Provider 终态 fence，或采取已证明覆盖旧包的期限/通道截止。

R1 增加 T13/T15。查询响应签名、fresh nonce 和链上时间均无法替代未来旧 k 的拒绝条件。AID-Guard III-E 已有直接机制重叠，见来源记录。

## CE3：只迁移返回成功的清单

E1 Release(refresh a) → P 创建子 RT y → 回包丢失 → E1 迁移仅导出已知材料 x → E2 撤销 x 并报告全世系关闭 → y 可刷新/使用。

修复：义务在发送前持久化，迁移全集包含 a；未知派生按 profile 保留。枚举完整性、单效果饱和或全谱系撤销有充分证据后才能关闭。E1 单方签名“清单完整”在 E1 失陷模型下无法承担完整性。

## CE4：旧域与新域重复发送

Q 旧 Release(k) 已在 E1 → Q 冻结旧 owner → E2 以新 a/k' 继续 A → 两请求均到 P。owner 更新提供 Q 内资格顺序；原生接受顺序仍独立。R1 只允许 active intent 的同 k 精确幂等重放或 terminal-no-effect 后单继任；撤回 A 后保留只读/善后。

## CE5：来源重标记与 B 受损

A.g0 的迟到 RT 到达 E2 → E2 改字段为 B.g1 → B 借其继续。此操作造成 origin 混淆；R1 T06 拒绝。若 P 本身只认共享账户密码、无法区分 A/B，系统需要先建立独立 B 原生支持；全账户撤销可同时停止 B。强 Preserve 由 D2 原生路径检验承担。

## CE6：失陷域拿到管理员能力

E1 运行中获得可删除全账户/修改恢复路径的密码。接管后 E1 删除 B 的支持或锁定用户。2-of-3 静态保管和诚实 BFT 均保持正常，B 仍失去可用性。针对任意 E1 恶意行为的 B 持续可用性需要撤回该管理能力且有足够幸存支持；接口缺乏恢复/隔离时 MODEL_BLOCKED。

## CE7：原生接受栅栏与业务效果

P 在 fence 前已接受“延时发送”，fence 后禁止新接受，队列在一小时后发送。若关闭声明承诺此后再无发送，声明为假。修复须取消/排空/效果前沿控制并计入已提交载体。允许 fence 前承诺结算属于另一种较窄 C_accept 合同，明确类型与时间。

## CE8：成员变化与旧配置回滚

新 E2 只验证旧 QC 便认为自己当前合格，或移动攻击者累计取得旧 quorum 钥后伪造迁移。R1 要求可信近期配置引导、当前读屏障、完整配置链及明确签名生命周期故障约束；动态权威故障上界未满足时保持 UNKNOWN。

## CE9：幂等与截止保留到期

P 对 k 去重/终态保留 Δ 时间 → E2 在该窗口内完成恢复并记录结果 → 网络中的另一份旧 k 在 Δ 后才到达 → P 已清除去重记录并重新接受。若 CLOSED/至多一次声明覆盖无限未来，该轨迹违反声明。

有限 TTL 加任意异步延迟缺少全期保证。R1 要么把声明时间范围限制在已证保留内，要么要求旧原生身份永久退休，或先取得覆盖全部消息的通道截止。单靠本地删除 outbox 和定时等待无法证实失陷 E1 已销毁旧材料。G 与候选共同承担这一条件。

## 覆盖见证

SEPARATION_GATE 的 X_1 中 G1 与 D1 可逐事件相同：已持久 a → 查回 → 原生撤销 A → 原生读回 → 执行/验证 B → 相同清理。原生能力相同则两者成功条件和 C_N 相同。故 CE1–9 用于推翻不完整设计，不能用它们声称相对强 G 的创新分离。
