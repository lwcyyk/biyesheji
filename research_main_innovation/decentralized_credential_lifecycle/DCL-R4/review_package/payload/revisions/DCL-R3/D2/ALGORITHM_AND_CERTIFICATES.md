# D2 有限算法与证书规格

2026-11-09。以下为数学定义与验证设计，新增可执行求解器为 0。

## 1. 输入审查

检查有限目录非空、任务/原生 scope 覆盖、完整失陷域映射、秘密使用 profile、派生/异步上界、原生 footprint、证据权限/完整性与稳定性前提、故障转换和合法观察。证据不足返回 UNKNOWN，并列精确缺项；求解预算耗尽返回 INCONCLUSIVE。有限精确模型的 IMPOSSIBLE 与真实世界全局不可行分开。

两侧精确性决定不可行结论的资格：环境行为遗漏会产生假可行；可用控制遗漏会产生假无解。仅有保守环境过近似时，可证明正结果可靠，负结果需要抽象反例消解或更窄 scope。

## 2. 精确有限求解

枚举全部有限配置 C，逐个求统一策略的最坏原生计数 J_h；在可行者中按 (J_h,R,D) 字典序选择。枚举可按 (R,D) 排序以便审查；仅在证明主要费用下界足以排除候选时允许提前剪枝。通用约束求解可采用相同域、目标与优化。

对固定 C：

1. 从初始 K0 展开全部故障、发送/丢失/原生接受、秘密使用/暴露和证据动作。知识状态 K 保留所有相同观察的具体状态，含资源/义务/来源/配置。
2. 先计算许可的 post-settlement 运行关系下的归纳安全区域 I_post。闭合声明所覆盖的旧能力路径在该区域内持续关闭；B 的后续政策按声明维持。证书给出允许 post-actions 和所有环境后继闭包。
3. 令 W0 为同时满足停止类型、B 完成目标、指定严格义务关闭且 K⊆I_post 的安全终态。A 仍 UNKNOWN、B 已完成的部分成功须用另一目标类型表示。
4. 定义 `SafeOut(K,a)`：a 在 K 中所有状态可授权，环境决策段每个前缀安全且保持 B 支持，全部合法观察分组完整、观察集合非空、每组后继K非空。空/模型外后继返回UNKNOWN。
5. `W(j+1)=Wj ∪ {K | ∃a: SafeOut(K,a) ∧ ∀o∈ObsPost(K,a), Post(K,a,o)∈Wj}`，计算至 h。

K0∈Wh 给出 h 步统一可见策略。K0∉Wh 且模型/动作精确、h 固定且检查穷尽时给出有界 IMPOSSIBLE。有限无限步 reachability 可迭代到不动点；该结论仍限有界状态及决策段模型。具公平约束的无限异步活性需另选对应博弈，当前算法保持范围外。

动作选择可固定 rank 最小、字典序打破平局；需要最坏原生计数最小策略时，用非负调用权重 d(K,a,o)，定义：

`J0(K)=0` 对 K∈W0，其余为∞；`J(j+1)(K)=min_a max_o[d(K,a,o)+Jj(Post(K,a,o))]`，只取 SafeOut 且全部子节点可行的动作，允许已终态停留。权重含查询/失败/清理。**R2修正：当隐藏段费用随具体世界变化时，上式逐段取max仅给保守上界，精确最优性采用第7节的累计费用扩展。** 原式保留以便核对R1修订，未被用于新实验。

## 3. 复杂度与通用表达

设配置数 L、每配置具体状态数 N、动作数 A、观察数 O。非空知识状态至多 2^N−1。显式朴素展开/递推可给 `O(L·h·2^N·A·O·T_Post)` 的宽松上界，T_Post 含能力闭包、前缀与后继构造。存储至少包含被访问知识状态、策略及证书。配置编码/闭包规则/输出成本均另计，压缩和增量缓存双方同等开放。

Horn 闭包在有限原子/规则上可用标准 worklist 计算。SMT/ILP 适合静态布置及给定场景约束；完整观测一致性和动态控制可先展开再 SMT，或用 QBF/博弈编码。单层静态 ILP 只核对逐场景末态时尚缺统一策略和全过程安全，G 获准添加同等博弈层。

## 4. 可行配置证书

证书对象 Cert 包含：

- 模型/业务/原生 profile/故障域/观察 schema 摘要与明确读取范围；初始 K0、h、目标类型及成本口径。
- 配置 C、组件→真实控制域映射、份额/运行使用能力表、全部历史/可能暴露边及依据。
- 策略 DAG：每节点精确 K、动作、rank、每个合法观察的子节点、全部动作实际原生微步骤和成本上界。
- post-invariant I_post、允许后续动作及对全部环境转换的保持证据；关闭 scope 及证据源条件。
- 当前 D1 快照 (cv,mv,v)、全部未决义务/来源/charge 摘要、材料对象可用性、执行镜像/托管测量引用、证书有效性前提与失效触发器。

检查器从原始模型重算闭包、行动许可、全部 Post、成本和 I_post，拒绝遗漏分支/空 K/伪造证据作用域。哈希确保对象一致，实际 profile 真实性继续依赖外部证据。

最优性另附：每个配置更小最坏 C_N 的排除，以及 C_N 相同时更小 (R,D) 方案的不可行/费用排除证书。仅验证一份可行策略即可接纳安全配置，最优性缺口保持独立。

## 5. 不可行/未知证书

有界 losing DAG 的每个 K 节点覆盖所有合法动作；每动作给出真实守卫失败或一个对抗观察后继，其子 rank 递减至 unsafe/goal-false-at-horizon。故障/攻击轨迹按同观察分组，保留共享决策。单条某动作失败轨迹只反驳该动作。

配置全不可行需覆盖全部有限配置，或给可独立检查的逻辑证明/UNSAT 证明。SMT unsat core 是诊断子集，证明能力依完整编码及可信求解/证明重放，core 列表本身无法证明整个命题。

UNKNOWN packet 列模型缺口，如未知登录旁路、完整枚举权限缺失、原生效果上界未知、TEE 回滚保证待证。INCONCLUSIVE packet 列实际停止限额，保持已发现 incumbent 的安全证书，最优性与无解各自待证。

## 6. 运行与重配置

每次 Release、Activate、Reconfigure 在 Q 事务内比较 Cert 的相关快照/能力前提。无关日志 version 增长可由已检查的依赖投影重用证书；涉及来源、授权、预算、义务、native profile、成员或暴露的变更需重评，或出具保持引理。

新配置证书须以 `OldObl ⊆ NewObl ∪ MatchingClosed`、`OldHist ⊆ NewHist`、intent/origin/charge 相等为必要守卫。成员更换保持真实故障域约束。运行失陷/未知使用采用最坏披露更新；缺完整材料时冻结相关放行并保留 UNKNOWN，独立 B 可按另证路径继续。

## 7. DCL-R2费用相关性修正

反例COST1：两个同观察世界w1/w2。策略a后b在w1费用为10+0，在w2为0+10；真实最坏总费为10，逐段max相加为20。另有共同费用15的一步动作c，原递推会选c，故一般不能据该递推声称精确最优。

修正：具体状态扩展为 `(x,cost_so_far)`，实际转换按同一真实后继累加费用。运行观察仍只取合法Obs(x)，隐藏累计费用不会成为额外观察；知识集保留所有相容的状态/累计费用对。

对固定整数上限M，在每个转换前缀检查累计费用≤M，将超限后继列为失败，按同一W_h递推求可行。依次排除更小M，得到最小可行M，再以R/D打破同费用平局。所有查询、失败、验证、B完成、建置/清理均进入同一累计计费，计费与grant预算分别保存。

正确性：按真实路径长度，扩展计数始终等于该路径的实际总费；知识更新保留与观察一致的所有计数，因而∃统一策略∀真实路径cost≤M等价于扩展游戏获胜。有限精确状态/动作与h下沿D2-2/3得阈值判定的可靠性和完备性。费用界/状态规模须计入复杂度；若最大总费用可界为B，知识空间上界相应改用最多2^{N(B+1)}，或更精细的可达状态界。

只有每观察段费用确实恒定、或存在已证明费用相关性保持条件时，原J递推可作精确代价。该修复属于标准资源扩展安全博弈，G同等采用；不构成相对通用方法分离。
