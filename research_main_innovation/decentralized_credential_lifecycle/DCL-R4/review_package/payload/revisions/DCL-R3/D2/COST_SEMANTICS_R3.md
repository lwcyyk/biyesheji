# DCL-R3：COST1、完整费用语义及阈值博弈证明

2026-11-10。重新从具体轨迹定义费用。纸面推导与反例；新增求解/机器检查0。继承主指标C_N，强G取得相同费用状态、求解技术和全部优化。

## 1. 成本边界

对真实微步骤历史τ，定义向量 `c(τ)=(C_N,C_msg,C_bytes,C_storetime,C_cpu,R,D)`。本阶段最优化顺序保留 `(worst C_N,R,D)`，其他维度逐项报告，不能以C_N相同推断总开销相同。

|费用|计入方式|
|---|---|
|原生业务发送|每次实际HTTP尝试计1；发送前预算预留是控制约束，与实际是否已发送分别记录|
|原生查询/发送/重试/对账|每次失败、超时、重试、内省、枚举、处置、验证各计1；一次批API计1并另列对象/字节|
|建置/配置切换/证据获取|涉及原生调用计C_N；共识、签名、快照、对象传输计相应维度；预建根/备用域不能免费|
|UNKNOWN持有|可能0个新增原生请求，仍占charged、持久空间和时间；按字节×持有时长报告。无限等待的存储时间费用可为∞|
|B完成与清理|声明工作负载要求的全部调用计入；清理未完成时不能当作成本已结清|

实际费用是对同一真实路径累加；最坏费用为同一观察策略下所有允许路径之sup。h限制决策段数，不限制墙钟持有时间。非负费用逐微步计入，native单位数/AT条数与API尝试次数分开。

## 2. COST1重新构造

初始两个不可区分世界x1/x2，h≥2。共同动作a不透露世界，随后共同动作b完成目标；另有一步c。a后仍须b，终态/义务条件相同。

|世界|a费用|b费用|a;b总费|c总费|
|---|---:|---:|---:|---:|
|x1|10|0|10|15|
|x2|0|10|10|15|

`max_x(cost_a+cost_b)=10`，而`max_x cost_a + max_x cost_b=20`。旧递推把x1的首段与x2的次段拼接，误选费用15的c。该反例要求这些费用或其区别没有成为合法观察；若每阶段费用本来公开且进入Obs，应使用相应观测分支，不能人为隐藏已有信息制造反例。对实际每HTTP费用公开恒定的微动作模型，旧式可在其适用条件下成立。

## 3. 精确状态与观察

固定有限物理模型 `M=(X,X0,A,Obs,Segments,Safe,Goal,Inv,h)`。x包含所有影响后续权限、预算、义务、故障、native状态和后续费用的变量。一个Segments(x,a)条目给出该动作到下个决策点间的全部允许微步、观察o、末态x'、费用Δ≥0和unsafe_prefix标记。

对阈值m，扩展状态为(x,z)，z是该历史累计C_N；z>m统一记为overflow失败。知识状态B包含全部与合法观察一致的(x,z)，非空。Obs仅提供真实允许的信息；若实际费用可观察，把它纳入观察；若不可观察，不能按z或overflow分支选择动作。

`Post_m(B,a,o) = {(x', clip_m(z+Δ)) | (x,z)∈B，存在具有观察o的合法segment(x,a,x',Δ)}`。

clip_m保留0…m，超限变为⊤。所有同观察末态和累计费用都并入同一个B；一个后继超限/前缀坏即使不可观察，也使该动作的相应策略分支失败。初始费用包含配置建置实际费用；未知建置费用也保留对应状态对。

## 4. 完整递推

`Admissible_m(B,a)`要求：每个真实状态都有合法权限/资源支持；segment/观察集合非空并完整；所有segment前缀安全、B支持保持、累计费用从未超m；模型外结果按UNKNOWN处理。

`W^m_0={ B | ∀(x,z)∈B: Goal_full(x) ∧ z≠⊤ ∧ x∈Inv }`。

Goal_full包含指定停止类型、B完成、严格义务为空和要求的清理；Inv对声明后续行为保持安全和已发关闭声明。DEFERRED/UNKNOWN可以是协议合法响应，但有开放严格义务时不属于Goal_full；其持久责任继续存在。

`W^m_(j+1)=W^m_j ∪ {B | ∃a: Admissible_m(B,a) ∧ ∀o∈O(B,a): Post_m(B,a,o)∈W^m_j }`。

所有Post必须非空，终态可立即停止计费。规定h内的所有环境延迟/timeout/endpoints均由segment覆盖；若Provider可无限不返回且没有timeout决策观察，有限决策模型前提不足。给真实超时观察仍不能把UNKNOWN判为已关闭。

最小阈值 `m*(C)=min{m | B0(C)∈W^m_h}`；配置有限全枚举后按(m*,R,D)选解。无可行阈值在精确有限模型内为IMPOSSIBLE；缺模型为UNKNOWN；搜索限额耗尽为INCONCLUSIVE。只证明一条策略费用上界不能授予m*最优性。

## 5. 可靠性与完备性证明

引理E（精确知识）：对任意合法观察历史，B恰等于其相容真实历史的末状态及同路径累计费用。初态按定义；归纳步逐真实segment相加，再按观察取并，两个包含方向分别由真实后继和Post见证得出。没有混合不同世界的前缀/费用。

可靠性：对j归纳。j=0满足所有真实候选的完整目标与费用界，Inv保证后续声明。j+1节点选择见证动作；Admissible保证所有微步安全/费用界及非空后继，引理E把每真实结果映射到某子B，子节点在j步内成功。故h内达成且真实最坏C_N≤m。

完备性：假设模型对环境和可执行控制精确，存在h步合法观察策略满足目标/费用。其首动作必须在所有相容状态合法且每segment安全不过费，否则有对抗轨迹。其每个观察子策略在h−1步成功，由归纳属于W^m_(h−1)，于是初B属于W^m_h。反向沿可靠性。阈值可行性随m单调；排除全部更小阈值后才得精确最优。

只有保守环境过近似时，接受结果保持可靠；负结果和最优下界可能来自伪反例，需要精化。无限h/公平性、连续持有成本或未界定绕行发送不由有限整数阈值定理自动覆盖。

## 6. 结构压缩引理及通用覆盖

若x已包含全部后续动力学/权限/可见性变量，累计z仅是非负目标计数且不影响后续转移，那么同一B中相同x只需保留最大的z。较低z拥有相同未来但更宽费用余量，不能成为更坏反例。对未来策略长度归纳，去掉同x的低费用副本保持阈值胜负；其物理观察仍相同。

有m+2个计数桶（0…m和⊤），再加“该x缺席”，知识映射数上界为(m+3)^|X|，优于任意成对幂集的宽松界。若累积费用也影响真实配额/转移/策略观察，则须把相关变量并入x或停用该压缩。该引理属于标准资源/加权知识状态的直接保持，可同等交给G；本轮没有建立其独立发表优先权或算法速度分离。

G按相同Post、累计费用和阈值递推得到相同胜集与m*；COST1修正消除了模型错误。所有持有/通信等次费用仍须完整报告。
