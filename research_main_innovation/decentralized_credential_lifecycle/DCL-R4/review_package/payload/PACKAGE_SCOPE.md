# 审查包范围

包内保留研究根的相对布局：当前研究Markdown/主张与来源索引，D1/D2/JOINT，R4全部规范/审查/验证计划，R4脱敏证据视图和公开定位日志，原33输入清单、原生能力表及来源/归档锁，R1/R2/R3历史文稿（部分元数据）。原历史文稿字节不改。

包外依赖：原33输入实际文件、完整46/94/120归档的未选工件、26+9+4源文件的实际源码内容、原生DB/二进制/ZIP、M1–M6原始运行日志、早期网页原始结果和未取得论文正文。包内路径/哈希只负责定位，不代表已附其内容。额外需要的公开源码由接收者按固定commit与URL取得。

当前库、历史文本和锁中的绝对Windows路径为来源定位字段。原规范中以纯文本提及的日志和源码也属于外部依赖。此包仅提供离线文稿导航；SOURCE_UNRESOLVED、UNKNOWN、历史失败及dirty构建前提持续有效。

PACKAGE_MANIFEST.json覆盖除自身以外的全部包内文件。PACKAGE_CHECK.json记包内链接/文件范围和启发式秘密扫描；包外REVIEW_PACKET_SHA256.json在ZIP生成后记录ZIP摘要与逐项流式校验。最终研究工作区行政结果在DCL-R4/evidence/DELIVERY_CHECK.json。哈希与扫描均不充任协议证明或人工安全认证。
