# 组合模拟关系与证明责任

2026-11-09。

## 1. 抽象关系

真实运行状态 r 包括 Q 日志、Provider 状态、在途消息、所有域可持有的材料/调用能力、秘密使用历史与配置。抽象状态 k 来自 D2。

定义 `r ⊑ k`：

- 实际授权来源、业务意图与预算映射到相同抽象对象；抽象可用额度至多实际可用额度。
- 每个实际已/可能披露、派生、异步载体和在途消息在抽象能力/义务中有覆盖；scope 与任务映射明确。
- 每个实际原生接受路径和故障转换在抽象模型有对应；合法观察映射保留同观察世界。
- 每个抽象允许控制有权限明确的实际动作实现；所有实际微步骤、费用与故障中间点都在 Post 覆盖内。
- 实际已发关闭声明的类型/版本/前沿与抽象谓词一致；真实保留任务仍有被映射的合法支持。

预算、义务和能力采用适合安全结论的保守方向。宣称 IMPOSSIBLE 时还需控制与环境精确性；安全模拟单方向足以支持已接受策略的可靠性。

## 2. 组合条件定理

若初始 r0⊑k0，D2 证书经可靠检查，D1 每个可控/环境微步骤都能 stutter 或对应到 D2 允许转换，且闭合声明的 post-invariant 持续成立，则 D1 的每条真实轨迹满足 D2 所验证的前缀安全、来源/预算/责任保持与条件目标。证明按真实轨迹前缀归纳建立模拟，再应用 D2-2。该形式是标准精化/模拟保持，当前项目的具体适配器证明待补。

真实原生动作若依赖本地适配器无法观察的状态，知识集必须保留全部可能状态。实际 Provider 越过模型边界时撤销相关策略资格并保留 UNKNOWN；已发声明能否继续成立仍由原有稳定性条件承担。

## 4. 准入守卫与迁移失败

新证书接纳需要验证当前快照及迁移清单。配置结果改变预算谱系、隐藏旧义务、抹去历史披露或仅通过改写任务 ID 排除旧路径时拒绝接纳。若只影响 A 子域，可保持独立 B 的有效证书；隔离条件来自真实共享资源图。

移动 E1→E2→E3 的多次接管保留同 i/a/k/origin/charge。失效的 E2 Ready 仅失去资格，Obl 仍在当前权威。长期原生幂等/fence 保留耗尽时，只读查询和闭合声明进入重评；系统需要原生通道截止或延长保留合同才能恢复强重试保证。

## 5. DCL-R2具体模拟

关系扩展为 `real r ⊑ (K,RHO,Cert)`：真实Token行、缓存父/用户/app副本、已发送网络包、审计待写、所有已/可能秘密和攻击调用在K某状态中被覆盖；S/U/L与真实调用界相容；RHO含这些责任；Cert的实际接口/权限与native footprint一致。

逐步保持分四类：Q提交保持i/o/quota与责任全集；网络/handler推进只删去有证据排除的可能相位；F5插入把同一attempt的可能效果转为待归属材料且消耗U余量；原生revoke只更新实际行/cohort，不删除缓存handler。T19只有在SAT或完整cutoff条件和全部材料处置满足时才移除对应kind。由这四类归纳可建立该抽象的保守安全模拟框架。

该框架在真实代码全路径、DB/时间/崩溃持久性及实际BFT部署上的逐事件证明仍待取得。选择CD25-BOUND可使用历史M3/M4/M6的有限见证；选择CD25-LEAK则必须扩展S_bypass和攻击路径，禁止复用受信创建者版本的旧证书。

## 6. 联合保持定理与判废点

若D2证书按真实profile通过、初态满足上关系、每个D1/原生微步骤都保持该关系、最终关闭条件在I_post下保持，则D1执行满足D2验证的声明scope内安全/保留性质。证明为真实步归纳＋D2-2的rank与终态不变量。

反例：旧证书把父revoke视为删除全部后继；真实F3→V3→F5仍创建子行，实际后继无对应抽象状态。因此保持证明失败，责任关闭被拒绝。修复为加入缓存handler相位和SAT/真实截止守卫；G可作同样精化。

本轮联合结论继续归为条件工程集成。通用精化、持续验证、RQ分域因果及EB配置历史已覆盖其一般形式；具体Casdoor映射提供实例证据，独立优先权及必要成本差仍待证。
