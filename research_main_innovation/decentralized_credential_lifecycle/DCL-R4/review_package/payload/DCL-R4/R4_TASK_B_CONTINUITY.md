# DCL-R4：任务B支持合同、配置裁决与有限正例

2026-11-10。保留[D2原Support谓词](../D2/CONFIGURATION_MODEL.md)的批准、当前Q/Gate、真实原生接受、材料及可用性条件。`Token仍存在`仅提供路径的一项材料条件。以下为纸面推导，实际部署验证0。

## 1. 合同与量词

**S1（安全优先）**：允许Prepare/Seal期间暂停B。所有前缀仍保持授权来源/预算/UNKNOWN/Hist；A仅在对应C_local/native/effect证据满足后宣布该层截止。若新Q合法quorum、数据、V/Gate、B批准、预算和P进展恢复，B恢复合法执行。材料可能在暂停期间过期，恢复需预留合法重新取得能力；缺此条件只承诺状态保留。

**S2(T)（严格前缀支持）**：在预定保护区间T中，`∃C∃π∈ObsStrategies ∀τ∈Runs(C,π,F) ∀prefixρ≤T: Support(B,last(ρ),C)`。实际网络、quorum可达、当前资格、秘密/材料、批准、剩余尝试预算、Provider服务能力及允许故障均在Support内。若要求每次请求在δ内完成，另给全区间的时延/视图切换/Provider处理上界。最终同步只支持相应最终进展；它对同步恢复前的所有前缀及时可用性留有空窗。

S2(T)不要求每个瞬间都恰有业务请求在运行；它要求每个规定前缀仍有能够合法服务允许工作负载的路径。任意新意图与预登记固定意图是两种工作负载，票据方案按实际范围声明。S2(∞)还需永久维护、更新/期限、到达负载与费用条件；有限T正例只支持其区间。

## 3. 新的原生轮换空窗反例 B-ROT

输入：B只有一个可接受的AT/RT行，rotation开启；唯一Gate发起refresh，P已插入子行、删除父行，响应携带子材料尚在网络中，Gate仍仅知父材料。此时fresh调用若检查父行则拒绝，子材料虽存在却尚无合法使用者可取得。该前缀Support(B)可能为假。双Gate共享旧材料也留下此窗口。

这条轨迹来自已核refresh微步骤；具体JWT/行检查和部署符合性沿原合同条件化。修复可以选择：预先取得覆盖有限T的B材料、在另一可用根保持服务时轮换一根，或有充分期限/响应界的非轮换/提前更新。根数量的通用下界仍待单独论证；这些替代方案使“两根在所有原生模型中都必要”的全称断言缺乏支持。

## 4. 一个可完整走查的有限S2正例

保护区间T=10分钟。迁移主Q_old四节点到无交集Q_new四节点，各f=1。另有预先投入使用的静态Q_B四节点、f_B=1；Q_B在T内保持ACTIVE且充分正确成员及时互通。它的治理/批准根可由同一用户合法签发，服务/管理控制与主Q的本次停顿隔离；共享用户根诚实且未撤回B的条件明示。

B有Gate_B1、Gate_B2两个受信非拜占庭执行门，允许至多一个崩溃；故障集合同时允许各Q至多一个拜占庭节点及一个B Gate崩溃。V_B和P受信、全T可达，V_B供存活Gate受控使用。Q_B、B Gate/V的故障域与主Q迁移故障明确分离。该配置对V_B或P全故障的可用性另有限制。

B材料在T开始前已合法取得，剩余有效期至少30分钟，保护区间加时钟误差、网络/排队和验证裕量小于该余量。T内采用fresh UserInfo读取工作负载，材料保持有效且无被允许环境/管理动作撤销；配置不在T内刷新唯一材料。E1/E2只有句柄，无法看到B可复用材料。Q_B从开始持有B的原intent/quota/attempt责任；A的UNKNOWN从主Q迁移，持续保留原归属。凡跨权威转移意图另需协议，本正例保持B权威静态。

设T内至多10个逻辑只读请求；一次Gate崩溃至多造成一个在途结果未知。每个请求最多两次原生读尝试，工作负载实际C_N上界20，包含失败/超时/重试。Q_B授予24次读取预算，全T内至少保留4次未用余量，以保持各前缀的可放行支持；保护负载到达上界后继续保留路径和余量。每次重试使用有序的Q_B批准及新attempt记录；同一逻辑只读请求保留原来源/预算，UNKNOWN记录保留到可接受的终态/保留政策。本见证只证明S2(T)，尚未单独证明所有UNKNOWN清空的Goal_full。假定单个故障检测/视图切换/网络/P响应总界适合服务δ，且入流负载低于存活路径容量。对状态改变型UNKNOWN请求，第二Gate不能直接套用此重试论证。

A停止选择C_local及受限创建/材料合同：A的受控发送上界S、每attempt创建上界U和完整识别下界L均有可靠证据，A旁路集合为空；对全部已知A材料处置，动作footprint与B材料/用户/app/session依赖隔离，全部A在途潜力已饱和/终态后才宣布相应native关闭。任意异步C_effect仍需专属载体合同。共享P的速率限制/资源耗尽须由A处置速率上界及B资源预留排除。

逐前缀证明：

1. 初态Q_B、两个Gate、V_B、有效材料与预算满足Support。
2. 主Q的Propose/Prepare/Seal/Transfer/Activate/Takeover/Retire仅改变主Q状态；B路径依赖投影与原生footprint保持。
3. 任一允许Q_B故障仍留下三个正确可达节点；所用PBFT及规定时延界提供当前有序服务。一个Gate崩溃后另一可信Gate及V_B/P仍可用。
4. 每个B尝试按Q_B扣预算，工作负载最多20次且24次预算保留至少4次余量，材料在完整T内保留期限裕量；读重试保留责任。时钟/网络/到达条件确保服务能力。
5. 环境转换均受上述故障集合和有效期条件限制，因此每个前缀仍有一条当前路径。S2(T)条件成立，真实实现精化与机器检查继续待做。

费用分开报告：预建B根及材料的原生取得/检查/清理、Q_B四节点、两个Gate、V_B、独立管理/存储/密钥、运行20次上界与24次预算中的未用余量、维护与共识消息。候选与强G共享相同全部资源；这里建立的是条件可行见证。

## 5. 可核验的不可行性见证

- **CUT-ALL**：故障集合允许切断B所有Gate到Q/P的路径。取该故障及其发生后的前缀，所有OR路径至少一项AND条件为假，S2失败；有限冗余均受此见证约束。
- **CUT-SHARED**：冻结精确动作目录中，A唯一可达坏路径与B唯一路径共享同一撤销原子，任何完成A停止动作都切断该B原子，且无预先替代。逐动作可核得无S2计划。
- **EXP-FINITE**：全部材料有限期限，后续每次保持支持必须耗至少ε>0维护费用，有限总预算m至多支持有限次数；若保护时间无限且期间必需更新，则最终存在失去支持前缀。永久有效根/零费无界维护需另列模型。
- **OBS-GAP**：B-ROT或隐藏路径失陷允许在观察前破坏唯一支持。仅收到报告后使证书失效无法修复已经失败的前缀；需预先鲁棒配置。

## 6. D2的S2证书义务

证书附`T/workload/δ/clock_margin/expiry_bounds`、全部Q/V/Gate/P依赖、每个FD故障集合及相关性、原生根/footprint、Hist与旁路、B意图权威/责任谱系、剩余预算和费用、网络/容量/维护假设。检查所有真实微步骤的中间前缀，包含Seal、原生轮换、崩溃恢复与超时；只检查决策段末态会漏掉B-ROT。

每个允许故障组合提供至少一条可持续的当前路径及保持证明。发现新根/披露/到期风险/管理员或入口变化时重新求证；未观测故障提前纳入闭包。单路径失败可输出明确cut，过近似模型只支持保守正结论，现实不可行证书另需精确控制/环境。

R4-C = CONDITIONAL_PASS：S1与S2分清，单/双Gate共Q失败，有限独立路径正例及不可行见证均可审；实际S2部署数量为0。强G采用同样路径/证书/标准求解，严格分离实例保持0。
