## 1. 协调机制选型

|协调方式|适用信任与提供的能力|对原生接受的依赖|
|---|---|---|
|单权威事务＋恢复|单一可信管理者、单主持久化；与现有 SQLite 最近|旧域可绕行时仍需 Provider 截止|
|Raft/Paxos 类复制|崩溃故障、有可信节点逻辑；共同顺序及恢复|恶意管理域超出其基本模型|
|BFT RSM|固定配置 n=3f+1、至多 f Byzantine、QC 至少 2f+1；认证链路与部分同步活性|仅对复制状态和验证的命令负责|
|许可联盟链|BFT RSM 加共同治理、可审计执行、链上状态与证明接口|秘密托管、链外事实及异步效果仍需独立组件|
|公开链|开放成员及外部结算/公共可验证性确有需求时评估|确认/最终性、费用、隐私和可用性均需计费|

D1 默认采用成熟 BFT RSM，把“独立管理域共同权威”作为要求。区块链保留实现选项；本轮缺少必须采用链的数据或功能分离。n=4,f=1 为最小审查配置，4 个不同进程共用同一管理员时按一个攻陷域计。

## 2. G1 的具体组件与接线

1. 用户签名批准终端登记 intent、来源、权限与预算谱系。
2. BFT RSM 保存批准、intent 唯一约束、reserved/spent、请求尝试、未决责任、成员配置和 owner 版本。
3. 持久事务/工作流将 Admit、Release、Record、Revoke、Handoff 各作为条件命令。outbox 在原生发送前提交。
4. 可信执行门/MPC/TEE/HSM 按声明能力使用材料；普通密码重建按暴露事件登记。原生 key 绑定范围与正文。
5. 结果未知时保留带费责任；使用精确读取、稳定幂等重放或 Provider 终态化＋单继任。Saga 仅执行已获准的补偿动作，补偿语义与原始效果分别记账。
6. 版本化 evidence verifier 检查来源、范围、完整性、因果新鲜度与原生截止。责任关闭和结果消费分别授权。
7. 迁移采用当前 QC 检查点、状态可用性、旧执行资格截止、新 owner 激活及持久责任重指派。成员变更采用所选成熟 BFT 实现已证明的重配置流程。

## 3. D1 有限子域的覆盖命题

令 P 为 D1-R1 的有限状态转换关系，Provider 与故障动作共用同一外部合同。把 P 的每个授权守卫、状态字段及唯一约束作为 G1 工作流规则。该实例化使用标准状态机/事务/工作流表达能力，保留协议问题域的具体规则；系统级组合是本轮给出的纸面构造。

关系 R_P(S_P,S_G) 为所有安全相关字段相等、外部通道中的请求多重集相等、证据引用相等。初始化显然满足。对每个 P 命令：G1 的相同条件命令做一次持久转换，更新同一字段；原生动作完全相同。对每个环境步：双方接受同样丢失、延迟、攻陷和原生状态转换。可按轨迹长度归纳得到逐步模拟；需要的工作流内部调度只增加 stutter。

因此 G1 保持 P 的可见安全保证和相同原生动作计数。任意公平 P 轨迹的 G1 实现调度仍需同样的公平/部分同步前提。该构造证明本轮规格功能可覆盖，未测量实际运行时间；通信、字节与磁盘成本允许相同日志和批处理，额外必要下界尚缺。

把“当前 G 组合”定义得可以任意添加候选完整算法时，黑盒功能分离本就难以成立。后续若主张复杂度优势，需要冻结可审查算法族与计算模型，同时保留合理通用优化，避免借定义排除竞争者。

## 4. G2 / G3

G2 对 D2 的有限状态和动作作标准精确展开。对每个配置 C 计算同一能力闭包、知识集合 K、全部可见观察后继与安全博弈胜集；或把同一有限递推编码为 SMT/QBF。给定 C 的属性公式与 D2 相同，因此可行解集合相同，任何共同目标的最优值相同。SMT 的 SAT/UNSAT 标签只覆盖所编码命题；超时返回 INCONCLUSIVE，缺模型返回 UNKNOWN。此论证关闭的是通用配置功能/最优值分离，问题建模、原生抽象和特定结构算法的独立新颖性仍需另证。

G3 组合 G1/G2：配置证书带 profile、历史暴露、成员、执行测量及快照摘要，RSM 在 Release/Activate 前事务性重验。历史状态变化触发重评；旧 unknown 和计费谱系在重配置中复制。此接线可表达本轮联合机制的全部守卫。

## 5. 与公开先例的关系

AID-Guard 支撑不确定责任与单继任的直接机制近邻；Root-Scoped Quiescence 支撑来源/支持、载体与通道责任；SAGA-BFT 支撑分布式治理；Horcrux、Seal、Lit 支撑不同托管/使用信任边界；MulVAL 支撑标准逻辑能力传播；EFFECTBOUND 支撑有限隐藏状态与部署保持。详细版本和实际核读范围见 SOURCE_AND_PRIOR_WORK。
