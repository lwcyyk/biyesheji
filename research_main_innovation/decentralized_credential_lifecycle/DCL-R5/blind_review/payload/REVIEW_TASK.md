# 凭据生命周期协议：阶段一审查任务

请仅依据本包定义、实例和您自行记录的公开依据，推导证明、反例或所缺前提。请在阅读作者既有证明/结论前固定初稿并计算哈希。此包由熟悉背景的助手摘录；请记录您此前是否接触过相关材料，及摘录是否足够。

待审问题：

1. 固定成员服务接续后，授权历史、Seal与child是否唯一？委员会无交集、连续两次成员变化、退休、旧钥泄露和不同引导锚分别如何影响结论？
2. 对登记请求，迁移能否保持意图、来源、预算、未知责任、去重及历史披露？对未登记原生行为能推出什么？
3. 新委员会取得状态和执行域获准使用秘密分别需要什么？快照/恢复/日志的秘密输出与Gate重启如何进入假设？
4. 崩溃、旧checkpoint、view-change与分区下哪些性质属于安全、最终进展或有界响应？
5. 本地放行、实际HTTP、原生撤销/创建/接受和异步效果能否组合到目标边界？
6. 有限费用知识状态的共同观察策略与阈值判定是否保持费用/目标？哪些状态压缩可用？
7. B的每前缀合法支持在给定配置、故障、期限、负载和费用条件下是否成立？

请对每项给出命题、所用假设、推导/完整反例、缺失定义、保证范围和需要的额外检查。实例是待检查输入，包中未给标准答案。可先只用纸面方法；工具运行须遵守另行获得的权限。
