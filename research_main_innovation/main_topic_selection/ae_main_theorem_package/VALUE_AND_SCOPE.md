# 理论价值与研究B的条件适用范围

版本 MT-1，2026-11-07。数学对象及证明见MAIN_THEOREM/COMPLETE_PROOF。本稿区分理论参数价值、理想执行合同和已实现B的实际动作，模型例不作为原生实验。

## 1. 参数w究竟控制什么

|量|含义|与w的关系|
|---|---|---|
|w|全局可选模式ID/不同模板列总库|搜索结构的对象|
|K|预测标签/有序中心数|去除相同预测签名后仍可达2^w|
|M|输入行数/逐行预算条数|一般输入量，不能并入w|
|v|坐标数|一般输入量，不能并入w|
|T_A|输入A的不同列型数|正半径下无w上界；I_h、Q=0、w=1就是YES且T_A=h|
|活动块数|算法对模式ID的当前划分部分|至多w，随搜索改变，不等于T_A或K|

U的意义是把未知共享模式与大量逐行条件的精确求解控制在w的参数函数内，K/M/v只进入显式输入固定多项式。K=2^{Θ(w)}时，K^{Θ(w)}形式的已显示保证可为2^{Θ(w²)}；U给2^{O(w log w)}乘输入多项式。这个比较说明保证形式的差异，不证明原方法每次必须达到其上界。

所有K行必须先读取；显式K指数于w时输入本身已很大。没有免费的隐式关系oracle；若另用电路或规则压缩Q，必须重证读取、标签存在性和输出合同。w增长时F(w)迅速变大，未知常数、每节点K/M扫描、位长和内存都影响运行可用性。当前没有实现或运行数据。

完整比较还包括COMPLETE_PROOF P13的通用有界修复参考：(1+max{w,3K₀})^{2K₀+1}poly(N)，即2^{O(w2^w)}poly(N)基本w-FPT。其无成本版是项目早期标准重推，本轮补齐列表/成本/域接口。核心候选价值据此收窄到条件紧的精细w依赖；该参考的整项已发表出处仍未绑定。

更有利的P14参考把原T1/T2直接扩到静态域/成本，给(K₀+1)^{O(w)}(w+2)^{O(w)}poly(N)≤2^{O(w²)}poly(N)。K₀≤poly(w)时它已达F(w)。当前潜在增量应与这个更强包络比较，集中于一般超多项式标签域，不能只拿P13的双指数界作对照。

## 2. 标准子域与完整正半径的差额

零误差时，一个模式不能解释两个不同观测列型，T_A≤w，枚举模式到列型/未用标记得到F(w)算法。每行允许一次错误时这个必要条件不成立。I_h小例只检验该压缩前提，w=1本身仍可直接处理，不作为复杂度分离例。

固定K有标准中心邻域分支：取一个尚未由已指定中心覆盖的行，枚举一个未指定允许标签及至多v+1个半径1邻居词。沿真实解分支总有一个未指定覆盖标签，每次固定一个中心，深度≤K；各坐标检查已有中心位能否扩为Ω_t中的tuple，剩余中心最后补齐。成本/列表均可同时验收，完整界[K(v+1)+1]^{O(K)}poly(N)。K预先固定时这很好，K随w指数增长时其输入次数也增长。

小v可直接枚举w^v；v=O(w)已经落入F(w)。固定实际错误位置后翻转观测也能精确处理，但朴素(v+1)^M费仍有M。总预算M无法保持每行预算；半径1的难点是定位未知例外并保留每行同一个标签。

因此核心候选增量集中在完整正半径、增长标签域且M/v一般的统一处理。已有标准子域和预处理均向强基线开放。EL-1下界的K=O(w²)只支持完整模型的最坏情形条件紧性，稠密K区域的独立下界没有由它取得。

## 3. 从M₁到矩阵的条件字典

令任务集T={1,…,v}，预先准备的独立原生撤销根J={1,…,g}。每条非平凡停止请求S_i作为共同初始状态上的一种备选首次情形，A_it=1[t∈S_i]。保留集合为T\S_i。

初始绑定f:T→J在请求到达前一次确定，每个任务恰有一个当前完整授权支持。原生根之间撤销效果独立，根数G=|J|含空备用根。

令D_g={0,1}^g\{0^g,1^g}，g≥2。标签p就是一个δ∈D_g：δ_j=1表示该请求终态撤销根j，0表示保留。设

\[
w=g,\quad K=2^g-2,\quad Q[\delta,j]=\delta_j,
\quad \eta_t=f(t),\quad \tau=0,
\quad \Omega_t=[g],\quad\Lambda_i=D_g.\tag{B-MAP}
\]

矩阵中心C_δ[t]=δ_{f(t)}给这一根处置方案对任务的初始预测停留位。行标签选择是该请求的整体根处置选择；K计数处置方案，w才计数语义独立根。全部K中心是理论输出，并不表示准备K个原生根。

不同token字符串、不同环境或不同句柄不会自动增加w。w只由已确认的独立原生效果单元计数；同一grant下的别名/后继属于同一个效果域时继续按该域算。

M₁的完整D_g高度结构化。固定绑定的两标签多数/平局及最小差额处理可在O(v+g)算距离，候选和强基线均可使用，无需强迫基线枚举2^g标签。定理D的下界则针对单位/边模板这一不同Q族，尚未归约到完整D_g子类；一般Q的条件紧性不自动成为M₁的条件下界。

## 4. Hamming距离等于最少重绑数的完整前提与证明

需要以下执行合同：

1. 所有根预建且独立可撤销，空根已付费；执行期间不免费新增根。
2. 每任务恰有一条完整当前根支持，根不能给代理绕过任务绑定的额外能力；缓存/副本/替代支持全部纳入合同。
3. 任一任务对任一既有根均有迁移资格，容量足够；账户、受众、权限和批准均满足。
4. 单任务原子重绑把支持从旧根切到新根，并完整退役该任务的旧支持。保留任务转换中持续可用，成功/失败与材料副本有明确语义。
5. 重绑期间所有根仍可用，之后撤销δ=1的全部根；停止目标在终态要求成立，保留目标在每个前缀要求成立。
6. 原生效果和授权支持在窗口内静态完整；无未建模并发派生、新授权、恢复或漂移。
7. 所有准备、重绑、撤销都有真实批准，成员资格和计费分别核验；请求/批准/决策步预算足够支付所用计划，原生费用另记。
8. 每条需求是同一f上的独立首次情形，分别执行；没有把不同请求的计划顺序拼接。

固定f、非平凡S及δ，记d_δ=Σ_t[A_it≠δ_{f(t)}]。在任何以δ结束的合法执行中，每个初始位错误的任务都须离开其初始根，至少重绑一次，故次数≥d_δ。

反向，将每个错误任务直接移到一个标签等于A_it的既有根。δ取到0/1，两种目的根存在且错误任务的原根不是目的根。完全资格、足够容量和原子退役使这些移动按任意顺序合法，保留任务持续有支持。之后撤销所有δ=1根，停止任务均失去支持，保留任务仍可用，恰移动d_δ次。

所以

\[
\min\text{重绑次数}
=\min_{\delta\in D_g}\sum_t[A_{it}\ne\delta_{f(t)}].\tag{B-DIST}
\]

非平凡请求必须有两种终态根命运；省去该条件会允许“有错误可搬但没有正确命运目的根”的假解。g=1时非平凡请求不可行；空/全请求按原模型零重绑直接处理，不把它们硬套D_g。

原M_r公理和距离引理已存在于research_recipe_r2/THEOREMS §§1–2。本稿重述完整条件和证明；其原生可实现性仍需外部合同证据。

## 5. 小型合法映射实例

g=2，三个任务a,b,z，备选首次请求分别停止{a}和{b}：

\[
A=\begin{pmatrix}1&0&0\\0&1&0\end{pmatrix},\quad
Q=\begin{pmatrix}0&1\\1&0\end{pmatrix},\quad
f=(1,1,2).
\]

全部域/列表满、τ=0。两行都选δ=(1,0)，初始预测110。第一行只有b错误，重绑b到根2再撤销根1；第二行只有a错误，重绑a到根2再撤销根1。两个计划分别从相同初态开始，均恰一次重绑，保留任务每个前缀可用。

三任务签名10/01/00互异，零重绑至少3根；当前一次重绑的2根方案说明正半径确有模型意义。例子只在上述执行合同成立时合法，没有新增原生实验。

## 6. 违反前提的反例

### 6.1 token别名被误算成两个根

两个任务a/b分别拿到不同token字符串，但它们都落在同一个grant撤销域u。请求停止a、保留b。若误写w=2、f=(1,2)、δ=(1,0)，矩阵给零错误；真实撤销u同时杀死两份支持，保留失败。

真实独立单元数为1。该例违反独立根前提；当前B的效果域分区原则本来就要求避免这种误计，并非本轮发现B实现漏洞。

### 6.2 目的根容量不足

沿§5初态，但根2容量只有1且z已占满。对第一行停止a/保留b,z，δ=(1,0)的Hamming代价1要求b迁入根2，容量不许。另一处置δ=(0,1)至少要移动a及z两次，超过1。矩阵YES，受容量限制的实际执行NO。

初始列域Ω只限制f(t)，不能自动编码未来迁移容量或任务—目的根资格；把这个反例“修复”为静态Ω约束需要新的执行保持证明。

### 6.3 连续请求改变了状态与目标

§5第一行执行后a已停止、根1已撤销。第二行原合同却要求保留a；它的独立计划不能从这个新状态执行并宣称全部原目标仍成立。备选首次请求与连续生命周期量词不同。

## 7. 域、列表和成本在应用中的来源

保守的(B-MAP)只用满域/满列表/τ=0。现有M_r足以证明这个数学特化，没有从真实服务假定额外字段。

- Ω可作为初始绑定的静态政策限制，或来自已证明子问题投影的允许模式纤维。它限制初始η；未来迁移的完整资格仍需单独成立。
- Λ_i可表示已核实、对该请求可执行的完整根处置方案。若批准/调用费用与具体迁移路径耦合，单个静态Λ不足以自动表达。
- τ_i(δ)已有算法来源是固定任务部分的错误数截到2：τ_i(δ)=min(2,Σ_{t∈T_fixed}[A_it≠δ_{f(t)}])。其余任务剩余预算恰为1−τ。SC分解中已使用这种数学成本。
- 原生HTTP请求、批准、人类确认或墙钟成本具有不同单位；没有依据时不把它们当τ=0/1的一次重绑预算。相关工程、信任和持久状态代价须向候选与G同等开放。

搜索“块退役”只是候选模式组退出E外选择；执行“旧支持退役”是安全原语。两个概念有不同责任，搜索定理没有实现旧凭据处置。

## 8. 当前B与M₁之间的已定位缺口

已读auth-lifecycle/docs/b/MODEL及b/engine.py：setup发行/创建/委托选定路径；停止菜单只有revoke、close、gate。config和路径集合在停止期固定，Native支持只会减少；没有停止期间的原子重绑动作。多条AND/OR路径的通常B配置也超出单任务单根前提。

B的G(C)只计与已选路径授权相交的撤销域；M₁的G=|J|计全部预建根，含空备用根。直接套用会混淆目标。需要对预建空根的发行/持有/批准/请求及资源计数明确收费。

小例：a/b都初始绑定根1，根2已付费但空，停止a时可把a迁入根2再撤销它，M₁费用G=2。只按初始已用域计数会得到1，却遗漏执行所需的备用根。当前B本来没有这条迁移动作，此例定位的是扩展时的计费责任。

当前B实现还限定最多8任务、16撤销域等有限目录；这些是实现可接受域，并非完整测试域。渐近定理没有证明在这些固定小域中胜过已有精确枚举，也没有扩大其生产适用范围。

因此当前B无需被重写成“已经实现本算法”。最少缺失合同为：

1. 一个有可核验语义的单任务迁移+完整旧支持退役原语，包含失败和副本处理，并证明Local/Native支持反映正确；
2. 与M₁一致的预建/空根资源计费和全部批准、请求、步数账本；
3. 完整支持目录、全迁移资格/容量、静态原生效果与单个首次请求边界在具体profile上的证据。

现有known-contract-single-path/v1原生绑定明确query_needed_profile=false，使用单registered世界和空probes，不能升级为部分可观测获取结论。Casdoor4.25.0现有profile只对已知结果及后继分别观察处置；旧撤销响应不能自动保证未知派生材料全部失效。它没有提供上述原子重绑合同。

这些限制使应用定位为**M₁条件理论推论；当前B的非单调扩展尚待refinement**。理论可独立成章。现实应用价值目前有明确的结构动机和精确缺失合同，尚无该平台端到端实现证据。
