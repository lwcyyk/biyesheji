# LP-1手工实例与范围

全部为纸面分析，未执行枚举或求解。域/列表均为正式输入。

1. **硬删列表丢解**：Q=[0]，A=[1]，K=w=M=v=1，Λ={1}、Ω={1}、半径1。原YES，源精确放置删空列表。固定实际错误e=1后翻转A成0，可由精确源接受。
2. **行列表不可省略**：Q的两行为[0]/[1]，A=[00]，K=2、w=M=1、v=2，Λ={2}，所有Ω={1}。原NO，放开Λ后选标签1零误差接受。
3. **0关系不可省略**：Q=[1]，A=[00]，K=w=M=1、v=2，列表唯一。原NO，普通保边同态无约束接受。
4. **全串标签不可分散**：Q两行[0]/[1]，A=[0011]，K=2、w=M=1、v=4，Λ={1,2}、全部Ω={1}。任一固定标签错2，原NO；逐坐标标签可零误差。
5. **删边不等于忽略0对**：Q=[1]、A=[0]，所有维度1、唯一列表。原半径1YES，删输入边仍是0非边，源精确识别NO。固定实际错误翻转为1则可正确接受。
6. **整块通配忘记预算**：Q=[0]、A=[11]，K=w=M=1、v=2、唯一列表。原NO；目标交叉块改*接受两处错误。
7. **角色编译尺寸**：w=K=1、Q=[0]、任意v≥1。新行角色为e=0…v，新列角色为t=1…v，交叉矩阵是全0行及v个单位行。因此新模式数v真实互异。原w=1仍可直接预处理，此例只检验该编译公式的参数增长。
8. **正确半径1角色编译最小例**：Q=[1]、A=[0]、唯一列表。新行角色(p,0)/(p,1)，新列角色(1,1)，交叉预测分别1/0；选择(p,1)精确匹配输入0，恢复原1次错误解。

全部反例只裁决其明确规则；固定掩码翻转及角色编译的全称正确性见LIST_B_IMPLICATION。
