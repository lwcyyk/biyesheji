# r=1组合n-fold编译引理检验裁决

版本 RC-1，2026-11-06。当前对话内知情模型辅助纸面研究。

**本轮总裁决：PROMISED_SUBDOMAIN_ONLY。**

获得一份完整、可恢复、固定输入多项式次数的编译：在重数为1的输入列型数量u≤c₀L（c₀为固定常数）时，时间和输出实例数量均为2^{O(Llog(L+2))}poly(mn+qL)。L=1及q₀=1的全部实例另有直接多项式处理。

两个初始编译规则分别被合法反例关闭；修正编译依赖本轮补全的支撑森林引理。一般r=1独立覆盖仍缺无界单列型接口，尚不采用STANDARD_COMPILATION_COVERS_R1。

## 1. 决定性成果

### 1.1 基本合同下的代表行反例

R包含所有L位签名中的一个重量w“孔洞”；输入由全部重量w行组成，每个位重复L+1次。完整输入NO，删除任意一条查询行后YES。

M=binom(L,⌊L/2⌋)为指数数量，故任何固定次数多项式数量的“只删行、保留原关系和列、不添加残余约束”规则均会失败。L=4给出6×20矩阵及完整15标签关系。

这是原NO到代表子问题YES的基本合同反例；恢复元数据无法产生不存在的原解。保留全量行数据并用其他残余结构处理的编译不在排除范围。

### 1.2 平均聚合计数的基本合同反例

A=(000;111;001)，R={0,1}，r=1。完整问题NO，但三份合法局部计数(2,0)、(0,0)、(1,0)的平均恰为主表(1,0)，给出源整数解。

逐坐标二元副本的平均一致性与非二元类型计数的平均不同；后者缺少逐行相等。该反例经标准行/列型去重、每型截断以及“重数≥L+1”预处理仍保持。低维直径检查可以提前处理此例，反例只关闭所列平均一致性公式。

### 1.3 支撑森林及紧界

固定任一r=1可行解，把每种重复输入列型连向它实际使用的模式。若存在循环，则每行的循环模式位必须恒定；否则至少两次转变引发两个错误。恒定又迫使循环类型的完整输入列向量相同，与类型互异矛盾。

因此该二部图为森林，并得到

\[
\#\{\text{重复列型}\}\le2L-1,\qquad
\#\{\text{支撑边}\}\le3L-2.
\]

错误列并集还满足

\[
|\bigcup_i\operatorname{Err}_i|\le2L-2+u.
\]

完整证明见INTERFACE_LEMMAS §4；PROOF_OR_COUNTEREXAMPLE §5给达到2L−1重复类型和2L−2错误列并集的显式r=1构造。

这些界作用于任意共同显式关系，允许重复及闲置中心、闲置模式、实际模式profile相同和同型任务拆分。它们为本轮新增的模型辅助数学推导；公开发表优先权尚未核定。

## 2. 修正编译及完整费用

先复用每型重数截断到L+1。若重复类型k>2L−1，由结构界直接NO。否则：

1. 枚举森林支撑与其正整数计数，共S_L=2^{O(Llog(L+2))}种原始候选上界。
2. 枚举u个单列型的共享模式，共L^u。
3. 对每份完整候选，逐行扫描显式标签，保存满足整个行预算的D_i。
4. 每行一个局部全1配置块。合法标签上端系数1，空域dummy系数2；唯一上端方程为Σγz=M。
5. 任意可行源解只选择真实标签；展开共享模式、按饱和证明接回删列，输出全部原有序q中心。

每个实例a=1、ν=M、Δ≤2，原始宽度≤q₀，块内列合并后宽度1。RHS位长O(log(M+2))，全部输入/元数据和输出已计费。NF25及KKM20的适用完整包络都只付固定输入多项式；这个后端本身也可直接线性检查。

一般独立界为

\[
2^{O(L\log(L+2))}L^uN^c,\quad N=mn+qL.
\tag{D1}
\]

u≤c₀L时，实例数和总时间落入目标F(L)N^c。ν=M可指数于L，仍能用完整包络；不能仅因ν超poly(L)判废路线。

u无界时不能用数量阈值剪枝判NO。全体L^u仍有正确性保证，时间按(D1)计；这份较弱一般界不覆盖T3精细时间。

## 5. 唯一下一项数学动作

**检验“固定重复计数后的单列型残余接口SC”。**

本轮已把重复列型的共享表压到F(L)个候选。固定其中一表X，对每行/标签定义已发生误差

\[
b_i(s)=\min\{2,\sum_{a\in J,\ell}X_{a\ell}[a_i\ne B[s,\ell]]\}.
\]

剩余u列都是原输入单列型。需要编译

\[
\exists\eta\in[L]^u\quad
\forall i\ \exists s:\ 
b_i(s)+\sum_{t\in U}[A_{it}\ne B[s,\eta_t]]\le1.
\tag{SC}
\]

下一步只检查这些由合法森林计数候选实际导出的b_i(s)，并要求固定边界下的可扩展性与恢复；任意标签集合的更广模型须另设合同。禁止调用T3、PR-C3或先完整枚举L^u后把它略去。

q₀=1的残余问题有标准多项式处理：b=2直接失败；某行b=1时中心被该行强制；全部b=0时检查第一行的半径1邻域，仍检查允许模式。预先固定的小q₀还能按未覆盖行和未指定标签作有限邻域枚举，时间(u+1)^{O(q₀)}poly(N)。这些特例单列；主要待检是q₀可增长至2^{Θ(L)}的一般签名域，不能把这个输入指数当成固定次数。

目标是F(L)数量实例和F(L)·poly(Mu+qL+Mq₀)费用，完整核算共享η和原标签恢复。若该接口成立，与本轮F(L)枚举组合仍为F(L)，从而完成一般r=1编译。

预算回归起点：§3平均反例的重复类型a=(0,1,0)、重数2、表(1,1)，给出b_i(唯一标签)=1；单列型为(0,1,1)。SC为NO，因为残余同一模式不能同时匹配0和1。

非单中心小例：L=q=2，R={01,10}，b=0，输入为全部16个长度4二元串，所有列均单列型。两个合法中心互补，半径1球各有5个点，无法覆盖全部16行，故NO；长度3的全部8行则YES。I_h、L=q=1、b=0另作u无界的简单可解检查，防止错误假定单列型数量受L限制。这些起点已可由本轮小域方法处理，用于约束后续一般接口的语义。

- **成功**：一般r=1独立编译补齐；再按森林和SC各自来源决定标准组合或新桥接贡献。
- **具体路线失败**：关闭该固定边界接口的相应构造；该保持要求强于原基本编译，不能据此排除所有参数保持编译。

这项动作来自本轮已证明的分解，不重开COL2026获取，也不重复T3原证明复核。
