## 2. 本轮决定性结果

详见 [T2_REDUCTION_ATTEMPTS.md](T2_REDUCTION_ATTEMPTS.md)。全部为纸面推导：

1. **P₄零误差反例。** A=P=[[1,1],[1,0]]在对应共同R中为T2 YES，自然二部图在零编辑下既不成团不交并，也不成不交完全二部图。排除保持矩阵边集的直接目标替换。
2. **双侧预算反例。** 单列全1、R={0}、r=1的T2实例始终YES；自然图K₁,N₀在N₀≥4时没有locally1-bounded团编辑解。K₁,₄给出k≥3与k≤2矛盾。消除列端限制若设置τ(v)=m，则源全局t至少m。
3. **d定位。** 全零矩阵产生m+n个孤立图顶点，图簇数不能直接设L。此例用于参数映射检查，零误差的直接特例仍保留。
4. **复制一致性反例。** q=1、R={0,1}、两条长度1串0/1、r=0，原共享中心NO，逐行私有模式YES。复制器件需显式强制同坐标共享模式。
5. **准确受限等价。** 闭邻接矩阵、单位模板、行列标签相等时，逐行误差等于顶点修改度，全矩阵误差和等于2|F|；这完整刻画源图合同，却增加了T2未要求的相等约束。
6. **精确费用补全。** 由KU核枚举d^{4dt}个标签，计算所有总/局部预算及恢复费用。源文FPT被落实为可比较的明确参数函数。

这些结果排除具体直接转换，同时留下可能的新归约。它们不证明所有桥接不可能，不提供任何强通用方法的必要代价下界。
