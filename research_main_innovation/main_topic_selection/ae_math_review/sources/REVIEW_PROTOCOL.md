# 输入隔离复核协议与时序

版本AE-MATH-1，2026-11-06。

1. 协调者如实登记已参与原构造及证明，采用知情审查口径。
2. 从THEOREM_IDENTITY的合同与T1/T2生成STATEMENT_ONLY.md，省去后续先例、状态和机制注释；原文件及截取稿hash均绑定。
3. 新子代理以fork_turns=none启动，没有继承当前会话证明历史。首阶段仅允许读陈述；文献和其他研究文件保持封闭。
4. 新审查者先写初始知识，再读陈述，提交自含推导及自报读取清单。首阶段两稿hash由协调者核对、复制到phase1_sealed并形成父级seal。
5. seal之后才复制四份原证明到proof_inputs_released、记录hash，并通过明确follow-up放行对照。首阶段两稿和回执保持原字节。
6. 第二阶段为已知现有证明的对照审查，输出逐项结论；协调者的补充判断仍单独标记知情来源。

隔离依靠新会话输入与操作纪律，缺少针对整个共享文件系统的技术访问沙箱。读取清单为审查者自报，工具执行记录可追溯；未进行系统调用级访问审计。hash固定的是文件版本，不证明训练知识来源或错误过程相互独立。

未申请模型覆盖，新审查子代理沿用父模型配置。当前证据属于同模型家族的新输入上下文复核，不等同于外部数学读者、不同模型或证明助手验证。

COL2026获取、文献优先权、最优性与机制实现门分别管理。新metadata更新只报告卷1086、文章116240和OA标签的研究者核读，不代表取得正文。
