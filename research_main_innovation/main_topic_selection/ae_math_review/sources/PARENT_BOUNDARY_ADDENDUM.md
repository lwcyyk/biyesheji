# 协调者知情补充：退化域的输出计费

日期2026-11-06。记录时点在第一阶段稿封存、协调者阅读其结果之后；不作为新审查者的独立输入，不向仍在第二阶段自主对照的审查者提供本文件。

第一阶段独立稿也识别出m=0的显式输出问题。主定理明确采用m,n,q,L≥1，故正域T1/T2无需改变。若面向所有退化输入给统一表述，宜单列实际编码长度N_enc与输出成本：

- m=0、n>0、R非空：重复任意允许模式，读入并输出耗时O(N_enc+nq)。
- n=0：输出q个有序空串，保守的格式成本O(N_enc+q)。
- R为空且n>0：读取足够的输入头/关系后NO，保守上界O(N_enc)。

这避免在L=0时也把qL=0误当作包含q个空中心的输出成本，也覆盖参数二进制编码。可以把退化包装统一写为O(N_enc+q(n+1))；该包装单列于主定理的正域参数界。

不将这个边界反例算作对非退化定理的实质反驳。它应归为表示/范围澄清，并在最终报告给出确切支持界。
