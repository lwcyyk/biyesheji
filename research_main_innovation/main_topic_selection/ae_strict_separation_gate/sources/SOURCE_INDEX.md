## 3. 新增文字和证明责任

- COMPARATOR_AND_COST：冻结位编码、公平有限调度、15程序/守卫/表示，明确成本/域preimage；固定K采用已有更有利组织。
- SEPARATION_CLAIMS：两族、参数、未证必要费用预测和判废条件；只追加一次ID/顺序置换修正。
- PROOF_OR_KILL：重列注入复用RC-1；兼容图安全试探及CUBE-Γ整族首次成功为本轮推导；手工位数仅文稿分析，未执行数学程序。
- DECISION：据此关闭本轮分离声明；T3/T+正确性、发表优先权、共同条件下界、原生应用及实现门各自登记。

原分支路线与后续补全/复核具有AI辅助参与，研究者组织和已有人工核读范围沿已校正记录。当前模型已知证明，未引入外部读者、独立会话或证明助手。
