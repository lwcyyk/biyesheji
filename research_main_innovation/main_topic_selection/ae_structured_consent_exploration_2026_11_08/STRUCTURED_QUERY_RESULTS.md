# 有结构偏好下的询问次数与精度

2026-11-08。当前对话内知情模型辅助纸面推导。本文延展先前 d 维询问模型，新增先验或参照结果时重新核算查询界。结论按受限模型登记，发表优先权待核。

## 1. 复用的判定目标

任务结果为 \(0,1,\ldots,d\)，其中 \(d\ge1\)。用户效用为

\[
u=(0,\theta_1,\ldots,\theta_d).
\]

审核规则、基准彩票和审核者沿用先前模型。其安全性精确等价于

\[
\theta_j\ge0\quad\text{对所有 }j.
\]

每次询问比较两个明确的彩票 p、q，精确返回

\[
\mathbf1\{\langle u,p-q\rangle\ge0\}.
\]

平局返回 1，算法确定性且允许自适应提问。上一轮在 \(\theta\in[-1,1]^d\) 下证明最坏需要且只需 d 次比较。

## 2. 二元等幅先验

本节增加先验

\[
\theta_j\in\{-1,+1\}\quad(j=1,\ldots,d).
\]

所有坐标采用同一效用单位。这个先验需要输入依据，按坐标单独改变尺度会改变彩票比较。

安全性现在等价于所有坐标均为 +1。

### 定理

在二元等幅先验下，确定性精确判定的最坏查询次数为

\[
q_d=\begin{cases}
1,&d=1\text{ 或 }d=2,\\
2,&d\ge3.
\end{cases}
\]

### d 为 1 或 2 的上界

d=1 时直接比较结果 1 与结果 0。

d=2 时比较结果 0 与对结果 1、2 各取一半概率的彩票。若用户回答结果 0 至少同样好，则 \(\theta_1+\theta_2\le0\)，判定不安全。若回答否，则两者只能都为 +1，判定安全。

这一步使用了精确的平局约定。零次查询无法区分全 +1 与全 -1，故两种情形都恰需一次。

### d 至少为 3 的上界

先比较结果 d 与结果 0。若回答否，则 \(\theta_d=-1\)，可直接判定不安全。

若回答是，已知 \(\theta_d=1\)。第二次比较

\[
p=\frac1{d-1}\sum_{j=1}^{d-1}e_j,
\qquad
q=\frac{d-2}{d-1}e_d+\frac1{d-1}e_0.
\]

若其余坐标全为 +1，用户对 p 的效用为 1，严格高于 q 的 \(1-1/(d-1)\)。若至少一个坐标为 -1，p 的效用至多 \(1-2/(d-1)\)，严格低于 q。因此第二次比较精确判定剩余坐标是否全为 +1。

### d 至少为 3 的下界

若算法至多提出一次查询，该查询在接收回答之前已经固定，可写成判断

\[
\sum_{j=1}^{d}w_j\theta_j\ge0.
\]

令 \(s=\sum_jw_j\)，即全 +1 参数的查询值。

- 若 s=0，全 -1 参数的查询值也为 0，两个参数回答相同。
- 若 s>0，存在 j 使 \(w_j\le s/d<s/2\)。把该坐标从 +1 改为 -1，查询值为 \(s-2w_j>0\)，回答保持相同。
- 若 s<0，对 \(-w\) 应用上一条论证，得到一个仅翻转单坐标的不安全参数，其原查询值仍为负，回答也相同。

所有情形都存在安全与不安全参数共享一个回答，故一次查询不足。结合上界，最坏恰为两次。

## 3. 已知正参照时的一次查询

在二元等幅先验之外，再提供一个只用于询问的参照结果 a，且已知 \(u(a)=1\)。原任务的安全判定保持为所有 \(\theta_j=1\)。

比较

\[
p=\frac1d\sum_{j=1}^{d}e_j,
\qquad
q=\frac{d-1}{d}e_a+\frac1d e_0.
\]

全 +1 时的效用差为 \(1/d\)。至少一个 -1 时的效用差至多为 \(-1/d\)。所以一次查询足够。由于先验同时允许安全与不安全参数，零次查询仍不足。

该结论同时使用二元等幅先验和已知正参照。它与上一轮完整连续先验的输入合同不同。

## 4. 查询合并的精度费用

现在仅分析上述具体比较在有界数值误差下的稳定性。设回答根据真实效用差 \(\Delta\) 加上误差 e 的符号生成，\(|e|\le\eta\)。

|具体提问方式|比较值距零阈值的最小间隔|对该方式的充分误差条件|
|---|---|---|
|逐坐标比较，二元先验|1|\(\eta<1\)|
|两次比较方案的第二问，\(d\ge3\)|\(1/(d-1)\)|\(\eta<1/(d-1)\)|
|已知正参照的一次比较|\(1/d\)|\(\eta<1/d\)|

证明均由比较值距离零点的最小距离直接得到。等于边界时，误差可能把不安全参数推到零并产生批准回答。

d=2 的一次比较方案会把一正一负参数放在精确平局处。任意小的有符号误差都可能改变其判定，所以该特殊上界依赖精确回答。

这些是所给提问方式的稳定性计算。任意噪声模型下的最优查询复杂度需要另行证明。

## 5. 强先验被误用时的反例

若仍允许连续参数，取 d=3 及

\[
\theta=(-0.1,1,0.1).
\]

两次比较方案的第一问通过。第二问中，前两个结果的均值为 0.45，参照混合的效用为 0.05，方案会输出安全。然而 \(\theta_1<0\)，所以原审核规则不安全。

该例说明二元先验是正确性前提，需要被可靠提供。正效用参照、问题表达和用户理解也都要计费。

## 6. 对真实授权交互的意义

合并询问可以减少交互次数，同时增加表达、理解和精度责任。若一问显式列出 d 个结果，其描述规模会随 d 增长。共享索引可以缩短文本，认知与判断费用仍需单独测量。

本轮据此保留一个研究问题，如何在已验证的偏好结构下生成合并问题，同时给出判断正确性、噪声范围和完整交互费用。

当前结论来自模型辅助纸面推导，尚无独占原创性判断。标准方法也能使用相同先验和参照，未取得同合同的严格代价分离。
