# 结构历史、全部前缀与T3完整费用

版本 PR-1，2026-11-06。对象为 [REFINEMENT_LEMMA.md](REFINEMENT_LEMMA.md) 的唯一修正过程。以下给出数学上界，未执行该过程。

## 1. 结构历史引理

全局Π从[L]一块开始，每个真分裂将一个非空块作有序真二分；退役块保留且不再细分。令k为截至某节点的累计二元分裂数，0≤k≤L−1。

记录全部分裂得到一棵有k个内部节点、k+1片非空模式叶块的有序满二叉树。每个内部节点再记它属于第几个预留行步；同一行可同时细分多个当前叶块。每个预留行至少有一个内部节点，故行步数u≤k。

一个充分的编码为：

1. 有序树形，至多Catalan数C_k≤4^k种；
2. 每个原模式到有序叶位置的映射，至多(k+1)^L种，实际需满射，放宽只增上界；
3. 每个内部节点的行步编号，至多max(1,k)^k种。

叶块决定每个内部节点左右子树的模式集合，左右即新位0/1。行步编号决定每一步的同时细分。忽略祖先先后、可用活动块等合法性条件只放宽编码。因此所有结构历史前缀至多

\[
H_L\le\sum_{k=0}^{L-1}
4^k(k+1)^L\max(1,k)^k
=2^{O(L\log(L+2))}. \tag{C1}
\]

L=1时H_L=1。该引理是标准树形/分区编码在本过程上的应用，单独没有算法新颖性含义。

## 2. 其余信息为何无需L²个自由位

在旧过程里，结构历史之外的未分裂块常值是独立的完整标签选择。本修正只在提交时保存这些常值，每个常值由当前最小支持代表的输入位给出。代表随E的增加确定性更新。

给定输入、结构历史、阶段动作顺序及各例外子选项编号，可逐步重建：失败行、冻结父块、全部支持、代表、拟定常值、标签存在性、提交、退役及规范候选。标签存在性只有真假，不枚举其见证组合；各行的标签独立扫描。

退役时刻由支持为空确定，无需每行另猜一份退役子集。E内模式分配在例外子选项中计费。待提交的细分早已记入结构历史，即使父块后来支持为空，其分裂进展也已支付、不会被抹去重用。

这正是反例之后补上的算法性论证：结构历史计数本身成立，而带值信息只有通过代表修复与有限标签条件才能避免重新自由猜测。

## 3. 全部搜索前缀

令a=L−1、b=r(L−1)。动作分三类：

- R：预留一个有真分裂的新行，至多a次；
- E：加入一个新坐标及模式，至多b次；
- C：提交当前预留行，每次唯一，至多a次。

正常无匹配例外≤L个，冲突例外≤2L²(r+1)个，待提交代表例外≤L²个，统一用

\[
Q=2L^2(r+1)
\]

个编号槽。具体列表由当前阶段和状态确定。一个节点可以编码为结构历史、动作类型词及E动作的局部选项编号。固定该编码后，每次R的具体细分从历史取出，其余动作均可由输入重建。

对u个R、v个E、c个C的前缀，c≤u≤a、v≤b，类型词数至多multinomial(u+v+c;u,v,c)。因而

\[
\begin{aligned}
\mathcal N
&\le H_L\sum_{u=0}^{a}\sum_{v=0}^{b}\sum_{c=0}^{u}
\binom{u+v+c}{u,v,c}Q^v\\
&\le H_L(a+1)^2(b+1)3^{2a+b}Q^b\\
&=2^{O(L\log(L+2)+Lr\log(Lr+2))}. \tag{C2}
\end{aligned}
\]

所有长度的前缀都已包含。待提交但尚未提交的节点取c=u−1或相应合法前缀；无效类型词也只放宽上界。r=0时b=0，直接使用上式；L=1时a=b=0。

没有m^{f(L,r)}或n^{f(L,r)}：行由当前完整距离检查确定，例外坐标来自一个无匹配坐标、一个小冲突或至多L个当前代表。没有q₀^{L−1}：R边选择结构，C边只作有限标签扫描且至多一个提交。也没有未计费的模式对应：结构叶块是原模式ID的子集，E赋值计入Q。

## 4. 每节点及边的费用

令N₀=mn+qL。使用显式矩阵与确定性列表/计数器即可。以下为保守计费，足以保持固定输入次数。

|项目|费用|
|---|---|
|初始读取A/R、整数|O(N₀)加实际整数编码长度；工作半径可截到min(r,n)|
|覆盖列签名去重|O(q²L)，保存原索引与完整R|
|结构块、代码及支持|O(nL²)+poly(L)；W长度≤L−1，待提交时使用冻结前缀|
|E和状态复制|每边poly(L,r+1)乘索引位长；也可用长度n数组，仍在固定输入多项式内|
|正常逐行D_h及完整距离检查|保守O(mq₀(L+n)+mn)|
|待提交(R3)标签扫描|O((|W₀|+1)q₀(L+|E|))，包含E的完整行误差|
|冲突提取|O(n+L(r+1))，各桶最多取r+1个ID|
|枚举全部有序细分/拒绝选项|每个相关节点至多2ᴸ poly(L)，包含未能提交的选项|
|代表例外/提交子状态|至多L²+1；包含已可提交时仍保留的代表分支|
|最终完整输出|O(nq+m log(q+1))，并作原合同验收|

一种总上界写法为

\[
\begin{aligned}
T\le{}&O(N_0+q^2L+nq)+O(H_{enc})\\
&+\mathcal N\,(2^L+Q+1)\operatorname{poly}(L,r+1)
\bigl[mq_0(L+n)+nL^2+1\bigr]
\operatorname{polylog}(N_0+2). \tag{C3}
\end{aligned}
\]

对输入整数读取先支付真实H_enc，工作预算截断后位长受输入和参数多项式控制。标准二进制编码费用被原参数上界吸收。

q₀≤q，正域中m,n,q,L均≤N₀；每节点q₀扫描是N₀的固定次数。q²L≤N₀²，nq≤N₀²。2ᴸ及固定参数多项式被(C2)的参数因子吸收。故

\[
T=2^{O(L\log(L+2)+Lr\log(Lr+2))}
\operatorname{poly}(mn+qL). \tag{T3}
\]

输入多项式次数及隐藏常数与所有参数无关。深度优先可仅保存长度≤2a+b的状态栈，输入只读共享，不需存整棵树。

## 5. 完整输出及边界

成功y来自全部原模式中的选择，故每坐标输出原q位tupleρ^{y_t}。活动/退役只限制当前E外搜索，不缩减R；E可使用退役模式。覆盖签名等价的原标签全部展开，完整q有序中心保留。实际覆盖标签来自最终全行检查，未用作隐藏分支。

L=1时只有固定模式，过程不预留行；q=1时L≤2，仍可求未知中心。r=0沿既有L^{O(L)}零误差处理单列，本过程也给b=0的上界；正r的证明无需零误差假设。r≥n可直接选任一模式、完整输出。

空域沿原澄清单列：n=0且q≥1输出q个空串；n>0且R空为NO；m=0且q≥1、R非空时任选模式并输出；q=0且有输入行为NO，q=m=0时按空tuple坐标约束检查。直接费用O(真实输入编码+q(n+1)+1)，不把正域N₀公式字面延到m=0而遗漏输出。

## 6. 与T2的比较范围

新式在固定正r下给2^{O(L log L)}的参数保证，替代旧2^{O(L²)}。一般改进来自L²项降到L log(L+2)；Lr项仍保留。没有给出该Lr项或新L log L项的必要下界。先例核查和模型辅助证明的复核级别见 [DECISION.md](DECISION.md)。
