# T2指数来源与T3冻结合同

版本 PR-1，2026-11-06。研究口径：知情的模型辅助数学推导；本轮跳过外部交接。T1/T2旧稿和优先权记录保持原版本。机制、求解器及穷尽验证器均未实现。

## 1. 初始待证目标

**T3在本轮入口登记为CONJECTURE。** 合同完整继承T2：m,n,q,L≥1，r≥0，A∈{0,1}^{m×n}，共同显式R={ρ¹,…,ρᴸ}⊆{0,1}ᑫ。求y_t∈[L]及每行一个全串固定的覆盖标签s_i，使

\[
\sum_t[A_{it}\ne\rho^{y_t}_{s_i}]\le r\qquad(i\in[m]).
\]

中心C_s[t]=ρ^{y_t}_s可重复、可闲置，模式也可闲置；输出全部原有序q中心，确定性精确判定。待证时间为

\[
2^{O(L\log(L+2)+Lr\log(Lr+2))}\operatorname{poly}(mn+qL). \tag{T3}
\]

入口状态和结束状态分开管理，最终裁决见 [DECISION.md](DECISION.md)。

## 2. 旧计数中的L²

覆盖列签名去重给q₀≤min(q,2ᴸ)。原搜索有a=L−1条行边、b=r(L−1)条例外边，每行边至多q₀个完整处置选择，故全部前缀上界含

\[
\sum_{u=0}^{a}\sum_{v=0}^{b}
\binom{u+v}{u}q_0^u[2L^2(r+1)]^v.
\]

其中

\[
\log_2(q_0^{L-1})\le L(L-1)
\]

产生T2中的L²项。每节点扫描q₀个标签本可按原输入qL的固定多项式支付；将它额外界为2ᴸ至多贡献O(L)指数。关系读取、q²L确定性去重和nq输出同样可放入poly(mn+qL)。真正待消除的是沿路径反复独立选择完整标签的乘积。

## 3. 划分计数与状态合并是两项命题

将每次二元细分记录为有序二叉树节点，记录该节点在哪一行步发生。总二元分裂≤L−1，带模式标签的结构历史只有2^{O(L log(L+2))}种；[COMPLETE_COMPLEXITY.md](COMPLETE_COMPLEXITY.md)给出完整计数。

这一组合计数没有自动给出算法。旧状态还存每条已选行在全部模式上的取值。两个处置可以产生相同的无值划分，却对已分开的类取不同位；这些位影响坐标投影、E和合法标签。即使完整无值历史相同，直接只留一个完整标签仍会丢解。[PROOF_OR_COUNTEREXAMPLE.md](PROOF_OR_COUNTEREXAMPLE.md)给出r=1、最优半径1的完整例子。

本轮只尝试一种修正：**活动类、延后提交与代表例外修正**。它保留活动类的带值码；对不再被非例外输入投影支持的类停止使用；每个已选行的完整标签改为输入可计算的存在性条件。未细分类的下一位由当前代表坐标给定，错误代表通过E分支支付。该过程详见 [REFINEMENT_LEMMA.md](REFINEMENT_LEMMA.md)。

## 4. 改进区间与已有特例

- r=0已有L^{O(L)}poly(mn+qL)的列类型枚举，沿既有标准结果单列，不登记为本轮新增贡献。
- 对固定正r，T2的显示参数指数为O(L²)，T3目标为O(L log L)。
- 更一般地，r log(Lr+2)=o(L)时，这一显示上界改进可显现；若Lr log(Lr+2)已支配L²，两式保证同阶。
- 这是两个算法上界的比较，不构成任何算法必要运行代价的下界。

本轮没有用反例排除T3本身，也没有建立ETH等假设下的T3下界。
