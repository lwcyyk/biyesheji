# 硬注意力屏蔽与共享动态量化的组合检查

2026-11-07，当前对话内模型辅助纸面推导。证据范围为明确算子的数学组合。本稿保存手工例、适用前提及先例归属。

## 1. 冻结的数学对象

考虑一个标量注意力查询，维数为 1，查询值为 1。键和值为

\[
K=(0,1,u),\qquad V=(0,1,0),\qquad u\in\{1,9\}.
\]

前两个位置允许影响输出。第三个位置受硬屏蔽，屏蔽在 softmax 前生效。两份输入的长度、位置、屏蔽、查询、允许位置的键和值均相同，仅第三个键的内容改变。这里把 K/V 视为算子的实际输入，尚无从自然语言 token 到这些数值的可达性证明。

在精确实数语义下，屏蔽后的输出恒为

\[
f(K,V)=\frac{e}{1+e}.
\]

## 2. 引入标准动态量化

在屏蔽之前，对三个键联合进行非对称 2-bit round-to-nearest 量化及反量化。采用

\[
z=\min_i K_i=0,\qquad s=\frac{\max_i K_i-\min_i K_i}{3},\qquad
\widehat K_i=z+s\operatorname{round}\left(\frac{K_i-z}{s}\right).
\]

该 min/max 公式见 KIVI §3.1，PDF 第 3 页。KIVI §3.3、PDF 第 5 页说明键缓存按通道跨 token 分组。本例检查该类算子与权限屏蔽组合后的性质。来源论文的主要合同为缓存压缩、数值表现和推理效率。[KIVI 原文](https://arxiv.org/abs/2402.02750)

|第三个键|共享 scale|前两个反量化键|第三个位置屏蔽后输出|
|---|---|---|---|
|\(u=1\)|\(1/3\)|\((0,1)\)|\(e/(1+e)\)|
|\(u=9\)|\(3\)|\((0,0)\)|\(1/2\)|

第二行中，\(\operatorname{round}(1/3)=0\)。两种输入均避开舍入平局，scale 也均为正。

因此

\[
\widehat f(0,1,1)-\widehat f(0,1,9)
=\frac{e-1}{2(1+e)}>0.
\]

第三个位置的注意力权重始终为零，其键值通过共享 scale 改变了允许位置的反量化结果。对更大分组，可加入固定零键、零值且同样被屏蔽的位置，min/max 与上述结论保持。

这是内容非干涉的反例。这里的输出差成立于给定的注意力和量化算子，生产模型利用链、实际危害以及具体浮点实现的逐位结果仍需各自取证。

## 3. 与已有原文的对应

Küchler、Petrov、Grobler、Shumailov 的 *Architectural Backdoors for Within-Batch Data Stealing and Model Inference Manipulation*，所读 arXiv v2 的 PDF 第 8 页，明确定位 ONNX DynamicQuantizeLinear 跨 batch 计算全张量 min/max 造成的信息流。第 6–7 页给出 ownership labels、shadow tensors 与算子级传播检查。

由此，共享量化统计量造成跨安全边界影响，以及通过信息流分析识别该通道，均已有直接先例。本稿把该机制实例化到一个请求内部的不同权限位置，并给出三个键的闭式计算。其优先权状态为具体检查例的项目内整理，主机制按已有工作归属。[Batch Isolation Checker 论文](https://arxiv.org/abs/2505.18323)

Span Veto Proposition 1，PDF 第 3 页，要求阻断全部跨位置通道，并要求确定性及 batch-invariant 执行。第 11 页单列缓存计算时的可见性策略和权限组缓存。加入上述动态量化以后，需要重新核验“全部通道”前提。本例揭示的是前提的组合责任。[Span Veto 原文](https://arxiv.org/abs/2610.15883)

## 4. 能处理本例的强基线

1. 按同一权限域计算量化参数，允许位置采用 \((0,1)\) 的 scale。
2. 采用独立的允许上下文执行，并在其内部量化。
3. 保留相关键的全精度表示，或者使用满足精度要求的逐 token 量化。
4. 通过完整依赖标签识别 scale 来源，再对失败图执行安全分组或其他已验证变换。

这些方法在本例上均有可用处理路径。其成本需要计入量化元数据、索引、临时缓冲、策略版本及调用费用。上述反例仅关闭“硬屏蔽可自动覆盖后续任意推理优化”的组合规则。最强安全基线的必要额外费用尚未取得。

## 5. 两条可复用的标准推论

### 5.1 单运行数值误差界与双运行非干涉需要分别验证

取 \(h\in\{0,1\}\)，允许输入为 \(l\)，参考函数为 \(f(l,h)=l\)。对任意 \(\varepsilon>0\)，近似函数

\[
g(l,h)=l+\varepsilon h
\]

满足 \(|g-f|\le\varepsilon\)，同时在固定 \(l\) 下随受限输入 \(h\) 改变。一般误差界允许这类依赖。该例属于非干涉作为双运行性质的标准应用。安全编译中对 hyperproperties 的保持已有系统论述，见 *Journey Beyond Full Abstraction* §3，PDF 第 6–7 页。[安全编译原文](https://arxiv.org/abs/1807.04603)

### 5.2 完整依赖标签提供充分条件

固定一个有限确定性计算图、公开的形状与策略、明确的算术语义。每个输入源有一个来源 ID。对每个节点 \(v\)，令 \(D(v)\) 为可靠的来源依赖上界。计算 \(D\) 时覆盖实际数据依赖、控制依赖，以及 shape、缓存、量化参数、优化选择等会进入输出的元数据依赖。常量依赖集为空。

若对每个输出 \(o\) 的允许来源集合 \(A_o\) 都有

\[
D(o)\subseteq A_o,
\]

则固定所有允许输入后，替换其他来源内容保持该输出相同。

证明按图的拓扑序归纳。节点输出由自身全部直接依赖的值和固定算术规则确定。可靠标签覆盖其祖先输入，因而固定标签中的来源就固定该节点的值。对输出应用该结论即得。该推论承担标准信息流分析的责任，出处为通用 IFC 与 Batch Isolation Checker 的同类传播规则。

对量化组 \(g\)，若其原节点来源集为 \(D(v)\)，可达消费者输出集合为 \(O(g)\)，一个保守的安全条件为

\[
\bigcup_{v\in g}D(v)\subseteq\bigcap_{o\in O(g)}A_o.
\]

完整后继计算也须通过相应依赖检查。该条件是充分条件。语义抵消会使某些混合组仍然安全，例如两个元素恰为 min/max 端点时，理想实数反量化可精确恢复两端点。实际浮点计算另需分析。因此“权限签名相同才允许合组”可作为保守策略，最优性需独立证明。

上述结论按固定形状的输出值非干涉陈述。运行时间、资源竞争、终止、动态长度以及外部副作用需要显式扩展观察模型。
