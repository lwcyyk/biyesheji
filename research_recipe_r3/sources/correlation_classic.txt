Abstract
We consider the following clustering problem: we have
a complete graph on /D2 vertices (items), where each edge
/B4 /D9/BN /DA /B5 is labeled either /B7 or /A0 depending on whether /D9 and
/DA have been deemed to be similar or different. The goal

agrees as much as possible with the edge labels. That is,
we want a clustering that maximizes the number of
/B7 edges
within clusters, plus the number of /A0 edges between clus-
ters (equivalently, minimizes the number of disagreements:
the number of /A0 edges inside clusters plus the number of /B7

a document clustering problem in which one has a pairwise
similarity function

that one does not need to specify the number of clusters /CZ

at approximation algorithms for both minimizing disagree-

7 Open Problems and Concluding Remarks
In this paper, we have presented a constant-factor ap-
proximation for minimizing disagreements, and a PTAS for
maximizing agreements, for the problem of clustering ver-
tices in a fully-connected graph
/BZ with /CU /B7 /BN /A0/CV edge labels.
In Section 5 we extended some of our results to the case of
real-valued labels, under a linear cost metric.
One interesting open question is to ﬁnd good approxi-

random case is also easy if deﬁned appropriately. However,
our approximation techniques do not appear to go through.
