# Frodo-FI：LWE 与辅助信息审计

日期：2026-11-06。审阅身份：`INDEPENDENT_AI_REVIEW`。本文件独立给出攻击所需的两项归约；它们与 FI §6.1 的模拟器论证分开。

结论：**指定分布下的归约 VERIFIED；把“LWE”概称直接用于任意 χ、任意参数或任意公开种子实现需要 EXTRA_ASSUMPTION_REQUIRED。** 第一块投影对于本轮固定攻击充分，所需额外的任意辅助信息 LWE 假设数量为0。

## A. 精确定义所用假设

令 λ 为安全参数，n=n(λ)、D=D(λ)、m̄=m̄(λ)，q=2^D，χ=χ_λ 可有效采样。D、全部矩阵维度与样本数为 poly(λ)。定义两个单行实验：

\[
\mathcal L_\lambda=(A,uA+f),\quad
A\leftarrow U(\mathbb Z_q^{n\times n}),\quad
u,f\leftarrow\chi^n;
\]

\[
\mathcal U_\lambda=(A,z),\quad
A\leftarrow U(\mathbb Z_q^{n\times n}),\quad
z\leftarrow U(\mathbb Z_q^n).
\]

其中 u、f 各坐标独立，u、f、A 相互独立。u 为小秘密，f 为小误差。A 的 n 列给出同一秘密下的 n 个 LWE 样本。若通常定义把样本排成行，则使用 A 的转置；均匀 A 的分布在转置下保持相同。

对判定器 D，采用

\[
\delta(D)=|\Pr[D(\mathcal L_\lambda)=1]-\Pr[D(\mathcal U_\lambda)=1]|.
\]

假设 H_nf 是：对此具体 (n,n,q,χ) 分布，所有 PPT 判定器的 δ 可忽略。若讨论量子安全，则需对应的 QPT 版本；本攻击本身是经典算法。

这与 Frodo 2021 规范 §2.1.3、Definitions 2.7–2.9 的 normal-form 决定 LWE 口径一致。规范允许 secret 与 error 同 χ，但没有替每个随意选择的参数族自动认证其困难性。FI 原文 pp11–12、19–20 使用 LWE 概称；其定理需补上该具体量词。

**EXTRA_ASSUMPTION_REQUIRED**：仅给出均匀秘密 LWE、无界高斯 LWE、搜索 LWE 或“底层 PKE 是 IND-CPA 安全”，均还需要相应归约和参数损失，才能支持这里的单行伪随机性。消息不可区分性本身没有断言密文第一块接近全环均匀分布。

## B. 更新矩阵 P2：n 个逐行混合

真实 P2=U2 A+F2。定义 H_i：前 i 行独立均匀，后 n−i 行按真实 χ 秘密与误差生成，A 在所有行中为同一公开矩阵。H_0 是真实 P2，H_n 是独立均匀矩阵。

从 H_(i−1) 到 H_i 的判定器 D_(P,i)：

1. 输入单行 LWE 挑战 (A,v)。
2. 自行采样前 i−1 个均匀行；自行采样后 n−i 行的 u_j、f_j 并计算 u_jA+f_j。
3. 第 i 行放入 v。
4. 输出整个矩阵的 mod2 满秩事件。

输入为真实行时输出分布为 H_(i−1) 的事件；输入为均匀行时为 H_i。攻击者无需知道嵌入行的 u、f。故

\[
|\alpha-p_n|\le\epsilon_P:=\sum_{i=1}^{n}\delta(D_{P,i})\le n\delta_P,
\]

这里 δ_P 为这些特定判定器的统一上界，时间预算包含行生成及秩计算。

**VERIFIED（归约范围）**：此步骤只分析 P2 的边缘可逆事件。它没有把完整 token ((P1,Q1),(P2,Q2)) 替成均匀 token。嵌入一个未知秘密的 P2 行后，其对应 Q2 行涉及同一未知秘密，完整 token 模拟另有义务；本证明的事件完全没有读取 Q2，故该义务未进入此归约。

也无需在此把 P1 的 nD 行替成均匀。因此 ε_P 的混合数量是 n，整个 token 的所有行数会用于生成时间，但不被凭空计入这里的优势损失。

## C. fresh 第一块及其实际联合视图

固定攻击的查询选择规则如下：消息为预设 M；选择第一次普通 Enc 得到的父；执行固定一次 Next 和 token 腐化；立即挑战；取第一块判定后终止。程序保存整个父 C 用来原样提交 O.Chall。它根据“第一次 Enc 的返回对象”选择父，查询资格依赖注册身份；对 C2 的内容没有条件分支。

判定所用投影可以取

\[
W=(\text{公开维度与}\chi,A,C_{parent,1},P_1,P_2,Y).
\]

实际输出还使用一枚独立公平硬币。A 允许留在 W 中供分析，输出函数事实上只需要 C_parent,1、P1、P2、Y 与公开参数。定义高效布尔事件

\[
\Phi(W)=[P_2\text{ 可逆}\land
(Y-\operatorname{Ord}_n(C_{parent,1})P_1)P_2^{-1}\in S_q^{m̄\times n}].
\]

在 fresh 分支，Y=U_cA+F_c，其中 U_c,F_c 的行独立 χ 采样，且其随机性独立于全部此前采样。

条件于 A，以下采样器可完全生成投影中的上下文：

\[
C_{parent,1}=U_0A+F_0,\quad
P_1=U_1A+F_1,\quad P_2=U_2A+F_2,
\]

各 U/F 的维度见映射文件，彼此独立。归约以输入中的 A 为唯一 A，采样这些实际秘密／误差，即得正确联合上下文。父与 token 的相关性因共享 A 被保留。

定义 G_j：上下文保持真实，Y 的前 j 行均匀，后 m̄−j 行真实。G_0 是真实 fresh 投影，G_m̄ 是 Y 整块独立均匀的投影。单行判定器 D_(ct,j)：

1. 输入 (A,v)，从上述真实上下文采样器生成 C_parent,1、P1、P2。
2. 自行采样 Y 的前 j−1 个均匀行，放入挑战行 v，再自行计算其余真实行。
3. 输出 Φ(W)。

输入真实行／均匀行分别精确实现 G_(j−1)／G_j。于是

\[
|\beta_{\rm real}-\Pr[\Phi(G_{m̄})=1]|
\le\epsilon_{ct}:=\sum_{j=1}^{m̄}\delta(D_{ct,j})\le m̄\delta_{ct}.
\]

**VERIFIED**：D_(ct,j) 自行生成 nD 行 P1、n 行 P2 和 m̄ 行父，均保留真实分布；额外计算成本纳入运行时间。它只为 Y 进行 m̄ 次混合。这个构造证明了可生成辅助信息下的联合替换，无需把辅助信息当作独立于 A 的无条件随机量。

### C.1 逐项说明被省略字段

| 字段／状态 | 可生成性与投影依据 |
|---|---|
| 全局 A、维度、χ、消息 | A 来自挑战，其他固定或公开 |
| 旧／新钥匙 S_e,E_e,B_e | 自采 χ 矩阵，计算 B_e=A S_e+E_e；第一块投影本身无需这些值 |
| 父 C2 | 归约知道 U0,G0 和旧 B_e，可真实计算；原样提交父保证注册检查通过 |
| P1、P2 | 归约自采所有 TG 小矩阵，真实计算 |
| Q1、Q2 | 在 fresh 归约中所有 TG 小矩阵和 epoch 钥匙都已知，故可真实计算 |
| 挑战的 Y | 由嵌入的一行及其他自行生成行组成 |
| fresh 挑战 C2* | 单行 LWE 输入没有给出 U_c 对应的秘密，完整真实 C2* 的生成需要另一个论证；此固定攻击没有读取其数值 |
| qid、epoch、phase、L | 固定查询顺序，均可记录；父身份真实有效，twf=0 |
| 普通 Enc/Upd 带（可选扩展） | 普通调用由归约自采，带和数值可一致提供；最小串无这些额外查询 |
| 挑战带 | 游戏保持隐藏，归约无打开义务 |
| 挑战后的交互 | 固定攻击立即输出，后续调用数为0 |

“忽略 C2*”的依据是攻击输出对完整视图的一个确定投影。两个真实世界中该输出等于同一 Φ／公平分支函数的求值。因此证明该投影的分布已经充分。归约没有声称可以把包含 C2* 的任意完整视图换成理想视图，也没有用虚构的第二块满足未证明的联合一致性。

若在原最小串前插入固定次数普通 Upd，归约知道全部 token，可以真实运行并生成它们的随机带。若附加已获准的历史钥匙，也可以诚实生成。固定攻击忽略这些返回值即可保留原边缘概率。对会根据这些字段自适应选择攻击目标的其他程序，本轮不扩张结论。

### C.2 更强的辅助信息是否必要

即使把**完整真实的挑战前视图**留给事件判定器，fresh 单行归约也可生成它，因为其秘密与挑战加密随机性条件于 A 独立。这里真正选择投影的是挑战输出本身及无需的后续交互。这样明确区分了“能生成的先前上下文”和“含未知 fresh 秘密的第二块”。

本攻击恢复的是更新 R；其使用的 LWE 假设涉及 token 的 U2 与 fresh 的 U_c。这些随机变量各有角色，恢复 R 对 H_nf 的困难性没有矛盾。

## D. 共享 A 与公开种子

**VERIFIED（FI 纸面 Setup）**：p12 直接均匀采样 A∈Z_q^{n×n}；p14 各 epoch 和 token 共用该 A。各矩阵通过 A 存在相关性。B、C1、P1、P2、Y 的生成全部使用输入中的同一 A，故上述两项归约保留了这种相关性。归约始终没有固定一个任意的 A 后再声称 LWE 安全；困难性按随机 A 的平均实验定义。

标准 Frodo 的实际 Gen(seedA) 与 FI 均匀 Setup 应区分。2021 规范 pp16–18 用公开 seedA 展开 A，普通 Frodo KeyGen 会生成该种子；FI 的 UE 实例需要核准其跨 epoch 共用 A 的方式。性能表中的 AES/SHAKE 标签提示实现差别，却无法确定其完整联合分布。

**EXTRA_ASSUMPTION_REQUIRED（公开 seedA）**：可直接定义 seeded 版本的单行假设

\[
(\sigma,A=\operatorname{Gen}(\sigma),uA+f)
\approx_c(\sigma,A=\operatorname{Gen}(\sigma),z),
\]

其中 σ 均匀、公开，u,f 独立 χ，z 独立均匀。若这项假设成立，则 B、C 两项归约原样成立，每一步保留 σ 与 A，损失替换成对应 δ_seed。

公开种子不能被忽略后直接写成“(σ,Gen(σ)) 与 (σ,A_uniform) 计算不可区分”：检查 A=Gen(σ) 就会区分这两个联合分布。普通隐藏种子 PRG 安全性本身覆盖不了这种公开种子联合替换。

对于**本轮固定攻击**还存在一个可选的较弱投影论证：它不读取 seedA，也不按其值选择消息、父或查询。若矩阵生成器的输出边缘 Gen(U) 与均匀 A 的差受 ρ_A 控制，则以输入 A 生成全部真实游戏、内部取 b 并输出猜对事件，就得到成功率差≤ρ_A。这个归约无需知道与输入 A 对应的 seedA，因为固定攻击不使用它。于是可在均匀 A 的 bias 下界上减 ρ_A。该路线需要明确的生成器边缘假设及正确模拟全部实际采样；它也只覆盖忽略 seedA 的这一攻击。

秘密 seedSE 经 SHAKE 展开的 U/F/G、尤其 TG 大矩阵与 R 的生成，也须单独处理。理想独立 χ 采样的归约可通过相应 PRG 混合迁移，但必须知道种子复用、长度、域分离和失败处理，才能计数损失 ε_rng。若把公开的普通随机带对应输出替成独立随机值，重放会暴露差别；本审阅保持普通带与普通调用的真实一致性。实际实现也可以直接提出覆盖其整个采样过程的具体伪随机性假设，随后重新给出有限 ε。

## E. 条件概率、联合概率及误差方向

定义 w 为 (A,父,P1,P2) 的任意真实上下文。在 G_m̄ 中，Y 与 w 独立均匀。因此在每个满足 J(w) 的正概率上下文中，支撑判定概率精确为 θ；求和得到 Pr[Φ(G_m̄)]=αθ。

这一步是信息论计数。之前 G_0→G_m̄ 的步骤是对高效 Φ 的**平均计算优势**界。二者结合给

\[
\beta_{real}\le\alpha\theta+\epsilon_{ct}.
\]

全程保持真实 token 和父的分布。估计 α 的 n 行混合另行使用；没有在 fresh 替换时暗中把 P2 改成均匀。最后按顺序代入

\[
\alpha-\beta_{real}\ge\alpha(1-\theta)-\epsilon_{ct}
\ge p_n(1-\theta)-(1-\theta)\epsilon_P-\epsilon_{ct}.
\]

这里 1−θ≥0 保证不等号方向。对每个固定可逆 token 的“真实 fresh 通过率≤θ+ε”并非本归约结论；本证明只需要联合事件的平均界，因而避免条件化放大及选择偏差。

## F. 渐近结论、实际参数与原证明的关系

**VERIFIED（条件定理）**：若 H_nf 对某个明确的有效参数族成立，n,m̄ 为多项式且总混合误差可忽略，N log(q/h)=ω(log λ)，则固定合法攻击具有常数 bias。只要求 θ 与1保持常数距离时，也足以违反可忽略优势要求。

**EXTRA_ASSUMPTION_REQUIRED（应用）**：χ 的分布、q/噪声比例、样本预算、生成器和运行时间必须与假设一致。Theorem 6.3 的正确性参数选择可能改变 q 及 χ，因而需要重新核对这些假设。固定的640/976/1344实例属于有限参数陈述，不能直接冠以“ε 可忽略”。普通 Frodo 文献给出的 attack-cost 估计也不能无条件等同于本审阅的特定判定器 δ 上界。

FI pp17–19 的 Conclusion 6.5／Lemma 6.6 诉诸 smudging，Sim.UE.Upd 把密文取均匀，Lemma 6.8 的关键论证转引 Nishimaki。本轮无需假设这些混合有效。直接公开支撑测试已经给出原更新分布与独立均匀第一块之间的差：可逆时更新接受率1，均匀第一块接受率θ。固定公开 token 与父的仿射约束必须由任何主张完整模拟的证明处理。

同时，指出原证明未展开 smudging 参数或完整 LWE 模拟，本身只构成证明缺项。当前 **COUNTEREXAMPLE** 裁定来自已经给出的合法攻击、恒等式和两项独立归约。

综上，在已核准 v4 行为公式及 H_nf（或明确替代假设）成立的参数族上，该结果足以挑战 FI Theorem 6.9 所声称的 rand-ind-eu-cpa；对象范围限于此 UE 与此游戏。普通 FrodoPKE 的消息安全、LWE 问题的困难性、其他版本／修改方案及实际部署的有限安全性均分别保留自己的证明义务。
