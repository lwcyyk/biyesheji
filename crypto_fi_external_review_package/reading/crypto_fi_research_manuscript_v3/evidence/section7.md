### 7.2 共同概率判据：条件行矩、端点与事件

取n,D,m̄,k≥1、q=2^D、0≤B≤D，k=n̄；作为FI打印域实例时另要求8∣n。χ为有限支撑对称整数律，同余点合并后解释其模群律。合同包括：A与消息/指定行在全部相关χ币之前固定，同A两代，给定A后全部原始χ坐标与调用为精确独立乘积律，一次诚实未筛选TG/Upd，以及§2的Ord_n、矩阵维度和官方半向上Decode。任意前置公开A分布可在逐A证明后平均。

令𝓑=σ(A,U₀,F₀,R)，V=σ(𝓑,U₁,F₁,U₂,F₂)。固定V后，同行k个残差由互不相交的钥匙/G原始列包生成，条件iid；p(V)为一个坐标落入共同正确残差集合𝓓的概率。因此

\[
p_{row}(A)=\Pr(J\mid A)=E[p(V)^k\mid A],\qquad\pi_0=|\mathcal D|/q.
\]

首先以有限和定义

\[
C_k(\pi_0):=\sum_{j=0}^{k-1}\pi_0^j,\qquad
F=\pi_0^k+C_k(\pi_0)Z.\tag{P-C}
\]

0≤π₀<1时才使用等价商式C_k=(1−π₀^k)/(1−π₀)；π₀=1直接由有限和得C_k=k。

**参数化判据P。** 设𝓖为𝓑可测好事件，每个固定A满足Pr(𝓖^c|A)≤δ∈[0,1]；每个好环境内已认证E[|p(V)−π₀||𝓑]≤Z，0≤Z<∞。则指定行与指定坐标事件S满足

\[
\begin{aligned}
L_J&=(1-\delta)(\pi_0-Z)_+^k,&
U_J&=(1-\delta)\min\{1,F,\pi_0+Z\}+\delta,\\
L_S&=(1-\delta)(\pi_0-Z)_+,&
U_S&=(1-\delta)\min\{1,\pi_0+Z\}+\delta.
\end{aligned}\tag{P-JS}
\]

相应区间为[L_J,U_J]、[L_S,U_S]。原始上界U_raw=(1−δ)F+δ也成立。这里的Z是需要实际认证的混合偏差；独立采样及同A合同单独无法给出高错误率。

**证明概要。** 点态x^k≤π₀^k+C_k(x−π₀)_+来自差商Σx^(k−1−j)π₀^j≤C_k；再用p^k≤p≤1，得到好环境内min{1,F,π₀+Z}。坏环境以1计费，真实坏质量b_A≤δ且好上界≤1，解除环境得U_J。先在每个好𝓑内用Jensen，再混合得L_J；坐标界由均值偏差直接给出。旧640证书采用的较弱全局Jensen下界[(1−δ)(π₀−Z)]^8仍可沿用，其精确分数与显示端点分别登记。

| 端点 | 准确处理 |
|---|---|
| π₀=0 | 𝓓为空，正确事件概率0；C_k=1 |
| π₀=1 | 𝓓为全群，正确事件概率1；有限和C_k=k |
| k=1 | C₁=1，行与指定坐标相同 |
| δ=1 | 通用区间[0,1]；π₀端点的精确事件值优先适用 |
| Z≥π₀ | 通用Jensen下界为0，上界继续用P-JS |
| F≥1 | F−1=C_k[Z−(1−π₀)]，故π₀+Z≥1，U_raw≥1且U_J=1 |
| B=0／B=D | 前者唯一标签、𝓓=Z_q、π₀=1；后者𝓓={0}、π₀=1/q |
| k=0；n=0或D=0 | 空行可另定义为必然事件、C₀=0；本算法命题取n,D,k≥1 |

令K为完整消息正确、I为初始完整正确，逐样本K⊆J⊆S给Pr(K|A)≤U_J。行下界留在J；完整下界可另用全零U₀/F₀/R事件。先完成原实验联合分析，再对Pr(I^c|A)≤α<1采用

\[
\max\{0,(L_E-\alpha)/(1-\alpha)\}

\]
