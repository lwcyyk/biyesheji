# 无历史数学审阅任务规格

本材料包已准备。新审阅子任务的启动等待用户明确授权。当前研究会话继续完成已授权的来源核查和证据审查。

审阅目标是核准STATEMENT_ONLY.md中的固定A直接概率界、P2-only选择界、三个有限证书及原游戏／共同正确性族映射。新审阅者使用空会话历史，并如实登记工具、实际输入和可见模型身份。

第一阶段仅读取STATEMENT_ONLY.md、INPUT_MANIFEST.json及清单中的两份公开PDF。自行推导证明或反例，可运行有限精确数学核对。提交PHASE1_DERIVATION.md、PHASE1_VERDICT.json和实际访问日志后封存哈希。原作者推导文件在此阶段保持未读。

第二阶段由主会话提供已冻结的作者证明及证书，逐项比对，核准差异、失效前提与贡献强度。本任务的独立性按实际上下文和访问记录判断。若提前读到作者证明，应登记实际知情范围。

全部新文件放入此目录下的review_output。研究权限为公开资料与纸面／有限数学核验。候选机制实现仍遵守用户既定分离门。

启动确认来自当前运行规则。该规则要求用户明确授权后才可派生新的子代理，此前已授权的既有Frodo对话可以继续接收研究任务。
