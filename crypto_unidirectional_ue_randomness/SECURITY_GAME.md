# UNI-R-CPA-1：固定切点的单向 UE 全随机带游戏

日期 2026-11-06。此游戏独立于 EE-R-PA1，**没有到期语义**。它冻结一个首轮攻击级别，不等同于原文全部自适应腐化游戏。主实例为 UNIUE-GP23-EG-CTX1；Frodo 基础反例使用同一查询骨架的 0/1/2 代平移。

## 1. 方向用可计算关系定义

主实例的完整钥匙 K_e=(x_{e,1},…,x_{e,e})。公开 Δ_{e+1} 包含 δ_i 和新坐标公钥，满足：

- 由 K_{e+1} 与 Δ_{e+1} 可计算 K_e：对 i≤e 取 x_{e,i}=x_{e+1,i}/δ_i。
- 由 K_e 与 Δ_{e+1} 能计算下一代的前 e 个秘密坐标，缺少独立新 x_{e+1,e+1}。本轮不把这称作可得完整 K_{e+1}。
- 公共 Upd 从 e 代密文走向 e+1 代。反向还原原密文/明文不是授权接口。

钥匙恢复方向与密文更新方向分别定义。名词 backward-leak 不代表时间墙钟、原生撤销或到期隐私。

## 2. 状态、权限与最小范围

素数阶群安全参数 κ；最多 L=poly(κ) 代、Q=poly(κ) 次自适应普通查询。单链，初始代次 1；**挑战代次预先固定为 2**，一次挑战。普通查询可在挑战前后自适应进行。所有更新令牌公开；公开公钥缓存按算法产生。

攻击者允许取得初始历史钥匙 K1，既可开始即取，也可稍后查询；其它完整钥匙查询按闭包规则判定。原生成/Next 随机带不暴露：Next 带含新秘密坐标，暴露它会直接赋予新解密能力，超出 RC26 普通 Enc/Upd 带扩展的首轮范围。

所有旧密文、令牌、正常完整带及已公开挑战版本可永久保存。诚实一侧擦除旧活动钥匙/带是应用前提；已经交给攻击者的数据不会因擦除而消失。

## 3. Oracle

- `EncLeak(M)`：当前 e 代诚实 Enc，返回 (C,id,ρ)。ρ 为固定公开采样器的**完整随机位输入**，包含 pad 的采样指数和加密指数的拒绝词；记录 M、来源和当前 e。
- `Next()`：诚实生成 K_{e+1}、Δ_{e+1}，公开 token 并更新缓存。若已有挑战，自动用新隐藏随机带更新挑战，保存历史版本。该带不返回。
- `UpdLeak(id)`：只接收注册的上一代**普通** id，按实际公共 Upd 独立采 η，返回 (C',id',η)，保持普通父子来源。允许同一父记录独立重复更新。
- `Challenge(M0,id_parent)`：只在 e=2 且尚未挑战时调用；parent 必须是 1 代普通记录，已知明文 M1。等长 G 元素 M0/M1。取均匀 b，b=0 返回 Enc_2(M0)，b=1 返回 Upd(Δ2,parent)。所有挑战生成带隐藏；新对象登记为挑战，不进入普通注册表。返回同格式的密文/opaque id 和公开代次，不返回区分 fresh/update 的来源分支标志。
- `GetChallenge()`：返回当前版本，历史已返回版本仍可保留。所有后继带隐藏。
- `CorruptKey(j)`：j≤当前 e。只有在合法性中未连接到预先声明的挑战代次及其可达后继的钥匙才允许；本公开 token profile 的非平凡合法查询为 j=1。由于挑战切点预先固定，任何阶段请求现有 j≥2 的钥匙都使实验判为非法并终止，返回独立均匀实验判定。不存在尚未生成的未来钥匙查询则返回 ⊥。没有发起挑战的运行不贡献优势。挑战后查询也按历史目标检查，不能因之后再更新就清除一次不合法暴露。

无 Dec oracle，无任意密文导入/自报 id 注册。复制挑战记录名或向普通接口附带同样字节无法取得普通身份。攻击者仍可离线运行任意公共算法；不能通过资格定义排除真实的代数攻击。

## 4. 可达闭包及平凡胜利

K 为实际腐化代次集，T 为已公开 token 的目标代次集。钥匙闭包 K* 是包含 K 的最小集合，且

    j∈K* 且 j∈T  ⇒ j−1∈K*.

当前主实例没有从旧完整钥匙到新完整钥匙的前向闭包。C 为已公开挑战版本代次；C* 是包含 C 的最小集合，且

    e∈C* 且 e+1∈T ⇒ e+1∈C*.

钥匙可再产生相邻 token 时，T* 可加规则 `{e−1,e}⊆K*⇒e∈T*`；本 profile 已公开全部 token，故 T*=T。禁止 K*∩C* 非空。由于挑战 2、公开后续 token，C* 包含全部可达 2,…,当前 e；K1 只闭合到 1，合法。

挑战来源及后继通过独立标签传播；普通接口没有导入等价密文的路径。对攻击者自己本地进行的前向更新仍在 C* 资格中考虑，即使中间版本没有显式获取。

非法查询串使实验返回独立均匀判定，不能贡献优势。优势为

    Adv_UNI-R(A)=|Pr[b'=b]−1/2|.

原文 `rand-ind-eu-cpa` 的 rand 指随机化方案和 fresh-vs-update 游戏，不表示返回随机带。某些原文以两个输出实验的概率差计优势，是本 bias 约定的 2 倍；比较时分别标注。

## 5. 最小合法查询族

| 事件 | 攻击者取得与可推导信息 | 合法性 |
|---|---|---|
| Setup/Corrupt(1) | K1；p1 可计算；历史未知对象若已解密，其明文知识永久保留 | K*={1} |
| EncLeak_1(M1) | 普通 C1、pad/加密完整位带及来源 | 所有输入明文由攻击者选择 |
| Next_2 | δ_{2,1}、p_{2,2}，以及 p_{2,1}=p_{1,1}^{δ} | 缺少新 x_{2,2} |
| 两次 UpdLeak(C1) | 两份独立普通 C2^N、η_1/η_2；可确定性重放 | 与挑战来源分离 |
| Challenge_2(M0,C1) | C2*，生成带隐藏 | {1}∩{2}=∅ |
| 普通 EncLeak_2 | 选择明文和完整新带，公共键下可诚实模拟 | 不返回挑战带 |
| Next_3/GetChallenge | Δ3、C3*；保留 C2*；可以本地前向更新其它分支 | K*={1}，C*={2,3} |
| UpdLeak(C2^N)、Corrupt(1) | 正常 C3^N/带；重复历史钥匙 | 条件持续成立 |

可再 Next_4，证明同样归纳。攻击者视图含所有历史、公钥、token、普通带、挑战版本和查询/失败记录。

## 6. 四项负控制

1. 直接请求 K2：命中挑战代次，非法。
2. 请求 K3 并保留 Δ3：可除去 δ 得 K2，闭包命中，非法；再次诚实 Next 不抹去这个历史事实。
3. 返回挑战初始 Enc 的 pad 采样带：从 Z/∏w 得明文，是直接平凡攻击，故不在普通泄露接口。单独一段更新带的具体能力另判，首轮统一保护挑战链所有带。
4. 复制挑战 id、改名或附带同一字节送 `UpdLeak`：注册资格拒绝。注册的诚实普通对象仍照常可更新，不能为防别名而关闭全部正向控制。

## 7. 秘密类型和恢复边界

公开群参数、公钥缓存、token 和 nonce 类元数据可见。普通带里的 pad 生成指数/加密指数、Frodo 的秘密噪声与随机矩阵，都属于随机性泄露，不被重命名为公开 nonce。K1 是获准钥匙输入；新 x_{2,2} 是新秘密密钥，绝非普通 Enc 带的一部分。

在 K1 暴露后，诚实 Next_2 的独立新秘密加上隐藏的挑战生成/更新带，保护新代次的新挑战视图。攻击者已经知道的明文不会被重新加密“收回”。本游戏没有回滚、分叉、持久重试、密码学删除或原生材料吊销承诺。
