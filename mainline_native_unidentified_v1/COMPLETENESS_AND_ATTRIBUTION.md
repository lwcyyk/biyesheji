# 集合完整性、排除归属与效果饱和

本轮组织只包含两个目标账户和一个干扰账户，后者名称包含第一个目标名称。每个目标有 A/B 两项批准，干扰账户一项批准，共五项预先登记批准，每项预算 10。每次放行至多消耗一个预算槽且产生至多一个原生单位，因此整个允许计划的原生记录生命周期上界为 50。撤销、UserInfo、内省和只读列表不新增原生单位。独立测量只用内省检查 RT，不执行可能创建的刷新探测。

该上界涵盖所有五项批准可允许的操作，宽于实际计划的五次初始发行和两次未知刷新。额外批准、未登记管理写入、传输重试或一请求多效果会使模型依据不足，继续 UNKNOWN。全体原生写入者由受控夹具与可信入口模型排除，敌对管理员/OS 用户的截止仍未证明。

pageSize=100 大于记录上界 50，p=1 对应 offset=0。原生 GetTokenCount 与 Find 分别执行，count/page count 只作为观察保存。完整性依据是同一个 Find 读取语句在其快照中的全部匹配记录均落入一页。该事实不证明观察后没有新记录。

原生 org 等值过滤建立获准范围。运行者在完整返回中按 user 和 application 等值选择目标账户，扣除权威账本中全部已知目标原生单位。唯一剩余候选只有在唯一未知创建、已知来源完整、批准/预算清单符合模型、创建者受控和 B 新创建暂停时才能归属 A1。同账户、用户名子串、相近时间或字符串数均不单独构成归属证据。

一个发送槽、每发送至多一个单位，若已经观察到唯一可归属单位，则剩余创建上界为 0。若新增候选为空，即使当前集合完整，未知请求仍可迟到创建，上界保持 1。M4-02 在真实发送前屏障下先查询，再释放发送并查询。

枚举分支收据标为 AUTHORIZED_SCOPE_ENUMERATION。M3 点读分支保留 IDENTIFIER_POINT_READ。检查器分别核对组织授权、全部返回范围、理论上界、页容量、单语句范围、精确选择、已知单位差集和唯一未知来源。最终关闭还需 A 已知单位处置及 B/干扰账户保留证据。

## 实际集合

M4-01 返回整个组织 3 项，其中目标 2 项，扣除已知单位后剩余 A1 一项。干扰账户名称含目标名称，但其单位不进入目标集合或候选集合。

M4-02 首次真实查询返回组织 5 项、目标 A0/B0 两项，新增候选为空，发送槽尚未执行，保留 UNKNOWN 和剩余上界 1。释放发送后再次查询，组织总数仍为 5，目标集合变为 B0/A1，剩余候选 A1 一项。记录数与页数相同没有被当作未来效果穷尽依据。

两个关闭收据都确认一个发送、一个单位效果上界和一个可归属观察，剩余创建上界为 0。集合覆盖仅为单个原生 Find 语句的读快照，关闭还依赖固定源模型和受控创建者等条件。管理员直接写入、额外批准、重试、多效果和多未知来源需重新判定。
