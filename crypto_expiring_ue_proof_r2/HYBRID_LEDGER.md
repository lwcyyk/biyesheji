## 2. 可安全写出的形式界

若所有版本/类型问题已校准，各步新增联合视图误差分别被证明有界，则三角不等式给

    Adv_R ≤ ε_fresh + ε_H + Adv_LS
            + 2M·P_RS·Adv_RS + P_ND·Adv_ND
            + Σ_i δ_R2,i + ε_cut + ε_other.

这里 P_RS/P_ND 是完成后的归约显式猜测因子；ε_cut 是固定采样器截断差异，ε_other 收集确有证明的其它近似。当前 δ_R2,i 和若干源语法尚待解决，故这行是**条件账本**，无法据此宣布增强安全。若界达到 1/2，优势定义本身提供平凡上界。

## 3. 仿射/重新采样步骤的约束

RC26 的 r̂−r 模拟使用已知标量并在完整 Z_q 上保测。DSG 隐藏向量只有群编码时，表达“存在向量/补空间可打开”无法提供可执行归约。任何替代模拟须给出已知输入到返回位带的算法、正确条件分布和共同未知量的跨查询一致性。

R2-LOCAL 避开了对普通输出重新采样的需要。若另一路线把普通 ExPunc 替成新鲜 Enc，则仍需从父对象、实际 Δ、新鲜子密文生成真实 η，并证明 (父,Δ,子,η,K_late) 联合分布。单次子密文边缘相同不能完成此步骤。

## 4. “完美重随机化”采样口径

在 Z_p* 中取 s,s' 均匀，固定非零 s 时 s+s' 会以 1/(p−1) 的概率等于 0，而新鲜 s 从不为 0。因此标量层的精确均匀性需校准。此事实本身没有给出群编码密文的有效区分器。

一般有限循环群 H 上，令 D 为均匀生成元、U 为全群均匀分布，TV(D,U)=1−φ(|H|)/|H|=:δ_H。对任何固定 x∈H，平移保持 U，故

    TV(D,xD)≤2δ_H.

同理 Z_N* 的固定加法平移可与均匀 Z_N 比较。若实现确为相应子群的公开同态采样、委派后仍落在同一图像子群、全部素因子足够大，则按正常向量/标量调用数作 union bound，可得到多项式倍的可忽略统计项。原抽象性质和未取得的 d-Lin 实例尚不足以冻结该数值界。该耦合适用于**带隐藏的挑战**；普通公开位带始终按真实 J 原样返回。
