# 共同正确参数、查询量、失败与包装迁移账本

2026-11-07。知情纸面证明。模型为MATRIX-SELECT-OUT-CF2及其秘密置换输入版本；有限核算见 [finite_math_checks.json](sources/finite_math_checks.json)，其证据等级仅为标量公式核对。

## 1. 非空族与真实χ

对整数λ≥2取

\[
n=8\lambda,\quad D=8\lceil\log_2n\rceil,\quad q=2^D,\quad
\bar m=\bar n=8,\quad B=2,\quad\chi=\chi_{640},\quad T_{\max}=n.
\tag{P1}
\]

FI-v4 §5.1允许D正整数、n为8倍数、B≤D；这是一组该打印参数域中的渐近实例。官方Frodo有限配置的固定D、估计安全级别和实现字节规范各有范围，CF2没有继承其有限安全级别认证。

χ₆₄₀是有限16-bit CDF分布。冻结表的CDF为
4643,13363,20579,25843,29227,31145,32103,32525,32689,32745,32762,32766,32767。
一个均匀16-bit词的低位作符号，其余15位确定绝对值。支撑恰为{−12,…,12}；P(0)=9288/65536，每个±12各为1/65536，全部有正概率；正负概率对应相等，整数均值精确为0。每样本固定消费16位，拒绝次数和采样失败率均为0。官方采样源码及已有精确表记录的哈希在来源记录中，整词独立均匀是本轮纸面采样合同。

q>24，故有符号小样本在Z_q中的表示一一对应。s=12，与g=nD、d=8一起给

\[
B_0=288n+12,\quad
V=nsB_0=3456n^2+144n,
\tag{P2}
\]
\[
W=(nD+ns)B_0
=288n^2D+3456n^2+12nD+144n.
\tag{P3}
\]

BΔ为n×8。其元素是n项U₂E₃加一个G₂再减n项F₂S₃，所以界2ns²+s；rBΔ每坐标再求n项，得到ns(2ns²+s)。这里没有遗漏矩阵内维，r与整块R的第一行一致。

## 2. 独立重证完整正确性和提升

初始残差η₀=aE+z−fS，有|η₀|≤B₀。每次更新展开为

\[
\eta'=\eta+HT_1+rB_\Delta\pmod q.
\]

取一致整数提升，逐坐标新增误差≤nDB₀+nsB₀=W，任意长度t链有|η_t|≤B₀+tW。这个界只用支撑和Ord位为0/1，允许H依赖过去噪声。

D≤8n，n≥16时

\[
B_0+nW\le2304n^4+3552n^3+144n^2+288n+12
<2529n^4<4096n^4<n^8/8\le q/8.
\tag{P4}
\]

倒数第二个严格不等式来自n⁴≥16⁴>32768。B=2的解码窗口半宽为q/2^(B+1)=q/8，故(P4)认证任意诚实钥匙、消息和最多n次更新的逐样本正确性，纸面解码错误率为0。它包含初始噪声，补齐只累计更新噪声时会缺失的项。

FI-v4 p.15打印的Theorem6.3用较松的
\(\widetilde W=2n^2Ds^3+2n^2s^3+nDs+ns^2\)。
本稿(P3)由乘积逐项重算，不依赖直接引用该打印式。CF2也满足打印数值条件：由于n=8λ，λ=2单独检查、λ≥3用ceil(log₂λ)≤λ，可得D≤2n。于是

\[
B_0+n\widetilde W
\le6912n^4+3552n^3+144n^2+288n+12
<7136n^4<n^8/8\le q/8.
\tag{P5}
\]

其中n≥16时3552n³≤222n⁴，144n²<n⁴，288n+12<n⁴，而7136<8192≤n⁴/8。更完整的正确性依据是(P4)的独立递推。

训练父固定后有|μ_C|≤B₀+nDB₀、|ξ|≤V，故|μ_C|+V≤B₀+W<q/8<q/2；全部中心观察均采用同一整数提升，回绕失败率0。

fresh挑战的虚拟r=0更新误差≤B₀+nDB₀≤B₀+W；update挑战的真实边界2更新加虚拟边界3更新误差≤B₀+W+nDB₀≤B₀+2W<q/8。所以δ₀=δ₁=0。0在χ₆₄₀支撑，逐样本界覆盖虚拟更新点；其小概率无需进入优势损失。

## 3. 固定多项式预算与优势

令

\[
g=nD,\quad d=8,\quad Q=4gD=4nD^2,
\quad\delta_{\rm est}=2^{-\lambda-4},
\]
\[
L_{\rm est}=\lambda+8+\lceil\log_2 Q\rceil,\qquad
R=8V^2L_{\rm est}.
\tag{P6}
\]

全部为可有效计算的整数，V>0。因e>2，

\[
2Qd\,e^{-R/(8V^2)}
=16Qe^{-L_{\rm est}}
\le16Q2^{-L_{\rm est}}\le2^{-\lambda-4}.
\tag{P7}
\]

模块遗漏ε_mod≤gD/(Q+1)<1/4。两实验各扣一次不可观察的均值失败，其余纸面失败为0，得到

\[
\boxed{d_{\rm sign}\ge1-\frac{nD^2}{Q+1}
-4Qd\,e^{-R/(8V^2)}
>\frac34-2^{-\lambda-3}.}
\tag{P8}
\]

因此绝对gap Δ>3/4−2^(−λ−3)，成功偏差bias>3/8−2^(−λ−4)，猜对概率>7/8−2^(−λ−4)。SELECT中心优势取bias。理论攻击为无LWE假设的输出／完整未来Key攻击；若另外声称这个新族的基础PKE安全，还需该族对应的明确困难性来源，当前证明没有提供该安全性认证。

## 5. 查询、随机位、状态与位复杂度

| oracle | 次数 |
|---|---:|
| Enc | Q+1 |
| Upd | QR |
| Next | 2 |
| Challenge | 1 |
| Key | 1 |
| Token／GetChallenge／Dec | 0 |
| 合计 | Q(R+1)+5 |

初始Setup单列为实验初始化；Next的内部KG、TG和官方缓存Upd均计入实验计算，普通Upd查询数仍为QR。只生成到epoch3，训练链长1，挑战涉及的最长链长2；整个参数族另外认证最长n次链。

Q=O(λlog²λ)，V=Θ(λ²)，L_est=O(λ)，R=O(λ⁵)，总调用O(λ⁶log²λ)。关键要求是V的数值为多项式；仅logV为多项式不能推出该结论。

朴素环坐标存储成本：公共A为n²D位；完整密文为8(n+8)D位；完整Key中的S/B为16nD位；token为(nD+n)(n+8)D位。PRP包装的种子另加其固定s_σ位于相应Key/token，攻击无需保存或读取它。

每次完整Upd的新鲜有效币为16·8n=128n位，普通训练共128nQR位；固定填充池可更长，其长度同样应计费。Q份完整父保存O(Q·8(n+8)D)位；H、标签和带变换记录需要poly(Q,g,D)位。流式处理R个子可用8个整数和计数器，额外O(8(D+logR))位，无需保存全部QR份子或随机带。

每份残差需O(nd)环乘法，HNF/SNF的输入维度和位长均为多项式。完整Upd自身O(8n²(D+1))环操作；Next的TG为O(n³(D+1))量级。用普通D-bit整数算法，总时间可界为

\[
O(QR\,n^2(D+1)D^2)+\mathrm{poly}(Q,g,D),
\]

另含有限次数KG/TG和数据读写，仍为多项式。这里没有优化密码实验或最优样本复杂度主张。

## 6. 固定秘密置换的精确投影耦合

冻结ctx=(公开版本、目标epoch、q、采样规范、池长)，在抽取ρ前确定，普通／挑战／自动更新使用同一算法。对任意固定σ和相应公开ctx，Π_σ,ctx是整个固定长位池上的双射。ρ独立均匀时

\[
\Pr[\omega_1=w_1,\ldots,\omega_t=w_t\mid\sigma,\mathrm{ctx}]
=2^{-Mt}.
\tag{P10}
\]

对自适应但抽币前确定的ctx，可逐调用条件化得到同样的转移核。输入碰撞和输出碰撞一一对应；独立均匀输入本就允许碰撞，无需排除或支付生日项。

可直接耦合：先采未包装的独立有效池ω_i，再定义包装ρ_i=Π^−1(ω_i)。对每个固定真实种子，ρ_i保持独立均匀，所有底层密文、钥匙和隐藏官方更新逐次相同。投影掉ρ、ω、σ及日志以后，攻击的查询选择和输出完全相同，因为其程序从未读取这些字段。未来完整Key即使含别的种子，也不改变这项条件于种子的等式；当前outgoing布局Key₃暴露σ₄，边界σ₃保持隐藏。

固定16-bit χ池在任何池值下都成功。采用有限拒绝采样时，需对同一有效池、停止位置和原子提交语义耦合，失败／成功及首个终止也相同；若池预分配与真实实现不同，则以ν_b记录，不能自动宣称精确相同。普通PRF通常缺少逐密钥双射性质，(P10)仅赋予此处真实置换。

这一结论说明：对满足本轮矩阵残差条件的对象，RNG输入秘密重参数化仍保留输出攻击。冻结C-PRP-GP使用群基底，缺少残差条件，继续保留其成熟组合覆盖结论。

## 7. 实际参数边界

CF2允许D随λ增长，属于FI打印域的纸面族；全部χ样本独立、无压缩、同一token复用是明确合同。论文性能表的AES／SHAKE程序若要获得数值攻击优势，还需：完整实际参数映射、最长更新T、种子／流复用及域分离、普通父是否限次、未来Key完整字段、输出压缩／舍入规则，以及能认证共同提升和解码失败的实际分布界。

实际参数上的充分界未满足、实际存在解密错误、fresh/update可区分分别需要各自证据。当前交付只在CF2取得共同正确、多项式查询、非可忽略优势；性能表实例及真实部署优势保持未决。
