# 最小费用、资源与成熟基线

## 1. 本例费用投影

L0预算采用三键(a_slots,b_slots,native_calls)。前两者是本例为各任务保留的额外放行额度，下界不超过真实grant当前余量；当前A源码的请求次数/真实总limit仍另列。已持有p/b的取得前缀C_prefix不在这9次额外原生包络内。

| 事件/动作 | 本例模型计费 | 真实最小场景含义/缺口 |
|---|---|---|
| admit＋release＋结果LOST | a_slots1、native1，h−1 | 接纳/放行是两次持久步骤，合成一个模型决策；spent已记。未发送时native仍预付，不返还 |
| 用户撤回甲 | native0 | 本地权威/RPC/日志/隔离有成本，不在native维度隐藏为计算0 |
| dispose p | native3 | 当前完整RT revoke、AT UserInfo/内省；失败也计机会 |
| 可信读取c证据 | native≤1，模型收1 | inbox补收可0；一次获准点读/单页枚举1。授权、完整性、来源成本另计 |
| 一次迟到读取 | native0 | 一次现有inbox/元数据读取及校验；无循环等待保证 |
| dispose c | native3 | 处置成功/未知分开；来源/批准/接受路径仍核验 |
| 乙一次UserInfo | b_slots1、native1 | 独立批准、当前source_rid和实际响应 |

包括已发生refresh的片段原生包络为1+3+1+0+3+1=9，两放行槽分别为1。实际L0从K_U接管，已付refresh=1作为sunk项，未来动作包络为8；原先取得p/b的更早费用另计。该数值由手算获得，未作为实测或最优值。无结果/失败的前缀仍留已收费与未结责任；模型未凭少计UNKNOWN取得优势。

这里的已付1指模型对已放行责任的保守预付。actual_sends=0时原生账本可能尚未扣槽，旧调用以后首次发送由这1覆盖；它不构成实际C_native已发生1的证据。abstract native_calls=8是扣除该未决责任最坏费用后的计划余额。

每步模型扣费为所选有限宏全部允许微步骤的上界，抽象余额由“预付最坏费用”定义，保持≤真实可用余量。重放/拒绝/RPC/验签/全状态读写和输出保留在C_other，C_total=C_prefix+C_native+C_other；没有给不同单位直接相加成一个已证通用费用值。R02的无释放屏障/网络等待边界沿用。

## 2. Q、G与容量

| 量 | 本轮解释 |
|---|---|
| Q_model | 当前L0初态K_U之后native_calls最大累计8；历史refresh的1另加为本段总9，a_slots/b_slots另维度。A source中Q仍叫requests且含回放的已付费用 |
| C_native | 真实scope中的AS/RS请求；单调用/无重发前提下≤该模型预付计数 |
| G_B | 初始B目录p/b的独立撤销域数量为2，条件独立来自源合同；本模型没有由raw native_roots自动优化G_B |
| G_trace | 初始已观测p/b；可信观测c后累计可为3，即使p已从当前表删除。潜在c槽不算已观测单位 |
| c_i=1 | 限一次已放行refresh的直接创建数；它与预算余额或根数量分开 |

子代再次刷新、其他rid/代理/外部持有者都需新增attempt与资源，或由可信前提封口。raw native_roots包含潜在c不表明实际已创建，更不表明它与p或b在所有接受路径均独立。

## 3. 成熟方法对照

| 方法/组件 | 同条件能力 | 本轮结论 |
|---|---|---|
| 手工有限状态机 | 给出同15节点、相同隐藏后继、责任与成本 | 已完整覆盖本例建模工具层，工程贡献保留 |
| 通用AND/OR/有限POMDP支持集 | 按观察取并集、全称安全/终态、有界费用 | 与当前W设计同类；本例无概率依赖，不把随机近似工具当精确基线 |
| 标准保守抽象/监督控制 | 合并隐藏状态、保持风险/责任、区分安全与必胜 | 提供本轮方法基础；事件路由新接口尚需明确定义 |
| 当前L0 candidate/reference/checker | 可处理raw同语法有限表的决策/证书 | 本轮未调用；编进模型不产生算法原创性 |
| 当前A/B/AB及R-J | 其source目录/point语义下的安全规划与最坏requests | raw多键预算和新增进度不能免费包装成旧bundle |
| 当前持久控制器＋人工合同 | 实际撤回、未知责任、隔离和对账 | 不受研究W菜单当前缺边影响；真实接线另证 |
| 标准多尝试流 | 固定I/容量/来源/持续失效下核H_T | 单次c_i=1为其最小特例，不申新流定理 |

强G获得相同原生权限/窗口/来源/结构/缓存和预处理，可以采用同一有限表示与监督目标。“raw L0可表示但当前A源码少字段”只承担该项目内接口差异的结论，通用方法的必要高代价另需证明。CE4同样适用于任何选择了该强终态目标的规划器；一般工作流可独立接受撤回，比较应保留强G的这些能力。
