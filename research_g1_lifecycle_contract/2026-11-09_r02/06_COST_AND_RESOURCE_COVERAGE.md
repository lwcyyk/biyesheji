# 预算、资源与费用覆盖

## 1. 指标字典

| 指标 | 定义与边界 |
|---|---|
| G_B | B登记配置所用独立原生撤销影响域；当前要求分区 |
| G_trace | 一条轨迹全生命周期观察到的不同原生单位并集；不同于时点活跃行/字符串数 |
| G_Mr | 理想M_r预建根及空备用根计费；需理想能力映射 |
| Q | 有限动作requests及明确external_debit；需宏展开价目 |
| C_native | 声明scope内真实AS/RS应用请求数；预记账H另计 |
| C_RPC | Controller/authority/provider内部请求、重放及重试 |
| C_compute | 读源/建模/搜索/检查/序列化/验签/数据库/恢复/输出 |
| reserved/spent | QUEUED预留/历史release数，包含UserInfo；dispose/query另走角色和预算 |

## 2. 本地记账与失败

admit首次reserved+1，尚未发送；release转为spent。放行未发送与已生效丢响应都保留spent。NativeHTTP在open前扣原生机会槽，崩溃也保留计费；spent不自动包含后续dispose/query。

同rid重放不新放行，但RPC/读状态/日志有本地成本；不同rid重新刷新是新attempt。下层重发若有ρ上界应乘请求包络并扩创建容量。无界重试不能沿用有限费用或容量1。

## 3. 原生价目与明确包络

| 动作 | 原生请求机会最坏数 | 说明 |
|---|---|---|
| refresh或UserInfo一次 | 1 | 无整请求重发；材料验证/RPC/存储另计 |
| dispose一次完整尝试 | 3 | RT revoke、AT UserInfo、AT introspect；失败前缀可少些 |
| 现有一次点读/单页枚举 | 1 | 查询前退出可能0；读取授权/集合完整性另证 |
| p页枚举 | p | 当前无一般分页完整性保证 |
| 乙后处置UserInfo | 1 | 与甲处置分开计费 |
| 当前权威恢复本身 | 0项AS为起点 | 读取/lookup为内部RPC/本地；后续query/dispose另加 |
| 环境/测量/账户收尾 | 按实际展开 | 方法成本与实验成本分别展示 |

纸面例：已有父P与乙B，一次refresh未知、一次query恢复子代、甲k份已知材料各完整dispose一次，再验乙UserInfo。方法片段包络为`1+1+3k+1=3k+3`；k=2时为9。初始发行/建户、重复查询/处置、测量和收尾另加。该数值未作为新实测或最优值。

对有限前缀t，n_f/n_u/n_d/n_q分别是预留的刷新/UserInfo/完整处置/查询宏数；每宏只执行其展开步骤、每机会至多一完整请求时：

\[
C_{native}(t)\le H_{all}(t)\le n_f+n_u+3n_d+n_q+C_{other}^{bound}(t).
\]

未发送的预付费用保留在上界；各scope环境/测量/清理要么入C_other，要么显式另表，不能隐藏。潜在未来宏需有剩余预算和总调用界。

## 4. Cost_contract ≥ Cost_real

费用采用向量`(原生请求机会,RPC数,批准数,字节/本地工作)`逐分量比较。每宏w(a)覆盖全部微步骤，已发生费用加未决预留承担任意前缀最坏上界；逐步扣费并求和证明。数字Q与毫秒/字节需要先给转换关系。

C_native分量已有上节条件包络。若A/B把cleanup/dispose设requests=1，真实完整3次会低估；修正至少3并加query/乙检查才能在该分量保持。拒绝和重放即使原生0，本地费用仍在其他分量。

当前A/B source的requests/approvals尚未绑定本轮价目，也无C_compute通用单价。纸面价目不能当作当前证书已覆盖所有真实费用，接入状态SOURCE_OR_REFINEMENT_GAP。

## 5. 计算、维护与恢复

AuthorityStore每mutation处理完整状态D_v及事件投影。对m次提交/读取，应统计Σ|D_v|的逻辑序列化/加密/写入；一次事务不能当作与状态规模无关的常数。SQLite物理WAL/fsync、锁等待和密钥可用另有系统条件。

完整费用目录：源读取/合同更新＋模型/图建立＋全部搜索/拒绝/超限＋证书＋全状态SQL/加密/投影＋正文编码/解析/ATRT验签＋journal/inbox＋对账集合/流＋缓存失效＋恢复＋最终输出。若各过程有证明包络T_j(input_j)，总计算包络为ΣT_j；本轮没有取得库/磁盘等待的统一数值或墙钟界，费用目录不充当运行时间定理。

输入长度、材料/响应上限和key规模可固定局部处理尺度；AS挂起、网络及权威不可达需额外条件。`native_provider.py:87—91,122—147`的hold屏障还含等待外部文件释放的循环；未约束释放/终止时间时，单次perform的等待与循环工作没有统一有限上界，见08 CE11。夹具释放或杀进程可形成另外的运行时限合同，但本轮没有证明它对全部允许执行生效。h≤8限制决策步，HTTP/RPC timeout限制调用者当前等待，均不证明后端效果或provider线程终止。

## 6. 证据复用与历史范围

双方可复用来源可靠且scope/版本/时点适用的证据，首次取证/存储/验证及后续新鲜度检查都收费。旧UserInfo成功不免费替代到期后的当前可用性；源/批准/接受路径改变须重检。

M2原生114、M6原生84、校准方法744/总5652及各版本回归按R01原定义复用。账本理论上是机会计费；历史完整响应支持各批实际执行范围，字段和分母保持。本轮新增原生/测试为0。

裁决：本地预算守恒和明确原生计数包络可证；现有研究预算到全部真实费用的自动同单位映射仍缺。最优性与相对最强G的必要代价差均未建立。
