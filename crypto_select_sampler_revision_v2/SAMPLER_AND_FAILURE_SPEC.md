# SPEC2采样、完整位带与失败状态机

适用算法UNIUE-GP23-EG-CTX1；适用游戏G-SELECT-ADAPT。理想版、C0-B版、FAIR-B版均采用本文件的位到标量解释。所有log为log₂。群与域算法在本抽象规范中确定性执行；库内部盲化、共享RNG状态曝光及侧信道属于另行映射前提。

## 1. 唯一规范采样器S_n

固定公开双射φ_n:{0,…,n−1}→目标域。n≥1。

* n=1：返回φ_1(0)，0位、0轮，永远成功。
* n>1：k_n=ceil(log₂n)。每轮读取新的k_n个独立公平位，按大端二进制解释为h。h<n时接受并返回φ_n(h)，否则继续。
* 理想版持续到接受。有限版每调用最多B≥1轮；连续B轮拒绝即耗尽。

每调用使用独立比特流。流可按实际调用顺序惰性分配，无公共种子及流状态曝光。调用开始前的历史可以包含b、过去所有私有/公开状态、自适应参数选择；新流仍独立。

设p_n=n/2^k_n。n>1时p_n>1/2（二次幂时等于1）。对每个输出v，Pr[T=t,Y=v]=(1−p_n)^(t−1)/2^k_n，因此Y精确均匀，T与Y独立，E[T]=1/p_n<2；统一上界为2。有限版成功条件下Y仍精确均匀，成功率1−(1−p_n)^B。

对任意调用开始历史H和由H决定的合法n：

    Pr[本调用B轮耗尽 | H] = (1−p_n)^B ≤ 2^(−B).

n=1时左侧0。若已经在本调用内观察r轮拒绝，余下B−r轮的界为2^(−(B−r))。全新的B轮尾界针对调用起点或另外B轮，条件化的位置需保留。

## 2. 域、索引与控制位

|用途|域大小n|词宽与映射|
|---|---:|---|
|F_q标量|q|k_q；φ(h)=h|
|F_q*钥匙/倍率/KHC新指数|q−1|k_(q−1)；φ(h)=h+1|
|三角位置|F=L(L−1)/2|k_F；按下述秩解码|
|矩形J|L−1|φ(h)=h+2|
|矩形R|L|φ(h)=h+1|
|全局b、公平终止位|2|直接读取独立一位；无需调用S|

三角固定按J递增、同一J中R递增排列。b_j=Σ_(h=2)^(j−1)(L−h+1)，空和为0。给定秩a∈{0,…,F−1}，唯一j满足b_j≤a<b_j+L−j+1，令r=j+a−b_j。该排列是固定双射，L=2时F=1且无随机位。

矩形独立抽J∈{2,…,L}、R∈{1,…,L}。R<J的位置公平输出。理想有效域条件分布等于三角均匀分布；有限索引失败率分别据自身n计算。

## 3. 完整普通位带的规范编码

记U(v)=Elias-gamma(v+1)，v为非负整数；gamma(m)=0^floor(log₂m)后接m的二进制展开。固定有限op/role编号表：Enc=1，Upd=2；pad=1，enc=2，khc=3。整数编码、域值及群元素编码均采用固定规范形式。

带格式是以下字段的串接：版本号U(2)、op、目标epoch、调用数，以及每个调用的

    U(role) U(coordinate) U(n) U(k_n) U(t)
    [按消费顺序排列的t个k_n位原始词]
    U(success_position).

成功调用的success_position=t；n=1时t=0、词串空、success_position=0。接收者按固定φ从末词恢复输出。前t−1词须≥n，末词须<n。普通Enc先按i递增采(z_i,r_i)，分别role=pad/enc；Upd先按旧i采a_i（khc），再按全部i采(z_i,s_i)。采样调用边界全部显式保存，拒绝词原样包含。无补齐位、无删除拒绝词、无另行随机标签。

带是每次成功普通响应完整返回的对象；父带保留，重复父更新使用新流、新带。公开元数据、id及带长度可以观察。失败响应只给统一FAIL，当前调用的部分带留在本地临时区并丢弃。Gen、Next、官方挑战链和判定器局部位带始终隐藏；完整Key只包含算法指定标量向量。

## 4. 共同状态与事务规则

已提交状态σ包括initialized、当前e、所有已生成K_e/P_e/Δ_e、普通不可变记录(id,e,M,C及表示)、公开id计数器、accepted、挑战起点c/M₀/M₁、当前私有官方缓存、直接曝光集C/K/T，以及halted。全局b在交互前直接抽一位。oracle次数在入口计入Q，这是资源账本，不回滚。

每个有效响应按“检查→临时采样/计算→一次提交→公开响应”执行。临时区对A不可见。对象/消息/群成员资格、当前epoch、Q/L预算、parent类型先检查；格式错误、错误id、未来未生成对象回⊥，密码状态保持原样。达到交互预算后进入正常终局。已存在Key/Token照实返回，即使历史随后无效；合法性用于最终评分。

任意S耗尽：丢弃本响应整个临时区；保留以前全部已提交状态；输出统一FAIL；halted=true，全局终止交互。无部分P、密文、带、id或曝光提交；A无法重试及覆盖终止输出。失败位置在FAIL中没有标签。

闭包只作用于已生成对象。由直接C/K/T计算最小不动点：j∈K*且j∈T*⇒j−1∈K*；{j−1,j}⊆K*⇒j∈T*；j−1∈C*且j∈T*⇒j∈C*。保留全部历史；valid当且仅当K*∩C*=∅。

## 5. 真实游戏逐接口状态机

|接口|检查、临时计算|成功提交与公开|耗尽后的原状态|
|---|---|---|---|
|Setup|未初始化；S_(q−1)采x11，计算P1|initialized=true、e=1、K1/P1；交付P1|未初始化、e=0、accepted=false|
|Next|e<L；临时采e个旧倍率及一个新钥匙，算新K/P/Δ；若accepted，再临时执行完整官方Upd|一并提交e+1、K/P/Δ及私有官方缓存；只公开P；C保持原值|旧epoch、旧K/P/Δ与旧缓存全部保留；即使新P已算出仍无公开|
|EncLeak(M)|M∈G；按固定顺序采全部2e个标量并计算|新id及普通记录、完整密文和完整位带一次提交|id计数器与记录集保持原值|
|UpdLeak(parent)|parent为当前前一代普通记录；采旧a及全部z/s|独立新id、子记录、密文及完整新带；父记录不可变|父与记录集、id计数器保持原值|
|Challenge(M₀,parent)|accepted=false，2≤e≤L，合法普通前代parent；暂存M₁；按b计算fresh或隐藏Upd|accepted=true、c=e、M₀/M₁、官方缓存及opaque id，C←C∪{e}同时提交；返回缓存|accepted=false；C不变；M/c/缓存和id均无提交|

Setup的隐式初始化属于游戏，不占A的Q次请求。挑战opaque id使用与分支无关的确定性格式，且位于官方谱系；普通oracle仅识别普通registry id。每次返回当前P与完整钥匙的规范化映射沿用CTX1。群运算和格式验证假定在规定成本内确定完成。

## 6. 两个有限评分版本

正常终局：A输出b′；计算h=1_{accepted且valid}，中心评分S=h(1_{b′=b}−1/2)。无accepted或无效时贡献0；需要0/1实验输出时用独立公平位正规化该零贡献。

**SELECT-C0-B-SPEC2：** 发生采样失败时强制b′=0，再用最后已提交状态计算h和S。尤其Challenge失败使accepted=false，评分0；挑战后失败可以产生固定猜测评分。若h=0，0/1实验输出使用公平正规化。中心评分是主定义，故其期望与正规化输出成功率减1/2一致。

**SELECT-FAIR-B-SPEC2：** 每个采样失败位置立即直接抽独立公平位作为最终输出，并吸收终止。对中心评分等价于用独立公平b′配合最后已提交h；条件于失败前缀及b，期望为0。无accepted/无效时复用该公平位，避免额外终止采样。任何后续A输出无覆盖权。

上述终局规则也包括Setup、普通带中途、官方私有更新中途的耗尽。FAIR位是一位直接抽取，耗尽概率为0。

## 7. 判定器的采样与原子提交

先用S_F选择三角秩；失败时C0输出0或FAIR直接抽一位。成功后直接抽全局b并启动A。每个公开响应使用上述原子边界。钥匙轨迹仅随实际生成时点公开。为固定有限判定器的计数，官方混合缓存采用eager方式：Challenge及以后每次Next时，先在临时区生成本代honest/embedded/uniform官方版本，再和该响应一起提交；Get只读取缓存。首次在第j代物化嵌入可以早于其公开时点。

因猜测不匹配、最终非法或保护对象无法回答而停止的理想归约始终公平补足。这些停止与S耗尽分开记账。已有对象才触发受保护钥匙/边界token停止；尚未生成的请求先回⊥。

终局匹配E_JR且存活时输出1_{b′=b}；其余终局公平输出。判定器局部采样耗尽采用对应C0/FAIR规则，并立即终止，优先于匹配规则。标准DDH包装器见X=1时直接公平输出，X≠1时运行该判定器。矩形版本使用两个S索引并保留相同有效位置模拟核。

有限真实游戏和有限判定器分别耦合其理想版本，费用计入误差；没有假定两种有限过程之间存在零误差的挑战链新鲜化。
