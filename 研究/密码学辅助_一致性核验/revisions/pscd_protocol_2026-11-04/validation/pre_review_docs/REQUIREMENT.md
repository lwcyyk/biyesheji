# PSCD需求论证与实现进入记录

2026-11-04。本文件在任何新增.mpc程序之前完成。用户本轮明确授权构建与测量三档协议原型。本轮按该授权进行工程可行性评估，独立密码学创新和通用方法分离分别登记。

## 1. 要实现的功能

同一认证记录残差来源，通过Prepare选定本次披露契约。P0向私密接收方交付支持及幅值，外部验证者获得输入无关的固定长度转录。P1向验证者公开支持及统计幅值脱敏转录，附共享掩码族内的精确误差说明。P2按授权公开支持及幅值。

P0的私密输出内容已由用户确认为“支持及幅值”。计算入口是完整残差的秘密份额，来源层使用既有AES-128-GCM记录关系。主测量采用GF(2^128)、d=k=3、r=2及n=8、64、256。四维五列变体限定n=5，单列补充验证。

## 2. 紧凑密钥论点

固定r、d时，一份M包含rd个域元素。P1-r5的矩阵材料为6个域元素，对照的完全独立逐项掩码为n个域元素。这是两种材料表示的准确比较。

该比较尚未证明所有通用方案都需要Θ(n)秘密随机量。历史k-wise独立基线已经给出相应反例，随机种子、展开后的材料、离线分享量和总熵分别计费。q随n增长时，每个域元素的位数也需计入。

P0的直接固定长度实现对rn个输出域元素和一个私密状态使用一次性pad，材料总量随n增长。P2公开完整输入，秘密诊断掩码可省去。因此本轮保留“P1共享矩阵材料固定为rd个域元素”，弃用跨全部方法/档位的O(1)密钥优势主张。

## 3. 同掩码复用与追加线性诊断

同一M跨次用于同一位置会泄漏幅值比例。若两次非零残差为a、b，则两列观察满足Y₂=(b/a)Y₁。该额外关系超出单次δ*保证。跨次复用论点据此弃用。

在一次已授权输出内部进行公开线性后处理，属于数据处理，隐私误差上界保持。但逐项掩码也允许对其已公开转录作同类后处理，这一性质尚未形成单独分离。

## 4. 档位与证书链

Prepare统一管理公开模型、来源范围、批准档位、一次性材料状态、证书引用和输出格式，具有可运行和可测试的机制组合意义。数学最优证书仅绑定P1的共享掩码模型。P0提供理想ABB中的完美隐藏论证，P2提供完整披露的功能说明，二者的完整资源最优性另行登记。

公开证书证明该公开模型的数学界。具体调用符合匹配分布，还依赖采样器实现及受信任预处理假设。公开凭证仅散列公开模型、代码和证书，秘密M、pad和秘密输入的散列均保留在私密实验审计材料中。

## 5. 对SG2开放问题的回答

当前资产尚未证明真实认证需求必须保留单一MV关系。PSCD允许调用者显式选择该代数表示和对应误差证书，同时保留逐项掩码、私密零判断及共享功能参考。共享矩阵的必要性、首次性和机制原创性继续标为未确认。

因此本轮的可检验目标是三档功能正确、输出作用域准确、单次材料状态正确、采样分布与数学证书相符、来源与gate真正接通，以及完整同条件成本。论文使用“提出并实现一个带受限模型证书的可切换诊断原型”，首次性主张仅在登记表中作为待验证命题。

## 6. 强对照与相同契约

- 逐项非零掩码采用独立非零随机量，并在P0向获准接收方提供相应私密恢复材料。
- 逐项私密零判断复用合规gate已经计算的零标志，避免重复收费。
- 完整共享诊断参考在本接口中接收完整残差份额，完整提取支持并按档位披露。其P1最简实现与逐项私密零判断等效。若入口改为压缩syndrome，需另设输入profile。
- pad-only在P0使用直接加性pad。在P1复用共同gate的支持输出，在P2退化为获准全开，这些等效关系单独报告。

主测量固定相同来源、gate、底座和批准条件。135个计划单元全部登记，包括失败和未运行。该实验用于开发评估。
