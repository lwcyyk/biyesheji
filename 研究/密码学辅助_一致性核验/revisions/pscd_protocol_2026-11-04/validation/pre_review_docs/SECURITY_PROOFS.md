# PSCD安全论证与证据边界

2026-11-04。下列模拟器在理想ABB中陈述。外围角色采用诚实但好奇模型，Prepare由诚实的诊断拥有者O承担，输入先固定、采样随后独立执行。外部验证者及至多一个计算方的被动视图为保护对象，O与获准私密接收方的授权知识单列。

## 1. 理想功能和实际视图

公共信息包括profile、n、域、公开字典、来源记录的公开字段、批准、预算、公开证书与独立handle。秘密输入摘要、M、pad、采样分支和恢复结果保留在私密实验审计材料。

验证者接口只发布receipt、公开模型/来源及public_transcript.json。result.json、private_fixture.json、private_material.json、党方日志和恢复结果属于具有全部合成输入权限的实验审计者。开发工作区没有部署级访问隔离，单机两进程也没有验证实体隔离的威胁模型。

对合法源域，AES-GCM关系在秘密计算内生成残差x。可选gate给出秘密accepted。P0向R返回x及S，或私密REJECT。P1向V返回S及统计脱敏转录，或公开REJECT。P2向V返回完整x，或公开REJECT。

## 2. P0完美模拟

PSCD计算Y_i=Mvᵢxᵢ，对固定长度rn个域元素逐项加独立均匀pad。另用独立pad隐藏accepted位。accepted为0时用秘密乘法把有效M置零，保持电路和输出长度固定。

给定任意固定x、M、gate结果及公共参数，全部密文域元素仍相互独立均匀。模拟器直接产生rn+1个均匀域元素，精确模拟V的公开视图。一个计算方只持有各pad和M的独立加法份额，条件于这些份额，另一个份额仍保证同一均匀性。ABB内部交互由底座模拟器处理。

R持有M和pad，可恢复每个Y_i并选取非零Mvᵢ分量恢复xᵢ。用户确认R获准获得支持和幅值。模拟R的视图时，模拟器获得该获准输出，采样独立材料并构造相应密文。

该结论描述理想ABB中的额外披露。具体MASCOT与系统CSPRNG具有各自安全假设和损失。源码、编译和诚实执行测试尚未形成部署的无条件完美安全结论。

Shannon1949第10节/Theorem6，以及本线不相容引理说明纯齐次可观察输出在空支持上恒零、在无抹除单支持上非零，无法满足相同的支持隐藏契约。P0通过私密恢复权限和加性随机量改变观察形式。经典原文定位沿用final_closure/CLASSICS_LINKED。

## 3. P1的条件幅值模拟

### R5-GF128

Prepare输出的核密度为割线并集中的h=(D+m)/[(q−1)Z]和其余合法点的l=D/[(q−1)Z]。随后均匀选frame。对三列支持，模拟器按基坐标的三个割线轨道使用h，全非零轨道使用l，并均匀生成对应frame。小支持使用投影或历史S5的直接不变性构造。

于是对任意合法固定支持和幅值，TV距离至多δ*=ml。对于声明的完整共享掩码族和全部≤3支持，该最坏模拟半径的下界与构造匹配。此处引用PRIORITY_VERDICT的S1/S2和r5 GENERAL_THEOREM，均标注**手工证明待外部复核**。S5按IK00/IK02的直接推论归属。

P1明确打开Y的零填充版本，S由非零列取得。若只打开S，幅值模拟误差为0，δ*的正值不应附在那种输出上。

### T2五列规范frame的特征二适用性

历史收尾稿以素数q≥401、五列Vandermonde陈述闭式。本轮单列域扩展前提，使用GF(2^128)上的[I₄∣1]。

1. 任意四列独立，五列唯一关系为全1系数，适用于特征二。
2. 历史MODEL_REDUCTION按非零列的平行分割、或关系坐标的相等块分类。计数只使用有限域的非零性、相等性和λ≠0,1，含q−2个交比。
3. 例如四方向的零和例外通过两个独立线性方程确定唯一排除点，λ和λ−1均非零。特征二保持这一计数。相等块的仿射等价也仍有q(q−1)个自由作用元素。
4. 计数表中的2、3、5作为整数计数或实数概率系数使用，概率分母的运算不在特征二域中进行。
5. 闭式对偶的精确符号非负性已对q≥400核对，故适用于这里的域基数。

因此规范frame可以使用相同的匹配密度和闭式。此扩展自身标为**手工证明待外部复核**。public/model_t2_*.json另含在q=2^128代入后的配对LP证书，check_models通过独立检查器的计数接口核验全部原始/对偶条件。该变体只在n=5补充验证。

### 误差的准确含义

δ*是完整抽象幅值输入族中的最优最坏模拟半径。实际AES来源可能只产生其中一部分输入，所以实际组合协议使用“至多δ*”的保证。启用额外禁配对策略后，原证书只给更大基础族的上界，最优性标签降为BASE_FAMILY_UPPER_BOUND_ONLY。

在具体实现层应另计ε_ABB、ε_RNG等损失。40位底座参数与GF(2^128)的数据域大小分别登记，δ*没有替代底座安全参数。

系统CSPRNG的保证属于计算不可区分假设，不能把其输出位数当成已测得的信息论熵。具体实现可陈述针对受限计算攻击者的组合区分优势界，保留δ*加底座/随机源优势项。本文没有给出实际系统的端到端TV恰等于δ*的结论。

## 4. 精确采样论证

R5从非零均匀三向量归一化得到均匀射影点。拒绝字典点后，对高组接受1、低组接受l/h=D/(D+m)。成功条件下逐核概率恰与h/l成比例，归一化恒等式Uh+Ol=1给出目标分布。独立均匀GL₂左乘产生均匀frame。

T2从均匀矩阵条件于满行秩及无零字典列，得到均匀合法核和均匀frame。按核类型接受1或l/h，得到相应两档密度。

有界重试在成功条件下保持上述分布，耗尽记为输入独立的PREPROCESSING_INCONCLUSIVE。它影响可用性。采样分支、内部耗时和秘密材料摘要不作为验证者输出，侧信道与恶意Prepare属于未审计范围。

当前次数上限针对矩阵/核候选与GL-frame重试。均匀整数及逐项非零数的底层随机位拒绝采样具有有限期望成本，最坏位数与Prepare硬时限尚未由实现保证。该限制单独计入预算口径。

## 5. gate与来源组合

零标志bᵢ=xᵢ^(2^128−1)保持秘密。饱和计数电路精确判定|S|≤k，满火花前提使其等价于本profile的独立支持要求。额外禁配对约束也在秘密标志上计算，公开profile改变时明确降级证书范围。

P0把gate状态和所有有效负载一并pad，合法和拒绝路径具有相同公开长度。P1/P2的理想功能允许公开REJECT，拒绝负载为零。gate关闭时标为PRECONDITION_UNCHECKED，隐私界依赖调用者遵守输入承诺。

AES-GCM前端证明的是在给定秘密密钥和记录上下文下的标签/明文关系。服务身份、密钥建立、TLS握手、时效和真实批准仍需要外部保证。原生数据来源保证与数学掩码最优性分别登记。

## 6. P2和跨档组合

P2模拟器获得获准完整x，直接产生相同输出。其功能为全披露，δ=0只表示相对该完整泄漏功能的模拟正确性。

Prepare材料通过单次Consume或RETIRE结束。切换产生新handle、M及pad，既有披露记录按来源ID累计。P0调用不会消除先前P1/P2已经披露的信息。

对有限次数、每次输入在当前材料独立采样前固定的调用，P1诊断误差可按标准混合论证上界为Σδ_j。P0理想额外误差为0，P2按完整功能披露，底座和来源损失另行组合。

复用同一M时，单位置的两次观察会暴露幅值比。该情况作为明确反例，生命周期层拒绝旧handle重复使用。单次转录的公开线性后处理受数据处理界约束，跨调用复用需要新的安全论证。

## 7. 证书与创新口径

证书绑定公开模型的最优值，采样器分布正确性由本节论证和受信任Prepare假设提供。它没有独立证明某台恶意机器确实按该分布采样。

接口组合、单次材料管理和来源/gate接通属于本轮实现成果。P0与P2没有获得完整资源最优证书，P1只在声明的共享掩码族内最优。“首个”“每档均具全局最优证书”和独立机制原创性保持未验证。
