# 扩大实现之前的决策门与反方审查

日期：2026-11-03。结论：**本轮不扩大结构优化MPC。** 通用gate及其直接支持输出参考属于前提核验，不是通过门槛后的新结构协议开发。

## 1. 固定贡献声明

可以准确声称：在明确的有限域、逐位置任意非零幅值、输入独立秘密线性掩码、带位置标签的掩码列观察模型内，完成了关系冲突界、自由行数可行性条件，以及全部拟阵独立族下有效掩码联合分布和资源的自包含论证；并实现有限公开模型的编译器、独立检查器和私密结构合规通用参考。

不能声称：新的通用密码原语、所有私密诊断的最优理论、强原创性已成立、端到端优于简单组合、恶意协议已审计、已经适配主线真实认证服务。

## 2. 候选逐项决策

| 候选 | 决策分类 | 继续发展的范围 |
|---|---|---|
| C1 | 直接推论或自然组合 | 保留为模型不可能性引理及可检查冲突见证 |
| C2 | 直接推论或自然组合 | 保留为模型可用性判据，修正active-only/自由r量词 |
| C3 | 保守归为直接推论或自然组合；完整表述优先权未决 | 保留受限理论结果，可再核对精确先例；目前没有升级强原创的证据 |
| C4 | 已有代数算法的实现与自然组合 | 保留有价值的证书边界修复、独立核对和可复现软件 |

“已有结果的重述”须有精确原命题覆盖证据；不能因为工具经典就武断说整条定理早已逐字发表。反之，没找到完全同形定理也不支持“具有实质新增内容”或“强独立贡献”。当前不把任何候选归入第四档。

## 3. 不扩大MPC的三项实证依据

1. 原AES/GCM关系允许同记录双失败，不能支持拟议压缩字典所需的结构承诺；路径A未成立。
2. 路径B能检查输入属于受限族，却拒绝原定位契约要求处理的一部分输入；不能用缩小功能制造优势。
3. 通用gate已计算所有秘密零标志，接受后直接公开支持不增加秘密乘法；C3的达到下界构造又与独立分块等效。尚无必要加入结构掩码层的端到端理由。

这不是“结构化密码方法不可能有价值”的证明。一个无需逐项零判断的高效结构gate、可信但非人为的结构来源、或不同合法观察契约可能改变结论；当前没有这些结果，故停止扩大实现。

## 4. 反方审查

此审查由同一助手以反方立场执行，非独立审稿或跨模型验证。

| 反方问题 | 本轮回答 | 遗留风险 |
|---|---|---|
| 只是换名组合群论/拟阵理论？ | 多数核心步骤确属既有工具；已降低贡献声明 | S5/S7全文及精确归约未决，不能排除完整先例 |
| 小域例外会破坏C3？ | 给出显式基交换恒等式，只需q>2，并做GF3/GF4核对 | 手工一般证明未经过证明助手/外部复核 |
| 相关随机性可进一步减熵？ | 联合完整乘积群迫使条件frame乘积均匀；空间可相关 | 若只需子族隐私，该群不再成立 |
| 证书是否仅信任标签？ | 新检查器枚举实际公开族，与标签分离 | 仍不证明该公开族就是现实世界允许族 |
| 输入源能被攻击者操控？ | gate只保证固定提交残差的结构；真实来源另需证明 | 本轮MPC仍为合成残差，没有生产来源保证 |
| gate拒绝了本应处理的失败？ | 是，已单列profile和18个小域反例 | 受限profile当前不能取代主线原功能 |
| 是否挑选差基线？ | 保留独立分块和gate后直接支持输出 | 由于门槛未过，没有进行完整五方法同契约端到端实验 |
| 测试通过就算安全？ | 否，有限代数检查与诚实MASCOT运行各有范围 | 恶意输入偏离、侧信道、重试组合、故障恢复未审计 |
| 行数/熵最优就等于通信最优？ | 否；域元素输出、采样、gate和预处理都须计入 | 未有完整性能优势证据 |

## 5. 五个最终判断

| 维度 | 判断 |
|---|---|
| 数学是否成立 | 修正量词及范围后的C1–C3有完整手工论证；本轮未发现模型内反例；不是形式化机检结论 |
| 优先权是否明确 | 基础工具明确已有来源；完整C3陈述优先权未决；强原创性未成立 |
| 构造是否安全 | 理想模型内的掩码构造有条件成立；通用gate理想功能明确；实际来源、组合和恶意实现安全未完成 |
| 实现是否符合 | 在记录的小域/规模与诚实运行范围内通过；边界和证书作用域明确；生产域证书与全协议尚未实现 |
| 完整成本是否有价值 | 有开发测量及负控制；目前没有结构层相对简单分块/直接零判断的端到端收益证据 |

## 6. 下一阶段进入条件

优先关闭原始全文/版本和C3精确归约缺口；数学复核应关注完整联合不变性而非再堆枚举。若目标是独立协议贡献，还需同时满足：真实场景可解释的结构来源或新的结构gate；成功范围与泄漏没有暗中变更；对独立分块和私密零判断有明确、可证伪的成本假设；同批准、同安全参数、同预处理及失败策略；完整成本账本含内存和恢复。

如果这些条件不能满足，应把本线保留为受限理论附录和可靠实现支撑，把研究重点放回A/B/AB的实际未解决问题。不能因为已经写了代码而维持不成立的强原创性主张。本轮没有作H-A/H-B/H-AB正式统计结论。
