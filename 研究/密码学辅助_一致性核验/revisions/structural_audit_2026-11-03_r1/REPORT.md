# 结构化私密诊断独立贡献审计：交付入口

2026-11-03，structural-audit-r1。

**结论：当前成果有受限模型内的数学与工程价值，但不足以确认强独立密码学原创性；尚无完整成本优势。停止扩大结构优化MPC，保留理论刻画、证书修复和通用gate参考。**

## 1. 本轮得到的可靠结果

修订后C1说明依赖关系中的每个位置都受到 ε_S+η_i≥1 限制，不是任意依赖支持的所有位置都必须消失。C2说明当行数自由选择时，存在完美隐藏且不抹除活跃位置的线性掩码，当且仅当每个允许支持独立。C3限于“恰好全部独立集”，分析有效矩阵Z=MB，得到分量GL直积不变性、r_min=max d_j及Σlog₂|GL_dj|熵下界与匹配构造。

证明补齐了基本回路到初等矩阵的显式计算、q>2的小域处理、不同基与冗余环境坐标的回译、联合乘积轨道及相关列空间的边界。一般允许族不能直接使用C3资源结论。完整推导与8类边界反例见 [PROOFS.md](PROOFS.md)。

逐命题先例核验显示：TV事件界、GL随机化、拟阵分量、对角共轭群生成和轨道熵规则都有经典基础。完整诊断表述的优先权仍有未决文献，不能因独立推导而认定原创。详细来源、版本、实际读取位置和变量映射见 [PRIOR_ART.md](PRIOR_ART.md)。

## 2. 必须影响研究方向的负结果

- 原分量检查器检查的是有外部前提的字典资源，未核对真实公开支持族；新版将两者分开，独立检查完整族及profile绑定。原冲突证书已有较强的模型引用检查，本轮没有将它与分量证书混为一谈。
- 两记录AES/GCM历史样例允许同记录的tag与claim同时失败；“每记录至多一个失败”并无来源保证。GF4的256个残差中，该限制拒绝了18个原最多两失败契约要求处理的输入。
- 通用gate已经秘密计算零标志。合规后直接公开支持无需增加秘密乘法；新跑的两种profile上均实测成立。结构掩码仍需另计采样、乘法与检查，不能仅凭行数下降宣称收益。
- C3匹配构造与简单正确的独立分块等效，未建立独立算法优势。

## 4. 五项结论独立登记

| 评估维度 | 当前判断 |
|---|---|
| 数学 | 修正范围后有完整手工证明，未发现模型内反例；未获证明助手或外部复核 |
| 优先权 | 基础结果有先例；完整C3优先权未决，强原创性未成立 |
| 安全 | 掩码与gate有条件性理想论证；真实来源和恶意部署安全未验证 |
| 实现 | 小域测试、独立证书检查及诚实本地MPC参考通过；不外推到一般实现安全 |
| 完整成本价值 | 没有结构层胜过简单分块或逐项私密判断的证据；内存和恢复等完整测量未完成 |

有限审计记录为898+70+21条断言，另有1016个群恒等式实例、538个gate输入、32个MPC参考场景。这些不同口径不能相加成某种“安全证明规模”。未运行项详见复现文档。

## 5. 下一阶段的进入条件

先取得关键未决全文并完成精确先例归约；若继续开发协议，必须找到合理的真实结构来源或更高效合规gate，并在同成功范围、同泄漏、同安全参数和预算下提出可检验的完整成本收益。满足这些条件前，不扩大结构MPC、不接入真实撤销，不宣称H-A/H-B/H-AB获得正式统计支持。
