# 原创性、已有来源与价值判断

2026-11-03。未将用户“直到出现强原创结果”的目标当作必须给出肯定结论的证据。以下为同一助手的研究与反方审查，不是独立审稿。

## 1. 本轮真正增加的对象

A：双行、四列三维标架模型的精确minimax模拟误差及达到界的非均匀核构造，包含秩1/2混合下界。

B：GF(7)上同一个U_{3,6}列拟阵的两种表示具有不同最优误差，差异有精确原始—对偶证书。

C：三维双行模型到共同核分布/各基轨道模拟器的有限LP等价；作为精确参考和证书基础。它是有限参考，不是对大密码域的高效算法。

与r1/r2的区别是：这里不再只计算经典不变分布或补集大小，必须协调不同基的轨道约束。均匀合法核在q>3时被严格改进；连完整列拟阵都不能决定B中的最优值。这些结果具有独立陈述和独立反驳的对象，不依赖主线AI代理的命名。

## 3. 优先权结论的准确强度

当前已有证据支持把A+B作为独立理论贡献候选继续发展；它们比此前“标准组件组合”更具体，有下界、匹配分布、严格分离和精确证书。没有找到直接覆盖它们的已读命题，但检索不是穷尽证明。

尚未确认强原创性成立。仍需核对统计随机编码、受约束通道随机化、群作用下的多个实验共同模拟、有限几何/编码论的分布优化，尤其不能把一般数学工具换名后据为原创。相关q-polymatroid结果是否能诱导更一般的描述也是未决项。

## 4. 反方审查与实际价值

1. **模型是不是人为缩小？** 是明确限定的线性观察类。逐项独立非零掩码在更一般编码类内可实现完美隐私，因此不能称所有私密诊断的最优下界。需要证明这一类在真实协议中值得采用。
2. **收益是否足够大？** A的相对误差改进仅O(q^−2)，密码学大域下极小。B是小域反例，误差约5%，不适合直接部署。当前价值主要是结构性理论发现，不是现实加速或可接受的安全参数。
3. **采样是否安全且高效？** 尚无新的认证采样器。秘密核类别、坐标模式不能泄漏。简单明文采样或诚实MPC运行不能证明恶意安全。不能免费获得非均匀秘密核和均匀frame原语。
4. **LP是不是独立算法创新？** 不是。群平均、轨道压缩、线性规划和原始—对偶证明都是既有工具；新增内容必须落在归约后可证明的具体最优结构及反例，不在工具名称上。
5. **证书是否循环？** 独立检查器不调用优化器/生成器，重新构造域运算和LP；但仍依赖手工证明的模型归约。它没有证明该一般归约，也没有证明真实认证关系。
6. **有没有更强简单基线？** 完美隐私GL、seed-repair、独立逐项掩码都保留。本文只击败均匀合法核这一明确基线，尚未击败上述协议的完整成本。
