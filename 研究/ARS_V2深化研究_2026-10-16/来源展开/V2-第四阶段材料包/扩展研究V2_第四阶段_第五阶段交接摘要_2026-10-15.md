# V2 第四阶段 → 第五阶段交接摘要

**日期：2026-10-15｜源报告：V2-CRITIQUE-r1｜仅研究建议，未运行实验。**

总体裁决：RP-005/006/008 继续 `CHALLENGE`，RP-007 继续 `PARKED`；旧版 RP-001—004 不改状态。现阶段没有独立安全收益实证，也没有 FROZEN 研究点。

关键修订：区分 `R1 等可信信息` 和 `R2 跨独立信任域` 两类公平比较；区块链的外部最终性收益主要来源于新增独立共识证据。比较 B4 时必须包含 B3/B5 等资源的无链独立公告或许可型 BFT。见证法定人数及链最终化不能自动替代应用层授权校验。

Web3：把链撤销交易提交、最终化、RP 观察和重要操作批准分成 `t_rev/t_fin/t_seen/t_admit`；不能在无限网络延迟和持久会话下保证绝对即时撤销。强基线是 SIWE/1271 + 可信状态源 + 短 TTL + OIDC Logout + 重要操作重检。

隐私：以链交易、见证查询、RPC 请求与账户辅助信息为联合观测面；隐私提升必须与固定批处理、匿名中继及无链公告比较，统计合法功能、恢复时延和链成本。

下一阶段优先级：`E0 = TL1 + TL5 + Reference Oracle` → `E1 = TL2 + 等资源公告对照` → `E2 = TL3` → `E3 = TL4` → `E4 = TL6`。将强基线正确性、业务不变量、允许泄漏、停止/转向条件事先注册。
