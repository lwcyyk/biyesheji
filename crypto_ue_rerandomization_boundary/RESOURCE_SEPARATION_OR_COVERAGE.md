# 完整 token 成本：覆盖与分离裁决

ROUND-006，2026-11-07。**裁决：STANDARD_COMPONENT_COVERAGE_NO_STRICT_RESOURCE_SEPARATION。** CR 是标准 nf-LWE 的直接推论；当前矩形参数 profile 与允许相同工具的成熟架构优化版完全一致。它可以改善某些固定统计参数账本，却未产生相对本轮优化通用对照的严格增量。

## 1. 先写完整主指标

设 d=n+ℓ、g_b=n⌈log_bq⌉。同参数同接口下

\[
L_{stat}=(g_b+t_{stat})dD,\qquad
L_{comp}=(g_b+2d+\kappa)dD.
\]

第二部分的行数比 t_stat/(2d+κ) 并非完整 token 的比值。比值应为

\[
\frac{L_{stat}}{L_{comp}}=
\frac{g_b+t_{stat}}{g_b+2d+\kappa}.
\tag{Cost}
\]

客户端和服务器成本亦包含 g_b；客户端仍需 source m 行矩阵来产生每一行 key-switch token。压缩 t 本身不会自动降低 m、epoch公钥或gadget。原Nishimaki文本取t=m，优化统计对照允许独立选择t，并按同一χ的统计误差认证，避免把未优化打印数值充作最强基线。

## 2. 固定 χ 与二进制 gadget

若 ℓ=O(n)、κ=O(nD)、χ每坐标熵为常数，并且统计基线需要 t_stat=Θ(dD)，二进制 gadget 有 g₂=nD。由(Cost)，两者完整 token 均为 Θ(n²D²) 位，比例有常数上界；第二部分的 Θ(D) 缩小不会成为完整 token 的 Θ(D) 优势。

ℓ远大于n时须重算：d可能主导g₂，这一“gadget主导”判断不能直接推广。即使原始统计对照在长消息上出现更大的行数差，同一标准组件仍可提供给 B_comp，见第6节。

固定表 χ 随 n、q 增长时，标准高斯 worst-case归约的宽度条件未必满足。Peikert2016 §4.2.2 Theorem4.2.4明确包含高斯参数 αq≥2√n；§5.2.3也指出紧凑PKE的加密随机量与秘密需要相应宽度，并带来较大的解密噪声。固定 χ 的 empirical LWE假设可以明示提出，但双方须采用相同的具体假设和归约预算。把该假设写成普遍标准困难性会夸大资源结论。

## 3. 对 power-of-two 环的优化统计账本

为避免给一般χ误用二元 universal-hash，给出一个直接精确碰撞计算。令 X,X'独立χ，

\[
c_j=\Pr[X-X'\in2^j\mathbb Z_q]
=\sum_z\Pr[X=z\bmod2^j]^2,\quad 0\le j\le D.
\]

对均匀 M∈Z_q^(t×d)，r∼χ^t，记col(M)为rM条件分布的碰撞概率。由差向量的最小2-adic valuation分层，

\[
q^d\mathbb E_M\operatorname{col}(M)-1
=\sum_{j=1}^D(2^{jd}-2^{(j-1)d})c_j^t.
\tag{SC}
\]

证明：两份r之差的全部坐标可被2^j整除的概率为c_j^t；最小valuation=j<D时，与均匀M相乘为0的概率是(2^j/q)^d，零差单列。将相邻项望远镜相消即得(SC)。因此Cauchy–Schwarz给出联合统计距离

\[
\Delta((M,rM),(M,U_d))
\le\frac12\sqrt{\sum_{j=1}^D(2^{jd}-2^{(j-1)d})c_j^t}.
\tag{Stat}
\]

这是信息论上界，其值可以用相同χ的精确有理数核对。对ε=2^−η，一项方便的充分选取为

\[
t\ge\max_{1\le j\le D}
\frac{jd+2\eta+\log_2D-2}{H_2(\chi\bmod2^j)},
\quad H_2=-\log_2c_j.
\tag{Entropy}
\]

分母为0时该项失去认证能力。特别χ=±1在j=1有c₁=1，公开奇偶测试已直接破坏均匀性。ρ={0,1}则c_j=1/2（j≥1），(SC)化为(q^d−1)2^−t，恢复普通LHL账本。

对离散高斯χ=D_Z,σ，σ≥8，经典高斯求和／Poisson恒等式给归一化常数Z_σ≥σ；对任意k，单调高斯的间隔k求和至多1+σ/k。因此

\[
\max_z\Pr[X=z\bmod k]\le1/k+1/\sigma,
\qquad c_j\le2^{-j}+1/\sigma.
\]

j=1时c₁≤5/8；2≤j且2^j≤σ时H₂≥j−1；2^j>σ时H₂≥log₂σ−1。故统一有

\[
H_2(\chi\bmod2^j)\ge\tfrac12\min(j,\log_2\sigma).
\]

由(Entropy)，统计基线可取

\[
t_{stat}=O\left(d\max\{1,D/\log\sigma\}+\eta+\log D\right).
\tag{Wide}
\]

适当高斯χ、σ≥Ω(√n)、q=poly(n)、d=O(n)、η=O(n)时，该数为O(n)，与t_comp同阶。高斯截尾、采样和 rounded/discrete 变体转换均需按双方共同预算支付；上述碰撞证明本身针对声明的D_Z,σ。

**重要适用边界。** 前驱要求的可忽略 smudging 比值可能迫使 S、q 超多项式；这时D=O(logn)的简化需重新检验。式(Wide)保留D/logσ，可直接反映这一变化。增大 q 同时使 worst-case 近似因子与实现位成本变化，不能只保留抽取行数收益。

## 4. gadget基数、宽度与压缩的共同优化

提高 b 减少g_b，同时把数字幅度放大到b−1；正确性需满足

\[
ms+S+Tms[g_b(b-1)+ts]<q/4.
\]

双方应在同一可行参数集合上最小化 LΔ，辅助成本也同时计入。b=poly(n)且高斯σ为poly(n)时，g_b与统计t可能同阶，收益主要表现为常数；D较大或允许非常大的b时，必须代入上式逐项核准。本文没有给任意b作“gadget总主导”的普遍断言。

对大基数、不同消息长度、超多项式q，原始统计方案的某些成本差可能存在；这些情形仍需同时认证LWE困难性、noise smudging、正确性和全游戏模拟。公平基线也获得相同b、预处理及有证明的压缩。hybrid中的均匀矩阵没有自动变成可用公开种子生成的正确token。

## 5. 常数收益与辅助成本

t缩小会减少token元素和一些生成／更新操作；χ取代±1的幅度却增加ts噪声项，每个χ样本也可能消耗多于一位随机输入。若进而把全部R_g/R_t也改χ，新增噪声因子会继续出现。κ需随总混合次数增加，源nf-LWE维度是d，源样本数是d，uniform-secret公钥步骤仍有m个样本；这些假设与运行预算都需一起报告。

sources中的有限数值仅核对碰撞／行数／token比特数公式，不构成满足全部正确性与困难性条件的UE参数证书。尚未产生完整参数上的可验证严格性能改进；更无已确认业务预算压力。

具体标量示例取χ640、n=640、ℓ=8、D=15、κ=η=128。对(Stat)以精确有理数求得该碰撞证书的最小t_stat=3006，t_comp=1424；b=2时g=9600，完整token分别为122530320位与107153280位，比为6303/5512，约1.1435。第二部分的约2.11倍行数比被完整账本显著缩小。允许相同组件的B_comp则与候选同为107153280位。该示例专供算术控制，整体正确性／安全可行性标为未认证。

## 6. 最直接的同成本覆盖

将候选记为C(Π,t=2d+κ)。在前述成熟矩形架构的优化集合内，B_comp使用**同一标准nf-LWE推论、同一ρ/χ/ν、同一K/N定义、同一gadget和同一t**。于是对每个共同参数输入Π，逐式有

\[
L_\Delta(B_{comp})=L_\Delta(C),
\]

并且客户端成本、服务器成本、随机位、密文／钥匙、正确更新次数和所有证明损失一一相同。若C的一项完整混合证明将来成立，它也为这个相同程序的B_comp成立。此覆盖依据为已明确列出的成熟架构与标准组件；没有把未来未知的新协议技巧预先赠给基线。

因此“只把statistical leftover hash替为CR并缩小第二部分”属于参数／证明方法优化方向。它没有产生相对允许同一成熟工具的通用方法的严格差距。该结论终止当前机制候选的核心创新主张；它保留对新结构、不同安全合同或新下界的后续研究空间。
