# 组件组合、正确性与完整游戏责任

ROUND-006，2026-11-07。**局部计算型替换 VERIFIED；完整 UE 安全结论 NEEDS_CLARIFICATION。** 本文给出足够完整的纸面参数 profile 来核对代数和成本；它属于成熟矩形架构的分布／行数调整。保护协议代码数量为0。

## 1. 纸面规格与原构造差异

使用 MODEL 中的共同 Π。令 F_e=[A|B_e]∈Z_q^(m×d)，S_e 均匀于 Z_q^(n×ℓ)，E_e∼χ^(m×ℓ)，B_e=AS_e+E_e。令 b≥2，η_b=⌈log_b q⌉，g=nη_b。

把 u∈Z_q^n 的标准代表按位平面顺序分解成 g 个 base-b 数字 D_b(u)∈{0,…,b−1}^g；G_b(S)=[S;bS;…;b^(η_b−1)S]，满足 D_b(u)G_b(S)=uS modq。q=2^D、b=2 时回到已记录的二进制行序。

* Setup：采 A∈Z_q^(m×n) 均匀，发布 Π 和 A。
* Gen：独立采 S_e、E_e，计算 B_e；epoch 钥匙为 (S_e,B_e)。
* Enc：采 a∼ρ^m、ζ∼ν^ℓ，输出 u=aA、c=aB_e+ζ+(q/2)μ，其中 μ∈{0,1}^ℓ。
* TokGen：采 R_g∼ρ^(g×m)、R_t∼ρ^(t×m)，输出

  \[
  K=R_gF_{e+1}+[0|-G_b(S_e)],\qquad N=R_tF_{e+1}.
  \]

* Upd：独立采 r∼χ^t，输出

  \[
  (u',c')=(0,c)+D_b(u)K+rN.
  \]

* Dec：逐坐标将 c−uS_e 舍入到0或q/2，输出 ℓ 位。

所有乘法在 Z_q 上，token 形状为 g×d 与 t×d。各采样失败统一返回 ⊥；数学理想版本使用精确独立分布。有限重试／高斯截尾的失败概率另纳入预算。

相对已取得的 Nishimaki 会议文本，这个 profile 把 N 的 m 行参数化为 t 行，把 Upd 的 ±1 改为 χ，允许 base-b gadget；在 power-of-two 模数下将 Enc/TG 的系数明确取ρ=U({0,1})。这些是行为改变，均已显式列出，原定理的参数／证明须重新核对。保留 ±1 时应回到适用的奇模数域并核准原定理；该原模数细节目前属于来源缺项。

候选取 t_comp=2d+κ。统计对照取满足统计误差目标的 t_stat。两者其余算法、分布、消息和权限相同。一个更激进的“所有系数都改为 χ、同时缩小 m”版本会改变每项噪声及全部替换，当前候选的安全结论不扩张到它。

## 2. 精确正确性递推

定义 η=c−uS_e−(q/2)μ。初始

\[
\eta_0=aE_e+\zeta.
\]

一次更新精确满足

\[
\eta'=\eta+(D_b(u)R_g+rR_t)E_{e+1}\pmod q.
\tag{Noise}
\]

ρ∈{0,1}、|χ|≤s、|ν|≤S 时，可选一致整数提升得到

\[
B_0=ms+S,\qquad W=m s\,[g(b-1)+ts].
\]

最长 T 次更新的充分正确性条件为

\[
B_0+TW<q/4.
\tag{Correct}
\]

该条件含初始噪声及每次成功更新；适用于重复更新形成的任意诚实链，明文始终相同。高斯尾界按所有 key/token/update 元素总数共同分配。若 R_g/R_t 的系数包络为 c_ρ，a 的为 c_E，则改为 B₀=mc_Es+S、W=msc_ρ[g(b−1)+ts]。因此将全部采样改 χ 会新增相应 s 因子。

同一个公开 token可服务多个父；多次 Upd 的 r 独立。r 没有64个额外样本等前轮证明阈值。最大可认证更新数由 (Correct) 直接取整；统计基线和计算 profile 都必须满足同一 T、同一失败预算。缩小 t 可改善此充分界，却须连同源 m、gadget 幅度和 ν 同时计费。

## 4. 两个能阻止错误组合的具体检查

**已均匀矩阵的要求。** 在真实 token 中 N=R_t[A|AS_new+E_new]，它含新密钥关系，也与 K 共享 F_new。CR的 M 均匀前提无法直接赋给这个真实 N。必须先完成 H_pk 和 H_tok；仅检验 N 的第一块边缘，遗漏剩余 ℓ 列和新钥匙关联。

**隐藏右边界与未来钥匙。** 若归约在内部替换 B_j 后不知道 S_j，右邻 token K_(j+1) 含 −G_b(S_j)。内部已随机化 token 可消除该义务；在 firewall 的右边界，token 虽未腐化，普通／挑战更新仍可能越过该边界，下一代钥匙也可能合法腐化。用“token 未返回”单独省略内部更新、或自行选择一个不一致 S_j，都无法完成模拟。前驱使用辅助更新与记录噪声来处理这类问题，当前维度／分布改动须重新证明其联合律。

有限 χ_ns 的 B′-bounded 性质不能单独推出 smudging。即使 Z∼U({−S,…,S}) 的边缘与 Z+t 距离为 |t|/(2S+1)，辅助信息 W=Z 时，(W,Z) 与 (W,Z+t) 可被相等测试完全区分（t≠0，无模合并）。父已含旧噪声时，须证明实际 W 条件下仍有适用掩盖性质。该例约束证明方法，未被登记为对 Nishimaki 原方案的攻击。

前轮 Frodo-FI的直接统计攻击同样表明：保留公开父/token的联合视图有实质作用。它对原方阵对象成立；当前矩形修改的完整安全性仍需本文全部步骤。

## 5. 损失、时间和 epoch 合法性账本

可单独核准的局部损失：每个替换公钥支付 ℓ 个 uniform-secret n维、m样本实例；每个随机化 token 支付(g+t)ε_ρ；每个计算型输出支付一个 d维、d样本 nf-LWE 优势与 δ_rank。所有归约时间均加上真实采样、矩阵生成和交互运行时间，不能直接代入裸 LWE 求解预算。

前驱外层使用 T+1 个挑战 epoch 混合与猜测两个 firewall 端点的至多(T+1)²损失，内部还有最多T+1个公钥/token epoch步骤。当前 H0→H_aux 与边界模拟尚未封闭，因此本轮没有把这些局部项拼成一条已认证的完整 ε_sec 总式。任何具体参数优化证书须先填入这一缺项，继而在同一总体失败预算下选择 κ、m、t 与 LWE参数。

forward/backward closure 保持原游戏约定。对主profile的b=2^w，从新钥匙可计算 K_Q−K_P S_new=R_gE_new−G_b(S_old)。若每个噪声条目小于q/(2b)，从最高gadget平面开始可逐块恢复旧S：最高平面先得到最低若干位；下一平面减去已恢复低位后，剩余候选至少以q/b间隔分布，逐步恢复全部D位。ρ的包络为c_ρ时，m c_ρ s<q/(2b)是一项充分条件。T≥1且其余参数正时，(Correct)中的g(b−1)项已蕴含该条件。一般基数的准确恢复与实际尾概率需另外核准。旧钥匙＋token的前向恢复困难性仍须按同一假设证明。当前未靠删去合法未来钥匙请求来扩大结论。

这里恢复的是旧解密秘密S_old，已经赋予旧密文解密能力，足以触发相应泄露闭包。若把“恢复整个旧钥匙对(S_old,B_old)”作为额外接口要求，还需提供旧B的公开缓存或单独恢复依据；本轮没有从S_old默推未知旧误差E_old及B_old。

## 6. 裁定

纸面算法与噪声递推可检查；均匀矩阵内部的CR替换成立。组件进入完整公开更新游戏还需辅助更新、未知钥匙边界和所有联合视图的证明。即便这些证明完成，当前规格与允许相同标准组件的 B_comp 完全一致，完整 token及辅助成本仍相同。

因此本轮终止“仅替换统计抽取即可构成相对优化成熟方法的新协议资源分离”的候选。完整 UE 安全未决项保留作来源／证明责任，不被用来削弱已经完成的 ROUND-005 密码分析结果。
