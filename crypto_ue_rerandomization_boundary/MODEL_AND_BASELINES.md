## 1. 安全接口与共同参数

保留原 rand-ind-eu-cpa 的公开普通父、可腐化完整更新 token、一次 fresh/update 挑战、合法钥匙腐化与后续挑战更新。令 K* 按 backward-leak 规则闭合，公开 token j 将已知 K_j 向 K_(j−1) 传播；禁止 K* 与挑战可达 epoch 集相交。接口同时允许普通 Enc/Upd 与合法未来钥匙腐化。最小攻击串仍是 Enc_0、Next_1、Corr(token,1)、Challenge_1；比较安全方案时须覆盖整个接口，单独通过此串仅提供必要条件。

T 表示最多 Next 轮换次数，访问 epoch 标签0,…,T；Q 表示整个交互调用预算。重新授权代次在本文指 UE 钥匙 epoch。原生批准、凭据撤回与恢复当前性各有业务合同。

双方共用参数元组

\[
\Pi_\lambda=(\lambda,n,q=2^D,\ell,m,\chi,\rho,\nu,b,T,Q,
\epsilon_{\rm sec},\epsilon_{\rm dec},\epsilon_{\rm samp}).
\]

消息为 ℓ 位；d=n+ℓ 为合并密文的环坐标数。χ 是相同误差分布及计算型更新系数分布，ρ 为相同的加密／token 行系数分布，ν 为相同初始附加噪声。区分这三类采样可防止把原文的 ±1 系数改称 χ 却继承错误困难性。主比较使用 ρ=U({0,1})，χ 支持于 [−s,s]，ν 支持于 [−S,S]；若使用高斯，以共同尾概率选 s、S 并支付相同失败预算。这个 power-of-two profile 是显式纸面规格，与 Nishimaki 打印的 ±1 profile 分开。

主profile的gadget基数取 b=2^w≤q、w≥1，以便同时核准整数数字与backward钥匙恢复；其它基数需自己的恢复论证。

双方也共用：公开 A 的生成方式；秘密分布（主 profile 为均匀 S_e∈Z_q^(n×ℓ)）；公钥 E_e∼χ^(m×ℓ)；采样器／种子长度；允许更新链长度；钥匙擦除与合法腐化接口。研究实例取 ℓ=O(n) 时会明示，长消息另作成本比较。

## 2. 两项实际需要的困难性

1. 公钥替换：uniform-secret DLWE(n,m,q,χ)，每个 epoch 有 ℓ 个独立秘密列。共享公开 A，按列混合；每步归约保留相同 A。
2. 计算型线性输出：normal-form DLWE(d,d,q,χ)，输入 (A₀,sA₀+e)，A₀∈Z_q^(d×d)，s,e∼χ^d。拟采用组件每次消耗一个这样的挑战、d 个样本。d=n+ℓ 与源 PKE 的维度 n 明确分开。

这两项同时提供给候选和通用对照。若从均匀秘密 LWE 推出第二项，需加入 normal-form 转换的样本与可逆子矩阵失败损失。Peikert §4.2.1 的转换已经说明这种工具；直接从 n 维安全级别赋予 d 维问题相同具体优势尚需参数评估。χ 的任意小支持本身无法认证困难性，固定 χ 的增长参数族尤其需要自己的依据。

## 4. 主指标与完整辅助账本

令 η_b=⌈log_b q⌉、g_b=nη_b。明文环矩阵 token Δ=(K,N)，K:g_b×d、N:t×d。q=2^D 时其标准完整传输长度精确为

\[
L_\Delta=(g_b+t)dD\quad\text{bits}.
\]

双方同样计算：公开参数 A 的 mnD 位、每个密文 dD 位、完整 epoch 钥匙 (nℓ+mℓ)D 位；token 生成约 (g_b+t)md 次环加乘，服务器更新约 (g_b+t)d 次数字／小系数乘加。基数 b 的数字幅度也计入位运算和噪声。ρ 为独立公平位时 TG 用 (g_b+t)m 个采样位，Enc 用 m 位及 ν 采样位，Upd 用 t 次同一 χ 采样器。一般 χ 的 Shannon 熵只是随机位下界，实际随机位和失败率按相同采样器计。

公开 A 的共同 Setup 可摊销，但每个 epoch 新 token 的两部分均收费。基线同享预处理、批处理和保存已取得 token 的权限。缓存节省在线时间时，存储与预处理分别列账。

从伪随机 hybrid 中“token 看起来均匀”推不出真实 token 可直接由公开短种子代替；真实 K/N 还需满足密钥与解密关系。发送 token 生成秘密随机性也会改变公开上下文。仅在有完整分布与正确性论证时才采纳压缩，并同时给双方使用。
