## 4. A—D 的逐项证明

### A. 正常更新桥接

普通记录每坐标存 `(ρ,w)`，其密文为 `(P^ρ,g^ρ w)`，并保持 `Z=M∏w_i`。新带解析为 `a∈F_q*、s,z∈F_q`，令 `v=g^z`，有 `P′=P^δ`。在每一条实际随机带上：

```
(P^ρ)^δ (P′)^a (P′)^s = (P′)^(ρ+a+s),
(g^ρ w) g^a (g^s v) = g^(ρ+a+s) wv.
```

于是存储 `ρ′=ρ+a+s`、`w′=wv` 即得到实际 Upd 输出。新坐标存 `(s_new,g^z_new)`；`Z′=Z∏v_i` 继续满足相同明文不变量。归约先用同一规范采样器产生真实新带，再按这些恒等式计算，所有拒绝词保持原样。

Enc 是归纳基。每次创建新普通 id 时复制父表示后更新；父 id 的表示及原带保留。按创建次数归纳可同时覆盖同父多次更新、分支记录和后来完整历史钥匙响应。指数 ρ 可以为零，这组等式照常成立。此处无需求出 δ；公钥 P′ 足够。

### B. 挑战链的联合新鲜化

先预采独立的完整潜在钥匙轨迹 θ，仅在 Next 时公开相应 P。对任一旧官方合法密文，在 θ 与已有历史固定后，旧坐标的新参数为

```
R_i=ρ_i+a_i+s_i,  W_i=w_i g^z_i.
```

对于每个 a_i、旧 ρ_i、旧 w_i，独立均匀 s_i、z_i 通过全域平移及群乘法产生独立均匀 R_i∈F_q、W_i∈G。每一对目标 `(R_i,W_i)` 有恰好 q−1 个 `(a_i,s_i,z_i)` 原像，质量为 `1/q²`。新坐标直接具有同一分布。转移核恰好为 `Enc_e(M_b)`，且与旧挑战的具体值无关。挑战初始分支 b=1 的普通父也适用；b=0 已是 Enc。

因此给定 θ、b、接受时的 M₀、M₁，所有官方代际版本具有独立 Enc 流的联合分布。适应性由转移核归纳处理：查询由可见前缀决定，当前响应使用对应核；后来选取的 Key/Token 只是揭示同一 θ 的坐标。对 θ 积分后，得到整个可见交互的联合等价。

重复 Get 读取同一缓存，不能重采。同一代的多个观察是同一随机变量。攻击者的本地更新与比较是其历史、公开令牌和自身随机带的函数，联合分布等价在加入这些函数后保留。隐藏 Gen/Next 带与官方带无须耦合为相同字符串；它们从未进入接口。有限截断时此结论应先在理想游戏证明，再通过失败耦合转移。

### C. 边界重参数化与完整未来钥匙

固定 `2≤j≤r≤L`。第 j 个新增坐标使用 X=g^x；`d_j=1`，段内 `d_e=∏_(h=j+1)^e δ_(h,j)`，公开 `P_(e,j)=X^d_e`，隐含钥匙为 `x d_e`。其他坐标照常生成。

令 `t=r+1≤L`。在 t 首次生成前，对每个旧坐标 i，原参数 δ_(t,i) 独立均匀非零，且

```
Y_i = δ_(t,i) x_(r,i),
δ_(t,i) = Y_i / x_(r,i).
```

固定任意非零 `K_r` 后，这是 `(F_q*)^r` 上的双射，质量逐点为 `(q−1)^(-r)`。再独立抽新坐标 Y_t，完整 K_t 因而是均匀非零向量，且条件于任何边界前历史仍可如此产生。归约选 Y，并首次公开 `g^Y_i`；既有 P、历史正常记录与随机带全部保留。对于 i≠j，旧钥匙已知，δ 可求；i=j 的 δ 隐含存在。

结合 A，边界普通更新在该隐含 δ 下逐带正确。未来钥匙、未来令牌从已知 Y 正常演进，既有公开编码和完整标量响应逐项一致。该双射需要的是隐藏边界标量的分布；在完整隐藏 Next 位带层面，长度不同的拒绝词通常没有逐串双射要求。其投影到可见视图的概率相同已经足够。

`r=L` 或执行在 r 结束时没有实际右边界，故无需生成 Y。该方法支持多个不连续隐藏边界：本轮只隔离 j 所在的可达段，后续已有完整标量可继续正常演进。

### D. DDH 嵌入、整份密文和可计算性

DDH* 输入为 `(g,X=g^x,U=g^u,V)`，x∈F_q*，u∈F_q；真实时 V=X^u，随机时 V=g^v，v 独立均匀。归约只获得编码 X、U、V。

在第 j 代首次公开官方版本时，抽均匀 Z∈G，为 i≠j 抽独立 `ρ_i∈F_q,w_i∈G`，令

```
w_j = Z / (M_b ∏_(i≠j) w_i),
C_i=(P_(j,i)^ρ_i,g^ρ_i w_i)  (i≠j),
C_j=(V,U w_j).
```

真实 DDH 世界中，u 是锚加密随机指数；`(w_(−j),Z)↔(w_1,…,w_j)` 为双射，所以全部 pad 独立均匀，Z=M_b∏w_i，分布精确为 Enc_j(M_b)。

随机世界中，给定任意整份输出和非零 P_(j,i)，非锚映射 `(ρ,w)↔(P^ρ,g^ρw)` 为双射。固定非锚输出及 Z 后，w_j 确定，`U↔Uw_j` 为双射，V 独立均匀。因此输出在 `G^(2j+1)` 上完全均匀，质量恰为 `q^(-(2j+1))`，包括 Z 与所有坐标的联合独立性。该分布证明可在数学上使用离散对数逆映射；归约实际计算只使用正向群运算。

| 数量 | 归约的知识 | 实际用途 |
|---|---|---|
| b、M₀、普通父 M₁、全部普通 ρ,w | 已知 | 正常查询、选择 M_b、最终评分 |
| 非锚钥匙、段内倍率、d_e、边界后完整 Y | 已知标量 | 对应 Key/Token、公开 P、未来演进 |
| X、X^d_e、U、V | 仅群编码 | 锚公钥及密文嵌入 |
| x、u、随机 v、x d_e | 隐含秘密 | 通过编码完成操作，均无需标量响应 |
| 边界 δ_(r+1,j)=Y_j/(x d_r) | 隐含秘密 | 唯一无法直接给出的右边界令牌分量 |

普通更新的真实新带不含 δ，故未知分量没有进入正常带响应。区间完整 Key 和右边界完整 Token 请求由 F 的规则处理中止；所有可能属于最终匹配合法历史的实际响应均可计算。

## 5. E—G 的受限测度、停止与求和

### E. 两个世界分别保留质量

在新鲜流参考混合 H_i 中，接受挑战后 e≤i 的官方版本是 Enc_e(M_b)，e>i 的版本是独立均匀群向量；正常接口和钥匙轨迹保持相同定义。定义 `μ_i=E_(H_i)S`。H_L 与真实游戏等价；H_1 的全部可见历史、合法性与接受事件均独立于 b，所以 μ₁=0。

对每个最终历史，j 可见时定义

```
r_j = max {r≤n : {j+1,…,r}⊆T*},   n=最终已生成代次,
E_jr = {accepted, valid, j∈C, r_j=r}.
```

这里 r_j 按从 j 连续前向可达解释，空区间允许 r_j=j。定义 `z_i(j,r)=E_(H_i)[1_(E_jr)(1_correct−1/2)]`。

为使判定器概率式唯一，补全以下输出规则：每个无法匹配的提前停止、公平终止或终局 `E_jr` 为假，输出独立公平币；存活且终局 `E_jr` 为真，输出 `1_{b′=b}`。既有正文 CT 42–44 的 p 式需要此规则。

对 DDH 的真实世界 v=1 取参考 H_j，随机世界 v=0 取 H_(j−1)。若 Ω 是完整带 b 的可见终局历史空间，模拟器存活且匹配的子测度记作 ν_v，则对任意可测 B⊆Ω，

```
ν_1(B)=Pr_(H_j)[B∩E_jr],
ν_0(B)=Pr_(H_(j−1))[B∩E_jr].
```

证明从未停止的每个前缀按相同随机变量分布归纳：根钥匙编码分布相同；段内倍率相同；右边界通过 C 的条件双射保持概率核；普通带与输出由 A 逐带相同；锚响应由 D 给出各自目标核；其他挑战流核相同。攻击者在同一前缀使用相同条件决策核。F 说明每个删去的前缀在 E_jr 上的未来质量为零，故限制到 E_jr 后不存在失去的质量。对终局事件作积分得到上式。

取 B=Ω 得事件概率质量相等。取任意 B 得事件内未归一化视图相等；质量为正时再归一化得到条件视图相等。公平补足所有其余质量后：

```
p_real(j,r)=1/2+z_j(j,r),
p_rand(j,r)=1/2+z_(j−1)(j,r).
```

该结论允许两个世界中的 `Pr(E_jr)` 不同。

| 已存在的 Token(r+1)，r<L | 若之后补齐 j 到 r 的可达链，则 r+1 可达；若某个缺边一直保留，则 r_j<r。两种终局均不属于 E_jr |
| 当前历史已出现 K*∩C* | 集合与闭包单调，未来查询只能保持交集 |
| 接受挑战时 c>j | 官方谱系从 c 开始，只前向发展；j 永远无法成为已返回官方版本 |
| 已跨过 j 且 j 未返回 | 历史私有版本无追溯接口，j∈C 已无法实现 |
| 终局无接受挑战、j 未公开或 r_j≠r | 匹配事件按定义为假；只在确定该事实时结束相应贡献 |
| 矩形采到 r<j | 规范事件的索引域为空 |

未来尚未生成的 Key/Token 请求须先返回 ⊥，并保持曝光集合原样。它们不能触发上表中针对“已存在”的停止。普通格式错误和错误 id 也照接口返回 ⊥；这类查询本身并不使历史非法。

自适应选择停止查询不会改变逻辑：对具体已发生前缀逐个判断，它的任意匹配续接都满足表内矛盾。真实游戏继续返回非法历史上的对象；模拟器只需保留最终有效事件上的测度。

例：公开 C₂、隐藏 Δ₃、公开 Δ₄，再 CorruptKey(4)。闭包给 K*={3,4}、C*={2}，该历史有效。此时另公开 Δ₃ 会使 C* 到达 4，另公开 C₃ 或 C₄ 则直接与 K* 相交。对 j=2 的归约取 r=2，边界在 3，K₃/K₄ 已知可正常返回。这同时验证了未来完整钥匙的合法情形。

### G. 事件分割与带符号求和

固定 j，`E_jr` 随 r=j,…,L 互斥，覆盖全部接受、有效且 j 可见的终局。不同 j 的事件可以重叠；求和论证仅使用固定 j 的分割。

在 H_j 与 H_(j−1) 中，唯一差异是第 j 个官方版本的分布。若该版本从未公开，攻击者在首个可能公开点之前的历史可按相同随机源耦合；一旦跳过 j，后代的独立流无需读取它。本地计算只能使用已可见值。因此 j 未公开分支的可见历史、合法性与评分贡献相同。于是

```
Σ_(r=j)^L [z_j(j,r)−z_(j−1)(j,r)] = μ_j−μ_(j−1).
```

把相同共同模拟器按三角域 `T={(j,r):2≤j≤r≤L}` 均匀选择，域大小 `F=Σ_(j=2)^L(L−j+1)=L(L−1)/2`，得到有符号输出概率差

```
p_real(D_triangle)−p_rand(D_triangle)
 = (1/F)Σ_(j=2)^LΣ_(r=j)^L(z_j−z_(j−1))
 = μ_L/F.
```

此时再取绝对值，得 `Adv_SELECT-I=F Adv_DDH*`。过程没有先对每个事件取绝对值。

矩形域须明确取 `{2,…,L}×{1,…,L}`，大小 Λ=L(L−1)=2F。r<j 直接公平输出；在任一有效固定位置上，采用与三角版本相同的 b、条件模拟核和终局匹配输出规则。两种理想采样的索引与后续随机源独立，故精确 `Adv(D_triangle)=2Adv(D_box)`。只比较域大小而未保证固定位置模拟器相同，将无法推出该等式。

## 6. 三版定理、误差与资源

### 6.1 所需规范采样器与约定

建议明确对大小 n 的离散域取 `k_n=ceil(log₂n)`；n=1 时直接返回唯一元素，否则每轮独立取 k_n 位整数 h，h<n 时接受，再按固定双射映射到目标域。F_q* 可用 n=q−1 映射 h↦h+1，也可用 ceil(log₂q) 位接受 1≤h<q；两者都具有至少 1/2 的接受率，但完整随机带不同，须固定其中一种。每个独立调用使用独立比特流。

该规则使每调用 B 轮耗尽概率 ≤2^(−B)，对任意适应性前缀同样成立；理想期望轮数 ≤2。固定相同输入、相同位流，将有限版本和理想版本耦合到第一个耗尽位置。

DDH* 的 x 非零，u,z 全域；标准 DDH 的 x 也全域。`τ=Pr[x≠0]=1−1/q`。标准判定器遇 X=1 时输出与 DDH 世界无关的固定分布，其他情况运行相应 DDH* 判定器。于是每个具名有限／理想版本均有精确 `Adv_DDH(D′)=τ Adv_DDH*(D)`。本稿规定 X=1 公平输出即可。钥匙、倍率非零保证解密、边界双射和非锚映射成立；pad 及加密指数可为零。

SELECT 优势是 `|E S|`，DDH 优势是两世界输出概率差的绝对值。后续误差以这两个约定计算。

### 6.2 SELECT-I 与 SELECT-C0-B

设 η_G=N_G 2^(−B)、η_D=N_D 2^(−B)。这些是统一上界，可用 min(1,η) 收紧；超过 1 时原上界仍然有效。

理想 D 单独截断后，每个 DDH* 世界输出概率至多改变 η_D；两世界累计至多 2η_D。因此

```
Adv_SELECT-I ≤ (F/τ) Adv_DDH(D′_B)+2Fη_D.
```

C0 游戏中，失败前状态与理想执行相同。失败后的有限评分和理想评分都属于 [−1/2,1/2]，所以差至多 1，给 `|E S_cap−E S_ideal|≤η_G`。判定器固定输出 0 相对理想续接的单世界输出概率差至多 η_D。最终

```
Adv_C0-B ≤ (F/τ) Adv_DDH(D′_(C0,B))+η_G+2Fη_D.
```

误差项没有额外 1/τ：它们是在 DDH* 条件域中估计，随后只把判定器优势换算到标准 DDH。最终评分继续检查接受标志及有效性，特别是 Setup、挑战前和挑战中途失败的情况。

### 6.3 SELECT-FAIR-B

在失败前缀固定、包括 b 固定后，独立公平最终猜测使有限游戏的条件中心评分期望为零。接受／有效指示量可以依赖前缀与 b，仍因公平币独立而得到零；理想续接条件中心评分位于 [−1/2,1/2]。游戏单世界期望差至多 η_G/2。

判定器失败时输出公平币，使输出概率为 1/2；相对任何理想续接概率，差至多 1/2。两个 DDH* 世界分别至多 η_D/2，合计 η_D。因此

```
Adv_FAIR-B ≤ (F/τ) Adv_DDH(D′_(FAIR,B))+η_G/2+Fη_D.
```

所需公平覆盖表如下。公平币用独立的一位直接产生，不能再交给可能耗尽的拒绝采样调用。

| 失败位置 | 游戏／判定器处理 |
|---|---|
| Setup、每次 Next 中旧倍率与新增钥匙 | 立即进入相应固定／公平失败终态 |
| 普通 Enc 与 Upd，包括所有普通带采样 | 同上 |
| 初始 Challenge 两个分支、私有官方更新 | 同上，即使对应版本从未公开 |
| 判定器的 rank 索引、秘密轨迹、边界 Y | 同上；此时可能尚未运行 A |
| 诚实挑战流、随机群流、锚 Z 与非锚 pad／指数 | 同上 |
| 任何另外采用 S 的控制随机性 | 同上；直接独立公平位可无拒绝产生 |

该半常数证明允许失败事件依赖 b、挑战内容或 DDH 世界。公平规则保证的是失败后的条件输出性质；失败概率仍须逐世界有界。若首个失败后继续让 A 查询，或令 A 覆盖公平输出，证明便需要重新分析。

### 6.4 次数重算

目标代次为 e 时，Enc 用 2e 个标量，Upd 用 `(e−1)+2e=3e−1` 个标量。Setup 与所有 Next 一共

```
1+Σ_(e=2)^L e = L(L+1)/2.
```

一次挑战最早在 2，初始分支与其后的全部私有官方更新至多

```
Σ_(e=2)^L(3e−1)=(3L²+L−4)/2.
```

两者合计 `2L²+L−2`。普通响应粗界为 `(3L−1)Q`；Q 包含其他查询使此式更宽松。理想混合每个诚实流 2e、每个随机流 2e+1，e≥2 时均≤3e−1；锚版本只需 2j−1 个本地标量。边界 Y 生成替代相同数量的 Next 标量。一个三角秩索引、少量控制位留足余量后，CT 74 的

```
N_G,N_D ≤ (3L−1)Q+2L²+L+1
          ≤ N=10(QL+L²+1)
```

成立。此为共同上界，实际游戏无需三角索引。矩形用两个独立索引，相应粗界增加 1。计数包括未公开官方更新；也允许判定器提前生成潜在轨迹，只按公开时点交付。DDH 挑战自身的随机数由 DDH 实验供应，不计本地 S 调用。

三角秩取 `h∈{0,…,F−1}`，按各 j 的块长 L−j+1 解码 `(j,r)`。规范 rank 拒绝采样接受率至少 1/2，F=1 可直接解码。有限矩形、三角索引成功概率一般不同，所以有限版本沿用各自真实采样器，精确 2 倍关系只给理想版本。

代入 N 后，分别得到原稿的 `(2F+1)N2^(−B)` 和 `(F+1/2)N2^(−B)`。这两项计算正确，其适用前提是 §6.1 的明确采样规范。

### 6.5 位长、转录与严格 PPT

每个词长度至多 `w=max(1,ceil(log₂q),ceil(log₂max(F,1)))`，实际域使用自己的 k_n。固定 w 只是统一长度上界；直接用较大的 w 做小域的朴素拒绝可能降低接受率。

有限标量／索引消费位数为 O(NBw)，普通可见带为 `O(Q L B w)`，解析边界和长度字段可被此界吸收或显式加 `O(QL log(B+1))`。令 ℓ_G 为群编码位长，协议响应的完整转录可写成

```
O((QL+L²)ℓ_G + QL log₂q + QLBw + Q log(Q+L+B+1)).
```

若将任意畸形输入的原始字节也纳入转录，应再加攻击者总查询字节数，至多用其运行时间 t_A 支付。内部标量／群对象状态为 O(QL+L²)；若缓存所有历史带，还须另计 O(QLBw) 位。理想带长度无确定多项式上界，期望长度 O(Nw)，拒绝轮数决定实际长度。

CT 78 的时间式在明确 `T_group` 包含所用指数运算，`T_field` 包含求逆等域运算，并令 B、log₂q、L、Q 及 t_A 都多项式后可以成立。闭包可用线性有向链上的可达传播实现每查询 O(L²) 的保守界。固定 B 使所有循环次数有确定界；理想拒绝采样给期望多项式时间。对严格 PPT 的 DDH 假设，应使用 CT 26 的截断式，并按所需误差取 B，例如 `B≥κ+ceil(log₂((2F+1)N))`。

### 7.1 缺失采样规则的可检查见证

令 `k=ceil(log₂q)`，q≥5。定义一种输出精确均匀的拒绝采样器：每轮读取两个独立 k 位词；第一个词的前两位为 00 且第二词属于目标域才接受；返回第二词。F_q 接受 0,…,q−1，F_q* 接受 1,…,q−1。每轮接受率分别为

```
p=q/2^(k+2),    p*=(q−1)/2^(k+2),
1/8≤p*≤p≤1/4.
```

该采样器精确均匀、独立流、完整记录所有词与拒绝边界，期望至多 8 轮，每词长度也符合原稿 w 上界。现有文本没有限定每轮只能读一个词或排除这个接受规则。单调用 B 轮失败率至少 `(3/4)^B`，显著大于 `2^(−B)`。

最小有效查询串：初始代次 1，`EncLeak(1)` 取得父 id，`Next` 到 2，`Challenge(g,id)`，收到密文时猜 1。取 L=2、Q=3，曝光集合 K=T=∅。记

```
a=1−(1−p)^B,       a*=1−(1−p*)^B.
```

挑战前成功概率为 `(a*)³a²`：三次非零采样来自 Setup/Next，两次全域采样来自父 Enc。挑战 b=0 的成功率为 a⁴，b=1 为 a* a⁴。

FAIR 的失败评分条件期望为零，成功时固定猜 1，故

```
E S_FAIR = −(a*)³a⁶(1−a*)/4.
```

C0 若挑战接受标志在有效输入通过、开始采样时置位，固定失败猜 0 给

```
E S_C0 = −(a*)³a⁶(1−a*)/2.
```

C0 若只在成功返回后登记接受，系数为 1/4。两种语义都保留同阶偏差。这也展示为何应固定接受提交点。

取 B=ceil(log₂κ)、固定 L,Q，则 a,a*→1，而偏差至少为常数倍 `κ^(−log₂(4/3))`，指数约 −0.415；原稿加性项为 O(κ⁻¹)。在满足 DDH 假设的群族中，任何 PPT DDH 判定器优势可忽略，有限定理若覆盖所有满足当前均匀性描述的采样器，就与该查询串冲突。该结论是采样规格过宽所致；采用 §6.1 的规范采样器后，此见证的失败概率重新落入声明的误差项。

仅作算术核对的 q=101、B=32 例子：非零单调用失败率约 0.0009551513，`2^(−32)≈2.3283e−10`；FAIR 偏差约 0.0002368446，C0 前置接受偏差约 0.0004736891。N=110 时声明的加性项分别约 3.8417e−8、7.6834e−8。小群本身允许高效求离散对数，这组数值仅验证概率与尾界；上段的安全性矛盾使用 DDH 群族和渐近 B。
