# 反例见证与必要补正

对象：SELECT-CONSOLIDATED-1。此文件为独立审阅意见及补正条款草案，提交原稿保持原版本。一般数学论证见 `MATHEMATICAL_REVIEW.md`。

## R1 — 采样器未定义到足以推出 2^(−B)

**标签：EXTRA_ASSUMPTION_REQUIRED。类别：定理缺少前提；对宽泛采样规格的可检查反例。**

位置：AG 7；CT 11、24–26、52–78。原稿只明确均匀标量、独立比特流与完整消费带；“已声明 mathsf S”的接受规则在提交材料中缺失。

精确均匀性与每轮成功率下界属于不同性质。取 k=ceil(log₂q)，每轮读两个 k 位词，要求第一个词前两位为 00，且第二个词属于目标域，才返回第二词。该采样器具有精确均匀输出、独立调用、期望至多 8 轮和完整可记录的带，却具有

```
p_Fq=q/2^(k+2), p_Fq*=(q−1)/2^(k+2)≤1/4,
Pr[一个调用在 B 轮内失败]=(1−p)^B≥(3/4)^B.
```

这给出原稿单调用 `2^(−B)` 尾界的直接反例。

进一步，合法查询串

```
EncLeak(1) at epoch 1 → id
Next to epoch 2
Challenge(g,id)
收到挑战密文时输出 1
```

令 a、a* 分别为全域、非零域调用在 B 轮内成功的概率。挑战前需 3 次非零调用与 2 次全域调用；挑战的两个分支分别需 4 次全域调用、4 次全域调用加 1 次非零调用。K=T=∅，历史合法。FAIR 中心期望为

```
−(a*)³ a⁶ (1−a*)/4.
```

C0 在挑战开始采样时记接受则系数为 1/2，仅成功返回时记接受则系数为 1/4。取 B=ceil(log₂κ)，固定 L=2、Q=3，偏差为至少常数倍 κ^(−log₂(4/3))，原误差项为 O(κ⁻¹)。在 DDH 安全群族上，这排除了将两个有限定理解释为“覆盖任意满足现有均匀采样文字的采样器”。

**最小修复：** 精确定义唯一 S。建议采用下列数学规范：大小 n 的域取 k_n=ceil(log₂n)，n=1 直接输出；每轮读 k_n 个独立公平位，整数 h<n 时按预先固定的双射输出，余下情形重试。明确 F_q* 使用 n=q−1、h↦h+1，或者明确采用 q 位宽方案接受 1≤h<q，两者选定一种。所有调用独立，所有已消费词、拒绝词和边界属于对应普通带。每调用 B 轮耗尽触发具名失败语义。

**改变范围：** 群算法的理想输出分布、曝光游戏主结构、DDH 假设保持一致。完整位带分布与有限截断游戏由此被具体确定，应产生新的定义／定稿版本和哈希。原稿两个常数在此补正下可保留。

**可选更一般表述：** 若选择某个其他明确 S，给出逐调用、逐前缀的失败上界 ε_B，并将所有 `2^(−B)` 统一替换为 ε_B。若域的接受率至少 p_min，则可取 ε_B=(1−p_min)^B。

## R2 — PPT 与参数长度量词

**标签：EXTRA_ASSUMPTION_REQUIRED。类别：定理缺少前提。**

位置：CT 15、24、52、65、76–78；AG 7、30。

Q 和 L 的多项式界约束查询与代数，攻击者本地计算时间还需另设限制。若“任意攻击者”按无限制计算理解，A 可在 L=2 的三查询串上穷举公钥的离散对数，选择 M₀≠M₁ 后解密挑战，bias=1/2，曝光历史依然合法。在 DDH 假设下，与该常数优势对应的期望多项式归约声明无法普遍成立。

**最小修复：** “对任意运行时间 t_A(κ) 为多项式、至多 Q(κ) 次查询的概率攻击者 A；群描述、群元素编码长度及 log₂q(κ) 均为多项式；所有所用群／域算法具有相应多项式界。”或者保留一般 t_A，明确结论只提供 `t_A+poly` 的模拟时间，只有 t_A 多项式时判定器才属相应时间类。

**改变范围：** 明确计算安全的攻击者类别与编码模型；算法及 DDH 假设的标准含义保持一致。严格 PPT 有限版本还需 B=poly(κ)；固定任意可超多项式的 B 只给出关于 B 的运行时间界。

## R3 — 失败终态与对象提交点

**标签：MINOR_CLARIFICATION。类别：游戏表述修正。**

位置：CT 52、65；AG 34–38、51–56。

需固定以下情形：Setup 中失败；Next 部分钥匙生成后失败；Next 已公开新 P、随后私有官方更新失败；Challenge 分支中途失败；普通响应部分带已经消费后失败；rank 索引在 A 开始前失败。

**最小修复：** 指定失败前哪些状态已经提交、何时记入 accepted/C/K/T、是否交付部分响应、FAIL 是否结束全部交互。可以选择每个响应原子提交：只有成功才登记返回对象与公开版本，失败时公开统一 FAIL 并终止；也可以明确逐步骤提交。两种选择都可采用本报告的耦合界，但它们定义不同的有限游戏。

C0 固定最终猜测 0 后仍按该终态计算接受与合法性；判定器采样失败输出 0。FAIR 在每个位置用独立公平币替代最终猜测／判定器输出；任何后续交互和输出覆盖均结束。公平币直接使用独立的一位，避免把它交给可能失败的 S。

**改变范围：** 完成有限游戏定义；具体采用的提交方式应在新版本说明。理想算法保持一致。失败事件可以依赖 b；证明通过逐前缀耦合处理。

## R4 — 明确 θ、规范事件与判定器输出

**标签：MINOR_CLARIFICATION。类别：证明展开。**

位置：CT 32–46。

建议补入以下数学条款：

1. θ 表示潜在完整钥匙／令牌标量轨迹，官方隐藏加密／更新带继续独立抽取；未来轨迹仅在实际生成时公开。
2. 对终局生成代次 n，`r_j=max{r≤n:{j+1,…,r}⊆T*}`；j∈C 指确实直接返回过官方版本，包括 Challenge 返回。
3. `E_jr={accepted,valid,j∈C,r_j=r}`。真实 DDH 对应 H_j，随机 DDH 对应 H_(j−1)，分别定义受限测度。
4. 存活且终局 E_jr 成立时，D 输出 `1_{b′=b}`；其他终局和允许的提前中止输出独立公平币。
5. 明列 `ν_v(B)=Pr_(H_target(v))[B∩E_jr]` 对所有可测 B 成立。取 B=Ω 给概率质量，其他 B 给事件内视图。
6. Key/Token 先检查对象已经生成。未来请求回 ⊥ 且曝光集合保持原样；错误 id/格式照接口返回。已生成区间钥匙或右边界令牌才进入匹配事件的停止论证。
7. 固定 j 按 r 分割；不同 j 的事件可重叠。先对有符号期望求和、望远镜消去，再取绝对值。

**改变范围：** 原归约、算法、游戏及 DDH 假设可保留。这些条款使 CT 的简写论证可复核。

## R5 — 资源及两个索引判定器

**标签：MINOR_CLARIFICATION。类别：表述与计数展开。**

位置：CT 19–22、74–80。

矩形域明确为 `{2,…,L}×{1,…,L}`，三角域为 `2≤j≤r≤L`。矩形无效位置公平输出；相同有效位置调用同一条件模拟核。这样理想优势精确差 2 倍。有限索引失败按各自真实 sampler 处理，继续采用原稿单独的有限界。

计数可按普通查询 `(3L−1)Q`、钥匙轨迹 `L(L+1)/2`、官方初始挑战与所有私有更新 `(3L²+L−4)/2`、索引及控制余量拆开。现有 `N=10(QL+L²+1)` 足够。说明 log 为 log₂，w 为词长上界，实际域使用自身的接受阈值和长度。

有限普通带总长度为 O(QLBw)，响应转录另含群编码、标量、id、代次与边界编码。对理想版本只能给期望带长与随机实际长度。若 T_group 仅指一次乘法，需要另计标量指数运算的位复杂度；可直接把 T_group 定义为文中实际使用的群算法成本上界。

**改变范围：** 资源说明与证明记账；算法、游戏及假设保持一致。
