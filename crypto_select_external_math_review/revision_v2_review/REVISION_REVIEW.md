## 3. R1：规范采样与旧反例

### 3.1 唯一采样器的四个不同结论

S2 7–21 明确：n=1 时输出唯一值，0 位、0 轮、零失败；n>1 时 k=ceil(log₂n)，每轮读取 k 个新的独立公平位，大端解释为 h，恰在 h<n 时接受，经固定公开双射 φ_n 输出。每次调用使用独立流，有限版至多 B 轮。

令 m=2^k、p=n/m。n>1 时 `2^(k−1)<n≤2^k`，故 `1/2<p≤1`，二次幂域 p=1。对指定输出 v 和 t≥1：

```
Pr[T=t,Y=v]=(1−p)^(t−1)/m.
```

对 t 求和得 `Pr[Y=v]=1/n`；再写成 `Pr[T=t]/n`，得到 T 与 Y 独立。由几何分布，`E T=1/p<2`。截断后

```
Pr[T≤B,Y=v]=(1−(1−p)^B)/n,
Pr[Y=v | T≤B]=1/n.
```

精确均匀、每轮接受率下界、期望效率、有限成功时均匀性由不同等式分别得到。

对任意**调用开始时**的自适应历史 H，可把 b、过去全部私有状态以及历史可见带纳入 H。给定 H，域大小 n 已固定，新流仍独立，因此

```
Pr[T>B | H]=(1−p_n)^B≤2^(−B).
```

n=1 左侧为零。若前缀已经包含当前调用的 r 次拒绝，则剩余耗尽概率为 `(1−p_n)^(B−r)`，对应上界 `2^(−(B−r))`。S2 21 明确区分了这两个条件化位置。定理中的 union bound 只使用每次实际调用的起点，符合所需前提。

### 3.2 域、带与条件带分布

S2 25–36 固定 F_q 用 n=q、φ(h)=h；F_q* 用 n=q−1、φ(h)=h+1。三角域用 S_F 加固定秩双射；矩形分别用 S_(L−1)、S_L。b 与公平终止位直接使用新的独立一位。q=2 时 F_q* 为单点；L=2 时 F=1，均按零位路径处理。

S2 40–50 指定 Elias-gamma 整数编码、版本/op/epoch/调用数、每次调用的 role/坐标/n/k/t、全部 t 个原始词和成功位置。采样顺序也已固定：Enc 的 `(z_i,r_i)`；Upd 的所有旧 a_i，再全部 `(z_i,s_i)`。边界可解析，所有拒绝词保留，正常成功响应一次交付完整带；原子失败只交付 FAIL。

给定成功标量 v 和具体 t−1 个拒绝词，完整词串的无条件质量为 `m^(−t)`，故理想条件带质量为

```
Pr[该带 | Y=v]=n/m^t.
```

这正是 T2 59 的式子。编码为确定映射，保留该概率。有限版条件于成功且 Y=v 时，还须除以 `1−(1−p)^B` 并限制 t≤B；本稿的条件带观察位于理想引理中，实际有限普通带始终由真实 S_n^B 产生，故没有误用该条件分布。正常桥接逐带恒等式足以支撑完整带接口。

### 3.3 guarded-uniform 的两个系数

旧采样器单轮接受率 p、p* 至多 1/4；B 轮成功率记 a、a*。三查询串的前缀成功概率 `s=(a*)³a²`，两个 Challenge 分支成功率分别 `a⁴`、`a*a⁴`。

成功时猜 1，FAIR 或成功才 accepted 的原子 C0 都只在成功挑战上贡献，故

```
μ = (s/2)[−a⁴/2 + a*a⁴/2]
  = −(a*)³a⁶(1−a*)/4.
```

若提前把 accepted 置真且失败固定猜 0，则

```
μ = (s/2)[(1/2−a⁴)+(a*a⁴−1/2)]
  = −(a*)³a⁶(1−a*)/2.
```

A2 31–37 与原审阅两种系数均正确。A2 的显式渐近下界也成立：κ≥64 时 B≥6、a,a*≥1−(7/8)^6≥1/2，且 `(3/4)^B≥(3/4)κ^(−log₂(4/3))`，于是 1/4 系数版本至少为 `3·2^(−13)κ^(−log₂(4/3))`。

SPEC2 每轮恰读 k_n 位并仅按 h<n 接受，额外 guarded 词及额外接受条件均在定义外。规范下仍可能出现挑战分支相关失败；例如 Upd 比 Enc 多一次非零采样。这种失败由逐调用尾界与 §6 的耦合支付。公平终止也不会自动使两个分支的成功概率相等。

## 6. 三个定理的独立核准与 FAIR 重证

统一 `F=L(L−1)/2`、`τ=1−1/q`、`N=10(QL+L²+1)`。SELECT 优势为 `|E S|`，DDH 优势为两世界输出 1 概率差的绝对值。

### 6.1 理想归约与标准 DDH 条件化

三角索引独立均匀，每个位置运行同一固定位置模拟器。因此

```
Δ_∞ := Pr_real[D_∞=1]−Pr_random[D_∞=1]
     = (1/F)Σ_jΣ_r(z_j−z_(j−1)) = μ_L/F,
Adv_SELECT-I-SPEC2(A)=F|Δ_∞|.
```

标准 DDH 在 X=1 的概率为 1/q；两个世界该分支均输出独立公平位。X≠1 时输入分布正是 DDH*，所以对于每个具名 D 都有

```
Δ_DDH(D′)=τ Δ_DDH*(D),
Adv_DDH(D′)=τ Adv_DDH*(D).
```

该式同时适用于理想 D、C0 截断 D、FAIR 截断 D。外部 DDH 实验提供的 x/u/v 抽样不计入本地 S 调用预算。

### 6.2 自适应第一次失败的共同耦合

为每个潜在本地调用分配独立流，理想和有限执行使用相同流、相同 A 随机性及同一 b。每个已提交响应在第一次耗尽之前完全相同。令 ℱ 表示“某个实际调用的前 B 轮全部拒绝”。

第 a 次调用起点是否到达由前缀决定；在到达的条件下，其失败率≤2^(−B)。对实际调用逐项条件期望再求和，得到

```
Pr[ℱ_G]≤η_G=min(1,N_G2^(−B)),
Pr_v[ℱ_D]≤η_D=min(1,N_D2^(−B)),  v∈{real,random}.
```

失败事件可以依赖 b、消息、查询策略、可见挑战和 DDH 世界。这里没有要求两个世界的失败概率相同，也没有要求不同调用的到达事件独立。事务内在失败后的状态可以与理想续接分叉；评分界就在该失败事件上支付全部分叉。

### 6.3 SELECT-C0-B-SPEC2

失败以外评分完全相同。C0 与理想评分都在 [−1/2,1/2]，故

```
|μ_C0−μ_I|≤Pr[ℱ_G]≤η_G.
```

对每个 DDH* 世界，固定失败输出 0 与理想续接输出的概率差至多该世界的失败概率，故 `|Δ_C0−Δ_∞|≤2η_D`。先比较 signed quantities 再取绝对值得

```
Adv_C0 ≤ F Adv_DDH*(D_C0,B)+η_G+2Fη_D
       = (F/τ) Adv_DDH(D′_C0,B)+η_G+2Fη_D
       ≤ (F/τ) Adv_DDH(D′_C0,B)+(2F+1)N2^(−B).
```

Challenge 原子失败 h=0 可在特定位置改善局部误差；挑战后的失败仍允许固定猜测贡献。全局保守 η_G 继续有效。

### 6.4 SELECT-FAIR-B-SPEC2：半系数的完整理由

在第一次耗尽的停止点，固定完整失败前缀 H，包括 b、耗尽的拒绝词、临时状态及最后提交状态。后者决定 `h_F=1_{accepted且valid}`。定义新公平位 W，与 H 独立；S2 的吸收终止保证抽 W 后 h_F 固定。

有限评分为 `S_F=h_F(1_{W=b}−1/2)`，故对每个这样的 H：

```
E[S_F | H] = h_F(1/2−1/2)=0.
```

理想执行从同一失败前缀继续使用余下独立位与 A 的续接，最终可能改变 accepted、epoch、曝光闭包或合法性；无论这些值怎样变化，`S_I∈[−1/2,1/2]`，所以

```
|E[S_I | H]|≤1/2,
|E[S_F−S_I | H]|≤1/2.
```

按第一次失败前缀的**未归一化质量**积分，并使用失败以外路径相同，得

```
|μ_FAIR−μ_I|≤Pr[ℱ_G]/2≤η_G/2.
```

该半界针对条件期望；个别公平币实现上的 `|S_F−S_I|` 可达 1。论证先对终止公平位取条件期望，再按失败质量积分。接受和有效性对 b 的依赖也被 H 固定，零条件期望继续成立。

判定器同理，但评分换成输出位。固定某个 DDH 世界与第一次失败前缀 H，有限输出概率恰为 1/2，理想续接输出概率为某个 p(H)∈[0,1]。因此

```
|1/2−p(H)|≤1/2,
|Pr_v[D_FAIR,B=1]−Pr_v[D_∞=1]|≤Pr_v[ℱ_D]/2.
```

真实及随机世界分别积分，再用三角不等式，得 `|Δ_FAIR−Δ_∞|≤η_D`。从而

```
Adv_FAIR ≤ F Adv_DDH*(D_FAIR,B)+η_G/2+Fη_D
         = (F/τ) Adv_DDH(D′_FAIR,B)+η_G/2+Fη_D
         ≤ (F/τ) Adv_DDH(D′_FAIR,B)+(F+1/2)N2^(−B).
```

挑战前和挑战内失败的 h_F=0；挑战后和部分 Next 失败按旧提交状态计算 h_F；索引失败可能发生在 b 与 A 启动前，此时判定器直接输出独立公平位。以上各情形均适用对应条件期望论证。公平位为直接一位，其自身耗尽概率为零。

两个误差式的 η_D 先在 DDH* 两世界上估计；只有判定器优势通过 τ 换算。因此加性误差项保持原常数，无额外 `1/τ`。

### 6.5 SELECT-I-SPEC2 的严格 PPT 推论

只截断理想判定器，每世界输出概率误差≤η_D；真实理想游戏本身保持理想采样。因此

```
Adv_I ≤ (F/τ)Adv_DDH(D′_I,B)+2Fη_D
      ≤ (F/τ)Adv_DDH(D′_I,B)+2F N_D2^(−B).
```

这里使用 C0 失败输出即可。该推论在 B 多项式时连接严格 PPT 标准 DDH 假设；精确理想等式仍单独是期望多项式归约命题。

### 6.6 独立定理裁决

| 定理 | 裁决 | 可引用结论 | 时间及误差条件 |
|---|---|---|---|
| SELECT-I-SPEC2 | 在声明模型内通过 | 精确 `Adv_I=F Adv_DDH*`；理想矩形关系；标准 DDH 截断推论 | 精确 D 为期望多项式；严格 PPT 用多项式 B 的截断 D |

## 7. R5：索引、调用数与完整资源

### 7.1 索引关系

按 j 块长 L−j+1 排列，秩 a 唯一解码为 `(j,r)`，故

```
F=Σ_(j=2)^L(L−j+1)=L(L−1)/2.
```

理想矩形域大小 Λ=L(L−1)=2F，r<j 公平输出；每个有效位置的条件模拟核与三角版本相同。理想输出概率差因此恰差 2 倍，绝对优势也恰差 2 倍。

有限三角使用 S_F^B，矩形使用独立 S_(L−1)^B 与 S_L^B，其索引成功概率一般不同。S2 为这些失败分别指定 C0/FAIR 输出，T2 把精确 2 倍关系限制在理想版本。矩形的有限界可用相同耦合证明，以 Λ 替代 F，并用矩形自己的 N_D；共同粗界 N 仍覆盖。

### 7.2 次数重算

普通 Enc_e 为 2e 次 S，Upd 到 e 为 e−1 次非零 a 加 2e 次全域样本，共 3e−1。全部普通响应的保守上界 `(3L−1)Q` 同时覆盖执行中途失败的响应。

```
Setup/Next 轨迹：Σ_(e=1)^L e = L(L+1)/2。
初始挑战及所有隐藏官方更新：
  Σ_(e=2)^L(3e−1)=(3L²+L−4)/2。
上述两项合计：2L²+L−2。
```

honest 流 2e、uniform 流 2e+1、锚版本 2j−1 均受相应 3e−1 上界覆盖；边界完整 Y 替换同数量的 Next 抽样。eager 策略使未公开官方版本的采样已计入。三角索引 1 次 S，加 b 与最多一个终止位 2 次直接随机操作，得到

```
N_G,N_D ≤ (3L−1)Q+2L²+L+1 ≤ 10(QL+L²+1)=N.
```

作为 S 调用上界计入直接位只会放宽界。矩形多一次索引，细化界加 1 后仍受 N 覆盖。Setup 不占 Q，但已单独计费；A 自身随机位计入 t_A。标准包装器 X=1 分支仅用一终止位；X≠1 分支运行 D，没有追加未计的终止采样。

### 7.3 位与时间

实际每个调用使用自身 k_n，统一上界

```
w=max(1,ceil(log₂q),ceil(log₂max(F,1))).
```

对于矩形，L≥3 时 F≥L；L=2 时一位已经覆盖其索引，所以同一 w 仍够用。有限原始随机词消费至多 NBw，直接位另计至多 2。S2 的整数头使每个普通调用另需 `O(w+log L+log(B+1))` 位，得到 T2 的普通带总长

```
O(QL[Bw+log(B+1)+log L+w]).
```

完整响应还包括群对象 `O((QL+L²)ℓ_G)` 位、完整钥匙和 token 标量 `O(QL log₂q)` 位、id/请求返回头 `O(Q log(Q+L+B+1))` 位；畸形输入总字节由 t_A 支付。若缓存历史带，其空间加入相应总带长。

理想原始带的期望长度≤2Nw；每调用头中 log(T+1) 的期望也有限，可用凹性上界 `E log₂(T+1)≤log₂(E T+1)≤log₂3`。实际带长一般为无界随机量。有限版每调用最多 B 轮，所有带与响应均有确定多项式最坏长度（在 B 多项式的条件下）。

T_G 已包含验证、群乘逆与标量指数，T_F 包含域求逆；写出群/域值、规范编码和带头的成本在这些位长及采样项中支付。所列时间上界

```
t_A+O((QL+L²)(T_G+T_F)+(Q+1)L²+NBw)
```

与上述成本相容。状态对象数 O(QL+L²)，闭包每查询 O(L²) 为足够的保守上界。

### 7.4 可忽略误差选择

取 T2 199 的

```
B=max(1,κ+ceil(log₂((2F+1)N)))
```

则 `(2F+1)N2^(−B)≤2^(−κ)`。FAIR 的 `(F+1/2)` 恰为 C0 系数的一半；I-PPT 的 `2F N_D` 也受 `(2F+1)N` 覆盖。在 L/Q 的多项式条件下，B 仍为多项式。又 τ≥1/2、F 为多项式，标准 DDH 可忽略优势经 `F/τ` 放大后仍可忽略。
