# FI打印算法中的明确共同参数族

ROUND-004，2026-11-07，Asia/Shanghai。身份：`INFORMED_COMMON_PARAMETER_CLOSURE`。本轮为知情手工数学核查；共同族与其不等式证明作为新增结果CF-1登记。

**裁定：VERIFIED。** 在FI v3/v4打印算法的抽象参数范围内，存在一个同时满足类型、有效采样、PPT长度、完整更新正确性界、停止预算及攻击概率条件的显式族。其困难性责任另列：指定H_nf或下文明确的uniform-secret源假设仍为条件。

## 1. 原文参数域与三个对象层次

FI v4 pp11–12明确给出D>0、q=2^D、0≤B≤D、正整数n,m̄,n̄、n≡0 mod8，消息域为{0,1}^{B m̄ n̄}。χ为对称、零中心、有限小支持、近似rounded Gaussian的离散分布，使用公开CDF表反演采样。p14的算法均为Z_q上的矩阵运算。

FI打印域没有给出D≤16这一限制。官方2021 Frodo规范pp17、23的固定规格及实现参数则有D≤16，并给出三组固定配置。作者性能程序的实际配置继续以其代码／commit和运行设置为准。

| 对象 | 本轮处理 |
|---|---|
| PAPER_IDEAL_MODEL：FI打印算法 | 采用任意允许的正D、一次均匀A、独立χ采样；CF-1位于此域 |
| OFFICIAL_SPEC_PARAMETERS：固定Frodo配置 | 保留640/976/1344的原D、q和表；CF-1复用其一份χ表，其他参数另行给出 |
| ACTUAL_BENCHMARK_CONFIGURATION | 作者UE程序与随机数配置缺项；本轮不给该程序赋予CF-1 |

CF-1保留打印的KG/TG/Enc/Upd/Dec公式和采样调用，仅选择其参数函数。它超出官方D≤16的固定实现域。若目标采用严格官方接口解释，本族应登记为 `OFFICIAL_SPEC_EXTENDED_PARAMETER_MODEL`，其结论限定到该扩展参数模型；在FI明写D>0的打印域解释中，它是参数实例化。本轮未编写适配大D的实现。

## 2. 具体参数函数 CF-1

取整数安全参数λ≥2，定义

\[
n=8\lambda,\quad L=\lceil\log_2n\rceil,\quad
D=8L,\quad q=2^D,
\]

\[
\bar m=\bar n=8,\quad B=2,\quad
T=k=t_{max}=n,\quad Q=3n+1.
\]

T为最大epoch下标：允许epoch0,…,n及n次Next；总epoch数为n+1。t_max表示方案认证的单条密文最大Upd次数，取n；k表示攻击最多试探次数，也取n。三种计数在这里明确给出，后文各按其作用使用。

公开A在Z_q^{n×n}均匀采样。每次KG、TG、Enc以及挑战Upd中的χ矩阵均使用新独立输入位。全次执行共用一个A及同一组D、q、B、χ；候选token之间没有重选参数。

该族满足

\[
n^8\le q<(2n)^8=256n^8,\quad D=O(\log n),\quad D\le8n.
\]

q与D始终按同一个定义联动。D进入W后的自洽性在兼容性文件中按这些界逐项核对。

## 3. 复用官方χ_640，精确采样

CF-1固定采用官方2021的χ_Frodo-640，整数支持为{−12,…,12}，s=12。按顺序列出0及每个正值／对应负值的质量分子：

`[9288,8720,7216,5264,3384,1918,958,422,164,56,17,4,1] / 65536`。

0项只计一次，正负项各计一次。相应CDF为

`[4643,13363,20579,25843,29227,31145,32103,32525,32689,32745,32762,32766,32767]`。

每个样本使用16个独立均匀比特，其中15位给大小，一位给符号。对**所声明χ_640**的采样是精确的；本族没有加入高斯截断、精度近似或拒绝采样步骤。与无限rounded Gaussian的分布差并未设为0，该差只在更强的困难性来源桥接中讨论。

16位指采样所耗随机位。数学样本为带符号整数−12,…,12，再按χ(Z_q)映到模q；环元素仍按D位保存。把官方uint16实现的负数编码直接当作大q元素需要另行适配，本轮没有做这项实现迁移。

全部概率和为1，偶数与奇数的质量分子均为32768。对任意固定A、U2及完整过去状态，F2 mod2为独立均匀二元矩阵，因此每个新token的条件可逆概率精确为

\[
p_n=\prod_{i=1}^{n}(1-2^{-i})>1/4.
\]

复用分布表没有把CF-1命名为官方FrodoKEM-640。此处n随λ增长，D至少32且随n增长，q和最大更新数均与原固定640配置不同。例如n=640时，CF-1取D=80、q=2^80；官方640配置仍为D=15、q=2^15。

## 4. 类型、长度与PPT

n为8的倍数，B=2≤D，所有矩阵乘积的维度与FI p14相容；消息长度固定为128位。q的二进制长度为D+1=O(logn)，A占n²D个采样比特。

钥匙、token与密文的环元素数量分别为O(n n̄)、n(D+1)(n+n̄)、m̄(n+n̄)。包括D位编码后均为poly(λ)。χ采样每项16位，矩阵维度和总调用次数均为多项式。

取k=T=n时，攻击至多n次Enc、n次Next、n次Corr(token)及一次Challenge，满足Q=3n+1。新生成钥匙共n+1把。停止阈值预先给定，最坏时间为多项式。

此前完整上下文归约的环操作界代入本族后为O(n⁴(D+1))；采用保守的D位整数运算计费，位操作时间可取

\[
t_{NF}(n)=O(n^4(D+1)^3),
\]

同时包含秩检查、数据读写和有限表采样。normal-form到uniform-secret的额外矩阵处理为多项式，其预算一并计入后文t_US。

## 5. 支撑和停止预算

h=25<q，并且对n≥16有25/q≤1/2，所以

\[
\theta_n=(25/q)^{8n}\le2^{-8n}.
\]

新F2在逐历史条件下奇偶均匀，故本族精确有

\[
p_k=1-(1-p_n)^n,\quad
1-p_k=(1-p_n)^n<(3/4)^n.
\]

这两项关于λ均指数衰减。k=n使用了n次真实轮换预算；它没有把一次Setup内的可逆token搜索当作免费重复。

## 6. 严格官方D≤16域中的认证冲突

如果同时要求n无界增长、D≤16、s≥1和B≥0，那么

\[
B_0=2ns^2+s\ge2n+1,
\qquad q/2^{B+1}\le32768.
\]

因此n≥16384时，连B0<q/2^(B+1)这一粗略初始充分条件也无法成立。该组条件的**确定性粗界认证交集**在无界n上为空。

这项冲突限定于所用充分界和固定模数域；它没有给出实际解密失败率。官方三组固定参数、其有限安全估计和CF-1分别保持各自作用域。
